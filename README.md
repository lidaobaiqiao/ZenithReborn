# 天顶复苏 · 0.3.127

当前版本保留天顶式飞剑、剑影、木质族和矿石族，移除武技组及后续新增的灵能族分类。0.3.124 新增神圣天堂族：神圣／星辰武器有效寄宿后，主剑命中召来落星。0.3.126 暂名剑灵：四把暂定成员激活后，为有效出战武器生成隐形玩家代理自动攻击。0.3.127 飞刃族初版：31 把无弹幕纯挥砍剑寄宿激活后，经普通攻击掷出手蓄飞刃。环境之力与既有单剑特性仍独立生效。印记等设计为用户核心留白的暂定项，尚未实现。旧武技存档字段只为兼容和回退保留，不再提供技能或界面。

验证证据分级陈述：两项目编译零错零警；飞刃族 17 项隔离夹具与 188 项引擎普查通过（见 [0.3.127 记录](docs/0.3.127-飞刃族初版.md)）；神圣天堂 15 项服务端检查通过（见 [0.3.124 记录](docs/0.3.124-神圣天堂与落星.md)）；剑灵 11 项代理/近战夹具与 15 项神圣天堂检查通过（见 [0.3.126 记录](docs/0.3.126-出战武器召唤初版.md)）。以上均为编译与服务端/夹具证据，没有图形客户端、自然游玩或多人验证。安装状态以 `artifacts/install-result.json` 为准。

## 从开局开始

1. 新角色得到空的「诅咒的天顶残魂」和不消耗的「凝胶信物」。旧角色可在工作台用 5 铜锭 + 1 坠落之星制作一枚全新残魂。
2. 按 `P` 或手持残魂右键打开寄宿界面。第一槽可放入武器预览与取回，但**未受祝福时不能攻击**。
3. 白天来到地表，背包携带残魂并使用凝胶信物；也可沿用靠近普通史莱姆、按 `P` 回应呼唤的旧入口。
4. 友善史莱姆王出现后，右键 NPC 逐段对话，最后点击「接受祝福：附着」。按 `P` 的界面也保留相同对话。
5. 此后第一槽永久稳定。放入近战武器、关闭界面即可左键御剑。**初始效能 65%，基础瞄准距离 192 像素。**

这是独立的友好剧情相遇，不需要击杀史莱姆王，不发原版 Boss 战利品，也不伪造原版击杀旗标。

## 核心系统

### 剑魂与槽位

四组槽位，全部随物品保存并含网络序列化：

| 组 | 容量 | 生效条件 |
|---|---|---|
| 普通槽 `Hosts` | 有效 `min(10, 进度容量)` | 按 Boss 进度逐槽解锁 |
| 支援槽 | 基础 5 + 动态扩展，上限 11 | 木质族最多 5、矿石族最多 6，累加 |
| 森林 / 全收集奖励槽 | 2 | 木 12 种全套 **或** 矿石 14 材质集齐 |
| 传奇槽（槽 ID 34） | 1 | 大师 + For the worthy 才生效；关闭后暂停保留、可空手取回 |

寄宿门槛：近战、`damage>0`、`pick/axe/hammer` 全为 0、非消耗、不可堆叠、非天顶剑，**同种武器全魂唯一**。
效能 `Potency`：未附着 0，觉醒 1.1，否则 `0.65 + Stage×0.04`。

### 六诅咒（成长曲线的骨架）

Boss 进度不直接给数值，而是逐道**解除限制**：

| 诅咒 | Boss 组 | 诅咒态限制 |
|---|---|---|
| 缚身 | 克苏鲁之眼、月亮领主 | 射程只到屏幕边缘的一半 |
| 切换 | 克苏鲁之脑、拜月教邪教徒 | 仅首把主剑特性生效，飞剑只算前 4 把 |
| 归鞘 | 世界吞噬怪、骷髅王 | 新一轮打断旧轮，旧剑提前淡出 |
| 阻隔 | 蜂王、世纪之花、石巨人 | 只能穿 32 像素实体（削弱态 64） |
| 独行 | 毁灭者、双子魔眼、机械骷髅王 | 每轮 2 把（削弱 3 / 解除 4 / 祝福最多 10） |
| 断锋 | 血肉墙、史莱姆女皇、光之女皇 | 本体100%、剑影各20%；同剑同目标原有上限3次（削弱态5）保留 |

阶段由组内已击杀数决定：2 个 Boss 的组「杀 1 解除、杀 2 祝福」；3 个 Boss 的组「0 诅咒 / 1 削弱 / 2 解除 / 3 祝福」。

### 出剑与伤害

- 一次挥臂出 `min(主剑数, 独行诅咒上限)` 把，按 `cursor` 依 `SoulId` 持久轮换。
- 飞剑生命周期 `phase 0→120`，每次更新推进 `Lerp(0.7, 2, 距离)`——**目标越近推进越快**；`phase<60` 为伤害期，`≥60` 返航，`≥120` 销毁。
- 伤害 `max(1, GetWeaponDamage(宿主剑) × Potency × 矿石倍率)`，**逐剑独立、不分摊**，不设统一天顶伤害下限。
- 命中冷却 16 子更新（配 `extraUpdates=1` 即 8 游戏帧）；`penetrate=-1`，单目标次数由断锋诅咒封顶。
- 0.3.79 起 15 / 30 / 45 三个**可见剑影也参与实体碰撞**，共享命中冷却与诅咒上限；普通拖尾与消散片无伤害。
- 0.3.105 起断锋解除后的剑影逐次乘0.8，祝福后各100%；伤害按实际碰撞单元结算，与外观透明度分开。

### 祝福与御剑爆发

每个诅咒满铭刻对应一个祝福，共 **6** 个：御剑、切换（百刃接力）、轮转（归鞘留锋）、穿界（破障）、独行、连斩（剑影全量伤害，替换旧剑痕爆炸）。

御剑爆发：有效战斗后 45 帧内每帧蓄能至 900（约 15 秒），满条保留，按 `O` 手动开启 600 帧（10 秒）。效果为视野拉远 + 远距离最高 50% 独立增伤。

### 种族

- **木质族**：12 把木剑。1/2/4/6/8/全套 → 强度 `1.10/1.20/1.35/1.50/1.75/3.00`，生命 `5/10/15/20/30/100`。全套另给 2 个真实剑位与森林成长（战斗满 300 帧涨 1 层，上限 12）。
- **矿石族**：14 种材质。阶梯 1（开放飞剑）/ 2、4（主剑 +5%、+10%）/ 6（折返再攻）/ 8（飞剑触发本矿效果）/ 10（伤害与速度 ×1.5）。全 14 种齐射后召来天铸巨剑。

### 环境之力

21 种环境，可选常驻机制与主动领域。

## 构建与验证

需要 .NET 8 SDK 与本地 tModLoader。项目当前引用 `E:/SteamLibrary/steamapps/common/tModLoader/tMLMod.targets`；安装路径不同请调整两个 `.csproj` 的 `Import` 及 `checks/run_wood_checks.ps1`。

```bash
dotnet build ZenithReborn/ZenithReborn.csproj -c Release   # 编译
pwsh -File checks/run_wood_checks.ps1                       # 隔离引擎回归，断言项数按启用套件动态统计
```

检查脚本只使用独立测试目录，**不会修改正式人物和世界**。图形客户端证据另存于 `artifacts/`。
另有两个专项探测：`checks/run_echo_phase_probe.ps1` 实测剑影相位偏移（确认与原版 933 一致，留作防误改护栏）。
