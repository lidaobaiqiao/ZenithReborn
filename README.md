## 从开局开始

1. 新角色得到空的「诅咒的天顶残魂」和不消耗的「凝胶信物」。旧角色可以在工作台用5铜锭和1坠落之星制作一枚全新残魂。
2. 按P或手持残魂右键，打开寄宿界面。第一槽可以放入武器预览、取回，但未受祝福时不能攻击。
3. 白天来到地表，背包携带残魂并使用凝胶信物；无需附近史莱姆。也可沿用靠近普通史莱姆、按P回应呼唤的旧入口。
4. 友善史莱姆王出现后，右键NPC逐段对话，最后点击「接受祝福：附着」；按P的寄宿界面也保留相同对话。完成后再次使用信物可请它回来查看成长路线。
5. 此后第一槽永久稳定。放入近战武器，关闭界面，即可左键御剑。初始效能65%，基础瞄准距离192像素。
6. 第一阶段结束，界面提示准备迎战克苏鲁之眼。已有后期成长框架仍保留，后续内容逐阶段完善。

这是独立的友好剧情相遇，不需要击杀史莱姆王，不发原版Boss战利品，也不伪造原版击杀旗标。相遇中的王不可被误杀，不造成伤害；附近普通史莱姆暂时不能伤害参与者。剧情中途关闭界面可以继续，退出或死亡可以重新呼唤。

如果已受祝福的旧剑魂还没有观看记忆，也可以在相同条件下补看这次相遇。

其他近战武器可以基础寄宿；天顶配方中的其余材料剑保留已有专属弹幕。附魔剑、星怒的灵能效果替代旧触发，不重复叠加。铜短剑保留已有的近身命中伤害提高20%的材料剑特性。

每种武器最多寄宿一把；支持放入、取回、交换及保留前缀。工具、远程武器、消耗或可堆叠武器、原版天顶剑及残魂本身不能寄宿。
