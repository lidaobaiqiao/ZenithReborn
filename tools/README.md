# tools 目录说明

| 条目 | 用途 |
|---|---|
| ZenithMaterialLab | 材质调参工作台，入口为仓库根目录的 `打开材质实验室.cmd` |
| xnbcli | 原版 XNB 解包工具；源码入库，`xnbcli-binary` 与下载 zip 不入库 |
| decomp / ilspy | 反编译工具与产物，可由 tModLoader.dll 重新生成，不入库 |
| build_vanilla_vfx_catalog.py | 重建 VfxLibrary/Vanilla 可搜索图鉴 |
| 打开能量薄刃A1.cmd | 能量薄刃A1 素材预览入口 |
