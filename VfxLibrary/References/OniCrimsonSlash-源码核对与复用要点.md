# OniCrimsonSlash：源码核对与复用要点

本文补充现有拆解，区分着色器具备的能力、项目已经使用的部分，以及后续接入工作。只整理资料，不改 WorkBuddy 正在调整的挥刀代码、正式包或存档。

## 学习重点

用户认可的是最后一劈的画面结果。后续优先复用现成材质、笔刷与噪声，接入真实姿态轨迹和按武器区分的配色，先让出现、运动、收尾连贯。不能把“多画几层”或提高残影数量当成质感的核心。

剑身一体组仍遵循已确认的一个慢底色、一个动态蒙版、一次最终合成。扫掠、锐边、碎边、内部变化和结束侵蚀应共同驱动这一效果；巨剑五次绘制的历史组合不等于每把武器都要复制五层。

推荐分别检查：起笔是否从真实刃位推进；挥动时刃线能否稳定辨认；尾部是否落后且自然断散；停止后形状是否继续演变、侵蚀收尽。静帧、匀速滚动噪声和统一透明淡出各自不能证明这些阶段已经完成。

## 对照实际公式的校正

| 项目 | 已核对的事实 | 接入含义 |
|---|---|---|
| 厚度指数 | `envPow=lerp(1.35,1.85,isArc)`：弧形 1.85，直线 1.35 | 原拆解表述写反。峰值位置分别为 `0.5^(1/1.85)≈0.688`、`0.5^(1/1.35)≈0.598`，不能按注释猜数值 |
| 刃线迟散 | `h=0` 时 `eLife=uErode*1.18-0.30`，`h=1` 时没有减项 | 刃侧侵蚀阈值更低，噪声更容易存活，所以相同条件下较晚消失；“阈值高 0.3”是反向表述 |
| 双方向侵蚀 | 最终阈值取 `max(eLife,eTail)` | 两条侵蚀规则合用；确定的噪声与种子仍会复现，不应说成每次天然不重复 |
| 扫掠 | 着色器支持 `uSweep`，现有 `MartialCrescentMaterial.Draw` 将它固定为 1 | 当前已扫弧度由姿态记录计算的 `signedSpan` 提供。换成玩家挥刀时，需选择并明确驱动几何扫角或材质揭示进度，不能宣称动态 `uSweep` 已接好 |
| 散锋 | 现有巨剑设置 `uSplitTail=.35`，直刃燃烧路径设置 `.85` | 它已使用，不能登记为“未启用” |
| 水墨 | 巨剑 `uInk=0`，直刃燃烧路径 `.42` | 同一着色器不同路径参数不同，不能笼统声称项目未使用水墨 |
| 不对称边缘 | 月牙模式区分外侧锐缘与内侧碎缘；直线模式的 `h=saturate(abs(p.y)/w+...)` 两侧对称 | 月牙的边缘分工不能直接等同于直线模式已经做到迎风／背风区分。复用时要核对模式与坐标 |
| 轨迹与尺度 | 当前巨剑入口固定半径尺度、按档位取色；接口没有外露任意刀长、颜色和扫掠进度 | 是成熟的专用接入，不是直接替换一个轨迹来源即可适配所有武器的通用接口 |

代码依据：`ZenithReborn/Assets/ThirdParty/CalamityOverhaul/OniCrimsonSlash.fx`、`ZenithReborn/MartialCrescentMaterial.cs`、`ZenithReborn/MartialSlashVisuals.cs`。不修改原始第三方资源来修正文档。

## 素材和配方分开管理

四份现有资源均与 `provenance.json` 的 SHA256 相同：原始 `.fx`、已编译 `.fxc`、笔刷、噪声。继续随资源保留已有作者、版本、许可证和哈希记录。各武器的颜色、时间曲线、轨迹、尺寸属于项目配方，不烘焙进共享第三方素材。

本机有多个 CalamityOverhaul 包，正式 Mods 目录中的旧包为 0.8018，不能当作 0.9209 的材料来源。已用项目现有 `checks/tmod_archive.py` 成功读取工作坊 2026.7／0.9209 包，并校验其 TMOD 容器完整性；包 SHA256 与现有来源记录一致。自定义格式不等于无法解析，也不需要当 ZIP 强行解压。

[0.9209 材质资源清单](CalamityOverhaul-材质清单.json)登记了 1000 个文件：499 份 `.fx` 源码、501 份 `.fxc` 编译效果。**这是资源目录清单，不是 1000 套已调好的特效预设**；本轮未复制额外资源、未新增插件、未进行这些材质的 GPU 或实战验收。选中某个材质后，应再核对配套笔刷／噪声、原使用方参数、绘制顺序与收尾驱动，才登记成可用配方。

## 下一次接入的顺序

1. 先重放用户认可的现有巨剑参数，建立可看的对照。
2. 采样玩家实际刃根、刃尖与挥动时间；轨迹与材质使用一致的局部坐标。断招、传送和切武器不能连接成跨屏残影。
3. 明确起笔、持续和收笔的驱动；将 `uErode` 与 `uTailErode` 的变化落实到可观察的形状收缩，保留刃线稍晚消散。
4. 每把武器复用材质并绑定自身底色。先完成一把的正常倍率画面，再推广，不以批量生成或编译通过代替美术判断。
5. 与真实鼠标使用和完整模组组合一起检查；黑屏仍是独立未解决事项，不能把夹具通过说成鼠标放置正常。
