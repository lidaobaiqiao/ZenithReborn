# 钛金剑剑身一体蒙版 R2

**用户当前偏好的视觉基准。** 用户亲自对比后表示R2已经很不错，并否定后续钩子方向；以[用户反馈记录](../../../../../docs/特效审核-用户反馈以R2为基准-2026-10-23.md)为准。此前审核者的“不通过”保留为历史判断，不代表用户否定R2，也不再构成继续加钩、加宽或提亮的依据。R2原图集、比例、配色和波动均保持送审版本，尚未接入正式渲染或安装。

## 本轮调整

R1因箭头形、遮剑和流向不连续被退回。R2改为贴合实际剑刃的连续半透明薄膜，剑尖只延伸6个图集像素，不加独立前帽。边缘由少量波峰向后传播，尾部逐渐收细；剑体中心Alpha约0.16，外缘峰值约0.64，不靠挖洞露剑。

形状采用可复用矢量配方，由原生SpriteBatch输出16帧Alpha图集。配方控制上下轮廓和透明度，不是固定贴图内滚噪声；不手工绘制16套独立图案，不新增底层渲染框架。`authoring.json`是可编辑源，`checks/ZenithPrototypeCheck/SwordBodyVectorMask.cs`是制作端。image_gen返工仍继承R1箭头轮廓的中间图，已留在`artifacts/swordbody-R2-imagegen-study`，未当成本版素材。

共用底色为`color._Shared.SlowFlowRadiantR2`，仍复用原有MIT NoiseSoft01。慢色场增加有色中间调、避免黑噪声覆盖底色；合成结果最后只进行一次预乘加法绘制，保持原版金属可见。没有额外白芯、光圈、星光或粒子层。底色不是Alpha形状来源。

## 素材和预览

- `active.png`、`contact-sheet.png`和`clip.json`由隔离GPU导出后登记。图集448×256／帧，4×4，20fps，线性Alpha过渡；库和预览使用完全相同的图集哈希。
- `authoring.json`记录主体比例和波峰参数；`clip.json`记录每帧上下波峰横坐标，可配合黑白动画追踪同一波峰。
- 出现／结束继续使用同一活动蒙版和同一底色相位，加连续揭示／撤尾包络；没有独立结束图案。
- 预览根目录为`artifacts/swordbody-R2-emissive/`，含黑白`mask-only.mp4`、三栏`breakdown.mp4`、明暗背景`loop-context.mp4`、完整`lifecycle.mp4`及原速移动`motion.mp4`。

移动片段为60fps、正常武器尺寸1.85，复用正式`OreFlightMotion`的后拉／加速曲线进行受控GPU回放；不是世界中的Projectile.Update或实际命中证据。固定姿态片段检验蒙版本身动态，移动片段只辅助判断拉尾方向和速度感。

`gpu.json`只证明真实GPU输出、相乘和结束清理；不代替美术审核。正式0.3.54包、战斗逻辑和正式人物世界均未修改。本次不代表实战、多剑或多人通过。
