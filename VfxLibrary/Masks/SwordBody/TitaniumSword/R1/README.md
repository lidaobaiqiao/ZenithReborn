# 钛金剑剑身一体蒙版 R1

美术审核不通过，保留作返工对照，未接入正式渲染。三项阻塞为箭头轮廓、遮住金属剑、连续向后流动不足；见[完整审核](../../../../../docs/特效审核-钛金剑SwordBody-R1-2026-10-23.md)。

## 素材

- `source.png`：image_gen 原始透明图集，原样保留。
- `active.png`：4×4 图集，单帧448×256，Alpha为唯一蒙版通道。技术处理仅提取Alpha并整数配准剑尖，不重画形状。
- `contact-sheet.png`：黑底Alpha总览；不是独立素材。
- `clip.json`：20fps、16帧、线性Alpha过渡，统一枢轴(305,128)、剑尖(408,128)，来源哈希及逐帧位移。
- `generation.json`：生成方式与完整提示词。素材为此次生成，不归为鬼切原作者资源，也不宣称人工逐帧绘制。

一个Alpha动画同时承担尾迹、剑身、边缘和剑头包络，不叠加V、双弧或星光。出现和结束暂用同一活动动画配连续空间包络控制，尚非独立制作的结束帧图集。

## GPU审核包

仓库根目录 `artifacts/swordbody-R1/`：

- `mask-only.mp4`：实际GPU黑白蒙版，裁自三栏预览中间区域。
- `breakdown.mp4`：相同时间的慢底色、动态Alpha、Color×Mask。
- `loop-context.mp4`：原版未改色钛金剑、固定姿态、暗／亮背景、正常飞剑尺寸1.85。
- `lifecycle.mp4`：0.3秒出现、1.6秒活动、0.5秒结束。
- `gpu.json`：隔离tML GPU记录。固定剑体仍有16082个明显Alpha变化像素，覆盖变化7961；逐像素相乘最大误差0，结束残留0。以上只证明技术执行，不证明动效美观或质量合格。

底色复用 `color._Shared.SlowFlowM1`，第三方NoiseSoft01来源和许可证仍由原资源目录记录，不复制改名。本次未调整该底色，以免混淆蒙版自身动态。

## 已知待审问题

轮廓可能更像火焰箭头，主体偏厚；当前普通Alpha合成会使暗底色遮盖原版金属剑。需要区分蒙版轮廓问题与合成模式问题，不能把改变底色或提高亮度当作蒙版已经打磨完成。循环是否具有明确向后传播感，需要实际播放审核，逐帧差异数值不能代替判断。
