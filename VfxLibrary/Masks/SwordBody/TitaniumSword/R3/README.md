# 钛金剑剑身一体蒙版 R3

美术复审未通过，保留作R4对照，未接入正式包。R3正常倍率表现仍弱，主波仍像尖鳍片；见[完整复审](../../../../../docs/特效审核-钛金剑SwordBody-R3-2026-10-23.md)。R1和R2也保留作对照，不扩大到其他剑。

R2已改善箭头轮廓、遮剑和波峰流向；本版集中修复其剩余的细描边感和规则鼓包。横截面改成向剑面内侧连续铺开的半透明薄膜，减少窄肩双线；同一Alpha的灰度相位也向后传播。一个波峰由实际剑尖附近低幅生成，经过剑身时形成斜向薄舌，随后前缘收窄、背缘拉长、高度消退，上下错相，不是把同一个圆包匀速平移。取消R2微小正弦毛边，不补噪声、粒子或独立前帽。

底色改用`color._Shared.SlowFlowRadiantR3`，降低红绿近中性亮值，保持青紫；没有整体亮度翻倍。蒙版、底色、最终一次预乘加法的分工不变，原版金属保持可见。

源配方为`authoring.json`；图集及统一画布／枢轴／剑尖／相位在`active.png`和`clip.json`。图集为原生SpriteBatch制作端GPU导出的16帧Alpha，预览使用相同图集；不由图像生成中间稿转制。`contact-sheet.png`只作黑底Alpha查阅。

审核包：仓库根目录`artifacts/swordbody-R3-emissive/`，含`mask-only.mp4`、`breakdown.mp4`、`loop-context.mp4`、`lifecycle.mp4`和`motion.mp4`，分别为黑白、三栏、正常倍率明暗循环、完整出现结束、同条件原速移动。GPU输出60fps；素材20fps线性Alpha过渡，未用光流插帧。

技术记录为实际GPU相乘误差0、结束残留0；编译0警告／0错误。不能据此声明美术通过。移动仅复用生产`OreFlightMotion`后拉和加速曲线的受控GPU回放；不是Projectile.Update、世界战斗、命中或多人证据。正式0.3.54包未修改或安装。
