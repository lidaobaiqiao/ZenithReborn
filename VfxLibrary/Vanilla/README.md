# 原版特效美术素材

打开 [浏览原版特效.html](浏览原版特效.html) 搜索、筛选并点击查看原图。素材由本机 `E:/SteamLibrary/steamapps/common/Terraria/Content/Images` 中的 XNB 转出，供本地项目查看和挑选，未接入生产模组。

- `Images/`：原尺寸透明 PNG，按弹幕、额外特效、碎片、辉光、火焰、物品火焰、粒子图集和其他分类；同名 JSON 是提取器保存的 XNB 描述。
- `DustByID/`：按原版 Dust 编号切出的三张 8×8 小图并排预览，来源为 `Images/粒子图集/Dust.png`；图集行列和帧尺寸以本机原版 Dust 实现为准。
- `Thumbnails/`：仅供浏览器快速预览，原始尺寸和透明度以 `Images/` 或 `DustByID/` 为准。
- `catalog.js` / `manifest.json`：浏览器数据与分类数量；编号和部分英文名称分别取自文件名和本机 tModLoader ID 常量。搜索中的中文主题是根据名称关键词粗略匹配，不是人工鉴定的完整分类。

同一资源可能是动画图集、遮罩或供着色器调用的纹理；单张原图无法反映原版运行时的切帧、着色、缩放、混合、运动和粒子组合。碎片、辉光及其他目录也包含并非战斗特效的素材。原版素材具体如何复用，需要结合原版调用代码和游戏画面确认，不能把预览直接当成现成动态效果。

素材提取使用本地游戏文件与 xnbcli 1.0.7；本地用于生成索引的脚本是 `tools/build_vanilla_vfx_catalog.py`。这份素材库不表示用户已选定美术方向。
