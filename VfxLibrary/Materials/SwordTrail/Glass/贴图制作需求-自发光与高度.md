# 贴图制作需求：EmissionMap 与 HeightMap

用途：交给图像生成模型制作。这两张图会被 `ZenithReborn/Assets/Effects/ZRSwordFlow.fx` 采样，
因此**必须严格按下面的坐标与值域约定出图**，否则接进着色器后不生效或效果错误。

---

## 共同约定

| 项 | 要求 |
|---|---|
| 尺寸 | 1024 × 1024 |
| 格式 | PNG 灰度（RGB 三通道相同即可，着色器只读 R 通道） |
| 色调 | 纯灰度，**不要任何彩色** |
| 无缝 | **必须可平铺**：左右无缝、上下无缝 |
| 禁止 | 文字、硬边、高频噪点、明显重复图案、大块纯色 |

为什么必须无缝：着色器采样器的 AddressU/AddressV 都是 Wrap，
且 U 坐标会乘 1.3~2.2 再叠加时间偏移，一定会跨越边界循环。

坐标含义（两张图一致）：

- **横轴 U** = 沿刀光的长度方向（起笔 → 收笔），会随时间缓慢流动
- **纵轴 V** = 刀光的宽度方向，**V=0 是刀刃（剃刀线），V 增大走向腹侧**

---

## 一、EmissionMap（自发光图）

### 它在着色器里做什么

```hlsl
float emission = tex2D(uEmissionTexSampler, float2(s*1.3 - uTime*0.06, depth*0.9)).r;
reflected += layerColor * emission * uEmissionStrength;   // 用剑色染色后叠加
```

即：**这张图的明暗 = 刀光自己发多少光**，亮的地方剑色越显。
当前最大强度 `uEmissionStrength = 0.55`，由制作端预设给出。

存在的老图信息密度只有 0.03（近乎空白），所以自发光几乎没内容可发，
画面因此读作"灰膜"。这张图是消掉灰膜感的关键。

### 形态要求

- 沿横轴形成**连续流动的发光带**，有明确的亮核，向两侧柔和衰减
- 纵向上：**靠近顶边（刀刃）最亮**，向底边（腹侧）逐渐变暗、变稀薄
- 整体要有起伏和流动感，像能量在刀身里奔流
- 可以有多条明暗不同的流带交错，但不要切成整齐的等宽条纹

### 值域（重要）

| 区域 | 灰度值 |
|---|---|
| 刀刃附近的亮核 | 0.85 ~ 1.00 |
| 带面主体 | 0.40 ~ 0.70 |
| 腹侧与暗部 | 0.10 ~ 0.30 |

不要整图接近纯白（会过曝成一片死白），也不要大面积接近纯黑（等于没发光）。

## 二、HeightMap（高度图）

### 它在着色器里做什么

```hlsl
float2 hUv = float2(s*2.2, mapDepth*1.6);
float hx = tex2D(uHeightTexSampler, hUv + float2(texel,0)).r
         - tex2D(uHeightTexSampler, hUv - float2(texel,0)).r;
float hy = tex2D(uHeightTexSampler, hUv + float2(0,texel)).r
         - tex2D(uHeightTexSampler, hUv - float2(0,texel)).r;
normal = normalize(normal + float3(-hx,-hy,0) * 1.5);
```

即：**这张图不直接显示，而是取相邻采样的差值（梯度）去扰动法线**。
所以真正起作用的是这张图的**起伏斜率**，不是绝对亮度。

### 形态要求

- 极低幅度的**低频起伏**，像丝绸或静水表面缓慢的波纹
- 沿横轴有连续的流动纹理
- **绝对不能有大反差**：梯度会被放大 1.5 倍加到法线上，
  一点点高频噪点就会让玻璃表面变得粗糙、发脏

### 值域（最关键）

**整图必须集中在中灰 0.5 附近**，建议范围 **0.42 ~ 0.58**。

- 0.5 = 完全平坦（无扰动）
- 越偏离 0.5，斜率越大，表面起伏越明显

宁可保守：先做一小点起伏，不够再加，不要一上来就做大起伏。
如果出图整体偏亮或偏暗，需要先归一化到中灰附近再使用，
否则相当于给整条刀光加了一个恒定倾斜，法线会整体歪掉。

---

## 出图后可以这样自检

1. 把图左右拼接、上下拼接，看接缝处有没有明显断层——有就是不无缝
2. 看直方图：EmissionMap 应该分布较宽；HeightMap 应该**窄而集中在中灰**
3. HeightMap 放大看有没有噪点——有就会让玻璃发脏
