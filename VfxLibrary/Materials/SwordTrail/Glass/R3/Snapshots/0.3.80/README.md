# 0.3.80 玻璃R3特效独立收藏

用户明确表示0.3.80特效也不错，要求单独保存。本收藏来自原始0.3.80交付，不包含0.3.81至0.3.84的增强或剑身取色改动。

- ZenithReborn-0.3.80.tmod：当时完整的可安装模组包。
- ZenithReborn-0.3.80-source.zip：当时完整源码、素材、工具、文档和检查归档。
- MaterialSnapshot/：从原始源码包逐字节提取的三组着色器源码/编译结果、主飞剑材质与折射接入、材质预设、默认贴图、GlassR3四张贴图/来源、生成提示词和制作脚本。
- flight-original-speed.mp4、tree-refraction-comparison.png（如有）：当时的历史预览，不是本轮重新验证的画面。
- manifest.json：原始来源哈希、82项包内源码/着色器/JSON对应检查和快照逐文件哈希。

当前正式安装继续保持0.3.85，即0.3.79回退效果；本收藏不自动启用。只有用户之后要求切换时才使用。

恢复完整旧版：正常退出游戏后，备份当前ZenithReborn.tmod，再用本收藏的0.3.80.tmod替换目标模组。此操作会切换整个模组版本，应由后续明确请求触发。

只复用材质：优先使用MaterialSnapshot；材质接入与Shader必须成组核对。完整源码包提供依赖上下文，后续版本不得直接覆盖全部生产源码。本轮未改变正式人物、世界或其他模组。
