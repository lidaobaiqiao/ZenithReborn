# 天顶特效材质需求（给豆包）

上一批七张已经进包（Brush / NormalMap / ColorField / SurfaceMap / HeightMap / EmissionMap / EnvironmentMap），这批发三张，目标是让**天顶剑的拖尾**有区域分工，而不是整条带面一个材质。

---

## 通用规格（和上一批一样）

| 项 | 要求 |
|---|---|
| 尺寸 | 1024×1024 |
| 格式 | PNG，**不要 alpha 透明**（见每张说明） |
| 平铺 | 四边无缝 |
| 对比度 | 中间调为主，不要大片纯黑纯白 |
| 色彩空间 | 线性（导出不套 sRGB） |
| 硬边 | 不允许锐利直线、几何图形、文字 |

---

## 1. ZoneMask — 四区遮罩（**最优先**）

**作用**：控制"带面不同位置用不同材质"。现在整条拖尾是同一套参数，导致刃口和腹部看起来一样。

**这是一张 RGBA 四通道图**，四个通道各画一块区域，**必须都填满、不能有透明**：

| 通道 | 区域 | 画什么 |
|---|---|---|
| **R** | 刃口 | 沿带面**外侧边缘**的一条窄带（占宽度 10~18%），形状像刀锋，尖端略宽、根部收窄 |
| **G** | 脊线 | 带面**中段**一条纵向走向的宽带（占 30~45%），边缘不规则，像金属的脊 |
| **B** | 腹部 | 带面**内侧**的大块区域（占 40~55%），边缘软，像玻璃内部 |
| **A** | 磨损区 | 集中在**刃口最外 3~5%** + **尖端附近**的斑块，其余为黑 |

**关键要求**：
- 四块区域**可以重叠**，不要互相排斥（重叠处 shader 会按权重混合）
- A 通道**必须有内容**（不能全黑，否则加载后会被当成"无数据"）
- 每个通道单独看是一张合格的灰度图（有结构、不是一片灰）

**为什么强调**：泰拉的贴图加载会清掉 alpha=0 处的 RGB，所以四通道都要有值，这张图不能靠透明区域表达。

---

## 2. ZenithField — 天顶专属色场

**作用**：天顶剑的颜色是**多色循环**（原版近蓝、远紫、边缘粉）。现在用的是矿石剑那套单色云纹，撑不起这个色域。

**画什么**：一张**横向缓慢渐变**的色场（灰度），从左到右有三个明显的"冷—中—暖"区段，段之间有柔和过渡。不是随机云纹，是**有方向的流动带**。

- 左 1/3：偏暗（冷色区）
- 中 1/3：最亮（能量核心）
- 右 1/3：中等（暖色区）

整体要有轻微的低频起伏（不是纯线性渐变），像三种颜色的光缓慢交融。

**规格**：1024²，灰度，横向优先无缝。

---

## 3. ZenithWear — 天顶磨损

**作用**：天顶剑的刃口应该有使用痕迹（细微崩口、纵向拉丝），现在用的是通用划痕，方向不对。

**画什么**：沿带面**纵向**（不是横向）的细密拉丝 + 少量崩口。拉丝要顺着刃的走向，不是横穿。崩口是零星的缺口（小块的暗斑，边缘软）。

**规格**：1024²，灰度，无缝。拉丝宽度 1~3px，密度中等（不要糊成一片灰）。

## 交付

- 命名：`ZoneMask.png`、`ZenithField.png`、`ZenithWear.png`
- 放到：`artifacts/vfx-textures/` 下各自新建文件夹，同时复制一份标准命名到 `VfxLibrary/Materials/Textures/`
- ZoneMask 请**单独确认四通道都有内容**（可以用工具分别导出 R/G/B/A 四张灰度检查）

---

## 验收标准

1. **ZoneMask**：分别导出 R / G / B / A 四个通道，每张都能看出一个明确的区域形状；四张叠起来覆盖整张图，没有大片空白
2. **ZenithField**：横向看有三段明显不同的亮度，过渡不生硬
3. **ZenithWear**：拉丝方向统一（纵向），不是杂乱的交叉划痕
4. 三张都四边无缝
