# 0.3.100：更通透、提高金属度、粗糙度为零

按用户要求，将“透明度低一点”具体落实为降低不透明度Opacity，使带面更透。调参如下：

| 参数 | 99 | 100 |
|---|---:|---:|
| 不透明度Opacity | 1.00 | 0.85 |
| 金属度Metallic | 无独立控制，按介质处理 | 0.25 |
| 粗糙度Roughness | 0.08 | 0 |

唯一参数来源为`VfxLibrary/Materials/SwordTrail/Glass/preset.json`；`checks/emit_glass_preset.py`校验并生成`GlassMaterialPreset.cs`，不新增玩家调参界面。其余光学值、56项开关和贴图保持99状态。

## 实际生效链

- `SwordFlowMaterial`允许粗糙度0并提交真实Metallic。`GlassOptics`增加金属度，保留旧三参数构造及解构接口，避免旧制作端调用失效。
- `ZRSwordFlow`让金属度参与介质F0与剑色导体F0的混合、GGX核心、有色环境/屏幕反射和透射配比。SSR强度仍为0.6，没有用增大反射强度冒充金属度。
- 运行端不再把粗糙度钳到0.02，shader不再钳到0.025；零值时阻止分区磨损把粗糙度重新抬起。表面图仍绑定，零粗糙度下粗糙度调制无贡献属于明确要求，不是漏绑定。
- GGX微表面分布仅保留极小数值保护，避免除零；实际材质参数、输出粗糙度和屏幕模糊值仍为0，不将其伪装成非零粗糙度档位。
- 旧屏幕覆盖度在成熟区会饱和到1，并用遮罩Alpha除回高光，单改带面Alpha不足以落实降低不透明度。现在由同一预设向`ZRGlassScreen`提交Opacity，最终背景混合和泛光也执行0.85，确保世界画面真实改变。

几何、连续UV朝向和全部生产贴图与99逐字节一致。没有重做轮廓、改颜色输入或碰战斗/存档。独立星芒、剑影与粒子仍按原开关生效，Opacity调的是玻璃材质而非原版剑图。

## 验证

两项目原生构建零错误、零警告，8426项引擎检查通过。42张实际GPU诊断图绑定当前生产包，实测参数为Opacity0.85、Roughness0、Metallic0.25。

- 全部有覆盖的法线/粗糙度像素中，非零粗糙度像素为0。
- 仅将金属度改为0，有34023个可辨变化像素；仅将粗糙度改为0.08，有657个可辨变化像素。两项不是写入后未参与输出的空参数。
- 保留三种剑色、动画、零透明度和完全消融检查。`refraction`子报告中的0.08是该独立IOR诊断显式传入的测试粗糙度，不是当前默认材质值；当前值记录在`actualParameters`及世界`parameters.optics`中。
- 正式五模组组合的复制测试档完成昼夜受控攻击，两轮均三剑实际命中、返回、父弹幕消失后的独立收尾通过，结束残余收尾为0。
- 原生滤镜同一帧分别隔离IOR和Opacity：白天Opacity1→0.85产生31812个可辨变化像素，夜晚产生63098个；IOR变化都在带面内，带面外变化为0。

首次1280×720夜间检查的世界行为和Opacity对照通过，但IOR累计RGB差90985低于旧固定门槛100000，报告保留在`artifacts/textured-sword-material/night-1280-diagnostic/`。没有降低门槛；随后按正式画面设置重测，累计差138044、5933个可辨变化像素、带面外0变化，通过原门槛。不能把首次结果改写为通过。
