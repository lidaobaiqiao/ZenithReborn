# 0.3.108：剑魂配阵与羁绊核心

2026年10月27日。基线为0.3.107。用户认为主页的界面、动画、信息显示和交互仍然普通，要求发挥创意继续优化。本轮聚焦武器寄宿主页，保留其余三个信息工作区。

## 最终体验

主页按“选择剑位—选剑预览—确认归位”组织。宽屏左侧为随身剑库，中间为主攻剑阵和独立支援阵列，右侧为剑位详情与固定操作。窄屏在同一工作区切换剑阵、随身剑库、剑位详情；短视口的确认与取回并排显示，说明独立滚动。顶部提供定位开放空位，主导航仍为寄宿、特性、成长、环境。

剑库由小物品格改为武器清单，直接显示名称、面板伤害、暴击和真实环境标签，可切换全部/未寄宿以及背包序/伤害排序。点击武器仅选择候选，右侧展示面板差值、寄宿限制、换入后的主攻数量与支援容量，以及旧武器的去向。数值明确标为武器面板，不能当作最终战斗伤害。

中央使用实时羁绊核心：读取已实装木质族、矿石族，显示主导族、六个阶段、阶段颜色和数量；最高阶段使用棱彩。主导族按阶段、数量和阶段内进度决定。矿石族的最高羁绊为10材质，14材质累计全收集仍是另一套奖励；没有为灵能或武技添加未实装羁绊。

主攻剑位保持固定圆环，支援改为独立规则阵列，奖励和传奇各自保留入口。节点渐入、选中刻度、核心呼吸和光点提供状态反馈。确认寄宿后，武器沿光轨到达剑位，随后一道弯曲流光从剑位加速进入核心。鼠标已有物品时仍可直接放入。装饰动画不移动点击框。

## 数据与模块归属

- `SoulArmoryLayout`：宽窄视口、分区、剑位与操作几何。
- `SoulUILibrary`：真实背包索引、筛选排序、候选清单。
- `SoulUIArmoryInteraction`：临时选择、确认、定位空位与动画事件。
- `SoulArmoryPreview`：在完整剑魂克隆上复用真实寄宿校验及容量计算。
- `SoulUIArmoryScene`：剑阵、节点与武器归位表现。
- `BondSnapshot`、`SoulUIArmoryBondCore`：羁绊只读状态、阶段颜色、核心及汇流绘制。
- `SoulUIArmoryDetails`：状态、面板对比、条件说明和固定操作。
- `SoulUIArmory`：主页协调；原`SoulUI`只接入入口，剑库实现从`SoulDomainUI`移出。

确认操作继续调用原有`EquipFromInventory`、`ReturnSelected`和`TrySwapHost`。保持物品对象、前缀和原背包格交换，不增加仓库，不复制物品。候选绑定背包位置与原对象，位置内容被替换后拒绝旧候选。关闭、卸载或退出世界会清理临时选择和动画事件。

85个既有C#文件、43项Assets与本轮开始时逐字节一致；修改3个既有UI文件，新增9个职责明确的源码文件，另更新版本说明。战斗、存档格式、素材和主剑材质保持。

## 验证与边界

两个项目使用tModLoader原生编译器构建，零错误、零警告。998项对应检查通过，覆盖原有UI输入屏蔽、物品交换/取回、新候选的只读快照、真实对象交换、失效候选拒绝、隐藏剑位不消费点击，以及宽窄和短视口布局。发现并修复了400单位宽视口的奖励/主攻边缘重叠、短视口操作区越界和中央数量压到下方剑位的问题。

最终实际GPU输出位于`artifacts/information-ui-0.3.108/armory-final/`，共56张，含28张固定动画年龄样本：13张归位/汇流连续样本、10张单独核心流光、5张入场样本。覆盖普通配阵、换入对比、未解锁拒绝、开局未附着、11个有效支援、640单位窄屏，以及原有特性/成长/环境工作区。

实际绘制入口的模拟点击确认：选候选不改变剑魂快照，确认精确交换原物品，锁定剑位不能寄宿，窄屏选择后进入详情，动画期间点击框固定。原有五类信息页模拟输入通过，浏览前后原剑魂网络快照一致。图像使用临时测试剑魂，不是用户角色的进度。

本轮未进行自然鼠标游玩、真实多人或战斗/昼夜矩阵；布局和美术仍以用户实际体验为准。没有修改阈值来掩盖失败，也没有把静态或离屏检查写成自然游玩通过。
