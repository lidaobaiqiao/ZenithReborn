# 0.3.89：夜间环境反射灰纹修订

> 已被后续用户选择取代：改以原始79为开发基础。89仅收藏，取消待安装，不作为后续材质方向。见[90基线恢复](0.3.90-以原始79恢复开发基线.md)。下方为89历史诊断和验证记录。

用户认可原始80白天的干净通透，指出夜晚灰白粗纹、格子和重复条带像脏膜，并提出可能与贴图有关。本轮承接已开始的89照明响应修改，补做贴图消融，并加入暗处同源平滑环境反射。原始79、80、88独立收藏保留。

## 贴图消融发现

隔离菜单使用原始80的编译着色器、同一生产剑迹网格、光向、时钟和颜色，逐项替换高度、法线、粗糙度和环境图。只改变背景亮度，不使用89的反光衰减来证明纹理改善。

- 原始环境图带有细碎云层、山线、水面纹理，曲面反射映射后会形成明显杂纹。
- 只抹平高度和法线，杂纹仍明显；只将粗糙度改为均匀值，变化更小。
- 只换均匀环境图，大部分杂纹消失。因此本次夹具中的主要纹理来源是环境反射图。
- 使用同源平滑环境图、保持80原Shader和光能倍率时，细碎纹理残差约为原来的50%。指标为显示RGB的2像素高斯高通RMS，采样Alpha大于160并内缩3像素的内部，**不是物理亮度、通透感或美术评分**。

对照图：[原始像素贴图消融](../artifacts/soul-trail-gpu-0.3.89-texture-ablation/texture-source-comparison.png)。上排原始80，中排仅抹平高度与法线，下排仅换平滑环境图；左暗背景、右亮背景。只裁切排版，没有调亮、调色或缩放。该图是定位材质输入的夹具，不是89最终夜间效果。

8位高度图实际仅123～133共11级灰，邻接台阶可能放大微表面扰动，但本次抹平对照不支持把它认定为主要原因。尚未精确复现用户录像相同姿态下的每一块格子，不能宣称全部网格伪影都已定位或消除。

## 实现

1. 从剑迹所在世界位置采样原版照明，显示RGB先按2.2次幂还原线性光能，再按亮度权重汇总。避免把偏绿、偏蓝剑光的最大通道直接当作强环境照明。
2. 暗处降低固定环境图、方向高光及少量内部流丝的光能，明亮输入完整沿用80。
3. 从原始EnvironmentMap在线性光能中生成低频EnvironmentSoftMap；横向周期、纵向镜像，高斯宽度32/16像素。平均RGB线性光能基本不变，纹素相邻变化降至原图约11%。原图不覆盖。
4. 暗处反射向同源低频图过渡，明亮时直接使用原始80反射。保留法线、倒角、粗糙度、IOR、透射、Alpha、真实剑迹与短尾。没有换回大面积发光，也没有把玻璃整体变透明。

本轮以用户正在试用的原始80为基底，配色也沿用80；**未将收藏88的实际剑身取色与有色流纹增强混入89**。

## 验证与边界

- 两个项目原生编译均零错误、零警告，8393项引擎检查通过。
- 三种固定颜色的明亮输入与原始80逐像素差0；法线、光学属性、透射及Alpha差0。固定暗处表面亮度约为原80的14%，这是孤立材质输出统计，不是世界最终亮度或美术质量结论。
- 正式五模组组合、正式画面配置的隔离世界覆盖白天、黄昏、深夜、局部光源。各场景报告、原生滤镜影响范围及包哈希由`checks/check_day_night_delivery.py`核对，结果见`artifacts/day-night-delivery-0.3.89.json`。
- 原始80归档的125项生产文件中120项逐字节保持，仅版本、SwordFlowMaterial、自有Shader源/编译件及构建清单变化；另新增平滑反射图与派生元数据。全部旧素材保持。
- 夜间首轮等待脚本因同时运行另一个图形夹具超过180秒，客户端随后自行正常结束并生成本次包哈希的通过报告；没有强杀或复用旧结果。
- 未验证自然鼠标游玩、真实多人；用户美术确认仍待进行。源码/GPU/隔离世界通过不能代表用户已认可夜晚效果。

正式磁盘安装状态以`artifacts/install-result.json`为准；游戏已启动时需要正常退出重启或重载模组才能加载新包，不能把磁盘替换说成已验证正式客户端加载。

本轮尝试正式替换时，正在运行的游戏锁住目标包，`os.replace`返回WinError 5。正式原始80哈希保持，89已另行打包至`artifacts/ZenithReborn-0.3.89.tmod`；待正常退出后才能替换。没有强杀游戏，也没有把安装记录提前改成89。待安装记录见`artifacts/pending-install-0.3.89.json`。
