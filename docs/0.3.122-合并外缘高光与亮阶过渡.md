# 0.3.122：合并外缘高光与亮阶到白色的过渡

用户要求把最外层分叉高光合在一起，高光颜色应从主体色亮阶渐变到白色。原材质的外缘刃线与另一条沿宽度游走的扫光各有中心，可能形成分叉；本轮将外侧扫光并到刃缘的同一位置，保留原有内侧细反光以及屏幕背景反射。核心高光从逐剑亮色随强度平滑过渡到白色，光晕仍保留剑色；不把整片剑迹直接刷白。该定位属于对用户描述的代码分析，是否正好消除了用户看到的分叉须实机确认。

改动归属于ZRSwordFlow材质计算与其颜色输入注释；剑迹几何、刀身接合、人物移动补偿、飞剑速度、剑影碰撞和屏幕反射代码与0.3.121包逐字节一致。两项目Release编译零错误、零警告；95项剑迹几何与生命周期检查通过。此检查不能证明最终亮度、白色过渡或分叉在所有姿态下正确。

尝试实际GPU夹具时，图形客户端报告Steam未登录或未运行，没有生成GPU图；不沿用0.3.121图片充当本版验证，也未重试或跑自然游玩、多人、世界或帧率。开发版经编译及必要几何检查后按既有项目交付方式安装，最终美术仍需用户确认。
