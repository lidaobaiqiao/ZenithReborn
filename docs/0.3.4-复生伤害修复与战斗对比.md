# 0.3.4 复生伤害修复与战斗对比

## 原因

旧公式在完成复生后仍使用各材料剑的伤害，再乘110%并除以有效攻击武器数量的平方根。十剑配置中，铜短剑等低伤害素材拉低面板，实际每把剑还被额外除以√10；对有防御的敌人，低伤害小段更容易被防御抵消。剑魂弹幕还使用「每个敌人终生只能命中一次」的局部免疫，而原版天顶允许冷却后再次命中。五段出剑调整后，这些旧限制没有被清理。

因此问题不限于面板数字。玩家报告的八分之一属于其游戏场景的观察值，本次不把这个比值当作适用于所有装备与敌人的固定常数。

## 修复

只有已完成永久复生的剑魂采用新规则；十种天顶材料、六魂芯及主线铭刻要求保留。复生前仍按原来的武器成长和分摊公式计算。

- 复生本体基础伤害：有效攻击武器平均伤害与原版天顶基础伤害取较高者，再应用110%效能。本机无前缀原版天顶基础190，普通十剑复生面板为209。
- 每把剑影至少继承复生本体的玩家加成后伤害，不再除以√剑数。高于该基准的寄宿武器仍能进一步提高其自身剑影伤害。
- 继承实际原版天顶的暴击、击退和前缀数值。剑魂传奇前缀在动态刷新后继续生效。
- 五个动作节点保留。原版每把剑间隔为10帧，复生五节点基础动作因此为50帧；装备攻速、机械祝福和已有支援效果继续影响速度。这样不会在换用天顶伤害后仍沿用低级素材的短动作而额外堆高发射频率。
- 复生剑影每8帧可再次命中同一目标，保留局部免疫，不逐帧无限命中。依据原版933弹幕15次更新的冷却及每帧两次更新，换算到剑魂原有每帧一次更新。复生剑身碰撞半长40像素，非复生仍为26像素。
- 复生状态随弹幕额外数据同步；不同客户端应使用同一模组版本。

仍保留每把剑的独立外观、配色与专属弹幕、五段轮换、原有椭圆轨迹、木系支援和森林奖励剑位。空剑魂仍不能攻击。

## 实际引擎对比

隔离tModLoader中直接运行原版`Player.ItemCheck()`、`Projectile.Update()`、碰撞及`NPC.StrikeNPC()`流程。目标固定在玩家右侧240像素，尺寸80×120，不移动、不击退；裸装，十把材料无前缀，表中传奇指主武器前缀。每组1200帧即20秒，包含自然出现的材料剑专属弹幕。独立于正式人物与世界。

| 目标防御 | 主武器前缀 | 原版天顶DPS | 复生十剑DPS |
|---:|---|---:|---:|
| 0 | 无 | 1267.15 | 3052.20 |
| 0 | 传奇 | 1755.35 | 3954.35 |
| 50 | 无 | 1099.65 | 2558.45 |
| 50 | 传奇 | 1551.60 | 3388.10 |
| 150 | 无 | 764.65 | 1625.15 |
| 150 | 传奇 | 1144.10 | 2079.50 |

这是固定目标、固定种子的引擎对比，不能等同于移动Boss、全部配装或模组环境中的DPS保证。修复后的本体伤害以原版为下限；材料剑的专属机制与已有机械祝福提供额外收益。运行记录为`artifacts/damage-comparison.json`。

本轮还检查了非复生成长保留、强力寄宿武器仍可超出下限、传奇重铸刷新、复生状态网络序列化及原有功能回归。未进行图形客户端观感或真实多人联机验证。
