# 0.3.94：P18宽高光扇形格纹隔离

> 用户实机纠正：关闭P18后棱纹依旧存在，变少主要是带面变暗看不见，边缘仍明显。因此关闭高光不能算修复，也不能把P18当成棱纹来源。后续95改查三角形朝向连续性，见[95记录](0.3.95-共享顶点连续朝向与棱纹修订.md)。下文保留为当时的消融记录。

用户已关闭P24，仍在带面上观察到明显的扇形条纹/格子，要求排查可疑项并先关闭，之后由用户实机检查。

## 排查与结论边界

取实际安装0.3.93包（SHA256 `2630cae8de6b3b20ec8c62d0c616cda5c8f44cc86743c174e5d4f27233ee05ca`），通过生产SoulMaterialTrail.BuildLayered和材质入口，固定夜间光向、颜色、动画时间，生成接近用户截图形状的单条13历史点弧面。属于合成固定姿态，不是截图当帧真实AI或逐像素重放。

- P24关闭仍复现扇形分段，外侧亮刃较平滑。
- 分别关闭P03尾部细缕、P05程序色场、P09倒角、P15带状反射、P17高光核、P19向白偏移，不能解释全部宽面格纹；尤其P03+P05合关时主要格纹仍在。
- 只关闭P18宽高光包络，宽面扇形格纹明显消退，亮刃保留。此项消融改变41170个像素，数量说明影响范围，不是美术好坏评分。
- 同一弧面的生产法线输出也显露对应三角形方向分段；相同材质的仿射平面没有同样的扇形格纹。结合shader从ddx/ddy(UV)构造朝向的路径，主要嫌疑为网格内UV导数在三角形间不连续，宽高光把分段显露出来。

这支持优先摘除P18，不等于已经修复网格、证明每一块格子都来自同一来源，或确认所有姿态均已干净。P18关闭也会带走宽亮面，不能把变暗冒充玻璃材质已完善。

- P18默认由1改0；保留用户已关闭的P24=0。
