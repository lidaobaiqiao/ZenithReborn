# 0.3.106：剑魂档案信息界面

2026年10月27日。用户要求优化天顶剑魂操作界面的其他信息页，配合图标与动画，并按创意网站的思路做出质感。基线是正式安装与归档一致的0.3.105。

## 信息与视觉设计

围绕“剑魂档案”整理四个信息页：生效共鸣、胜利铭卷、百剑藏书、万境星图。保留顶部的原有页面名称，避免让老入口难找。原来所有信息都是等重的长段落，现在先显示摘要、状态与可选择的节点，再按需展开完整效果、激活条件及个人铭刻。

- 生效特性与特性图鉴共用卡片系统。主标题、原版剑图标、已激活/待激活状态、两行摘要和详情入口分层显示。完整说明与激活条件在所选卡片下方展开，不丢失数值和规则。
- 宽屏左栏承担木质/矿石/剑术/成长分类筛选并显示真实条目数，不重复顶部页面导航。窄屏收起左栏，分类移到正文上方，卡片由三列/两列收为一列。
- 成长页将十个普通剑位做成可点选的进度节点，默认定位下一目标；六枚魂芯按收藏状态显示，六道封印使用锁链、护盾、回鞘、断刃等对应含义的徽记。左栏可定位解封、魂芯、封印和外域章节。
- 环境页用二十一张原版物品图标卡组成环境图谱。选择卡片只改变查看对象；展开领域、选择/取消常驻仍通过独立按钮调用既有校验。左栏可定位图谱、所选环境详解及收集规则。
- 视觉采用深色档案底、统一线宽徽记、少量金/青/紫/绿强调色。信息页使用清晰无描边文字，放大标题和正文；已拥有、未拥有、当前选择分别区分。进度圆环读取真实比例，不添加虚构数值。
- 动画包括切页淡入、图标分批显现、基于时间的悬停过渡、详情淡入与轻微流光。装饰不移动命中框，不给状态或按钮添加等待时间。

图标复用原版物品和代码绘制的矢量徽记，没有新增图片素材、Shader或玩家依赖。武器寄宿剑环与战斗特效保留。

## 模块归属

`SoulUI.cs`保留输入、页面协调和滚动裁剪入口，原来混在入口文件里的特性与成长绘制已经拆出。

| 文件 | 职责 |
|---|---|
| `SoulInfoLayout.cs` | 界面单位下的自适应排版与纯缓动函数 |
| `SoulUIGlyphs.cs` | 页面、类别与封印的统一线条徽记 |
| `SoulUIInformation.cs` | 信息卡片、正文、按钮、上下文边栏与短时显示状态 |
| `SoulUIArchive.cs` | 生效特性/图鉴的只读分类、卡片与完整详情 |
| `SoulUIMemories.cs` | 成长节点、魂芯、封印和既有领取入口 |
| `EnvironmentUI.cs` | 环境图谱、当前选择和既有环境操作入口 |

显示状态不写入剑魂存档。战斗与进度数据仍从原有模块读取，图鉴浏览不授予效果。所有本轮修改文件的代码注释均使用中文。源文件对照确认78项原有C#文件及43项Assets文件逐字节保持；已有非UI生产源码均未改变。

## 对应验证

执行`checks/run_wood_checks.ps1 -InformationUi`。两个项目原生编译均零错误、零警告，875项定向检查通过：原有多种界面缩放、隐藏剑位拒绝点击、输入屏蔽、物品原引用交换与取回、分类只读浏览、窄屏信息排版、卡片不重叠、缓动边界及既有魂域控制。没有例行重跑整套战斗或昼夜材质检查。

实际GPU在独立临时配置中调用正式`SoulUI.Draw`，使用测试剑魂而非用户角色。最终输出24张图：四个信息页、展开详情、章节定位与640单位窄屏，另含12帧固定时间采样的切页过程。模拟输入验证分类筛选、卡片展开和章节跳转均成功；所有浏览前后的剑魂网络快照逐字节一致。数据和渲染结果绑定本轮包SHA256。

这是实际游戏绘制与模拟输入验证，不是实际鼠标游玩或真实多人验证。图形客户端原先未运行Steam，正常启动Steam后会话可用，未绕过游戏验证。图形客户端属于独立测试配置，产物保存后清理；原生退出处理可能继续持有资源，脚本会在正常关闭无响应后只终止自己启动的测试进程，不接触正式客户端、角色、世界或个人配置。
