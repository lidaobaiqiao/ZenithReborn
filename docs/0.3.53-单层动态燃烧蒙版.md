# 0.3.53 · 单层动态燃烧蒙版

日期：2026-10-23。用户明确否定剑头V形、双弧、星光及拖尾多层拼贴，要求少量底色与动态蒙版，在材质内部形成燃烧感。本条替代0.3.50～52关于多层剑头与包覆叠加的表现方案。

## 表现与接入

- 矿石飞剑／天铸巨剑／附属剑片各使用一片连续的现成编译材质，贯通尾迹、剑身和实际剑尖。原版剑型仍作为低亮底色，保留此前的私有转色副本、轮廓定位与材质配色。
- 移除V形线、双月牙、单独白芯线、剑尖星光、旋转环、贴图重影及另外叠加的包覆层。飞行期间不再持续喷射旧星芒Dust。
- 使用原始MIT `OniCrimsonSlash`现成直刃模式，单Quad／单Pass；内部复用双频笔刷流动、domain-warp噪声场、随时间改变的侵蚀阈值和原有燃边。降低底色及白热增益，不把外部几何图案当成动态火焰。
- `OreFlame`只设置已有参数与提交几何，未修改／重编译第三方Shader、笔刷或噪声资源。普通主剑、武技已认可的流光主体以及Luminance依赖保持，无新增插件。
- `OrePierceFeedback`在原版DrawDust之后统一绘制连续材质，避免重复在PostDrawTiles及前景各绘一遍。命中提高当前材质热度，不添加冲击环；仅保留短暂的原版池碎光与合并声效。
- 结束仍独立保存20／36帧，但改为同材质侵蚀熄灭及一张低亮剑影，不再扩散圆环或三条裂线；少量结束碎光由原版Dust继续消散。巨剑余烬锚定实际命中处，最终剑影保持实际末位。

攻击运动、加速、时序、碰撞、伤害、支援／槽位、存档与网络格式均未修改。

## 验证

- 生产及检查模组编译均0警告、0错误，引擎8268项通过。删除已移除的旧椭圆冲击模型7项断言，保留独立结束及全部战斗回归。
- 隔离GPU直接调用生产绘制函数，固定剑体、采样轨迹和镜头，只推进材质时间：0与0.2秒的蒙版图像有22476个明显颜色变化像素、11300个可见覆盖变化像素。这是内部流动／侵蚀变化，不是图像整体移动。96帧静止燃烧预览为`ore-burning.mp4`，使用真实60fps GPU帧。
- 保留十四配色、摄像机平移、GPU状态恢复、原纹理不变／副本缓存、实际巨剑像素剑尖对照、17条OnKill夹具及结束0有效残留像素检查。14把飞剑实际OnHit回调各发出4枚碎光，同目标重复回调不再发出；此处验证的是原生Dust池分配和回调去重。
