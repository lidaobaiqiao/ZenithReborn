# 玻璃反射研究与小面光试作

## 研究结论

1. 干净玻璃是介电体：在空气和折射率 1.5 的玻璃单界面，正入射反射率约为 4%，掠射时反射增强。薄玻璃的两侧界面和内部反射不等同于单界面 4%。折射与反射由视角、界面法线和折射率决定。[PBRT 介电体模型](https://www.pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF)
2. 微表面粗糙度描述微小面元方向的统计分布；特定方向的微结构会导致各向异性。磨砂、蚀刻与抛光玻璃的散射不同，整张横向笔刷不能代表干净玻璃的普遍表面结构。[Walter 等，Microfacet Models for Refraction through Rough Surfaces，2007](https://doi.org/10.2312/egwr/egsr07/195-206)；[PBRT 微面元](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)
3. 高光形状来自光源、环境、表面法线与视角；平滑玻璃也可能反射出细长灯具或窗框。因此这里去掉的是材质上无条件沿剑迹平铺的拉丝，不假称任何玻璃都不会出现长条反射。[Filament PBR 文档](https://google.github.io/filament/Filament.html)；[Heitz 等，实时多边形面积光，2016](https://blog.selfshadow.com/publications/s2016-advances/)
4. 覆盖度表示表面是否存在，透射表示存在的表面让多少光通过。透明玻璃可以仍有表面反射；粗糙的薄壁会模糊透射。有限厚度的吸收可按路径长度近似，屏幕空间折射无法恢复屏幕外或被遮挡的场景。[Khronos 透射](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_transmission/README.md)；[Khronos 体积](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_volume/README.md)

## 本项目对照与试作

0.3.111 的笔刷素材确实有明显水平拉丝。对同一姿态做实际 GPU 消融：关笔刷后连续亮刃仍在；关闭旧 P24 内部条纹后细条减少；关闭亮刃后亮像素从 757 降到 0。表面宽高光自身也会覆盖大片带面，因此不能将全部线纹归因于一张笔刷图。原始结果见 `artifacts/clear-glass-0.3.112/highlight-baseline-111/highlight-probe.json`。

试作取消笔刷及自发光贴图对玻璃表面光的驱动，也停止把按带面宽度采样的人造地平线当作真实环境；实际当前帧屏幕反射仍保留。反射、透射与菲涅耳使用同一连续曲面法线；虚拟矩形面光通过反射方向的角度范围计算，未使用固定在 UV 上的小方块。此计算是实时近似，不是完整多边形面积光积分，也没有场景深度、屏外环境或完整光线追踪。

按普通介电玻璃语义，制作端金属度由用户此前设定的 0.25 改为 0；剑色仅作为虚拟光源的艺术配色。粗糙度 0、主体密度 0.1、折射虚拟厚度 18 和轨迹网格保持。表面光缓冲试用半精度浮点以降低微弱线性反射的量化损失，原始数据导出为八位 PNG 不能证明半精度本身；应查看实际显示与原生管线。
