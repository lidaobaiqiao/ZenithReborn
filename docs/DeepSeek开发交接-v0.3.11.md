## 文件入口

- `SoulItem.cs`：有效容量固定原上限，数组中多余字段是停用恢复区；`HasLegacyExpansion`、`TrySwapHost`控制只取回。`Stored`是持久化顺序，不是UI顺序；界面请使用`SlotItems`/`ItemAt`。
- `SoulUI.cs`/`SoulInput.cs`：正常三页，有遗留物品才显示第4个取回页；不要再开放扩展位放入。
- `OreFamily.cs`：材料映射、有效槽计数、合法主命中调度、来源/目标冷却；不解锁槽位。
- `OreFlyingSword.cs`：正常绘制、20帧成形、第21帧刺出、目标主体与生成身份过滤、来源失效结束、实际寄宿剑外观。
- `HardOre*.cs`：原六矿独有机制；`Wood*.cs`：原木系；`SoulSwingPlayer`：五段出剑；`SoulCombat`：逐剑伤害。
- `checks/ZenithPrototypeCheck/OreCheck.cs`：新矿石真实命中和17槽/遗留恢复检查，现已加入普通回归，不再仅手动专项。

## 构建与验证

```powershell
dotnet build ZenithReborn/ZenithReborn.csproj -c Release --nologo
pwsh -NoProfile -File checks/run_wood_checks.ps1
```

.NET8与本地tModLoader必需。两份csproj及检查脚本仍使用本机E盘tModLoader路径，换电脑需调整；脚本会创建artifacts。隔离检查不修改正式存档。

`python checks/package_install.py`默认会替换本机正式模组；仅导出时先设置`$env:ZENITH_PACKAGE_ONLY='1'`。安装必须备份并核对包内DLL/源码及哈希；锁文件时先备包再等用户正常退出，不强杀、不自行关机。图形测试夹具仅允许stage-one-playtest隔离profile，正式profile不得启用检查模组。

当前引擎1826断言通过。编译/引擎/图形/多人证据分开；不能照搬0.3.8的图形验证给0.3.11贴已测标签。见本版验证记录。
