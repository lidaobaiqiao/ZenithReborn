# 0.3.95：共享顶点连续朝向与棱纹修订

用户确认94关闭宽高光后棱纹仍在，边缘明显；变少主要是变暗。此前以关闭P18后的可见度下降判断可疑来源过早。本轮保持现有开关、亮度参数和几何位置，从三角形插值与朝向计算排查。

## 定位依据

在原94安装包的生产弧面上增加独立诊断：

1. 固定灰色、固定0.25透明度的BasicEffect绘制，不经过生产高光/形状计算。内部重复叠亮像素为0，未发现此合成姿态的网格重叠。
2. 只翻转每个四边形的内部对角线，保持边界、UV、颜色与光照。扇形棱纹的斜向跟随对角线变化，说明表面方向计算依赖三角形划分。
3. 生产shader用`ddx/ddy(h)`计算横向，再由此构造高光/折射的表面朝向。UV在每个三角形内线性插值，但导数在相邻三角形间可能跳变；共享几何位置并没有保证共享表面朝向。

这些证据支持“逐三角形朝向不连续”是本合成弧面棱纹的来源。高光只是显露问题，不应作为关暗画面的修复手段。未精确重放用户截图当帧，也未证明世界每种姿态都只存在这一种伪影。

## 实现与归属

- 新增`SwordFlowMeshBasis.cs`，仅负责计算连续UV朝向。每个逻辑共享顶点汇总相邻三角形的屏幕空间UV梯度，按面积加权后单位化，再让GPU在三角形内部插值。
- 顶点身份包含位置、UV与颜色；不焊接真实UV接缝或覆盖度不同的表面。退化尾尖采用有限中性方向，兼容观察矩阵的旋转、缩放和翻转。
- `SwordFlowMaterial.Draw`只接入扩展顶点提交；shader使用插值朝向替代逐三角形`ddx/ddy`朝向。几何生成器`SoulMaterialTrail`未修改。
- 保持每个顶点的位置、原始UV和颜色/覆盖度，未改网格数量、剑迹、攻击、碰撞、时序、材质光强和配色。
- P18/P24默认仍保持用户当前的关闭状态。诊断中同时打开前后两版P18检查；用户可在面板第43项打开P18复查，不需要恢复P24。
- 纯代码资源限制继续保持，不新增或启用任何自有特效贴图。

## 验证

- 两项目原生编译零错误、零警告。新增6项朝向合同检查，当前配置8159项引擎通过，覆盖位置/UV/颜色保留、共享顶点一致、单位化、观察旋转、UV接缝分离、退化输入有限性。
- 前后同样开启P18、关闭P24，固定颜色、夜间光向、材质时间和13点弧面。新结果明显减弱原先三角形分面，恢复宽亮面进行观察，没有降低光强隐藏问题。
- 固定灰色几何输出逐像素一致；仿射平面材质输出最大通道差0。
- 在完全相同的几何覆盖区统计8位图像亮度，旧28.6616、新28.6865，比例1.00087。该统计仅说明本夹具没有通过压暗隐藏分段，不是完整物理光能测量。
- 连续朝向法线输出变化29717像素；对照图片只裁切排版，未调亮、调色或后期平滑。
- 完整包与物理移除36项素材包使用同DLL，40张实际GPU图逐像素一致，继续确认本轮纯代码路径的素材独立性。
