# 武技族 WJ2 · 三档剑势与天顶巨剑

> 2026-10-30 用户决定保留木质族和矿石族，删除武技组与后续新增种族；本页仅作历史设计记录，不再是开发计划。

日期：2026-10-22。当前游戏基线：0.3.42。本文记录用户新提出的攻击体系及明确确认的归属。**这是武技族提供的新攻击方式**，不是整个天顶剑魂无条件自带的核心能力。尚未实装。

本页替代[WJ1](武技族WJ1-剑势与招式开发准备.md)作为武技下一步设计入口。WJ1的主修/副修、十把剑各有主动招式、100点剑势、默认G、档位与奖励均未被采用，不能混入WJ2。其他种族也应拥有各自参战方式的方向来自用户，但本页只记录武技，不替其他族设计攻击。

> 最新补充：用户明确武技羁绊为 **1／2／4种**。1种解锁剑势、最高二档；2种开放三档并提高剑势伤害；4种使整套武技攻击不再限武技主攻。三档羁绊都增加共用支援位，必须做到四把武技剑全放支援、主槽使用任意可寄宿武器也能使用完整玩法。下文“剑势三档”是资源/攻击档位，不能与1／2／4种羁绊混淆。尚未实装。

## 用户确定的总体体验

天顶剑体现掌握多种武器、让它们以不同方式并肩作战。原版飞行切割保留为基本攻击，也负责积攒武技剑势；武技启动后可以改变攻击形态。不能再把“必须所有时候只保留原版攻击”当成限制，去否定用户已明确设计的替代形态。

剑势分三档，每档具有不同攻击方式。用户明确了一档启动后停止原版攻击；此前“每个种族提供新的攻击方式”的总体方向与此一致。启动的具体输入、选档和消耗尚未确定，不自动继承WJ1的按键与操作。

## 已确定的羁绊：1／2／4种

| 当前有效不同武技剑数量 | 剑势机制开放程度 | 生效范围 | 支援奖励 |
|---:|---|---|---|
| 0 | 不获得武技提供的剑势攻击体系 | 其他种族照常按各自规则生效 | 不提供武技贡献 |
| 1 | 激活剑势，最高可到二档；一档刺剑与二档巨剑均能使用 | 仍限武技主攻使用，具体事件资格接入时细化 | 增加共用支援剑位 |
| 2–3 | 最高提高到三档，开放时停突进终式，同时提高剑势伤害 | 仍限武技主攻使用 | 2种档再次增加共用支援剑位；3种没有额外新档 |
| 4及以上 | 完整三档剑势，不再要求继续凑武技族才补齐核心玩法 | 不限武技组，任意当前可寄宿的主攻武器均能使用整套机制 | 4种档再次增加共用支援剑位 |

“1种最高二档”是两种完整攻击形态都开放，不能实现成第一种只有身后刺剑、等2种才补二档巨剑。两种已经开放三档终式，不能把时停再藏到四种、全收集或更高档。

“2种提高剑势伤害”的具体比例尚未指定，不能沿用WJ1或擅自写成50%/翻倍。新增支援每档给几格也未指定；不能把“每档都加支援”自动解释成每档恰好1格，导致四把武技剑最终只有三格可放。

四种的“不限武技组”覆盖整套攻击体系的使用资格，包括基本攻击积攒、启动、身后飞剑、巨剑、终式与相关效果。不能只把额外伤害开放给其他武器，而充能或三档演出仍要求武技剑在主槽。具体伤害公式与联动细节仍另定。

## 四把纯支援的硬性要求

目标配置是：**任选四把不同武技剑放进实际有效的共用支援，所有主攻槽都可以放玩家想用的其他可寄宿武器。** 在这套配置下，武技完整三档必须可蓄势、可启动、可完成演出和伤害；不要求某把武技剑额外留在主槽、传奇槽或奖励主槽。

- 武技主攻和武技支援共同参与不同武器种类计数，支援不是只提供一个名称或图鉴解锁。
- 同种武器不同词缀/实例不能凑出四种，旧取回数组及未真正开放的物品不能伪造羁绊。
- 支援武器提供族玩法与实际已定义特性；不因本条自动提供其面板伤害、武器攻速或独立普通主剑。
- 四种通用化后，主槽武器保留自己的身份、伤害与已有特性，不需要被改成武技族。
- 四种已经是本族核心玩法的完全体。以后即使设计额外收藏奖励，也不能以“全收集”名义补上本应四种就能拥有的必要动作。
- 取下后只剩三种时，不限族能力停止；主槽全为其他族时，不能沿用先前四种资格继续蓄势或启动。已在执行中的动作如何安全收尾单独定义，不让时停/位移残留。

### 当前支援算法需要处理的问题

当前 `SoulSupport.Capacity` 从基础主槽作为种子，再逐步接纳已开放支援。它只注册木质与矿石；这次并未修改代码。未来接入武技时，仅增加一个1／2／4计数器不足以兑现纯支援目标。

需要验证：当武技贡献来源全部在支援、主槽没有任何武技，甚至主槽也没有木质/矿石时，支援容量和武技资格不能在重算、移动、存读档后一起归零。也不能靠忽略取回槽隔离或把所有暂停物品直接计入来修补。

共用支援的起始容量、每档奖励数量，以及纯支援配置的配置/重算规则需要形成一致实现，具体方案尚未选定；本轮不擅自新增永久槽或修改木质/矿石奖励。若实现仍需另一个种族常驻主槽来维持四把武技支援，应明确判为未达成目标，不能交付成“已经支持任意主攻”。

## 以后新种族的设计参照

用户要求以后种族也可参照这一结构：用少量本族武器开放本族新攻击方式，并在较低投入时开放给其他主攻武器；本族构筑能够在共用支援中完成，让主攻选武器的自由保留。

武技具体采用已确定的1／2／4。其他新族应沿用“少量支援、核心机制完整、可通用化、逐档贡献共用支援”的原则，具体数量与动作另行设计，不由本页批量定成同样的剑势或同样的三档攻击。当前已实装木质/矿石不因这条方向被自动回退或重做。

## 四段攻击流程

| 状态 | 入口与攻击 | 命中/演出结果 | 退出说明 |
|---|---|---|---|
| 基本攻击 | 使用现有原版天顶式攻击命中敌怪 | 有1种武技可蓄至二档，2种起可蓄至三档；4种起其他族主剑也能使用 | 玩家启动剑势后的形态规则如下；具体切档方式待定 |
| 一档剑势 | 启动后停止原版攻击；每次攻击在玩家身后召唤3–6把飞剑 | 飞剑旋转后刺出；命中Boss后不消失，留存并造成持续减益 | 持续时间、退出与资源消耗待定 |
| 二档剑势 | 在一档基础上，释放所有武器后，自身召唤天顶巨剑并斩出强烈一击 | 巨剑斩击打飞所有已刺入的飞剑 | 随后恢复正常；“正常”指回基本攻击还是继续一档，待明确 |
| 三档剑势 | 召唤天顶巨剑后，玩家攻击触发时间停止，随后猛地冲向敌怪斩击 | 剑身在敌怪体内造成多段伤害；迟滞约2秒后猛地斩出，剑气跟随斩出，造成巨大伤害和剑痕 | 时停结束点、剑痕后续效果与最终返回状态待定 |

三档是“不同剑势档位的攻击方式”，目前不能擅自写成每次都强制从一档演完二档再到三档，也不能默认一开三档就把三套效果无条件同时触发。

## 一档：身后成剑、旋转、刺入

确定顺序：

1. 启动一档，停止原版攻击的发射。
2. 每次攻击在人物身后召唤3–6把飞剑。
3. 飞剑先旋转，再刺向敌怪。
4. 命中Boss不会直接消失；后续二档所说的“已刺入飞剑”来自这一过程。
5. 刺入阶段造成持续减益。

实现时应把“身后形成”“旋转准备”“刺出”“命中后刺入留存”分开表现，保留可辨认的武器模型。不能只在Boss中心生成一个静止伤害点，就声称已实现背后出剑与刺入。

3–6把的成长来源尚未指定。它可能与剑势、种族数量或其他进度有关，但本页不代替用户选择，也不擅自规定寄宿不足3把时重复生成、留空或补幻影。

持续减益的类型、伤害/强度、叠加口径尚未指定。“命中不消失”不等于允许无限多投射物永久堆积，也不等于用户已经确认无间隔帧伤；这两项需要作为具体玩法规则继续设计。

## 二档：巨剑斩击、打飞刺剑

确定顺序：

1. 保留一档的飞剑过程。
2. 释放所有武器后，玩家自身召唤出天顶巨剑。
3. 巨剑斩出强烈一击。
4. 这一击打飞所有已刺入的飞剑。
5. 然后恢复正常。

“打飞”是这次攻击的实际表现，不能只删除Boss上的剑并放一次爆炸替代。巨剑与刺剑应在同一时刻产生明确的联动反馈。

“所有武器”采用的集合尚未指定：基础主槽、当前有效主攻、支援所代表的武器，以及一轮3–6把飞剑之间怎样对应，都需要明确。打飞后飞剑的方向、是否继续伤害、穿透、回收方式也未确定，不能冒充用户已指定为朝外散射或全体齐射同一目标。

## 三档：时停、突进、剑身多段、迟滞斩出

严格保留用户描述的时间顺序：

1. 召唤天顶巨剑。
2. 玩家攻击触发时间停止。
3. 玩家猛地冲向敌怪并斩击。
4. 剑身在敌怪体内造成多段伤害。
5. 迟滞约2秒。
6. 猛地斩出。
7. 剑气跟随斩出，造成巨大伤害与剑痕。

**约2秒明确属于剑身进入敌怪后的迟滞段。** 不能直接拿它作为整个时停的总时长，或把时停结束、迟滞结束和剑气结束合并成同一个未经确认的节点。

“玩家冲向敌怪”包含玩家本体的动作，不能只生成一把会冲刺的巨剑代替。具体由玩家位移还是带有替身演出、位移过程怎样操作与防护，需要结合后续选择确定；当前确定的目标体验是玩家持巨剑冲入斩击。

时停不是调用全局暂停后让整套演出也停止。实现需要明确哪些对象冻结、哪些对象继续演出。对Boss、普通敌怪、敌方弹幕、友方攻击、队友、世界计时的影响范围尚未确定，多人适用方式也未定。

“巨大伤害”和“剑痕”是确定的收尾目标，但没有指定倍率、暴击规则、剑痕是否持续伤害、后续触发或易伤，不能擅自套用现有连斩祝福的剑痕效果。

## 尚需明确的规则

| 问题 | 当前明确部分 | 尚未确定部分 |
|---|---|---|
| 武技族解锁 | 1／2／4种：二档上限、三档及伤害提高、整套不限族；三档都增加共用支援，四把纯支援可完成 | 各档支援具体数量、纯支援容量配置与重算方案、伤害提高比例 |
| 剑势积攒 | 基本攻击敌怪可以积攒，有三档 | 首击/连续命中的计数、三档阈值、伤害是否影响积攒、形态期间是否继续积攒 |
| 启动与选档 | 一档有明确“启动”动作，三档有攻击触发节点 | 按键、最高档自动选择还是玩家选档、是否允许保留高档用低档 |
| 消耗与返回 | 二档斩击后恢复正常 | 每档消耗、持续时间、是否可取消、正常具体指哪种状态 |
| 身后飞剑 | 每次3–6把，旋转后刺出 | 数量成长、所代表的武器、瞄准方式、刺入数量与留存周期 |
| 一档减益 | Boss被刺入后受到持续减益 | 类型、强度、叠加及对普通敌怪的行为 |
| 巨剑与打飞 | 所有武器释放后巨剑斩击并打飞已刺入飞剑 | 武器集合、打飞运动与后续伤害 |
| 三档时停 | 玩家攻击触发，允许继续突进与斩击演出 | 冻结对象、结束节点、多人处理、Boss恢复后状态 |
| 三档突进 | 玩家冲向敌怪，剑身多段，迟滞约2秒 | 目标选择、巨型/虫体敌人落点、碰撞与防护、空挥或目标死亡后的动作 |
| 终式伤害 | 强烈巨剑一击、多段、末斩、跟随剑气和剑痕 | 各部分伤害来源、倍率、命中间隔与结算关系 |
| 武器与其他系统 | 武技是新的攻击方式，其他族有其能力 | 与切换/独行等诅咒、祝福、矿石与环境触发的具体对应，不自动继承旧稿 |

这些未定项需要服务于上述演出与手感。记录未定不代表要给玩家增加额外资源税、冷却、复杂操作或强制风险。

## 后续落地边界

- 当前只是记录和整理；源码、游戏版本、正式模组、存档均未改变，不运行无关构建。
- 基本攻击保留现有逐剑伤害、轨迹与特效；用户明确允许武技启动后切换新的攻击形态，不能擅自把新形态压回只有原版飞剑。
- 飞剑应能保留对应寄宿武器的模型与来源身份；巨剑、多段、末斩与剑气各部分的伤害公式需要独立明确，不沿用WJ1的教授武器/主修副修公式。
- 武技的新投射物、附着剑、多段伤害和剑气需区分主攻事件与派生事件，避免一击递归生成无穷飞剑或反复刷剑势。具体哪些攻击能触发其他族特性另列规则，不一概切断所有联动。
- 时停和玩家位移涉及持续状态，需明确启动、取消、死亡、切图、目标消失与多人同步后的恢复；不得把残留冻结当成正常时停效果。
- 不改木质/矿石既有成员与全收集条件；武技采用用户新定的1／2／4羁绊，三档贡献共用支援，四把纯支援开放完整不限族玩法；具体每档格数另定，不能把WJ1的1/2/4/6/8/10与三格支援直接复用。

## 新增验收场景

| 配置/动作 | 必须成立 |
|---|---|
| 只有1种有效武技，武技剑作主攻 | 可使用一档与二档，无法蓄到三档 |
| 2种有效武技，主槽与支援混放 | 三档开放，剑势伤害提高；同类型重复不算第二种 |
| 3种有效武技，主槽全为其他族 | 不因超过2种就提前获得四种通用化 |
| 4种武技全部在支援，主槽无武技 | 完整三档可蓄势/启动/攻击，各主剑保留自己的身份 |
| 上述配置主槽也不含木质和矿石 | 不依赖其容量种子才能维持武技支援配置，仍达到纯支援目标 |
| 将最后一把武技主攻移到支援、切换人物持有状态、重载世界 | 满足四种的合法纯支援配置不掉层、不因重算使自身支援失效 |
| 从四种取下一把，仅剩三种 | 不限族停止；重新补齐后正常恢复，临时时停与演出状态能正确收尾 |
| 将四种武技放入停用或旧取回区 | 不能按纯支援配置算，不能伪造槽位与通用化 |

本轮只更新设计与验收要求，上述场景尚未在引擎或游戏中执行。
