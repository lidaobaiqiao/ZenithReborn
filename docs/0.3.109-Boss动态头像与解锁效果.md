# 0.3.109：Boss 动态头像与解锁效果

2026年10月28日。基线为0.3.108。用户指出特性详情的右侧留白很大，而激活条件只有一行，要求从官方中文 Terraria Wiki 获取 Boss 动态头像，显示击败前后的明暗状态，并在右侧说明解锁的属性。

## 玩家可见的变化

六个封印特性的详情下方，现在直接列出这组需要挑战的 Boss。左列显示头像、名称和这把剑魂的个人铭刻；右列按累计击败数量展示削弱、解除、祝福后的完整效果。未完成的头像与效果暗显，完成后头像恢复颜色并出现柔光；已获得的阶段点亮，当前阶段标注“当前生效”。普通武器、矿石、木质特性仍显示其真实寄宿条件。

同组 Boss 可任意顺序击败，因此目标列与阶段列分别判定。先打教徒和先打克苏鲁之脑都解锁切换的第一阶段，不能把某个 Boss 错当成固定阶段的专属条件。双子魔眼是一个目标，两只都完成才贡献一道铭刻；一只时显示1/2。旧档兼容解咒保留能力，但不会伪造已击败头像或提前获得祝福。未附着的剑魂显示“已解锁 · 待附着”，不宣称属性正在生效。

成长记忆保留六封印选择卡，展开后复用同一组头像与效果组件。宽屏左右排列，较窄的详情区先列目标再列阶段；保留各区域独立裁剪和滚动。

## 资源与模块归属

素材来自[官方中文 Wiki 的 Boss 页](https://terraria.wiki.gg/zh/wiki/Boss)。11个目标使用完整 Boss GIF；世界吞噬怪、骷髅王、毁灭者、史莱姆女皇使用清晰主体图配小型 Wiki 动态表情，主体附轻微悬浮。没有把低分辨率表情直接放大成主体，也没有把静态主体谎称为完整身体 GIF。

`Assets/UI/BossPortraits/sources.json`登记来源、原文件哈希、帧数和帧时长。19张PNG包含15个动画图集和4张补充主体，保留原始 GIF 的每帧时序；统一包围盒避免逐帧裁切抖动。游戏只读取本地资源，不访问网络。原图归 Terraria / Re-Logic 所有，Wiki 文件页标注游戏媒体版权；Wiki 文本的共享许可不被当作图像授权。原始下载归档位于`artifacts/boss-unlocks-0.3.109/wiki-originals/`。

- `SoulBossAnimation`：帧时序、循环与图集坐标。
- `SoulBossPortraits`、生成的`SoulBossPortraitCatalog`：素材映射与资源绘制。
- `SoulBossUnlocks`：只读个人铭刻、部分完成、旧档与阶段状态。
- `SoulCurseDescriptions`：从原`SoulCurses`移出的统一说明，当前和未来阶段共用。
- `SoulUIBossUnlocks`：目标列和阶段列绘制、文字测量与窄屏排列。
- `SoulUIArchive`：特性详情接入；`SoulUICurseUnlocks`：成长页封印选择与展开。

原`SoulCurses`的组别、铭刻位、数值与生效规则保持；提取按指定阶段求值的只读入口，供未来效果说明复用。没有临时修改剑魂的进度来计算预览，也没有在 UI 复制一套属性数值。93个既有C#文件、43项旧Assets逐字节保持。`SoulUI`入口与108完全相同，成长页中的封印绘制移到归属明确的文件。

## 验证

- 两个项目用tModLoader原生编译器构建，0错误、0警告；1182项对应UI检查通过。
- 新增检查覆盖六组所有击败组合、先打列表后项、双子部分完成、旧档兼容、未附着与原始GIF帧时序。
- 最终33张正式UI实际GPU输出，包含8张固定时间动画样本，覆盖六组未完成/全部完成、部分完成、反向击败顺序、640/960窗口及125%UI缩放。
- 所有渲染前后剑魂网络快照一致。两种不同的首杀顺序在同累计数时，右侧奖励列逐像素一致；脑头像的8个时间样本包含4种不同的实际画面。
- 头像明暗统计只取原图Alpha确定的不透明内部，排除暗底和圆环。最初整块区域均值受背景面积影响，不能代表头像亮度；修正采样区域后保留原比值标准，没有通过降低阈值取得通过。

第一次客户端启动因Steam未运行而失败，无GPU报告。用户完成登录后重新验证。缩放检查最初直接将物理分辨率交给UI绘制，造成夹具重复缩放；修正为正式UI层使用的逻辑尺寸，并加入缩放边界断言，最终画面已核对。构建工具仍重新编译自有Shader，但字节相同时不重复覆盖`.fxc`，避免无关UI构建反复写入未变化的生产资源。

证据目录：`artifacts/information-ui-0.3.109/boss-release/`。摘要与改动审计：`artifacts/boss-unlocks-0.3.109/`。动画预览`boss-unlock-preview.gif`由本轮实际GPU样本组成；图中使用临时剑魂，不能当作用户角色进度。
