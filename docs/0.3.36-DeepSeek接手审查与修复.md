# 0.3.36 DeepSeek接手审查与修复

日期：2026-10-21。以交付0.3.32的源码压缩包作对照，核对到DeepSeek的0.3.35本地源码及正式安装包。

## 接续状态与用户确认

审查开始时，build.txt和正式模组均为0.3.35，安装哈希为`56d4106796f19e59681433e8ccc4ce3e799cf6d145a18e6ce43aa27595dc69fd`，与安装记录一致。源码的主要变化为：

- 0.3.33新增实际传奇难度专属主攻槽34，独立LegendaryHost及保存／网络／重铸／HERO保护。
- 0.3.34把S6并回支援弧；每把主剑首次命中独立积攒飞剑，取消同魂／目标共用10帧门槛；主槽矿材及Active主剑飞剑触发不受切换过滤，支援仍受约束。
- 0.3.35修正传奇槽被识别为支援槽的说明问题。

用户已在本轮明确确认上述传奇槽、取消共用冷却、主攻飞剑切换例外三项玩法变化，本轮保留，不按0.3.32旧限制回退。150%基础飞剑伤害、两族支援奖励累加、共享两格全收集奖励未被改回。

## 发现及修复

| 问题 | 复现／影响 | 0.3.36处理 |
|---|---|---|
| 多支援节点重叠 | 11格塞进80度弧，正常视口也出现多对实际点击框重合 | 小数量保留外围支援弧，大数量沿下方外围展开；短视口适配节点尺寸 |
| 掉层后无法准确取回 | 按当前SupportCapacity排位，0／1格时多个仍保存物品的暂停槽挤到同一点 | 按VisibleSupportCount排位；真实点击回归逐个取回暂停的11格 |
| 未来编号冲突 | S15的旧公式得到34，与传奇槽冲突；交换入口又固定只允许0～34 | 支援双向映射跳过34，交换按实际可见／保存数量验证；不移动存档物品 |
| 图鉴与代码不同步 | 实际已无10帧门槛，图鉴仍写有冷却与切换限制；主槽材质分项还使用TraitMains | 统计分项改用真实Active主槽，说明明确主攻例外和支援限制 |
| 专项未接入全量 | 传奇检查只在独立环境变量模式运行，常规7964项不含该项 | 传奇专项并入常规回归，新增布局、暂停取回、保留编号及图鉴一致性检查 |
| 交接入口过时 | 顶部虽提0.3.32，正文仍把17槽／旧冷却当“当前必须遵守” | 两份入口重写为当前规则，历史放回版本文档 |

仅修技术与交接问题，不另加战斗数值或新的种族机制。后续超过11格的额外支援允许滚动延展，不能再占用传奇34，也不能激活旧扩展取回数组。
