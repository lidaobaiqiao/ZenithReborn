# 0.3.12 生效特性与图鉴

日期：2026-10-20。信息区与剑魂物品提示只显示当前构筑生效的特性，不列未寄宿木剑、未激活森林之力或未获得的祝福。

按P后查看「生效特性」，或切换「特性图鉴」。图鉴列出已实装的木质、矿石、剑术与成长特性，支持全部/分类查看，并标注当前是否激活和激活条件。尚未实装的M1候选、停用扩槽和不可达全套奖励不会作为已开放特性列入。

生效表示当前有效寄宿/成长状态允许该机制；命中触发类仍须实际命中和满足目标、间隔等条件，不把它写成正在回血或正在施加状态。纯支援矿石没有矿石主剑时，不显示百炼飞剑生效。预览、未解锁、暂停森林槽与旧扩展取回区均不计入。

正常界面四页：武器寄宿、生效特性、成长记忆、特性图鉴。有旧扩展物品时才额外显示旧物取回页；它仍只可取出，不提供新槽位。图鉴浏览不改变保存、战斗或成长，17有效槽保持原样。

验证：编译、有效槽/支援判定、真实物品提示过滤、全套取下失效、图鉴分类不改存档，以及新增页签后的旧物取回检查。图形客户端和真实多人结果另记，不能以引擎断言替代。

结果：生产与检查项目编译通过，完整隔离检查1861项断言通过。图形客户端确认生效页显示混合构筑8项特性，未激活森林之力只出现在图鉴；图鉴页、分类控件、状态标记和换行正常。筛选点击时隔离角色被史莱姆击杀，未把该次点击记为成功；分类与动态过滤由引擎检查覆盖，真实多人未测。
