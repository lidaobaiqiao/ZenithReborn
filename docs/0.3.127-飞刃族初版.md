# 0.3.127：飞刃族初版

用户提出飞刃族设计：给寄宿后没有远程手段的纯挥砍剑补上属于自己的远程攻击方式；弹幕剑自带远程不收，奇形怪状的非常规武器需要逐把特殊处理暂缓。动机与名册依据见[飞刃族FB1](飞刃族FB1-候选名册与攻击方式.md)与[飞刃族F1](飞刃族F1-掷刃与印记.md)；名册由引擎普查产生（`FlyingBladeSurveyCheck`，校验样本魔光剑 shoot=974、草剑 shoot=976 与用户指认一致）。

**印记为用户认定的核心设计，本轮留白不做**，待用户思考后单独成轮；相关结构未进入生产包。

## 实现

- `FlyingBladeFamily`：31 把名册与激活判定，与神圣天堂同构——族成员有效寄宿且至少一把有效主攻时激活，支援槽计入，切换诅咒过滤沿用不绕过。
- `FlyingBladeHand`：手中蓄能。每 0.3 秒（18 帧）叠一把，弹容量 = 独行诅咒役使上限（诅咒 2 / 削弱 3 / 解除 4 / 祝福 10）；挥臂时经 `SoulSwingPlayer` 现有攻击时机一次性掷出全部，以瞄准线为中心每把相隔 5°，掷后清空重蓄。仅本地玩家生成弹幕。
- `FlyingBladeShot`：三阶段弹幕——直线飞出（速度 12、射程 600 像素，未命中飞满同样转入旋转）→ 原地旋转三圈（45 帧，持续伤害每 8 帧一次、直击的 50%，8 帧共享免疫）→ 直线收回（伤害归零，回到玩家身边消失）。外观直接使用寄宿武器原版贴图逐剑区分，不新增材质管线。
- 命中伤害走 `SoulCombat.BladeDamage` 现有结算；初版不与祝福、环境、剑灵联动。

## 验证

两项目编译零错误零警告。隔离服务端 17 项行为夹具（`ZENITH_FLYING_BLADE_CHECK`）：名册边界与 31 把计数、名册-普查一致性（逐把 shoot==0）、主槽/支援激活与失效、蓄能节奏（首把、18 帧间隔、独行上限待命）、齐射数量与清空、相邻 5° 扇面与速度一致、直飞转旋转、45 帧旋转存活、转入收回、收回期无伤害、暂定初值断言。普查专项 `ZENITH_FLYING_BLADE` 输出 188 项引擎数据。

夹具驱动方式备注：手动调用弹幕 `AI()` 只跑行为逻辑，位置积分由真实 `Update()` 完成，夹具中手动补积分模拟位移；`FlyingBladeHand` 提供时钟与瞄准点注入缝供夹具使用，生产路径不受影响。

## 边界

未验证：实际游戏画面、自然操作、多人、31 把全部武器的逐一实机弹幕复核（舌锋剑等 shoot 字段外特殊机制待查）、性能、美术观感。印记（用户核心设计，思考中）、跨族联动、特性界面条目均未实现。所有数值为暂定初值，非用户定案。

## 热修（2026-11-01 当日）

首装包在客户端加载阶段抛 `MissingResourceException: FlyingBladeShot`：新弹幕类既无贴图文件也无 `Texture` override，tModLoader 找默认资源路径失败。隔离服务端夹具未抓到此问题——**服务端不加载图形资产，资产完整性是服务端夹具的固有盲区**。修复为 `Texture => "Terraria/Images/Item_" + ItemID.FlyingKnife` 占位（绘制仍由 PreDraw 用寄宿武器贴图接管，报错中的 SwordSpark 仅为模糊匹配建议，其贴图一直在）。已重新打包安装，运行中客户端需重新加载模组。教训：新增 Mod 类型必须有贴图资源或显式 override，该项只能由客户端加载或资产清单校验覆盖。
