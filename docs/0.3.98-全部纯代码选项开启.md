# 0.3.98：全部纯代码选项开启

按用户要求，将贴图相关项以外能独立生效的选项全部设为默认开启。延续纯代码输入限制，不开放屏幕采样。

## 当前生效项

- 分支：B1主飞剑拖尾带面、B4独立消散片、B5飞行表现入口（只执行代码光照）。
- 分支内部：B4-1本体、B4-2消失曲线、B4-3尾部吞噬、B5-2剑身光照、B5-3玩家光照。
- 带面：P01～P19及P24，共20项；此次恢复P18宽高光包络及P24沿迹条纹。

56个面板项中共28项默认开启。B2剑影、B3星芒、B6碎光及其依赖这些贴图分支的修饰项保持关闭；B5-1贴图粒子单独关闭。P20、P25的贴图输入项、P21～P23屏幕输入项及B7全组继续禁止。

## 模块归属

默认值、允许策略仍集中在`VfxIsolation`。B5从整体禁止改为允许入口，其贴图粒子细项标记外部输入，代码光照允许；细项新增与分支和带面一致的允许判定，全开和逐项面板切换都遵守这一策略。

`SoulZenithEffects.EmitFlying`在粒子发射点增加纯代码硬限制，直接改粒子开关也不能绕过；两处`Lighting.AddLight`仍独立执行。其他贴图分支保持既有总闸。没有新增粒子或渲染框架。

Ctrl+F10恢复当前纯代码全开预设；Shift+F10打开所有允许项；F10全关。原来的“Ctrl恢复P18/P24关闭”提示已更新。97内缘轮廓、95连续朝向、Shader源码与强度参数、攻击、伤害和存档均未修改。
