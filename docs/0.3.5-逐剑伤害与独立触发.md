# 0.3.5 逐剑伤害与独立触发

按本次确认的设计，保留各寄宿武器分别计算的模型，并取消旧的√剑数分摊。撤回0.3.4的统一天顶伤害下限与共享原版属性模板。

## 每把剑分别计算

主剑影基础伤害＝该寄宿武器经玩家加成后的伤害×剑魂成长效能，向下取整、最低1。效能沿用原成长：附着后65%，每个节点增加4个百分点，永久复生后110%。

不使用其他寄宿武器的平均伤害作为该剑的伤害，不设天顶剑下限，也不除以寄宿剑数。增加一把强剑不会抬高弱剑的单次伤害，取下另一把剑也不会通过取消分摊来提升剩余剑的单次伤害。成长阶段变化及原有明确的支援/羁绊效果仍可影响强度。

各剑保留自己的寄宿前缀、暴击、击退、外观尺寸和飞行时长。飞行时长沿用原有18至55帧限制。单次挥臂仍共用有效主攻剑的平均使用间隔，但已不固定采用0.3.4的原版天顶五剑间隔；五段逐把生成和跨挥臂轮换规则保留。

剑魂物品面板显示平均参考伤害，实际命中由该次出剑的寄宿武器计算，已在提示中说明。主剑魂前缀不再作为原版天顶模板复制给每把剑；寄宿剑自身的前缀参与该剑的属性计算。

森林成长继续只增强主剑伤害；专属弹幕以该次主剑的基础伤害计算。支援槽继续只贡献特性与羁绊，不作为独立主攻剑。

## 重复命中与触发

所有阶段的剑影都采用每剑独立局部免疫，同一剑对同一敌人间隔8帧可再次命中，不再终生限一次。另一把剑不共享该剑的命中冷却。未获附着的残魂仍不能攻击。

附魔剑与星怒不再共用角色的一个45帧冷却。现在按持有者、剑魂ID和武器种类分别计时：两种特性可分别触发，同种特性仍保持45帧间隔。各自剑气/落星继续使用其来源剑的30%基础伤害。其他专属弹幕、木系应用间隔、传播预算等既有规则保留。

## 检查

已用隔离tModLoader引擎检查：

- 低级剑无天顶伤害下限；加入或强化强剑不改变低级剑的单次伤害。
- 实际生成的剑影保留各自伤害、暴击、击退及飞行时长。
- 通过真实`Projectile.Damage()`验证不同剑可独立命中，同一剑在冷却后可再次命中；冷却内不会重复造成伤害。
- 两种灵能特性同帧各触发一次，各自冷却期间不连发，45帧后分别恢复；子弹幕使用各自来源剑的伤害。
- 保留五段轮换、网络序列化、木系与成长系统回归，并记录原版对比数据供观察。本版不设置达到原版天顶输出的硬性指标。

对比数据在`artifacts/damage-comparison.json`；0.3.4历史数据另保存在`artifacts/damage-comparison-0.3.4.json`。本轮未实测图形客户端或真实多人联机。

复现命令：`pwsh -File checks/run_wood_checks.ps1`。
