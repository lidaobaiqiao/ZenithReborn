# 0.3.57 真实轨迹与巨剑材质拖尾

用户要求把普通主飞剑拖尾换成武技巨剑斩击的材质质感。接手时源码仍标0.3.56，但正式包哈希已变为`17f9e049271bdb522482df897d058632f4c7c79903889982e9edd428e8c28573`，与上一份0.3.56安装记录不同；接手前源码与该包单独备份在`artifacts/takeover-before-0.3.57/`，没有回滚其他人的改动。

## 问题与实现

接手代码的`SoulBlade.DrawRibbonShader`只读取轨迹首尾位置相对玩家的角度，再调用`DrawOrbit`画玩家中心的圆弧。它丢弃中间位置与剑身朝向，无法代表天顶飞剑实际扫过的区域。更早的`TrailSlash`则将同一月牙四边形逐段拼接，也不是连续材质带面。

现在`SoulMaterialTrail`沿实际记录的剑中心和旋转，插值连接剑身横截面；亮边跟随剑尖，暗侧沿各帧剑身方向展开。使用32次历史更新（每帧两次更新，完整历史约16游戏帧），旧端收窄。传入GPU的顶点位置就是该带面，完全不需要玩家圆心或假定固定半径。

纹理坐标单独映射到原始OniCrimsonSlash的极坐标刃面：纵向对应尾→头，横向对应破碎暗侧→白热刃缘。这样保留成熟材质的笔刷、流动、非对称亮暗与尾部侵蚀，同时形状仍由剑实际走过的位置决定。一把剑一次连续三角形提交，不逐段画独立月牙，不新增渲染目标、着色器或游戏依赖。

颜色继续读取`SoulVisuals.Tint(itemType)`。现成编译Shader、笔刷、噪声及MIT许可证保持原样；使用私有Effect克隆。普通攻击时序、伤害、碰撞、网络、存档和矿石H4剑身组未改。

`SoulVisuals`复用现有完整状态恢复入口，恢复纹理／采样器0～2、混合、深度、光栅、裁剪与顶点绑定。清理掉未使用的BasicEffect字段。通用残影不再给剑魂容器再叠一把虚构剑，也不把摆动类工具当近战剑；测试剑保留已有内容身份与配方，移除进世界自动赠送。
