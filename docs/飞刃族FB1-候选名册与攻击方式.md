# 飞刃族 FB1：候选名册与攻击方式

用户 2026-11-01 提出飞刃族设计，动机明确：**弹幕剑自带远程手段，而纯挥砍剑寄宿后只剩飞剑齐射一种玩法，武器之间手感同质。飞刃族给这些没有远程攻击手段的剑补上属于自己的远程攻击方式。** 因此名册只收无弹幕的纯挥砍剑；一切自带弹幕的剑不需要这个族，奇形怪状的非常规武器需要逐把特殊处理，不入首批。

名册由引擎普查产生（`artifacts/flying-blade-survey.json`，188 项全量；校验样本魔光剑 shoot=974、草剑 shoot=976 与用户指认一致），按获取方式分两组，数据文件 `artifacts/flying-blade-candidates.json`。

## 攻击方式

- 弹容量等于独行诅咒役使上限：诅咒 2 / 削弱 3 / 解除 4 / 祝福 10。族的力量挂在封印解除进度上，不另立成长线。
- 每 0.3 秒向手中叠一把飞刃，叠满待命；释放后清空重蓄。
- 普通攻击键掷出手中全部飞刃，以瞄准线为中心每把相隔 5°，满编 45° 扇面。
- 刺中敌人后旋转三圈（暂定每圈 15 帧）后收回；旋转期间持续伤害，暂定每 8 帧一次、直击的 50%，沿用 8 帧共享免疫。
- 旋转过程叠加印记；印记方向见下节。
- 回收为直线返回，途中无伤害，与矿石族折返再攻区分。

宪法自检：触发走普通攻击键而非独立按键，全程没有玩家招式；飞刃是各剑自己掷出的刃，力量溯源清晰。

## 印记（方向未定，两案并列待勾）

- **案 A · 族内消化**：印记只属于飞刃族内部闭环，例如叠满 5 层引爆一次范围伤害或增伤窗口。影响面小，先跑起来，但族与族之间没有咬合。
- **案 B · 跨族齿轮**：印记是可被其他族攻击消费的状态——落星、剑影、代理攻击打在带印目标上有额外行为。飞刃族成为"标记手"，种族协作叙事最浓，但牵动神圣天堂、矿石、剑灵三条线，验证面大。
