# 0.3.110：剑位选择与点击穿透修复

2026年10月28日。根据用户实际界面反馈，修复寄宿主页选择剑位后仍显示剑库候选，以及滚动内容截走固定按钮点击的问题。基线为已安装的 0.3.109。

## 原因与处理

1. 选择中央剑阵时，旧实现只更新剑位编号，未清除剑库候选；右侧始终优先显示候选武器。现在点击任意中央剑位，包括再次点击当前剑位，都会退出候选预览并显示该剑位的实际武器。需要换入时，先选剑位，再点剑库武器预览并确认；临时选择不改变物品或存档。
2. 详情区原本只裁剪绘制，按钮的鼠标命中仍使用未裁剪的矩形。成长路线虽然被固定操作区遮住，仍可能先消费点击。`SoulUIInformation` 现在为信息组件维护与绘制一致的界面裁剪范围，嵌套裁剪取交集并在结束时恢复；不可见或被裁掉的区域不接收悬停和点击。固定寄宿、取回按钮继续使用各自的区域，成长按钮可见时仍正常打开。

候选清理归 `SoulUIArmoryInteraction`，剑位选择归 `SoulDomainUI`，滚动裁剪及命中归 `SoulUIInformation`；确认交换、原物品身份、前缀、背包去向和原有校验不变。剑库提示文字同步说明操作顺序。

- 修复后两项目原生编译均为 0 错误、0 警告；1202 项对应检查通过。实际 GPU 生产界面输出 33 张独立画面，覆盖重复选中与切换剑位、固定寄宿和取回、禁用按钮、滚动偏移 24、窄屏和 125% 缩放。寄宿/取回检查使用临时人物和真实物品交换，确认旧剑去向及候选对象身份。
- 特性列表、成长节点、封印卡和环境图谱的可见点击仍正常；浏览原始测试剑魂前后的快照一致。图形报告：`artifacts/information-ui-0.3.110/interaction-release2/gpu.json`；与正式包绑定的汇总：`artifacts/ui-validation-0.3.110.json`。
