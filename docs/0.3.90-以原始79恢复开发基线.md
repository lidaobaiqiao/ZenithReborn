# 0.3.90：以原始79恢复开发基线

2026-10-25，用户在纠正“发光玻璃主要应由着色器实时形成”的方向后，明确要求「所以需要以79版为基础」。本轮落实开发基底选择，不继续以80/89的环境反射调参方案开发，也没有另行设计或实装一套新外观。

## 当前实现

生产目录以`artifacts/ZenithReborn-0.3.79-source.zip`为唯一恢复依据。120项生产文件与原始79逐字节相同，仅`build.txt`版本标记为0.3.90，用来区分本次恢复动作。包内81项源码、着色器和JSON也与工作区相同。

- 恢复79的ZRSwordFlow、ZRGlassScreen、ZRMaterialSurface源码/编译件/构建清单，以及SwordFlowMaterial和SoulSceneRefraction。
- 从生产路径撤下80的GlassR3贴图、89新增平滑反射图及来源数据、后续新增的SwordSpritePalette；已完整备份，没有删除收藏。
- 保留79已有的三个可见剑影实体伤害、独立短尾、运动、攻击、武技、矿石H4、槽位、存档与个人进度。
- 本轮恢复79原配色。用户此前要求“颜色跟随实际剑身”的需求仍保留，但88的取色实现未混入当前基底，也不能称本轮已经实现。

后续发光玻璃从79继续：通过着色器梳理透射、曲面反射及有色自发光；贴图只作为必要的材质输入。尚未确定或实装新Shader参数、美术外观和新的日夜响应，不能把本轮基底恢复说成发光玻璃重制完成。
