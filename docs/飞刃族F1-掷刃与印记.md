# 飞刃族 F1：掷刃与印记（设计草案，全部数值为暂定初值）

> 状态（2026-11-01）：掷刃部分已实装并安装为 [0.3.127](0.3.127-飞刃族初版.md)，17 项隔离夹具通过。**印记是用户认定的核心设计，本轮留白未实现**，用户思考中；下文印记段仅作设计留存，勿当已实装。

## 动机与宪法检验

飞刃族不是又一个收集种族，是一张补票：**给寄宿后没有任何远程手段的纯挥砍剑，补上属于自己的远程攻击方式。** 现状是无论寄宿什么，攻击都归于统一的飞剑齐射——握着罗马短剑和握着彩虹猫之刃的手感不该是同一个。弹幕剑天生就有远程，不缺；因此本族只收引擎核验无弹幕的纯挥砍剑（普查数据见 artifacts/flying-blade-survey.json 与 flying-blade-candidates.json，检查代码 FlyingBladeSurveyCheck.cs）。

天顶剑核心检验：飞刃的力量溯源到"这把剑自己掷出的刃"，不是玩家招式；弹药量绑定独行诅咒的役使上限——封印解除即编制扩充；触发走普通攻击键，无独立按键、无 HUD、无凭空招式。过尺。

## 机制（暂定初值，非定稿）

| 项 | 初值 | 说明 |
|---|---|---|
| 弹容量 | 独行诅咒役使上限：诅咒 2 / 削弱 3 / 解除 4 / 祝福 10 | 不另立成长线，随六诅咒进度自然扩编 |
| 蓄能 | 每 0.3s 向手中叠一把 | 释放后清空重新蓄；蓄满待命 |
| 释放 | 普通攻击键掷出手中全部飞刃 | 与御剑左键共用攻击时机 |
| 扇面 | 以瞄准线为中心每把相隔 5° | 满编 10 把 = 45°；2 把 ±2.5° |
| 弹体 | 复用原版飞刀弹幕速度；外观逐剑取色（沿用矿石族飞剑的取色路径） | 统一行为、逐剑颜色 |
| 命中后 | 刺入旋转三圈（每圈 15 帧，共 45 帧），随后直线收回 | 收回途中无伤害，与矿石折返再攻区分 |
| 持续伤害 | 旋转期每 8 帧一次判定，伤害为直击的 50% | 沿用 8 帧共享免疫帧 |
| 印记 | 直击与旋转 tick 各叠 1 层，持续 3 秒（180 帧） | 族内消化：满 5 层触发一次爆发，伤害为该剑直击的 200%，小范围（96px）。跨族消费（落星/剑影对带印目标特殊行为）为候选方向，初版不做 |

## 触发（与神圣天堂同构）

族内成员有效寄宿、且至少一把有效主攻剑时激活；支援槽成员计入。切换诅咒的"仅首把主剑生效"沿用现有过滤，不绕过。

## 职责划分

- `FlyingBladeFamily`：名册与激活判定（仿 HolyHeavenFamily）
- `FlyingBladeHand`：玩家侧蓄能状态（手中飞刃计数与叠层计时）
- `FlyingBladeShot`：飞刃弹幕（掷出、扇形、旋转、收回）
- `FlyingBladeMark`：印记状态与爆发
- 绘制与取色复用现有 SwordFlow/取色路径，不新建材质管线
