# 0.3.80候选：玻璃反射与同源材质R3

用户认可0.3.78的剑影/短尾形态和0.3.79的剑影伤害，指出高光像画上去、主体缺乏通透感。本轮只改材质与必要接入，不改几何、剑影间距、伤害、碰撞、飞行、槽位或保存。

## 已查明的原因

默认剑流存在独立于法线的`razor/innerRim/reflectionAt/fineReflection`坐标亮线，叠加后形成稳定白线。已有法线主要参与背景折射，并不决定这些高光。默认路径生成表面遮罩时还会大幅压掉被透射的背景，玻璃读起来像涂色膜。

部分已声明输入没有进入正式路径：高度贴图没有真正参与默认法线；默认色场先绑定、随后被空逐剑绑定覆盖；默认路径不输出既有的光学属性/透射缓冲。反射使用的现场快照仅在隔离测试启用，正式原生合成下不能把备用白纹理当作现场环境。屏幕泛光原先从世界亮点扩散，也会使材质亮度受背景白块影响。

## 新材质

- 取消坐标白线，改用曲面/倒角法线、GGX微表面分布、粗糙度与菲涅耳形成方向性高光。
- 环境反射按反射方向采样新中性全景，粗糙度控制过滤；最终合成可做小范围当前帧屏幕反射近似。不是三维场景追踪SSR。
- 内部保留原IOR1.5、粗糙度0.08、透射0.55、覆盖度1、虚拟厚度72；通过偏折背景、吸收与反射分离体现玻璃，不能以降低整片透明度代替通透。
- 默认剑流也输出既有光学/透射缓冲，并保留成熟带面完整替换偏折背景的语义，避免混回完整树干。通用材质仅调整属性缓冲的类型标记，材质计算保持。
- 高度、法线与粗糙度共用一张低振幅标量源图，法线按真实剑迹的切线基底展开。默认色场只调亮度，逐剑颜色仍由原配色控制。
- 移除从背景亮点额外扩散的泛光，所有反射/透射限制在实际带面内。未新增场景复制或玩家材质界面。

以上仍是二维薄面和屏幕空间近似，不称完整Blender BSDF、HDR环境测量或完整三维光线追踪。

## 素材来源与复用

两张原稿均由本轮内置`image_gen`生成：中性环境全景、灰度流纹表面。它们不是从其他模组提取的资源。由灰度源图做低幅度标量归一、周期边界处理，再数学导出同源法线与粗糙度。

- 生产输入：`ZenithReborn/Assets/Vfx/Materials/SwordFlow/GlassR3/{EnvironmentMap,NormalMap,HeightMap,SurfaceMap}.png`。
- 原稿/成品：`artifacts/vfx-textures/{EnvironmentMap,HeightMap,NormalMap,SurfaceMap}/GlassR3/`。
- 提示词：`VfxLibrary/Materials/SwordTrail/Glass/R3/generation-prompts.json`，保留实际内置工具请求。
- 库入口：`VfxLibrary/Materials/SwordTrail/Glass/R3/entry.json`。
- 转换脚本：`checks/prepare_glass_r3.py`。来源与成品哈希见生产目录`provenance.json`。

环境U缝、高度U/V缝的浮点误差为0；高度约0.482–0.520，单位法线浮点误差约2.2e-16。数据正确不等于游戏美术合格。旧素材保留，R3放在版本子目录中优先绑定；没有复制灾厄大修的Shader/笔刷/噪声。成熟模组参考仅借鉴输入职责分工，不能把其能量刀光当成现成物理玻璃。

## 编译与验证状态

原生编译与8393项引擎检查通过，0.3.79三个剑影的伤害及原有玩法回归保持。独立制作模组升级0.1.3，仅在制作/隔离档使用，适配本机原生编译和新的材质属性标记。

新增GPU对照固定几何、色场时间和Alpha，只改变光方向、环境方向及粗糙度；检查颜色响应与Alpha完全保持，避免把透明度变化说成质感改善。原IOR同帧背景对照、完整滤镜链世界对照、通用材质实验室也需要重新运行。
