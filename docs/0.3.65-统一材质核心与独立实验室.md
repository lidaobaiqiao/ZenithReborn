# 0.3.65 统一材质核心与独立实验室

用户要求先实现功能，再逐个测试，并将可视化材质工具做成独立测试模组。此次按这个顺序完成材质合同、渲染实现、实际飞剑接入、独立工作台及导入导出工具，再进行逐项GPU和隔离世界检查。默认武器绑定没有切换到新材质，正式玩家没有新增材质编辑界面。

## 生产特效

`SurfaceMaterialDefinition.cs`是唯一参数合同，含基础色、金属度、粗糙度、IOR、Alpha、透射、吸收、法线、凹凸、高度置换、反射、各向异性、主光、环境光、涂层、光泽、薄膜、自发光、次表面和薄层体积参数。范围与中文标签共用，拒绝非有限值、未知JSON字段及越界参数。

`SurfaceMaterialRenderer.cs`与`ZRMaterialSurface.fx`实现统一材质：GGX微表面直接受光、菲涅耳、方向环境贴图反射、切线法线、表面参数图、吸收透射、涂层、边缘光泽、各向异性与方向、自发光等。高度图实际移动细分绘制网格，凹凸另行改变法线；二者都不改变碰撞。底色缓慢流动、动态形状蒙版和图集播放相互独立。可接入底色、蒙版、法线、表面参数、高度、自发光和环境图七类PNG。

环境反射确实按反射方向采样经纬图，但不是实时场景反射／光线追踪。次表面采用包裹光近似，体积采用解析薄层吸收与散射，薄膜采用三波段干涉色近似。它们均有实际渲染作用，不是空控件，也不等于Blender完整Principled BSDF、三维体积或离线积分。环境粗糙度目前使用有限邻域模糊，尚无完整预滤波IBL／多重散射补偿。

通用数学模型参考[Filament材质说明](https://google.github.io/filament/main/materials.html)与[技术文档](https://google.github.io/filament/Filament.html)。本次代码独立编写，没有复制Filament／MaterialX实现，没有引入它们的运行库，也没有恢复其他模组的着色器、笔刷或噪声。继续复用现有FNA、原版照明及原版屏幕滤镜基础设施。

`SwordFlowMaterial`支持逐剑Artwork.SurfaceMaterial引用以及受控制作绑定；现有空绑定保持不变。`SoulSceneRefraction`在有新材质时准备逐像素光学属性和透射数据，在同一最终阶段合成背景。反光、法线、属性和透射图都是同一形状的辅助数据，不是独立叠四层刀光。新材质的自发光可在真实飞剑存在时向原版Lighting提交光源，默认WorldLightStrength=0，不向正式飞剑附加火焰粒子或减益。

未绑定新材质的剑继续使用0.3.64自有材质和配色；新增核心默认不载入额外美术。矿石H4四份源码及21张蒙版与0.3.64源码包逐字节一致，见artifacts/ore-preservation-0.3.65.json。攻击运动、伤害、碰撞、时序、槽位和存档保持。

## 特效库与制作工具

入口为`VfxLibrary/Materials/Surface/entry.json`。`schema-controls.json`由正式C#参数合同导出，导入工具不另写一份范围。美术仍按大类和实际剑名组织：底色、蒙版、法线、表面参数、高度、自发光、环境图；材质只引用对应输入。

独立项目`tools/ZenithMaterialLab`生成`ZenithMaterialLab.tmod`，依赖ZenithReborn≥0.3.65，仅在material-lab-profile隔离档启动界面。制作界面包含分类滑块、球体／平面／剑迹网格、校准背景／外部背景、动画暂停、旋转主光、贴图刷新、图集帧列与速度、逐剑配色预览、调试数据、保存／加载、撤销／重做、截图及导出。剑迹网格使用合成历史输入调用生产网格方法，不冒充实际战斗轨迹。

启动入口为`tools/打开材质实验室.cmd`。构建使用`checks/build_material_lab.ps1`；交互启动使用`checks/run_material_lab.ps1`，加`-Check`运行逐项GPU检查。独立目录只启用正式核心与实验室，不复制正式人物或世界。实验室不写入正式Mods启用列表。详细素材约定和操作见`tools/ZenithMaterialLab/README.md`。

`checks/import_material_export.py`验证导出JSON、PNG、图集尺寸和哈希，默认只列出操作，加`--apply`才按实际剑名写入源码与特效库，已有文件先备份。接入后仍需构建与验证，不自动安装。隔离导入已验证正常，未把演示材质绑定到正式武器。
