# 六祝福 · 已确认机制与待定参数

日期：2026-10-21。用户在五种新增祝福建议后确认采纳，并将御剑改为战斗蓄条爆发。已按此机制完成0.3.38源码实装；首版参数、操作及验证状态以[0.3.38实现记录](0.3.38-五祝福与手动御剑.md)为准。

## 已确认的机制

| 祝福 | 机制 | 实装状态 |
|---|---|---|
| 御剑（缚身） | 战斗积攒御剑条，满条后保留能量，由玩家手动开启强化状态：玩家视野翻倍，距离越远伤害越高，最高增加50% | 0.3.38已实装 |
| 切换 · 百刃接力 | 不同寄宿剑连续首次命中同一敌人，逐步强化后续剑的首次命中特性；同剑帧伤不叠层，达到上限后保持，断战清空 | 0.3.38已实装 |
| 轮转 · 归鞘留锋 | 主剑完整完成往返，为自身储存一次强化；该剑下次登场首次命中释放短距离斩痕，沿途伤害取该剑自身数值 | 0.3.38已实装 |
| 穿界 · 破障 | 主剑穿过实体地形后，获得一次下次命中附加短暂破甲的机会；重复穿墙不能无限强化 | 0.3.38已实装 |
| 独行 | 按个人铭刻提高每轮主剑数量：三王4、世花6、石巨人7、教徒8、月总10 | 已实装 |
| 连斩 · 剑痕 | 每把主剑分别记录对每个敌人的连续命中，达到次数后引爆自己的剑痕；取该剑自身伤害，每趟最多引爆一次 | 0.3.38已实装 |

这些额外效果只在相应祝福阶段生效。解除仍立即恢复全部正常能力，不必等到祝福。分组及个人Boss铭刻规则不变。

## 御剑：替换此前的剑围建议

用户明确确定的是战斗积攒、满条保留并手动发动、视野翻倍、距离增伤且上限50%。不得自动开启或在满条时自动消耗。此前“剑围改变轨迹覆盖范围”的建议不再采用。

以下是落地建议，尚未由用户确定：

- 视野翻倍按可见横向和纵向距离各为原来2倍解释，即相对玩家当前缩放平滑拉远；不是改变分辨率或UI缩放。强化结束后平滑恢复，兼容玩家原缩放。
- 用户已明确：御剑必须手动开启；满条后保留能量等待玩家释放，不自动发动或消耗。具体触发按键尚未指定。有限持续时间及结束后重新积攒为落地建议，积攒时长和持续时长待定；脱战不得擅自清空或衰减已蓄满的能量。
- 同步扩大可操控御剑距离，让扩大视野有实际用途；扩大倍数及距离增伤达到上限的位置待定。
- 距离增伤采用命中时玩家到目标的距离，使用独立且明确的倍率，封顶1.5倍；是否也作用于百炼飞剑、斩痕等衍生伤害待定，不能重复结算。
- 积攒不能被帧伤次数或衍生攻击递归无限加速；有效目标、计量单位和充能速度待定。
- 御剑条提供可见进度及满条反馈。视觉变焦必须保留鼠标选点一致性，死亡、切走武器、进入魂域时的状态与恢复规则需要明确处理。

## 其余待定参数

| 机制 | 尚需确定的参数 |
|---|---|
| 百刃接力 | 每层强化、层数上限、接力超时、不同剑按宿主身份还是武器类型区分、非数值特性的适用方式 |
| 归鞘留锋 | 斩痕倍率、范围、逐目标命中规则及储存有效期；每把宿主独立且最多储存一次 |
| 破障 | 破甲数值和持续时间；实体穿越识别需排除背景墙、平台及无效反复采样 |
| 剑痕 | 引爆所需命中次数、伤害倍率、断连时间；同魂、同剑、同目标独立记录 |

## 开发边界

- 新增效果不恢复分摊、统一伤害下限或共用飞剑冷却；保持逐宿主伤害和原版主剑时序/轨迹。
- 御剑负责距离爆发，切换负责不同剑的特性接力，轮转负责完整往返，穿界负责地形，独行负责数量，连斩负责同剑连续命中。
- 斩痕、剑痕引爆等衍生伤害不再次驱动整套祝福或飞剑积攒，避免递归。
- 普通槽、共用支援、奖励槽、传奇槽规则不因这些设计而擅自调整。
- 0.3.37的切换诅咒四主剑例外继续有效；解除后的正常能力不计作切换祝福额外奖励。

本页保留设计来源及原来未定参数，首版采用值见0.3.38记录；不得将首版调参声称为用户指定的精确数值。
