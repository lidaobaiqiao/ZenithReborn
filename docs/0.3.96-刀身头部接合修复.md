用户指出弧面右下角缺了一块，没有与刀身连起来。本轮修复当前纯代码剑流头部的几何范围与形状裁切，不调整高光强度或开启素材。

## 原因

生产几何在头部年龄0时使用0.44的收肩系数，再乘1.52倍半剑长，宽度仅为0.6688倍半剑长；shader内侧边界约在宽度的0.8～0.95处继续渐隐。可见带面因此只覆盖剑尖附近，达不到刀身中后段。此前`FullyFormed`只让成长倍率为1，没有消除这次头部收窄。

独立GPU检查读取原版附魔剑、泰拉之刃、星怒贴图，按生产1.6倍显示比例计算刀长并叠加。旧包三个刀身的40%～95%检查位置多数为Alpha0，复现断开的区域。这不是靠增亮能补回的范围问题。

## 修复及职责

- `SoulMaterialTrail`负责几何：前18%真实归一化路程内，头部从完整两倍半剑长平滑过渡回原来的宽度公式；剑尖锚点、旧尾收束与其余路程不变。
- 顶点颜色绿色通道传递反向接合权重：头部G=0，接合区外G=1。红色仍为年龄、Alpha仍为原生命周期覆盖度。权重由几何统一产生，不在shader再维护一份长度参数。
- `ZRSwordFlow`负责形状：按接合权重将头部内侧边界延伸到刀背，防止扩大后的几何再次被旧遮罩裁空。
- 不改刀身贴图、尺寸、碰撞、攻击、时序、存档、配色和光强。P18/P24默认仍关闭；连续朝向与纯代码资源限制保持。
- 本轮针对当前ZRSwordFlow基础路径；未启用的通用Surface材质未据此宣称完成接合适配。
