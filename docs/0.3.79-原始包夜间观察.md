# 原始0.3.79包的夜间观察

用户在要求以79为后续基础后，补充「你可以看一下79版本的夜间效果」。本轮直接运行收藏原始79包，没有用恢复后的90候选冒充原包，也没有修改材质参数。

被测包SHA-256：`c7b88428525a192e5764de000e180be73184933a41a86bf61a3832bd1fecdad1`。正式五模组组合、正式画面设置只读复制到专用隔离档，固定夜间和受控三剑攻击；正式人物/世界和当前安装包保持。

## 观察

- 泰拉之刃的薄亮边与内部窄扫光在暗背景上清楚可见，内部保持绿色透光带面，能看到偏折后的树干与树冠。
- 同组附魔剑和星怒也保留夜间亮线和内部色差。
- 此场景没有看到80用户录像中那种大片灰白粗纹铺满表面的观感。这里是新夹具与用户录像之间的定性观察，未宣称逐像素同姿态对照或所有环境都已验证。
- 79的可见亮边/扫光主要由Shader带面坐标形成，原生表面输出叠加窄亮线并与当前偏折背景合成；这种观感不等于已经完成物理真实的曲面高光或完整发光玻璃模型。不能因画面干净就宣称无需后续材质工作。

## 验证

原始79三剑生产AI、实际命中、返回、独立收尾检查通过。原生滤镜同帧IOR对照通过，变化限制在材质剑迹内，外部变化像素为0；结果绑定上述原始79包哈希。不是自然鼠标游玩或真实多人验证。
