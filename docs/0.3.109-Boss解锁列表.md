# 0.3.109：封印铭刻 Boss 解锁列表

2026年10月27日。基线为0.3.108。用户认为成长记忆页的封印铭刻只用小方块圆点加一行文字，右侧大片空白，玩家看不出想要的属性怎么激活。要求改成直观的 Boss 解锁列表：每个封印一个横向区块，左侧放官方 Wiki 的 Boss 动态头像，右侧写每击败一位后累计解锁的阶段效果，未击败暗显、已击败点亮，祝福完全达成时用棱彩。

## 最终体验

成长记忆页的封印铭刻标签改为“六封印·解锁路线”。每个封印一个横向区块，顶部是封印图标、名字和当前阶段，下面每一行对应一位 Boss：左侧是动态头像和 Boss 名，右侧是阶段标签（削弱、解除、祝福）和该阶段生效的具体效果。

已铭刻的头像和效果点亮，未达成的整体暗显并垫更暗的底。玩家可以直接对照头像和效果，知道自己想要的属性要打哪几位 Boss。双子魔眼这一行明确标注“两只”，说明激光眼和魔焰眼都要铭刻。某组全部达成时，该组的祝福标签和文字进入棱彩流动。

页面保留组内滚动，六个封印区块较长时可上下查看，末尾保留外域留痕区块，说明猪龙鱼公爵和鹿角怪不施咒、只记录胜利。

## 解锁规则核对

阶段效果严格按真实代码呈现，不按列表顺序要求玩家：

- 同组 Boss 可以任意顺序击败，按累计铭刻数依次进入下一阶段。
- 两 Boss 组：第一位解除、第二位祝福。
- 三 Boss 组：第一位削弱、第二位解除、第三位祝福。
- 祝福仅在该组全部铭刻时生效；旧档的兼容解除不授予祝福。
