# 0.3.107：按操作重排界面与精简入口

2026年10月27日。基线为正式0.3.106。用户先要求删除没用的界面，随后指出不能默认原有布局合理。这轮重新安排信息与操作路径，不把106的长卡片排布当作既定结构。

## 106的问题与本轮取舍

106的大标题、装饰圆环和上下文左栏占用了较多首屏面积；特性展开会挤动后续卡片，查看环境后还需要继续向下寻找操作按钮。成长目标、魂芯与封印共用长页面，空的旧物取回仍占主导航。这些问题应从任务和阅读路径解决。

主导航现仅四项：武器寄宿、剑魂特性、成长记忆、环境之力。独立“生效特性”和“特性图鉴”合为同一个工作区，通过“当前生效／全部特性”切换；旧图鉴页面身份与重复绘制入口已移除。旧物取回不再占导航，有遗留物品时从配剑区提示进入，取空后入口自动消失；旧存档物品和取回校验继续保留。

| 任务 | 新排布 |
|---|---|
| 查特性和激活条件 | 左侧筛选列表，右侧固定完整详情；两个区域各自滚动，选择不挤动其他内容 |
| 找下一步成长目标 | 目标固定在上方，下面选择剑位路线、魂芯收藏或封印铭刻，当前分组单独滚动 |
| 管理环境 | 图谱与选中环境详情并排，领域、常驻、恢复自然等操作固定在详情区底部 |
| 窄屏阅读 | 列表/图谱在上、详情在下，分别滚动；保留全部操作，不借用武器剑库的宽度 |
| 处理遗留物品 | 配剑区有物品才显示提示，回收视图可返回配剑；取空后不能再进入空视图 |

信息页使用完整工作区，宽屏主导航与品牌压到同一行。删除大幅介绍板、装饰性进度环和信息页左栏；下一步与条目状态保留真实数据。没有外域铭刻时不显示空外域记录，剧情完成后不再显示重复信物教程。视觉沿用已制作的原版图标、语义徽记和轻量过渡，点击区域保持固定。

## 模块归属与数据

新增`SoulUIPages.cs`集中页面身份、名称、颜色与主导航。布局几何继续归`SoulInfoLayout`，嵌套裁剪/独立滚动归`SoulUIInformation`；特性、成长和环境分别归原有对应文件。主入口只协调当前工作区，不保留图鉴的第二套展示分支。

特性筛选、当前选择、成长分组、图谱滚动均为临时UI状态，不写入剑魂数据。环境选择卡片只切换查看对象，实际领域与常驻依然要通过对应按钮确认操作。战斗、成长条件、Boss铭刻、物品存储与校验逻辑均保持，78项原C#文件及43项Assets逐字节未变。
