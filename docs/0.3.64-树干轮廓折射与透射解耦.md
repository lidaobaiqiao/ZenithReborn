# 0.3.64 树干轮廓折射与透射解耦

用户否定0.3.63：树木经过剑迹时仍完整，画面没有预期的玻璃折射质感。0.3.63虽有最终像素差异，仍未达到这个视觉要求，不能把前版PASS当作用户认可。

## 本轮确认的问题

旧合成把未偏折画面与偏折画面按Transmission=0.55混合，然后又按较低的覆盖度与原画混合。读取0.3.63真实法线图，既定树干区域的覆盖度中位数约0.533，因此未偏折原图最终权重约0.707，完整树干仍占主导。该区域横向折射位移中位数约2.73像素，纵向约5.81像素；竖直树干沿自身纵向偏移也难看出轮廓断开。前版将“参数导致若干像素变化”当成了足够的完成证据。

## 改动

- ZRGlassScreen不再把Transmission解释为原画／折射画面的混合比例。已存在的玻璃内部采样偏折背景，Transmission负责吸收能量；原画只在羽化、形成和侵蚀消散处混回。几何覆盖与透射分开，不再在玻璃内部保留占主导的未偏折树干。
- ZRSwordFlow法线由稳定的双轴弧面产生：宽度方向曲率加上沿真实剑迹的倾角，沿迹方向根据实际UV梯度校正。背景不使用滚动噪声扭曲，保持有组织的曲面，避免恢复液化质感。
- IOR仍1.5、粗糙度仍0.08、透射仍0.55、虚拟屏幕厚度仍72。此次没有靠继续提高IOR或大幅厚度放大替代修正。
- 只改两份自有着色器和版本号；运动、碰撞、伤害、存档、槽位、逐剑配色和矿石H4保持。没有玩家调参面板，没有引入新框架、第三方材质或贴图。

这里仍是按二维虚拟曲面计算的屏幕空间折射，不能把IOR=1.5独自解释成某个固定的真实玻璃外观。实际畸变由表面朝向、虚拟厚度和合成共同决定；本轮以树干轮廓的实际错位核对实现。
