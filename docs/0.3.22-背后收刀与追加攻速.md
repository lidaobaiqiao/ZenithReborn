# 0.3.22 · 背后收刀与追加攻速

旧主剑在绕行周期结束时直接Kill，只有普通弹幕绘制和逐渐淡出的网格拖尾，没有人物背后的独立回收阶段。

现在主剑完成原有飞行后，追加10帧纯视觉收刀。保持回收起点相对人物的位置，平滑收向身后14像素、重力方向2像素的位置，旋转为背后斜收角度并淡出；跟随人物移动、左右朝向和倒置重力。收刀阶段CanDamage=false，不增加主剑命中、矿石积攒或特殊机制触发。

新增SoulSheathingLayer，将返回武器作为人物DrawDataCache的一部分放在BeforeFirstVanillaLayer，随后人物身体和装备自然遮挡它。使用独立Between排序，不绑定可选翅膀的显隐。普通弹幕PreDraw在收刀时返回false，BuildRibbon同样停止，避免前景复制和旧拖尾残留。原飞行阶段仍保留原有伤害时长、运动、独立伤害与4节点轮换；飞行模型不在进入收刀之前提前完全消失。

相对0.3.21再提高5%挥臂攻速：在上一版整数周期上除1.05后向上取整，最快38→37帧。主剑飞行周期、矿石飞行速度、UI动画速度保持原值。
