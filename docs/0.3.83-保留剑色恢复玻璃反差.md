# 0.3.83：保留剑色，恢复玻璃反差

用户明确“保留这次的颜色，这次质感远不如上一版”。因此颜色基准是0.3.82的实际剑身取色，玻璃质感基准是0.3.81；不再将强发光作为默认美术方向。

## 修改

0.3.82新加入的整面能量发光显著抬高暗部，同时按最大通道统一压缩反射和底光，使细节反差被压平。这轮撤下该能量块，恢复0.3.81的弱内部底色/流丝/自发光图系数0.050／0.070／0.085以及逐通道压缩。没有通过降低Alpha代替玻璃，也没有添加静态白线。

保留0.3.82剑身取色、缓存、边缘配色和反射染色。现有法线、环境、GGX、粗糙度、菲涅耳、IOR1.5、透射0.55、厚度72保持；短尾、剑影、攻击与结束形态不改。并非把整个Shader恢复成与0.3.81字节相同：逐剑色彩部分按用户要求继续保留。
