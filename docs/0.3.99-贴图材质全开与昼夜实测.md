## 开关与职责

- `VfxIsolation.PureCodeOnly=false`，7分支、18细项、25带面及6滤镜项共56项默认全开，包括剑影、星芒、粒子、碎光和屏幕玻璃。
- 默认恢复统一由`ApplyDefaultPreset`读取同一元数据表，不再另写一套纯代码专用布尔状态。旧夹具方法名保留为兼容转发；重新设为纯代码时，外部输入仍由同一允许策略过滤。
- Ctrl+F10恢复完整预设，Shift+F10全开，F10全关；提示已更新。
- 轮廓仍属于`SoulMaterialTrail`，连续UV朝向仍属于`SwordFlowMeshBasis`，本轮没有改两者，也没有改生产Shader或光强参数、攻击、伤害和存档。
- `SoulSceneRefraction`修复开启总闸后滤镜常驻的问题：仅有飞剑或独立收尾时激活，避免无效果时持续运行全屏路径。

## 实际加载问题

第一轮虽56项全开，普通贴图的`uUse*`仍全为0，只有原始四区数据成功。原因是`TryLoad`把带`ZenithReborn/`前缀的完整资源键传入`Mod.HasAsset`，后者检查模组内相对键，因此静默回退。现使用`ModContent.HasAsset`，并记录可选图加载异常，不再把“开关已开”当成“贴图生效”。

最终实际绑定8路：笔刷、噪声、法线、表面粗糙度、高度、自发光、环境和四区。`bindings.json`没有逐剑色场或动态图集配置，`uUseColorField/uUseMotionMask`因此仍为0；未擅自挂图改变剑色或用旧动态图集覆盖97几何。这两项不属于56个面板开关，不能虚称全部库内图片都已使用。
