# 特效库M4 · 矿石剑批量蒙版

正式运行包仍为0.3.54。本轮把钛金剑R2配方家族铺到其余21把矿石剑，只制作剑身一体组Alpha图集并登记为审核候选；不修改攻击、伤害、碰撞、存档、槽位或正式渲染路径，不安装正式包，不制作圆环与粒子。

美术分工由本轮自制定稿：逐剑底色按矿石金属性原创，蒙版在R2形状语言内做节奏分化；用户观看后仍可推翻。

## 工作方式

延续用户已明确偏好的R2视觉基准：独立慢流动底色 × 自身具有形状动画的Alpha，一次最终合成；拖尾、剑身、边缘和剑头从同一张图集获得形状。每把剑不重新画形态，而是把R2配方按各自原版贴图自动配准——沿生产代码`OreSwordEffects.BladeReach`相同的对角轴实测剑尖距离与中段半宽，映射到R2基准画布（448×256、枢轴305,128、103画布像素等于钛金剑1.85倍游戏内剑长）；尾迹宽保持R2的20:8身尾比，波动区间随枢轴相对移动。管线三个写死钛金剑的文件已参数化：`SwordBodyVectorMask.cs`按配方家族校验并实测贴图，`SwordBodyMaskPreview.cs`按环境变量加载任意ItemID并导出实测profile，`run_swordbody_preview.ps1`按剑名定位目录、等待并校验导出。

天铸巨剑没有原版贴图，autoFit无从测量，其蒙版仍待制作，未列入本轮。

## 逐剑底色

21把各有一份按金属性定稿的慢流动色场（`ColorFields/SwordBody/<剑名>/`），沿用R2家族语言——暗底加两层反向流动噪声——主色取自该矿石在游戏内的身份色：铜橙、锡青灰、钢灰、铅灰蓝、亮银、暖金（钨）、金、冷银白（铂金）、钴蓝、钯橙红、秘银青绿、山铜粉、精金红。暖重金属流动慢、冷轻金属流动快。钛金剑保持用户偏好的R2青紫共享色场不动。色场与Alpha图集完全解耦：切换色场后逐剑重跑GPU，蒙版哈希逐一与切换前一致。

## 节奏演化

蒙版形状语言与R2完全一致——同一层贴剑薄膜、锥形尾迹、行进波峰；不加钩、不分叉、不普遍扩大提亮。只按剑的“性格”分化波动节奏：短剑紧促（波高16、循环0.7秒），低档宽剑保持R2基准的沉稳（18、0.9），高档宽剑刃面流动更饱满（20、0.8），肉后五矿张扬但有节制（20、0.75）。演化记录在各剑authoring.json的`evolution`字段。

## 结果

21把全部通过隔离GPU导出与登记：静止姿态蒙版变化、轮廓覆盖变化、底色×蒙版相乘最大误差0、结束无过期残留像素，逐项标准与钛金剑R2一致。实测几何复现了原版贴图的模板分组——8把短剑同一剪影（tipX 358、剑长53.0），宽剑按铜锡铁铅／银钨／金铂金三档（365/60.0、368/63.0、371/66.0），肉后五矿各自独立（山铜90.0至秘银97.0）。同模板剑共享图集几何是预期结果：将来靠各剑自己的贴图引用与色场区分，不为换色重复造轮子。

各版资源在`VfxLibrary/Masks/SwordBody/<剑名>/R2/`：authoring.json（含GPU实测回填的tip/枢轴/剑长、逐剑色场指向与节奏演化参数）、active.png（4×4共16帧，仅Alpha为蒙版通道）、clip.json（相位与波峰登记）、contact-sheet.png（黑白Alpha）。逐剑底色在`VfxLibrary/ColorFields/SwordBody/<剑名>/`。入口entry.json已更新为review-candidate并引用R2，库校验`PASS: 23 swords/forms; 144 entries`。

## 证据与边界

- 每把剑一次真实隔离GPU客户端导出（`-nosteam`、独立存档目录），gpu.json逐剑落盘：passed、maskSha256、相乘误差、过期残留、原版贴图来源、生产包未改动。
- 图集为RGBA预乘白色，仅Alpha有意义；GPU回放60fps线性Alpha过渡，与登记clip.json一致。
- 以上全部是制作端与隔离GPU证据：不代表美术审核通过，不代表实战、世界攻击或多人联机验证，未接入正式渲染路径，正式包SHA256保持`3c946c7321796716e553db03699945bf1c7e77ad989de500bbcddbb628fc98cf`。
- 底色暂用共享`color._Shared.SlowFlowRadiantR2`（与钛金剑R2基准同一色场）；逐剑专属色场属于后续美术决定，本轮不擅自分配。

## 复现

```powershell
# 单把：配方 -> 隔离GPU导出（等待并校验）-> 登记
python checks/make_autofit_recipe.py VfxLibrary/Masks/SwordBody/<剑名>/R2
pwsh -NoProfile -File checks/run_swordbody_preview.ps1 -Revision R2 -Sword <剑名> -Vector -Emissive -Local
python checks/register_swordbody_vector.py artifacts/swordbody-<剑名>-R2-emissive-local VfxLibrary/Masks/SwordBody/<剑名>/R2

# 批量：每次取若干把未完成剑，断点续跑，GPU卡死自动杀客户端重试一次
pwsh -NoProfile -File checks/run_swordbody_batch.ps1 -Take 3

python checks/vfx_library.py validate
```

登记脚本的Pillow依赖在无网机器上由`checks/png_stdlib.py`（纯标准库PNG读写）无缝回退，两种后端输出一致。
