# 0.3.119：主飞剑加速与安装

用户反馈飞剑速度被减半，要求改回来并安装带0.3.118缺口修复的版本。核对收藏0.3.79与0.3.118源码，主飞剑的阶段步长及每帧两次更新相同，未能从本轮特效迁移中找到减速代码；按用户要求，以0.3.118为对照将实际飞行速度提高两倍，不把其称为已证实的某次代码回退。

SoulBlade每游戏帧由两次更新改为四次，保持每次阶段增量和剑影按更新次数采样；本体轨迹和剑影一起加速，旧8游戏帧共享免疫换算为32次更新。提前回收淡出按原游戏帧节奏递进。攻击碰撞更快穿过目标，实际命中机会和帧率开销可能随之变化。矿石辅助飞剑未调速；剑迹79材质、0.3.118的缺口修复和剑影伤害系数不变。

两项目Release编译零错误零警告。320项针对性检查覆盖三种距离下同一剑魂每帧四次更新与旧两帧的相位和位置、免疫、剑影伤害和矿石叠层；先前使用原版弹幕的无图形服务端夹具因光照依赖失败，未把它作为通过结果。实际GPU白天隔离世界三剑命中返回、三个剑影伤害和独立收尾通过，记录在 `artifacts/soul-flight-world-0.3.119-echo-damage-speed-check/world.json`。实际鼠标、多人、帧率与美术未测；119没有重复118的固定姿态接合GPU对照，相关几何和着色器与118包逐字节一致。
