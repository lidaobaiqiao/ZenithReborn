# 环境属性 E0 · 分类入口

日期：2026-10-21。以用户最新说明为准：**环境属性是叠加在每把剑上的独立属性，与种族属性并行。一把剑可以同时具有种族、环境及独有特性。**

此前将「环境族」理解成一个需要与木质、矿石互斥的新种族有误，已撤回。丛林、雪原等环境特色体现在武器上，环境组机制与种族羁绊分别设计，既有木剑和矿石剑也适用环境属性。

- 各剑的环境标签数量、具体效果、羁绊计数和奖励尚未定案。
