## 两层特性的生效规则

1. 每把剑只归一个剑族，获得“1个族特性＋1个单剑独有特性”。单槽即可发挥两层能力，族特性不要求凑齐套装。
2. 种族按来源和主题划分；短剑、阔剑、投掷等仍是攻击形态标签。天顶材料身份另作标记，不覆盖原有剑族。
3. 武器必须实际处于已解锁寄宿槽且参与攻击才提供能力，背包或未解锁槽不提供加成。同族多剑不重复叠加玩家全局属性。
4. 增伤、穿甲、间隔与判定加成默认只作用于来源武器；族内共享标记和冷却按下表处理。治疗等玩家效果使用独立共享上限。
5. 一趟主剑影对同一敌人仍最多主命中一次。不同武器、不同飞行实例的主命中可以累计指定连击；附属射弹、补斩、持续伤害默认不触发族特性、独有特性或新的计数。
6. 跨剑标记在多槽时由其他剑消耗；只有1把实际激活寄宿武器时，允许本剑下一趟主命中消耗，不能创建后同击自吞。该兼容规则适用于秘银剑、时尚剪刀、Arkhalis剑。
7. 各种减益遵循免疫；不以强制冻结、强制击退或按Boss最大生命扣血作为绕过难度的手段。
8. 天顶剑和真铜短剑的两项设计只作为最终形态分支预案。当前天顶剑不可寄宿的限制保持；不向剑魂中再次装入完整剑魂，也不把1.4.5物品直接加入1.4.4工程。

## 统一数值与结算口径

| 项目 | 定义 |
|---|---|
| D | 来源主剑影射出时的伤害快照，已经包含武器伤害、装备/词缀与残魂成长效能；不含本次暴击、目标防御与命中条件增伤。附伤计算不再次乘成长效能 |
| 百分比增伤 | 只作用于表中指定的主命中或射弹；种族与独有的同类条件增伤先相加后结算，不层层乘算 |
| 补斩与独立射弹 | 直接补斩默认不暴击；独立射弹可继承父剑暴击率，但不得从已暴击伤害再计算D |
| 连击计数 | “每第N次”循环触发后清零；同目标机制按玩家、SoulId、武器类型与敌人实体归组记录。虫体部件用所属主体归组，不用不同节数刷不同目标计数 |
| 有效主命中 | 对敌对、非训练假人目标实际造成正伤害的主剑影命中；无敌、友方、零伤害与纯视觉事件不累计 |
| 冷却归属 | 单剑时间冷却按玩家＋武器类型共享；种族时间冷却按玩家＋剑族共享；治疗另按玩家共享。连击与标记仍记录SoulId来源。多弹幕、多槽、换槽和更换残魂不重置尚未结束的时间冷却 |
| 时间 | 60帧＝1秒；计数超时按各行规定，停用、死亡与世界切换清除临时战斗状态，不清除成长存档 |
| 射弹安全边界 | 默认只由一个权威入口生成，保留SoulId来源；使用每目标命中上限。默认寿命不超过90帧、离玩家不超过600像素；另有更严格行内限制时采用行内限制 |
| 单目标附属伤害预算 | 普通常规武器按单次出剑预期不超过肉前0.60D、肉后0.90D规划；不把暴击后伤害作为预算基数。持续伤害按行内层数和时间封顶；终局合一斩单独核算 |
| 范围攻击 | 未另行说明时最多伤害3个不同敌人；不因为敌人密集而无限分裂或连锁 |
| 低伤害取整 | 附伤触发后可保留至少1点有效伤害；多枚微弱弹幕按整组预算分配有伤次数，其余保留视觉，不能每枚分别保底1点而突破整组预算 |
| 治疗预算 | 所有新增治疗共用：每次至多4生命；任意360帧内累计至多max(1,min(8,ceil(最大生命×2%)))生命。遵循原版吸血资源与禁疗规则；不从假人、友方或零伤害获取治疗 |
| 出剑间隔 | 各来源间隔修正统一合并，建议最低6帧；不改变已经稳定的剑影椭圆轨迹、朝向或飞行时间 |
| 视觉 | 延用0.2.4弧面拖尾；新效果优先复用小剑气、短弧与少量粒子，避免全屏闪光与大规模爆散 |

## 后续实现拆分

先实现可复用的条件增伤、标记消耗、命中计数、受限附属射弹、持续伤害和治疗预算，再以配置填充各剑。独有名称和触发条件可以不同，不为每把剑复制整套AI。

第一批只落地第一阶段能获得的常规武器，并复用已有近身增伤、霜火、中毒、剑气与落星基础；其他阶段按游戏进度推进。族特性、独有特性、命中来源与冷却应在同一调度入口处理，避免不同钩子重复结算。

交互上在寄宿界面同时展示“剑族／族特性／独有特性／条件与冷却”。不在每次攻击时刷聊天，不要求玩家靠猜测理解触发条件。

核对要求：100个原清单条目一一对应，常规71项、非常规29项；每项只分配1个族、1个独有特性；族ID均有效。原分类与阶段信息继续保存在[武器分类表](武器分类表-常规与非常规.md)。
