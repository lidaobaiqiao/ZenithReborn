# 0.3.70：真实剑迹的独立消散

本轮沿用已接入的天顶飞剑材质和素材，工作范围是补齐结束动画。修改前已核对正式安装包与工作区的SoulMaterialTrail、ZRSwordFlow及素材绑定一致；没有重做、移动或重新接入贴图。

## 原因与新表现

旧实现从运动阶段60开始同时降低整片可见度和提高材质侵蚀；父弹幕仍不断把返回后的静止姿态写入历史，带面会随历史覆盖而缩没。纯材质慢放能看到侵蚀，并不等于实际剑结束后仍有足够几何呈现它。

现在在正常返回或提前收回时复制最后最多32组真实剑身中心与朝向。活动剑停止重复绘制该带面，独立余迹继续用现有材质绘制：旧尾和暗侧先被侵蚀，亮刃短暂存留并熄灭。正常结束最多20游戏帧，提前收回最多12游戏帧；密度保持到末段，主要由形状侵蚀而非整片透明度下降表现消失。Shader可能在寿命上限前完全侵蚀收尽。

这份数据跟随摄像机正确投影，但不再被父弹幕的静止历史覆盖。父弹幕提前销毁也不截断余迹。每次只捕获一次，列表上限64条，世界退出和模组卸载清空。

没有新增伤害弹幕、碰撞、粒子层或场景缓存；未延长攻击或修改原版返回动作、伤害、命中冷却、存档、槽位和网络字段。现有逐剑配色、材质、贴图、IOR与粗糙度保持。

## 实现位置

- `SoulTrailEnding.cs`：姿态快照、独立游戏帧寿命和材质绘制。
- `SoulBlade.cs`：正常返回/提前收回时捕获，OnKill补足未捕获情况；菜单、专用服务器或无图形设备时不读取贴图。
- `SoulSceneRefraction.cs`：余迹参与现有法线、反光、光学属性和透射的统一准备；仅余迹存活时滤镜也可保持工作。
- `SoulVisuals.cs`：无法安全准备滤镜的原有备用绘制路径，同样支持余迹。
- `ZRSwordFlow.fx`：只在结束进度大于0时增强旧尾/暗侧侵蚀，并让原生合成也保留窄侵蚀边缘反光。
- `ZRMaterialSurface.fx`：通用材质共用相同方向的收尾，保持区域素材和逐剑参数。

## 验证

8355项引擎检查通过，新增检查覆盖：父历史被清空后快照保持、摄像机平移、全密度侵蚀与寿命独立于剑速。初次无图形设备的粒子回归触发了贴图读取，已通过视觉入口的图形设备/菜单判定修正，并重新通过完整回归。

实际GPU固定姿态/时间与0.3.69对照：两张固定图和四种配色图全部逐像素相同。结束序列初始14803个可辨特效像素、中段11580个、终点0；图形状态恢复和完全侵蚀无残留通过。此计数来自隔离固定轨迹，不是世界战斗或美术认可。

默认材质和分区通用材质分别在隔离世界测试三剑真实AI、直接命中、返回；额外先Retire再销毁父弹幕，原生合成中仍能观察到余迹，最后余迹为0。结果含`endingAfterParentKill`、`endingsCreated`、`remainingEndings`。原有玻璃同帧滤镜、场景保护和实验室逐项检查以本版对应报告为准。
