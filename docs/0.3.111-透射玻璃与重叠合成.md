# 0.3.111：透射玻璃与重叠合成

用户反馈现有刀光的玻璃仍不够通透。本轮改动让背景细节更清楚地透过主体，保留亮刃和局部有色高光，并修正同一区域多次绘制造成的发亮厚膜。美术效果仍由用户判断，技术通过不等于美术认可。

## 实现与归属

- `ZRClearGlass.fxh`：默认剑流的线性颜色、菲涅耳基础反射率及按路径长度衰减的吸收计算。这里只是二维屏幕薄层近似，没有三维场景深度或完整光线追踪。
- `ZRSwordFlow.fx`：把整片贴图自发光限制到亮刃和局部高光；环境、色流和消散光先转换为线性光能。表面 RGB 和 Alpha 使用同一覆盖度，反射权重和逐色透射能量独立输出。
- `SoulSceneRefraction.cs`：默认剑流和自定义材质统一准备法线、表面光、光学属性、透射四个缓冲。抽出重复提交循环，生命周期、资源释放和图形状态恢复沿用原入口。
- `ZRGlassScreen.fx`：读取当前帧背景，把表面光与透射一次合成；逐材质反射强度来自属性缓冲，不把默认反射参数强加给自定义材质。
- `SwordFlowMaterial.cs`：只负责把输出模式传给对应着色器。`ZRMaterialSurface.fx` 同步第三属性通道的约定，自定义材质反射为零时该通道保持零。
- `preset.json` 是唯一制作端参数源，`GlassMaterialPreset.cs` 由原生成脚本产生。

吸收使用 Beer-Lambert 形式，让路径较长处损失更多透射光。原理参考 [Khronos 的体积材质说明](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_volume/README.md)；本项目仍是屏幕空间近似，不声称实现该规范的完整三维体积模型。

## 参数与覆盖

| 项 | 0.3.110 | 0.3.111 |
|---|---:|---:|
| 主体密度 Opacity | 0.1 | 0.1 |
| 金属度 Metallic | 0.25 | 0.25 |
| 粗糙度 Roughness | 0 | 0 |
| 折射率 IOR | 1.5 | 1.5 |
| 屏幕虚拟厚度 Thickness | 72 | 18 |
| 其他制作端参数 | 原值 | 原值 |

没有修改剑迹网格、连续法线、轨迹或攻击规则。固定姿态的新旧法线与覆盖缓冲逐字节一致。最终合成现在使用缓冲中的实际覆盖，不再在覆盖达到 0.48 时提前饱和为 1；主体密度仍与几何覆盖分离。因此改善来自合成修正、局部发光和更轻的折射，不能只归因于某一个参数。

全部 57 个现有选项仍默认开启；没有换贴图、关掉材质层或给玩家新增调参入口。

## 实际验证

正式包与源码基线先核对到 0.3.110；安装包 SHA256 为 `0fb010fbab3302897a079e676801a4a187302d5fa5ce4e66dbfe5827b705fb39`。

1. 两个项目原生编译均为零错误、零警告；只运行相关的 **95 项剑迹、连续法线、生命周期及摄像机检查**。
2. 新版 **41 张实际 GPU 输出**包含颜色、缓冲、三个剑色、三张固定时间动画、空覆盖、消散及自定义材质样本。对比使用同一背景与姿态，没有调色或后期补光。
3. 在完全相同的像素区域，四次重叠相对单层的归一化表面光能：**旧版 2.1087，新版 0.9878**。新版约 1.2% 的差异在八位缓冲量化范围内，没有旧版的累加变亮。
4. 主体密度为 0、0.1、1 时覆盖完全相同；主体为 0 时仍有 19,826 个可见表面光像素。空覆盖、生命周期结束和完全消散的残留差异均为 0。
5. 使用正式启用组合及画面设置，在独立人物/世界执行一次白天原生滤镜检查。三剑实际命中与返回通过，350 帧使用当前帧原生滤镜，未发生延迟回退；独立收尾最终剩余 0。
6. 原生同帧 IOR 对照有 20,185 个变化像素，刀光覆盖外变化为 0；四个材质缓冲的覆盖差异为 0。空间扰动仍生效，最大作用范围外变化为 0。

新版被测包 SHA256：`11cd178e26885298305bad2b0360e8675338c4f40122ff19dc4646b322972e58`。

夜间图是历史真实背景上的本轮生产着色器重放；本轮没有重新运行夜间、黄昏及局部光源世界矩阵，没有自然鼠标或真实多人验证，也没有做帧率基准。默认材质从两个缓冲变为四个缓冲，2560×1600 时增加约 31.25 MiB 颜色缓冲显存及两次材质提交；不能声称性能完全不变。
