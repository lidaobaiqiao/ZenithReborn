# 0.3.19 · 悬浮剑环与柔边暗底

用户反馈大蓝底框碍眼，本轮调整界面材质、层次与留白，不改游戏数值或寄宿规则。

- 移除覆盖整个窗口的蓝色不透明矩形、整圈边框和顶端粗色条。
- 寄宿页改用边缘渐隐的椭圆暗底，剑环、天顶碎片和光点悬浮在其上。边角可看到游戏场景。
- 标题和底部操作提示分成窄圆角悬浮条，少量香槟金细线作点缀。关闭按钮平时只保留图标，悬浮时才显示底色。
- 详情/图鉴/成长页有独立半透明炭黑圆角面板；滚动进入寄宿详情时才出现局部暗底，保障长文阅读。
- 降低滚动轨道、槽位描边和环境泛光的存在感；保留武器配色、寄宿光环、呼吸、光点、碎片摆动和切页动画。
- 采用普通透明混合与程序生成的小纹理，不使用真实背景模糊、画面采样或全屏渲染目标。

源文件：`SoulUIStyle.cs`负责圆角表面、柔边衬底与悬浮条；`SoulUI.cs`保留输入和布局入口；`SoulUIEffects.cs`仍负责剑环动画。所有新增纹理在卸载时释放，线段仍指定MagicPixel的1×1源区域。

输入区域保持原面板矩形：透明边角仍然提前捕获鼠标，面板外背包可用；不能因去掉底色而漏出世界攻击或底层背包点击。保留17槽索引、存档、逐剑伤害、成长和词缀保护。

验证：Release编译0警告0错误，引擎4295项检查通过。图形客户端观察与边界另记在`artifacts/ui-validation-0.3.19.json`并绑定最终包哈希；不等同真实多人或全模组验证。
