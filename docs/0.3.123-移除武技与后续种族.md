# 0.3.123：移除武技与后续种族

用户决定保留木质族和矿石族，删除武技组和后续新增种族。运行时后续种族中实际存在的灵能族只有名册和查询，没有已实现的数值或战斗效果；现已移出。其他后续族方案未实装，历史设计文档保留但明确标记终止。武器物品仍可按原规则寄宿，旧的迅捷、坚固、寒霜、自然与奥术单剑特性属于此前运行的特性分类，本轮保留；环境之力也独立保留。

移除武技剑势积攒、三档攻击、刺剑/巨剑/剑气、冻结和减益、武技HUD、G/V按键、试作配置及其本地化。普通攻击直接回到剑魂原有挥动与发射入口。此前武技渲染器中通用的显卡状态保护被提取为 VfxRenderState，继续服务主飞剑与其他特效；普通近战共用的消散粒子与挥砍特效保持。

旧存档中的 `martialCharge` 和 `martialTier` 保留为只读写的遗留字段，并保持网络末尾的三字节格式和重铸保护；这些数据不参与战斗、界面或输入，便于旧档回退。删除前完整生产源与检查工程快照保存在 `artifacts/before-remove-martial-families-20261030-163605/source-and-checks.zip`，对应正式包也在该目录；删除的运行模块及检查另存 `checks/archived-removed-systems/0.3.123/`，仅为历史归档，不进入当前编译。

两项目Release构建零错误、零警告；300项针对性检查覆盖移除类型、原有普通攻击发射、旧档/网络/重铸、木质与矿石；421项剑影、铜锡联动与诅咒检查通过。检查使用独立测试档，不直接改写玩家存档。曾把旧 UiCheck 加入本轮检查，发生“Orbital navigation is inside the clipped host canvas”失败；保留 `artifacts/remove-martial-families-0.3.123/removal-check.txt` 和日志，没有改断言或称界面通过。相关运行路径中移除了武技HUD，但本轮未做图形界面、实际鼠标、世界游玩或多人检查。源码审计确认木质/矿石核心、剑迹几何、人物移动补偿及主要着色器与删除前字节一致；共用显卡状态保护的搬迁未做新GPU验证，因此不能声称画面逐像素不变。0.3.122原本也未取得实机GPU画面。
