# 0.3.97：按用户蓝线修正刀光内缘

用户否定96外观后，明确要求继续修复，不能以回退结束。随后给出蓝线标注：保留的内缘应连续收向刀身，叉掉护手下方伸出的多余部分。本轮以此为形状依据，不能再用“覆盖整个武器长度”代替目标轮廓。

## 生产修改及归属

只在`SoulMaterialTrail.Sample`调整带面宽度曲线。原来的0.44→1收肩会先收窄再鼓起；96又在头部强行扩大到两倍半剑长并将材质边界推到1.06，导致覆盖伸过护手。本轮改为1.20→1的连续收束，沿用原来的尾端渐窄、轻微呼吸和历史姿态。头部几何宽度约为1.824倍半剑长，实际可见边界继续由95原材质羽化，落在刀刃靠护手的位置。

96的顶点G接合权重和shader边界覆盖全部撤下。97中途尝试的“14像素局部连接面”也在收到蓝线后退出，不作为最终实现；其源码与图像留在`artifacts/sword-head-join/local-0.3.97-r1-source/`和对应r1目录。最终顶点布局、网格数量、绿色通道与材质均恢复95约定，避免把同一个轮廓参数拆到几何和shader中重复维护。

保留95连续朝向和纯代码输入限制；P18/P24默认仍关闭。本轮不改高光强度、颜色、剑图、剑尖锚点、运动、伤害、碰撞、收尾规则或存档。
