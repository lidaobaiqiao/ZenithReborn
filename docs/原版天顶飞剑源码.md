要点：

- **索引 0 是最新，索引越大越旧**，每次 update 整体后移一位。

- mode 4 = mode 2 再加「玩家位移补偿」，避免玩家跑动时历史点留在原地。

public struct FinalFractalHelper
{

    public struct FinalFractalProfile
    {

        public Color trailColor;
        public SpawnDustMethod dustMethod;
        public VertexStrip.StripColorFunction colorMethod;
        public VertexStrip.StripHalfWidthFunction widthMethod;

        public FinalFractalProfile(float fullBladeLength, Color color)
        {

        private void StripDust(Vector2 centerPosition, float rotation, Vector2 velocity)
        {
            if (Main.rand.Next(9) == 0)

                for (int i = 0; i < num; i++)

                    dust.fadeIn = 0.4f + Main.rand.NextFloat() * 0.3f;
                    dust.noGravity = true;
                    dust.velocity += rotation.ToRotationVector2() * (3f + Main.rand.NextFloat() * 4f);
                }

        }

## 5. `VertexStrip` — 网格怎么铺

```csharp
public void PrepareStrip(Vector2[] positions, float[] rotations,
    StripColorFunction colorFunction, StripHalfWidthFunction widthFunction,
    Vector2 offsetForAllPositions = default, int? expectedVertexPairsAmount = null,
    bool includeBacksides = false)
{
    int num = positions.Length;
    int num2 = (_vertexAmountCurrentlyMaintained = num * 2);
    if (_vertices.Length < num2) Array.Resize(ref _vertices, num2);

    int num3 = expectedVertexPairsAmount ?? num;

    for (int i = 0; i < num; i++)
    {
        if (positions[i] == Vector2.Zero)       // ★ 碰到空点就截断
        {
            num = i - 1;
            _vertexAmountCurrentlyMaintained = num * 2;
            break;
        }
        Vector2 pos = positions[i] + offsetForAllPositions;
        float rot = MathHelper.WrapAngle(rotations[i]);
        int indexOnVertexArray = i * 2;
        float progressOnStrip = (float)i / (float)(num3 - 1);   // ★ 0 = 剑，1 = 尾
        AddVertex(colorFunction, widthFunction, pos, rot, indexOnVertexArray, progressOnStrip);
    }
    PrepareIndices(num, includeBacksides);
}

private void AddVertex(..., Vector2 pos, float rot, int indexOnVertexArray, float progressOnStrip)
{
    Color color = colorFunction(progressOnStrip);
    float num = widthFunction(progressOnStrip);
    // ★ 垂直方向 = 朝向 - 90°，左右各偏 num
    Vector2 val = MathHelper.WrapAngle(rot - MathHelper.PiOver2).ToRotationVector2() * num;

    _vertices[indexOnVertexArray].Position      = pos + val;
    _vertices[indexOnVertexArray + 1].Position  = pos - val;
    _vertices[indexOnVertexArray].TexCoord      = new Vector2(progressOnStrip, 1f);
    _vertices[indexOnVertexArray + 1].TexCoord  = new Vector2(progressOnStrip, 0f);
    _vertices[indexOnVertexArray].Color         = color;
    _vertices[indexOnVertexArray + 1].Color     = color;
}
```

即：**一个点生成左右两个顶点，沿「朝向 −90°」方向各偏 `halfWidth`，V 坐标 0/1，U 坐标 = progress。整条带子双面（`includeBacksides`）。**

## 8. 时间线：每把飞剑的一生

`localAI[0]` 从 0 涨到 120 就 `Kill()`。增长率 `Lerp(0.7, 2.0, 速度映射)`，`extraUpdates=1` 所以每游戏帧涨两次。

假设全速（涨 0.7/update = 1.4/帧）：

| localAI[0] | 游戏帧 | 发生什么 |
|---|---|---|
| 0 → 5 | 0 → ~4 | `Opacity` 渐入，剑显形 |
| 15 | ~10 | 蓝色最远剑影（索引 15）待命，但 t=0 还不亮 |
| 20 | ~13 | 索引 15 剑影达到满亮（0.75 × Opacity） |
| 35 | ~24 | 索引 30 剑影满亮（0.50） |
| 50 | ~34 | 索引 45 剑影满亮（0.25） |
| 60 | ~41 | 粒子不再喷（`num2 < 1` 失效），网格拖尾已铺满 60 点 |
| 75 | ~52 | 索引 15 剑影开始淡出（t=60） |
| 83 | ~58 | 索引 15 剑影消失（t=68） |
| 105 | ~73 | 索引 45 剑影开始淡出 |
| 113 | ~79 | 索引 45 剑影消失 |
| 115 → 120 | ~80 → ~84 | 剑本体 `Opacity` 渐出 → Kill |

**注意**：三个剑影不是同时存在的。它们是**依次点亮、依次熄灭**的——最近的剑影先出现也先消失，最远的最后出现、最后消失。这就是原版看起来「剑影像一串依次点亮又灭掉的残像」的原因。

## 9. 我们 vs 原版 差异表

| 项 | 原版 933 | 我们当前 `SoulBlade.cs` | 后果 |
|---|---|---|---|
| 剑影采样间隔 | **15 次 update** | **3 帧** | 剑影密 5 倍，连成一条 → 「11111」 |
| 剑影数量 | **3** | `trailCount` / 3 ≈ 20 | 糊成一团 |
| 剑影 alpha | `(60-j)/60` → 0.75 / 0.50 / 0.25 | `(1-k/60) * 0.55` | 远端衰减曲线不同 |
| 剑影旋转偏移 | `-PI/4 * spriteDirection` | `+PI/4 * (1 - spriteDirection)` | sd=1 时差 45°，sd=-1 时差 90° |
