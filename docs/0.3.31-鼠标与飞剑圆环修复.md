# 0.3.31 鼠标与飞剑圆环修复

## 独立界面鼠标

根因是全屏魂域筛除原版界面时只保留了`Vanilla: Mouse Text`，实际绘制鼠标的独立层`Vanilla: Cursor`也被删除。现在保留鼠标文字、原版鼠标和鼠标携带物三层，沿用它们原来的绘制次序与缩放，不自绘第二个鼠标。背包、血条等背景层仍隐藏；输入拦截时机不变。

## 飞剑圆环缺口

旧角度使用每把剑各自的年龄。飞剑逐击积攒，较早出现的剑年龄较大；齐射又以各自年龄安排共同释放，导致各剑转角不同、最后一个闭合间隔尤其明显。

现在所有剑使用共同固定相位：`-π/2 + 2π × 序号 / 当前阵列总数`。出现动画仍按各剑自己的年龄计算，仅几何角度改为一致。完整阵列各相邻角度及首尾间隔相等；中断释放时仍按存活成员重新排布，不增加缺失武器、不多积攒飞剑。

## 主槽剑触发

至少一种有效矿石主剑解锁飞剑后，所有特性有效的主攻剑均可在首次有效命中积攒一把，不再要求本次命中的剑也是矿石剑。主攻包括正常主槽及已解锁的共享奖励槽，不包含不出主剑的支援槽。

- 切换诅咒未解除时仍仅第一把主攻剑提供特性，其他剑不会绕过诅咒积攒。
- 没有有效矿材解锁时，普通剑不会凭空生成飞剑。只有支援提供矿材的解锁入口仍保留10层要求。
- 主剑首次命中只尝试一次、后续帧伤不补触发、同魂／目标10帧冷却和衍生攻击不递归保持。
- 每把飞剑仍按积攒它的实际主剑伤害计算并保留来源；矿石主剑自身＋5%／10%奖励不加到其他剑上。
- 降至10种以下仍可由已解锁的非矿主剑积攒，但立即失去10层飞剑伤害与速度＋50%；图鉴已同步。

本轮不修改17槽、存档字段、原版主剑攻速、粒子或0.3.30特效。
