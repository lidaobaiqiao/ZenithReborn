# 特效库M2 · 分类与剑身一体组

日期：2026-10-23。用户已确认M1底色与动态蒙版分离，进一步要求按特效种类分类，各类按剑名存放动效蒙版；底色保持相似分类，方便复用。

## 已建立的结构

- [VfxLibrary/README.md](../VfxLibrary/README.md)：分类、制作与复用约定。
- [VfxLibrary/INDEX.md](../VfxLibrary/INDEX.md)：按中文剑名浏览蒙版与底色。
- `Masks/SwordBody/剑名`：拖尾、剑身流动、边缘、剑头破空作为一套完整动态蒙版制作，共用一个底色引用。这四项是覆盖范围，不是四个叠加槽。
- `Masks/Rings/剑名`、`Masks/Particles/剑名`：圆环和粒子独立分类，不塞进剑身一体组。
- `ColorFields/类别/剑名`：对应底色入口，通过稳定ID共享来源，不复制相同纹理或慢流动配方。圆环、粒子默认可引用同名剑身底色。

剑身一体组的`appear/active/finish`是时间段，沿用同一画布、枢轴与色场相位；+X朝剑尖，不将这些时间段或局部动效重新拆成多层。运行时接入后，底色输出应按引用复用。

本轮按实际OreFamily.MaterialSwords登记22种物品，加天铸巨剑召唤形态，共23个剑名／形态入口；短剑与宽剑分别登记。每个入口含三类蒙版和三类底色位置，共138份逐剑描述，加3份共享来源，共141条。

逐剑蒙版均为`awaiting-art`，画布、枢轴及动画留空；底色为`unassigned`。目录和引用不代表美术完成或已经接入游戏。M1原版火焰示例归入共享粒子形状来源，不能冒充正式剑身一体蒙版。

## 查找、检查与打包

`checks/vfx_library.py`提供search和validate，核对唯一ID、目录分类、底色引用及循环、资源／来源文件、剑身一体组覆盖与唯一底色入口；23个剑名／形态、141条记录检查通过。

原版资源以资源路径引用；原始MIT笔刷、噪声及许可证／provenance保留原位置，不搬迁或复制。`Examples/M1/composition.json`记录已有演示的底色、蒙版、时序和实现位置。

后续源码归档已加入VfxLibrary目录。本轮没有重建／安装模组，没有覆盖0.3.54安装报告或历史归档。其他对话的灵能族基础、全部生产渲染源码、战斗、环境、槽位与存档保持。本轮只是资料整理，没有新增GPU／世界／多人测试结论。
