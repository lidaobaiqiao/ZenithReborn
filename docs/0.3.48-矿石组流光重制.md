# 0.3.48 · 矿石组流光重制

开发接续至2026-10-23。用户要求用已确认的新流光技术重做矿石组特效。本轮覆盖十四材质百炼飞剑、天铸巨剑，以及现有肉后六矿的附属表现；不实现肉前八矿M1草案或更改羁绊数值。

## 表现修改

- 十四材质蓄剑：两段有厚薄变化的材质色弧环围绕剑体收束；沿用原来的出生动画、共用圆环角度及不同材质配色。
- 飞剑齐射：原来的多条直线拖影改为原版MagicMissile动态流动材质、现成OniCrimsonSlash直刃模式和Luminance细亮芯。仍使用原有最多8个位置样本，传送和第二趟折返清空历史。
- 天铸巨剑：金白色收束预兆、宽流焰坠落尾迹和低扁扩散的材质冲击弧；剑身保留实际材质原版贴图，30帧预兆及坠落时序保持。
- 钴轻刃：蓝色短流刃；山铜三花瓣：粉色弯刃；钛片：银白弧刃和轨道流光。附属弹幕继续使用原来的运动、数量、命中与存活规则。
- 钯金只在实际成功治疗后给玩家暖色收束碎光，秘银生成印记时给目标绿色粒子反馈，精金条件命中时给目标红色碎光。它们是短促提示，不增加新的印记机制或持续效果。
- 生成、飞行和命中的旧点状粒子接入共用`SoulFlowSpark`，保留各材质色相，脱离后独立减速淡出。普通主剑既有原版粒子与轨迹不替换。

## 复用与接入

`OreVisualRenderer.PostDrawTiles`集中调用飞剑、天铸巨剑和附属弹幕的纯客户端绘制接口，使用当前原版VertexStrip、Luminance PrimitiveRenderer、原版MagicMissile和0.3.47随包已有的MIT OniCrimsonSlash资源。没有增加依赖、Shader或贴图。

`MartialCrescentMaterial`抽取同一材质初始化／四顶点提交，并开放现成直刃和弧形模式给矿石组。武技入口的几何、配色与参数保留。每次绘制完整重置材质参数，外层恢复混合、深度、栅格、裁剪、0～2纹理／采样器及顶点／索引缓冲；Effect仍私有持有并在卸载时释放。MIT资源、许可证和来源哈希继续随包保留。

攻击触发、各剑独立伤害、1／2／4／6／8／10阶梯、每主剑首击积攒、取消共用冷却、折返、命中次数、词缀、支援、累计收集、存档与网络格式保持。肉前八矿候选新机制仍未实装，武技仍是默认开放的攻击原型。
