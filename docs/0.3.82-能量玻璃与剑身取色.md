# 0.3.82：能量玻璃与剑身取色

> 后续用户反馈：保留本版颜色，但质感远不如上一版。不能将本版整面发光/统一压缩当成美术认可；0.3.83沿用颜色，恢复玻璃反差。

用户认为0.3.81对比优秀成品仍暗淡，且颜色必须随剑身变化。本版保留R3玻璃基础，调整光能和色彩来源，不改变攻击、短尾或实体剑影伤害。

## 生产修改

- 新增SwordSpritePalette：按当前物品贴图的当前帧取刃身主色，排除透明、暗描边和多数剑柄区域；缓存按物品/帧/纹理组织，卸载清理。银白剑不强行染随机颜色，无具体物品的制作预览继续接受调用方颜色。
- SwordFlowMaterial仅在默认主飞剑路径接新主色，原形态种子仍使用原输入，避免颜色改变动态蒙版；其他系统的SoulVisuals调色表不动。
- 同一ZRSwordFlow内增强亮色主体、动态流丝与法线驱动刃缘，减弱中性反射对色彩的主导；按最大通道压缩光能，避免各通道分别压缩趋于灰白。没有叠新贴图、静态白线或额外粒子。
- Alpha公式、法线、IOR1.5、粗糙度0.08、透射0.55、厚度72、短尾形态和结束时序保持。所有素材字节保持；无新玩家依赖或玩家材质设置。

## 成熟成品对照

见[特效库对照记录](../VfxLibrary/References/能量玻璃-成品对照-2026-10-25.md)。查看用户提供的红色鬼切截图及本项目历史青紫巨剑，并核对灾厄大修CrimsonSlashRenderer与灾厄ExobladeProj实际调用方。借鉴亮色主体/热刃/暗侧的职责划分，不复制其材质或着色器，也不冒充运行外部模组的同场景对比。
