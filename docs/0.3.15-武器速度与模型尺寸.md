# 0.3.15 · 武器速度与模型尺寸

用户反馈0.3.14仍然太快、模型过小。上一轮仅放慢了释放节奏，主剑真实飞行仍为18～55帧，矿石飞剑冲刺24像素/帧、显示为原武器72%。本次分别调整释放节奏、飞行时长及纯显示尺寸。

| 项目 | 0.3.14 | 0.3.15 |
|---|---|---|
| 基础挥臂周期 | 平均寄宿间隔×1.5，25～90帧 | 平均寄宿间隔×2.25，40～135帧 |
| 攻速加成后的最快整轮 | 25帧 | 40帧，5节点至少间隔8帧 |
| 主剑真实绕行 | 来源间隔÷近战攻速，18～55帧 | 来源间隔×1.75÷近战攻速，36～90帧 |
| 主剑显示 | 来源尺寸 | 原显示×1.6，模型/残影/弧面/粒子位置同步 |
| 矿石冲刺速度 | 24像素/帧 | 12像素/帧 |
| 矿石剑显示 | 原武器贴图尺寸×0.72 | 原武器贴图尺寸×1.25，比上一版大约74% |

`SoulItem.EmitBlade`将实际飞行时长写入原弹幕ai字段；`SoulBlade.DisplayScale`独立于原碰撞用`Projectile.scale`，`OreFlyingSword.DisplayScale`也只参与绘制，矿石碰撞尺寸仍为20×20。仍保留主剑每8帧再次命中、原伤害公式和每次出剑的首个有效命中机会；改变释放/飞行节奏会改变整场战斗的命中次数和DPS，本次没有承诺总DPS不变。

2026-10-20：生产模组与夹具编译0警告、0错误，隔离引擎3647项断言通过。实际原版ItemCheck自动连击验证极端攻速下最快40帧、各出剑节点至少8帧且只轮换一次；实际发射验证绕行时长下限、主剑显示与碰撞尺寸分离、矿石速度与尺寸，并回归首击触发、帧伤、UI输入和存档保护。木质族检查中的手工计时同步到当前最短周期，避免用旧25帧截断测试。

本版未重新运行图形客户端手感、完整模组组合或真实多人测试。0.3.14的图形记录仅是历史证据，不视为0.3.15实测。正式安装结果和备份路径记录在`artifacts/install-result.json`。
