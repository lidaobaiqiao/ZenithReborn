## 已确认：属性与机制分别判定

| 层次 | 用户确认的规则 |
|---|---|
| 环境之力收集 | 玩家收集环境之力，获得对应属性；环境仍与种族、单剑特性并行 |
| 属性 | 收集后提供属性，不要求玩家必须站在对应环境内 |
| 独立机制 | 默认只有身处对应环境时才生效；不能因已经收集就让全部机制在所有地形自动运行 |
| 环境适应性 | 代价来自不适应的环境，而不是拆分攻击、暂扣伤害、消耗恢复或增加承伤等机制内惩罚 |
| 环境祝福 | 随收集的不同环境数量增加，获得环境祝福；玩家可以选择若干环境机制常驻生效 |
| 范围环境切换 | 玩家可以将自身一定范围内的环境切换为已经激活的环境，获得主动运用环境的能力 |
| 主动环境强化 | 用户明确不限制主动环境，并使主动环境的对应效果增强50%；不得为了维护常驻名额价值而自行增加限制 |

森林适应性按用户2026-10-22最新决定：没有任何虚弱环境；此前沙漠/地狱减半提案已撤回。其他相克为设计候选，首版实现详见0.3.40记录。

“收集环境”与现有有效寄宿标签之间如何取得、保存、失去，用户尚未细定。本页不擅自将其实现为永久登记、背包持有效果或新的武器寄宿计数规则。

## 最新确认：主动环境是额外优势

用户明确撤回助手提出的“用持续时间与冷却约束主动领域，以免绕过常驻名额”方向。主动创造环境本身是玩家获得的力量，应鼓励使用；不能将助手的平衡顾虑升级成实现要求。

主动环境提供对应环境效果增强50%。设计表达上应清楚区分自然环境下的通常效果与主动环境下的强化效果。具体与共同羁绊、适应性以及各机制参数如何结算，后续逐项明确；不得由这条规则自动把伤害、频率、数量和范围等所有参数同时乘1.5。

不自行加入持续时间到期、冷却、资源消耗等限制，也不为“保持祝福价值”削弱或取消主动环境的强化。常驻机制与主动环境两项能力同时保留，不要求将后者设计成受限的临时爆发。

## 与共同羁绊的关系

保留E3确定的共同成长方向：环境数量决定共同强化档位，每个符合生效条件的环境机制采用该档位。共同强化不豁免机制的环境门槛。

设计及将来UI应分别表达：

1. 已收集/已激活的环境及其属性。
2. 因当前环境而正在运行的机制。
3. 玩家通过环境祝福选择的常驻机制。
4. 当前主动切换的范围环境。

以上是不同状态，不得用同一个“激活数量”同时代替全部状态。共同羁绊的具体计数集合与祝福数量档位需在落地前明确；E4的每种加10%与满21种三倍仍为未获批候选。

## 简单示例

玩家拥有森林、冰雪、地狱三种环境之力，当前身处森林：三种环境属性按各自适应性结算；默认只有森林独立机制满足地形条件。若玩家已获得一个常驻机制名额并选择冰雪，冰雪机制也可以在森林运作。

玩家还可以主动选择已激活的环境，切换自身一定范围的环境。切换后的地形判定、适应性与机制启用应采用统一规则；具体是否替换原环境、允许几个环境并存，以及常驻机制是否仍受不适应惩罚，尚未确认。

## 待设计，不能擅自定案

- 环境之力的收集来源、激活条件、归属玩家或剑魂，以及是否需要持续寄宿。
- 收集数量对应的祝福档位、常驻名额数、选择与切换方式。
- 常驻是豁免地形门槛，还是同时豁免环境适应性惩罚。
- 范围环境的半径、选择方式及同时可切换的环境数量；不擅自附加持续时间、冷却或资源门槛。
- 主动环境增强50%对属性和各机制主参数的具体映射，以及与共同羁绊和适应性的结算关系。
- 范围切换是环境之力的局部领域，还是改变真实群系判定；不默认修改地图方块，也不默认只改背景视觉。
- 范围内其他玩家、敌怪、Boss召唤/狂暴、刷怪与掉落是否受影响。
- 人造范围环境与原有环境的优先级，以及是否能反向增加收集/共同羁绊数量；不得通过自身领域未经设计地循环制造收集进度。
