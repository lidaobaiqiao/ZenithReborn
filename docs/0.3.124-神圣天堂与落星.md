# 0.3.124：神圣天堂与落星

用户指定神圣及太空武器组成神圣天堂，星辰主题也计入；有效寄宿后主剑命中自动召落星。首批名册为珍珠木剑、星怒、神圣剑、真神圣剑、星光、狂星之怒、日耀喷发剑、破晓之光。珍珠木剑同时属于木质族；名册独立于可修改的环境属性，原木质和矿石规则保持。至少一个有效族成员与一把有效主攻剑使该特性生效，支援及切换限制沿用现有有效槽规则；未新增种族收集档位或支援奖励。

本机反编译的原版 Projectile.AI_148_StarSpawner 显示自然落星 projectile 12 的基础伤害为 1000。落星使用原版落星贴图、默认规格和第5类坠落AI，以独立弹幕实例承载，白天也能用且不会生成可拾取物品。命中敌人或方块后产生半径120像素的1000基础伤害冲击；直击目标主体不重复承受冲击，每个其他目标主体仅受一次冲击。方块会阻挡落星；目前按目标命中位置上方600像素生成，目标可通过移动躲避。每枚剑魂300帧冷却为本轮暂定初值，非用户确认的数值。目标防御及游戏伤害浮动仍会影响实际数字。

`HolyHeavenFamily` 管理名单，`HolyHeavenProc` 管理触发和冷却，`HolyHeavenStar` 管理落星及冲击；主飞剑只增加调用。特性界面新增神圣天堂筛选和说明，不改变天顶剑迹、飞剑速度或旧族算法。两项目用本机 tModLoader 编译，零错误零警告；独立服务端15项检查覆盖有效主槽、支援、界面筛选、生成、1000基础伤害、直击、范围排除、冷却、方块撞击和世界清理。没有做真实游戏画面、自然游玩、多人或美术验证。
