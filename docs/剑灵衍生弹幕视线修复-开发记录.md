# 剑灵衍生弹幕视线修复开发记录

本记录描述工作区中的开发候选，**不代表已打包安装或已通过自然游玩验收**。源码版本号仍为 0.3.130；安装状态应以实际安装记录为准。

## 问题与修复

UpgradableZenith 的 TerraZentih 由剑灵代理发射原版 933 弹幕后，命中效果通过真实玩家的 `GetSource_FromThis()` 创建 `UncenteredSwoosh`，而非以 933 为父源。该剑气要求按使用者位置检查方块视线。此前剑气读取真实玩家的位置：真实玩家隔墙、代理与目标同侧时错误地无法造成伤害；反过来，代理隔墙而真实玩家与目标同侧时又可能错误命中。

`LivingChannelProjectile.cs` 将来源代理身份 `Origin` 与依附型弹幕 AI 的 `Proxy` 分开记录。直接由代理使用物品产生的弹幕记录来源；同归属的弹幕父源可以继续传递来源。已记录来源的弹幕在 `Damage` 执行期间建立可嵌套的线程内来源上下文，以识别该次伤害回调中由相同真实玩家或对应代理作为来源创建的弹幕。退出或异常时恢复上一层上下文。

对于要求检查使用者视线的弹幕，`CanHitWithMeleeWeapon` 检查期间临时使用对应代理并在退出时恢复。来源记录本身不会使未知弹幕的 AI 切换到代理；伤害和命中回调也不会因来源追踪而整体替换真实玩家。既有依附型弹幕的 AI 代理行为保留，具体仍以源码为准。代理已失效、玩家不匹配或无可确认来源时，视线检查退回原有真实玩家路径。

## 已有验证

- 实际 UpgradableZenith 隔离服务端复现：原路径下的正反隔墙错误均已复现；候选代码下代理与目标同侧时子弹幕造成伤害，代理隔墙时子弹幕未造成伤害。真人持有该模组武器时，隔墙不命中、移墙后可命中；实际命中观察器看到的 `Main.player` 为真人。原始输出位于 `artifacts/modded-followup-20261105/`。
- 独立测试入口 `checks/ZenithPrototypeCheck/LivingChildSightCheck.cs` 由环境变量 `ZENITH_CHILD_SIGHT_REPORT` 显式启用，仅在隔离服务端执行。测试用真实代理发射父弹幕，模拟命中回调以真人为来源创建 `ownerHitCheck` 子弹幕，并检查正反隔墙伤害、普通真人弹幕无误绑定、回调中的真实玩家状态与上下文恢复。两代理来源的嵌套伤害及异常恢复采用直接调用伤害包装器的合成测试，不代表两把武器的自然战斗。测试报告 `artifacts/fix-modded-sight-20261105/child-sight.txt` 为 **13 项通过**。
- 原有剑灵隔离回归包含蝙蝠棍真实治疗链及视线等检查；含新检查的隔离副本曾通过 **66 项**，对应 `artifacts/fix-modded-sight-20261105/report.txt`。独立检查中直接修改生命值仅用于验证回调的玩家状态归属，不能单独证明治疗链。
- 候选主模组和独立检查模组由 tModLoader 原生编译器在独立目录构建，均为 0 错误、0 警告。验证所用候选主模组 SHA256：`43ACA3C479458A69810E82F85A0C956D2F8C05F92E748A31C44E9E3C7C4DAE7B`。

## 边界

此修复识别实际物品来源、同归属父弹幕来源，以及已确认代理来源的伤害回调中由相同玩家产生的来源。没有关联来源、脱离该伤害调用窗口的延时生成、异线程来源和未知模组自行维护的其他玩家引用，不保证覆盖。尚未验证所有近战武器及所有模组、图形客户端、自然操作、真实多人或性能；隔离服务端结论不等同于这些验收结果。
