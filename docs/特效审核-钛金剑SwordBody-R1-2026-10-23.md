# 钛金剑 SwordBody R1 画面审核 · 2026-10-23

结论：**本轮美术不通过，需要 R2；当前可保留为结构样例，不宜批量适配。** 外轮廓确有动画、剑尖定位和剑身尾迹连接成立，但箭头式大色块遮住原版剑体，边缘动态的连续流向不足，明暗背景下的材质观感不统一。

本结论属于审核判断，不等于用户认可，也不授权修改玩法、安装或替换正式包。

## 审核证据与边界

- 制作方提交的 `artifacts/swordbody-R1/context.png`、`breakdown.png`，以及同目录 `loop-context`、`lifecycle` 的原始 GPU 帧；另查看 `VfxLibrary/Masks/SwordBody/TitaniumSword/R1/contact-sheet.png`、`clip.json`、`generation.json`。
- 以提交包的正常倍率固定姿态为准。审核从原始 60 fps 图像序列抽取关键帧、循环接缝和收尾连续帧，未另行启动实时视频播放器。对运动节奏的判断来自时序画面，不能声称已完成原速实战观感验收。
- 审核抽帧位于 `artifacts/swordbody-R1-review/`，均为原画面等像素裁剪拼排，没有调亮、锐化或放大效果；标签时间从对应片段 0 秒起算。
- `gpu.json` 是制作方的技术记录；本审核读到其相乘误差 0、过期残留 0 和未安装等标记，未独立重跑技术夹具或核验正式包哈希。技术通过不替代美术结论。
- 提交内容为固定姿态隔离 GPU 预览；运动攻击、命中反馈、多剑重叠、复杂地形和多人均不能据此判为通过。

## 阻塞项

### B1：箭头／火球轮廓抢走了剑的身份

位置：`breakdown.png` 中间白色蒙版和右侧结果；`loop-context` 全循环均存在，尤见 0.00、0.20、0.40 秒。

前端是稳定的大三角，后方膨大成团，再分出数条火舌。第一眼更像带尖头的魔法弹或火球；正常倍率下难以先认出“被能量包络的钛金剑”。连接完整这一点成立，但连接完整不能抵消主体造型不合适。

修改方向：让真实剑刃轴线和长宽关系主导主体，收窄中后段的鼓包，减少前端三角的面块感；最前端直接顺着剑刃收尖。尾部宽度沿剑身向后递减，边缘波峰留在同一蒙版内，不补独立 V、双弧或星芒。不要只把整张素材等比缩小，需重做主体与尾部的比例。

### B2：持续状态遮住原版剑体，着色结果缺少金属可读性

位置：`context.png` 上下两栏；`loop-dark-1x.png`、`loop-light-1x.png` 的全部关键帧。与 `lifecycle` 0.20 秒及 2.00～2.20 秒露出的原版剑体比较最直接。

持续阶段主要看到青黑色块，只剩尖端少量紫白像素和边沿能提示原版贴图。消散时原版金属剑才重新显露，说明包络与剑体的关系没有处理好。暗背景下外缘过暗偏软；亮背景下青黑主体更像烟或墨迹，弱化了锋利、流光的感觉。

修改方向：先在同一蒙版中降低覆盖实际剑体区域的 Alpha，保留连续的半透明包络，让金属纹理和明暗稳定可见；再调整共用底色的青／紫分布和局部明度，使细边缘有清楚但克制的光感。不要把整层统一提亮到白，也不要通过挖大洞来露剑。收窄主体后重新判断覆盖度，避免只改透明度留下宽大薄雾。

验收目标：正常倍率下，循环中随意停帧都能辨认出剑刃、剑尖及至少一段连续的原版明暗结构；明背景仍像能量包络，暗背景仍看得清细边缘。

### B3：外轮廓会变，但连续向后流动的证据不足

位置：`loop-dark-1x.png` 0.10～0.35 秒和 0.40～0.60 秒；蒙版 16 帧接触表。

这不是固定轮廓里滚噪声：上下火舌和尾端确实有形变，应承认这一进步。但上侧大弯钩与下侧火舌多次在相近位置换形、涨落；从相邻形态中难以跟住同一个波峰持续向后传递，局部更像形状交叉融化。线性 Alpha 过渡能缓和跳变，不能单独证明运动连续。

修改方向：在一整段循环中明确少量可追踪的边缘波峰：靠前段生成，沿侧缘向尾端移动、拉长和消失。相邻帧保持同一波峰的对应关系，新旧波峰交接；主体固定，尾部延迟响应。优先重排或重做动画相位，不先靠增加帧数、加速播放或加粒子掩盖问题。

验收目标：先只看黑白蒙版，能指出至少一组波峰从前向后的完整过程；再看着色和原版剑体合成的原速片段。外轮廓像素变化量只用于确认有动画，不作为本项通过标准。

## 建议项及当前可保留部分

- **一体关系可保留。** 尖端、主干和尾部来自同一连贯蒙版，未见重新拼回独立前帽、双弧或绕圈粒子。无需为解决上述问题拆回多层。
- **循环接缝暂未发现明显硬切。** 核对 0.70～0.85 秒，即 16 帧循环跨越 0.80 秒的画面，未见剑尖突然换位、空一帧或整片重置。此结论限于所检查时序帧，原速节奏仍待确认；接缝不是当前优先返工点。
- **结束有撤尾和淡出，基础收尾可用。** `finish-1x.png` 1.90～2.30 秒可见尾部逐步撤去。主要问题是被遮住的剑在 2.00～2.20 秒重新显露，视觉主体从能量块切回金属剑。先修 B2，再判断是否还需要收尾调整；不建议为此新增爆闪或独立结束图案。
- **边缘清晰度需随主体重做一起复查。** 当前细尾柔糊、粗火舌占比偏大。保留适量软边，控制少量有方向的细尾，避免补锐化光圈；不要追求每根毛刺都发亮。

## R2 最小提交范围

仍只做钛金剑单例。按 B1 → B2 → B3 的顺序修正，提交同一版素材对应的黑白蒙版、底色×蒙版、原版剑体明暗背景循环和完整出现／结束；增加一小段实际移动的隔离回放，以检查拉尾方向和速度感。静止片段与移动片段各自标明原速、实际倍率；可另附慢放，但不能替代原速。

R2 通过单例后再讨论多剑叠加和批量适配。此处没有要求安装正式包或开展真实多人测试，也没有要求恢复历史叠层方案。
