# 0.3.93：纯代码特效隔离与贴图独立验证

用户要求逐项排查混入的难看特效，只允许纯代码效果，绝不引用项目特效贴图。接手时虽已有纯代码预设，SwordFlowMaterial仍加载笔刷、噪声、法线等图与四区原始数据，逐剑材质可绕到另一渲染器，面板全开也没有资源限制。因此不能凭预设名称认定已经实现隔离。

## 实现及模块归属

- `VfxIsolation.PureCodeOnly` 为本轮统一策略；外部输入依赖写在现有分支/构成定义内，不另建一份运行状态。面板切换与全开服从同一限制，shader参数提交端再次过滤。
- `SwordFlowMaterial` 在读取素材配置之前停止加载；原始通道、默认纹理、逐剑素材及通用材质绑定均受限制。绘制时只绑定代码创建的1×1白色中性值，不采样真实屏幕。
- `VfxSwordMask` 不登记或请求矿石剑身图集。`OreSwordEffects.Halo` 停用自有光斑；两个自定义粒子保留类型登记，但改用原版中性资源完成登记并关闭发射入口，避免自动加载自有SwordSpark。
- 屏幕滤镜激活入口也服从纯代码策略。没有删除原素材，没有调整攻击、伤害、碰撞、时序或存档规则。

## 本轮起始状态与操作

- B1带面、B4消散片开启；消散片本体、消失曲线和尾部吞噬开启。
- 20项程序构成开启：P01～P19、P24。可逐项摘除，找出不满意的贡献。
- P20噪声图高光、P25自发光图，以及P21～P23屏幕采样项锁定关闭。
- B2/B3/B5/B6及B7关闭并锁定，避免原版粒子/星芒和屏幕滤镜混入。
- F7下一项，F8上一项，F9切换；不允许的项会显示禁用原因。F10全关；Shift+F10只打开允许的纯代码项；Ctrl+F10恢复上述预设。

1×1中性纹理由代码创建，不是项目图片。剑本体和正常游戏画面仍按各自原有路径绘制；本轮隔离针对上述特效贡献，不把“没有我们的特效贴图”说成“整个游戏没有纹理”。

## 本轮验证

- tModLoader原生构建两个项目零错误、零警告；当前隔离配置8153项引擎检查通过。粒子分支在当前配置关闭，其专项按既有检查入口跳过，不能称原8393项全部重测。
- `PureCodeVfxRenderCheck`调用生产SoulMaterialTrail/SwordFlowMaterial，在实际GPU绘制默认、全开、强行开启外部项、20项单项关闭、12帧运动、三种剑色及零覆盖度，共39张图。
- 检查素材字典/原始通道集合全部为空，默认笔刷和噪声为空，11个素材/屏幕使用uniform为0，存在的采样器全部绑定运行时1×1中性白图。
- 对不存在的纹理路径发起运行时材质绑定，确认被拒绝且未请求资源。面板全开对应的setter和绕过面板直接写数组，均不能恢复外部输入贡献。
- 由完整包制作物理删除36项`Assets/Vfx/`资源及自有光斑的隔离包。验证两包DLL逐字节一致；两个独立客户端39张GPU输出全部逐像素一致。删除列表、DLL及两包哈希见`artifacts/pure-code-vfx-0.3.93/package-independence.json`。
- 首轮严格对照未通过，RGB最大差1～2、Alpha一致；检查发现夹具只固定材质动画时间，未固定世界时刻。补齐固定白天16200后重新运行通过，未放宽像素标准。首轮失败记录保留在`first-attempt/`。

当前证据是受控GPU与引擎检查，不是自然游玩、真实多人、美术认可或每个程序项在所有姿态下均可独立产生可见像素的证明。消融记录中P06/P07在非消散状态、P08在无屏幕采样状态可能没有当前帧颜色差，需按功能前提测试。

复现：先`pwsh -NoProfile -File checks/run_wood_checks.ps1`，再`pwsh -NoProfile -File checks/run_pure_code_vfx.ps1`。专项汇总见`artifacts/pure-code-vfx-0.3.93/independence.json`。正式安装状态以本轮安装记录和实际哈希为准。
