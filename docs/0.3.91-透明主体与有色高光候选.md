# 0.3.91：透明主体与有色高光候选

> 用户最新反馈：材质本身应有光亮，当前仍有不明色块，并要求查看单独高光图。本轮仅补导出[正常显示的三色高光](../artifacts/clear-highlight-0.3.91/highlight-display-three-colors.png)，未修改生产材质。该图在无世界背景时仍有暗块/条带，说明至少一部分问题来自材质/高光计算，不能把全部色块都归因于背景折射。后续须保留透明玻璃表面的柔和亮度，再做更强的局部高光；当前91未获美术认可。

用户明确79只有两项主要缺点：高光不如后续版本，亮边到主体/暗侧缺少过渡、整片偏实。随后提出「主体本身透明，过渡色本身是一块高光」。本轮以原始79开发基底实现该结构的第一版候选，未安装正式包，尚未获得美术确认。

## 材质结构

- 主体只保留偏折后的当前背景、少量中性光能损失与菲涅耳反射损失，撤下整片底色和均匀自发光。
- 剑色集中进入一块由曲面法线、主光方向和粗糙度控制的高光。使用后续版本采用的GGX计算窄核，有限面积光源的柔和近似包络形成过渡。主光方向按世界日/月相位计算，不读取R3固定环境图。
- 保留79薄亮刃，撤下横穿主体的平行坐标扫光线；有色高光由亮核连续过渡到透明区域，不另画一片贴图。
- 保留79原折射法线、真实剑迹、IOR1.5、粗糙度0.08、透射参数0.55、厚度72及覆盖度公式。没有降低整片Alpha冒充玻璃通透。
- 原生滤镜将高光光能与透射背景在线性空间相加。通用分区材质的高级透射分支保持。

沿用79原配色，尚未把88的实际剑身贴图取色接入此基底。不新增贴图或第三方资源；攻击、伤害、剑影、碰撞、运动、时序、槽位和存档保持。

这里是二维曲面与屏幕空间材质近似，不称完整物理光学或完整三维光线追踪。

## 验证

- 两项目原生编译零错误、零警告，8393项引擎检查通过。
- 实际GPU中光向变化影响134449像素，三种输入的高光输出不同。高光较弱的内部采样域，在均匀灰背景上平均亮度比约1.001；只说明该域接近背景，不代表整片已经达到用户要求。
- 与原始79对照的RGBA8法线/覆盖度缓冲最大差1个8位量化级。公式/几何未改，新增计算后编译器排布可能引起量化边界变化；验收允许最多1级，未宣称像素差0。首轮严格0门槛报告保留为`gpu-first-attempt.json`。
- 正式五模组组合、正式画面设置的隔离白天/夜间世界均通过三剑实际命中、返回和结束清理。原生滤镜同帧IOR对照通过，外部变化像素0。
- 夜间与收藏原始79共136条姿态记录逐项匹配，位置/角度/阶段最大差0；背景细节随机性未做逐像素一致承诺。
- 本轮未测自然鼠标游玩、真实多人，未重新做三个剑影的专项伤害测试；不沿用其他包哈希冒充本轮验证。

当前正式包仍原始80。本轮只打包候选，90原始79开发基底已收藏；89继续停用，不自动安装91。
