# 能量薄刃A1：八张贴图验收与制作候选

本轮接收用户通过豆包制作的八张512×512灰度图。原图位于`artifacts/vfx-textures/energy-blade`，不覆盖、不重新生成原交付；`_brush-raw.png`不在本次八张验收范围。

## 原图核对

八张均为512×512、L模式、不透明PNG。刷纹、噪声、高度、粗糙度的横向首尾平均差约为1.46、0.88、0.83、0.37个灰度级，适合继续做横向循环测试，不把这个数值当作无缝美术认证。笔刷纵向首尾平均差17.74级，因此A1配方只沿U滚动，V频率设为0.8、纵向速度0，避免在有效带面内重复纵向接缝。

高度范围86～136，粗糙度59～127；四区按同一UV配准。当前分区主要沿带面宽度划分，属于第一版通用区域，不宣称已经按真实泰拉之刃像素轮廓逐点手工配准。

完整逐图SHA256、范围及接缝记录见`artifacts/energy-blade-a1/preparation.json`。

## 派生与接入

- 从height有限差分生成normal：U环绕、V边界保持；法线归一化，绿色正向沿V。高度系数0.035，制作配方的法线强度0.65。高度图本身不额外驱动几何置换或重复凹凸。
- surface按现有通用材质合同打包：R金属0、G用户粗糙度、B环境遮蔽1。全局粗糙度0.24与灰度相乘，局部区域调整前约为0.0555～0.1195。
- 四张region分别进入RGBA，生成`regions.zrdata`直接上传，保留Alpha为0处的RGB。
- 底色沿用逐剑Tint与现有材质；没有把所有剑涂成同一颜色。IOR1.5、透射0.55、虚拟厚度72、整体覆盖度1。四区分别轻调亮刃、主体、暗侧和少量细缕；整体动态形状保持现有程序路径。
- 本轮没有更换正式ZRSwordFlow或21把矿石H4；通用Surface材质仅在独立制作档使用候选配方。

登记入口：`VfxLibrary/Materials/Surface/TerraBlade/EnergyBladeA1/entry.json`。Brush、Noise、Height、Normal在对应大类的`SwordTrail/_Shared/EnergyBladeA1`；粗糙度/表面图与区域图在对应大类的`SwordTrail/TerraBlade/EnergyBladeA1`。原始图来源标为用户经豆包提供，法线/通道转换和配方由项目编写，不混称为第三方模组素材或全部手绘。

## 验证

独立实验室0.1.2复用已安装0.3.69的生产SurfaceMaterialRenderer，自身编译成功。专用档是`artifacts/material-lab-profile-energy-blade-a1`，不覆盖原工作台草稿或正式人物世界。

实际GPU对照包括未接入这批表面图的通用材质、完整候选、逐项关闭NormalMap/SurfaceMap/Brush/Noise/LayerMask、三种武器Tint、48帧固定合成剑迹回放。完整候选相对基线有3602个可辨变化像素；逐项关闭均产生实际画面变化；两者覆盖轮廓相同。运动另用固定平面排除轮廓呼吸干扰。

结果和最终主包/实验室包哈希见`artifacts/energy-blade-a1/gpu/artwork.json`。这些图是合成轨迹的材质预览，不是世界战斗、鼠标攻击、真实多人或用户美术认可。新素材尚未写入正式武器绑定。

素材导出经过`checks/import_material_export.py`导入专用`artifacts/energy-blade-a1/import-stage`，验证四区原始载荷与材质字段可以进入标准来源结构，仍未改正式源码绑定。

## 打开、调整与重做

双击`tools/打开能量薄刃A1.cmd`打开候选的独立工作台；第一次复制候选，后续交互打开保留专用档已有Input与草稿。左侧仍为通用材质滑块，细节层配方可编辑专用档的`MaterialLab/active.material.json`后加载。

`checks/prepare_energy_blade.py`可重新生成派生文件；`checks/run_energy_blade_preview.ps1`自动生成实际GPU对照；`--register-library`在GPU记录通过后登记候选。需要重调区域时改原交付的新版副本并建立下一版本，不覆盖这次验收原图。

本轮主要变化是细纹、局部反光与材质分布，不是扩宽或加厚整片特效。下一步由实际预览决定笔刷强度、法线强度及分区过渡是否合适，再考虑正式逐剑接入。
