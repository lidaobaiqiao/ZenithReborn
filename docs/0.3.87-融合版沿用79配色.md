# 0.3.87 · 融合版沿用79配色

用户要求「特效颜色沿用79方案」。本轮保留0.3.86融合版的玻璃质感、光效形状和强度，仅把新增亮刃及扫光颜色对齐原始0.3.79。

## 颜色核对及修订

逐剑基础配色原本就没有改变：`SoulVisuals.cs`与0.3.79逐字节一致；`uBodyColor`仍为原配色乘1.25，`uEdgeColor`仍按79的0.64向白混色、乘1.22。

差异在86新加的局部补光：原先将layerColor按0.72向白色混合，扫光又另做0.40混色。本轮改为79原始高光表达式：

```hlsl
float3 edgeLight=lerp(uEdgeColor,float3(1.15,1.18,1.22),0.55);
```

刃缘和两条扫光共用这个79高光颜色。86的补光宽度、强度、运动、动态蒙版和结束窗口保持。未启用82的剑身贴图取色。

这里的「沿用79」指逐剑调色来源、主体/刃缘颜色输入和高光混色配方；融合版仍有80的受光、反射与背景透射，不能宣称最终画面的RGB与79逐像素一致。

## 范围和证据

相比86，仅修改ZRSwordFlow源码/编译结果、着色器构建清单与版本号四项；其余121项生产文件字节相同。攻击、伤害、轨迹、玻璃法线/光学/透射/覆盖度及各类保存规则保持。
