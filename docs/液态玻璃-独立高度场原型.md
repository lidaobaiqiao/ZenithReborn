# 液态玻璃：独立高度场原型

## 范围和状态

根据用户提出的“曲面起伏 → 法线 → 反射与折射”方案，建立检查模组内的独立平面 Shader 原型。它没有接入生产刀光，也没有安装；正式安装仍为 0.3.111，SHA256 为 `11cd178e26885298305bad2b0360e8675338c4f40122ff19dc4646b322972e58`。0.3.112 D 继续保持未安装的研究候选。

## 原型结构

- `checks/ZenithPrototypeCheck/Assets/LiquidGlass/LiquidGlass.fx`：在宽 2、高 1 的等尺度平面上生成最多三条弯曲条带，条带宽度、高度和中心线随时间连续变化。条带本身不发光；使用最终高度梯度形成法线，同一法线输入虚拟矩形面光、菲涅尔和单界面屏幕折射。
- 条带横向截面使用 `max(0, 1-d²)³`；当前候选纵向也用同类有限支撑凸包，因而不再有大段恒高的平顶。距离是同一沿向位置的横向偏移近似，并非曲线的精确最近距离。当前参数形成偏短、相对集中的两处起伏，不能当作已经铺满刀光的液态表面。
- 多条带可选择严格最大值，或仅在高度接近且均高于基面的区域进行有限平滑。平滑权重在接近基面时趋零，每次合并最多抬高 0.003 个表面坐标单位，三条依次合并最多抬高 0.006。渐退区的交叉法线仍不保证完全连续。
- 矩形面光是反射方向上的角度近似，非精确面积光积分。折射是单界面屏幕空间近似，不能表现背面、被遮挡和屏幕外内容。

## 已有检查

`checks/compile_liquid_glass.py` 使用本机 D3DCompile 独立编译 Shader，成功且无编译器警告。`checks/check_liquid_glass_geometry.py` 的标量数值检查通过，结果在 `artifacts/liquid-glass-prototype/numerical-check.json`：单条截面的边界高度和斜率趋近零；代表性交叉处严格最大值左右斜率为 -0.25 / 0.5，平滑后约为 0.12488 / 0.12512；平滑抬高在两条高度趋于零时也趋于零。这是数学性质检查，不是 GPU 或美术验证。

独立客户端在 RTX 4060 Laptop GPU 上运行，检查模组以零错误、零警告构建。最初高度场输出与背景完全一致；固定色与简单浮点分支探针通过，但复杂效果仍失败，失败证据保存在 `artifacts/liquid-glass-prototype/20261029-124320-720/`。反汇编显示原字节码用预着色器计算模式分支布尔值；保留相同源码、仅在独立编译脚本禁用预着色后，实际 GPU 输出从背景变成预期的高度与法线图。单变量对照证明编译选项影响了本机结果，不足以断言具体哪个运行时组件有问题；原始字节码保存在 `artifacts/liquid-glass-prototype/original-preshader.fxc`。

早期参数的 GPU 结果见 `artifacts/liquid-glass-prototype/20261029-125028-722/`。单条带也出现长亮线，主要亮线不在交界区，不能简单归因于 `max`。相同输入下以两倍宽高渲染并用 8 位输出的 2×2 通道平均降采样，部分断续点变得更连续，但长线仍在；这是采样相关性的有限证据，不是线性光能积分或性能数据。仅改变面光方向和角尺度的候选（`20261029-125219-652/`）让长线减少，但形成月牙状反光，另一时刻仍出现细线。

随后保持该面光，改变纵向凸包得到当前候选。最终结果与包哈希见 `artifacts/liquid-glass-prototype/20261029-125529-283/liquid-glass.json`。固定光源，分别采样 0.3、0.5、0.7、0.9、1.1 五个时刻，高度、反光和纯折射输出均有变化；固定曲面时移动光源，反光变化而高度和法线保持一致。纯折射对照保留同样的菲涅耳，只更改采样坐标，有 3917 像素发生变化。当前五个样本的严格交叉黑底反光表现为两片较完整的小面，未看到早期样本的贯穿长线或月牙钩，但画面偏暗；这只是独立平面上的离散固定输入与历史白天背景重放，不是自然世界、连续动画或美术通过。

当前样本以近等高区域（边界图 R≥192）和反光 R≥20 衡量，严格/平滑交界亮点分别为时刻 0.3 的 44/0、时刻 1.1 的 51/0。只说明该阈值和样本下的差异，不能证明其他交界或姿态无伪影；平滑也使这些位置的反光更弱。当前几何候选的 2× 降采样与原分辨率有 938 像素差异，在至少一图非黑的 1157 像素范围内 RGB 平均绝对差约 7.25/255，不能称采样问题已全部消失。试改前源码/字节码分别保存在 `artifacts/liquid-glass-prototype/before-curvature-trial.*`、`before-light-angle-trial.*` 和 `before-rounded-shape.*`。

## 后续接入边界

下一步应在保留曲面产生反光的前提下，继续验证有限支撑凸起在真实刀光网格上的映射，检查不同姿态、曲面尺度与时间下是否仍形成可辨小面。当前仍不能判断整体液态感是否达到用户预期；不能把固定 UV 亮斑、遮掉部分线条或孤立平面的结果当成最终刀光效果。

现有刀光纵向 UV 取决于实际轨迹长度，横向 UV 取决于带面宽度，二者不是等尺度；现有连续方向只保留方向而未保留完整尺度。因此不能直接把原型的 UV 偏导用作生产坡度。接入时需要明确连续、带尺度的坐标映射或梯度变换，处理尾端退化并检查是否重新出现网格分面。高度场的 `max` 只选择同一张虚拟表面的外层，不解决多张独立剑影的真实三维遮挡。

尚未接入生产刀光或原生世界、未测性能、自然操作或多人，也未获得美术认可。原型的多次曲线与光学计算不能假定适合生产实时预算；应在实际接入后测量，再决定直接计算或复用缓冲。当前无自动安装计划。

## 真实刀光网格的隔离试验

检查模组新增 `LiquidGlassTrailMesh.cs`、`LiquidGlassTrailRenderCheck.cs` 和独立 `LiquidGlassTrail.fx`：复用候选 0.3.112 D 的 `SoulMaterialTrail.BuildLayered` 输出几何，但不调用生产玻璃材质或生产屏幕合成。网格准备阶段在世界像素坐标计算 UV 梯度，对共享顶点做面积加权，并把带尺度的梯度交给着色器；着色器在统一的世界长度单位下使用链式法则求高度坡度，反射与折射共用同一法线。

面积加权是连续梯度近似，不是每片三角形严格雅可比。首轮固定网格共有 288 个三角形，其中 4 个退化，1 个顶点没有有效梯度；退化处跳过、无贡献梯度归零，并对极端坡度做钳制。这一夹具只支持单位缩放、无旋转及整数平移，不能推断其他相机或全部姿态准确。

首轮 GPU 报告位于 `artifacts/liquid-glass-trail-prototype/20261029-130000-123/liquid-trail.json`：高度图随 (40,20) 平移时，61293 个比较像素全部对应；覆盖外合成差异为 0，纯折射差异为 123 像素。但整条刀光约 61293 个覆盖像素中只有 39 个非黑反射像素，历史背景上几乎不可见。报告 `passed` 仅表示所列通路条件成立，不表示效果可见或美术通过。该轮几何来源包 SHA256 为 `71ba4a2c24ae6c936b26d464ce620362fb1f6216a480f19a0b51ac5de99a5474`；该结果不适用于之后修改的独立 Shader 与检查模组。

随后依据首轮实际法线提出对照：保持曲面仅变换光源方向，再在同一光源下改变曲面物理长度单位；夹具同时输出斜率钳制区和近似梯度边误差。检查条件要求单独改变光源时高度、法线和钳制图不变，改变尺度时高度与法线确有变化。17:16 一次启动被 tModLoader 的 Steam 登录校验拦截，失败日志保留在 `artifacts/liquid-glass-trail-prototype/20261029-171630-228/`；恢复后 `20261029-171849-892/` 实际运行通过，尺度 200 的反射由尺度 100 的 130 像素增至 500 像素，这仍是同一光源下变化了曲面大小的隔离结果，不表示成品。

为了检查曲面能否在刀光不同位置产生光学响应，隔离 Shader 新增第三处错开的圆滑高度凸起，并以三者的最大高度构成同一表面；没有直接绘制亮纹。最终 GPU 报告为 `artifacts/liquid-glass-trail-prototype/20261029-172051-233/liquid-trail.json`：固定姿态、整数平移匹配 61293/61293，覆盖外变化 0；只变光源时高度与法线图不变，尺度 200 候选出现 728 个非黑反射像素，坡度钳制像素为 0。相比双凸起对照 `20261029-171849-892/` 的 500 像素，出现了额外局部亮面；但历史背景合成仍呈几处孤立亮片，主体液态质感不足，不能当作成品或美术认可。`passed` 是夹具通路合同，不是外观通过。

该固定网格的面积加权梯度边误差平均约 0.006、最大约 0.442（原始 UV 单位、1136 项比较）；最大误差位于屏幕约 (97.57,105.65)、UV 约 (0.9875,1.46) 的横向方向，靠近退化尾端。在本次两种高度单位、该点的固定输入下它不位于三个凸起的有限支撑范围内；这不能证明其他姿态、时间或附近区域没有误差。GPU 均为固定相机和合成轨迹、历史画面重放，尚无自然操作或生产世界结果。检查包 SHA256 `54fabcd46eeb8fb80013390f1a12a951447304f1f81952901d5dda116ec1ae50`；实际几何来源为 0.3.112 D 候选包，SHA256 `71ba4a2c24ae6c936b26d464ce620362fb1f6216a480f19a0b51ac5de99a5474`。双凸起源码与字节码保存在 `artifacts/liquid-glass-trail-prototype/before-third-ridge.fx`、`.fxc`。

当前环境未发现现成的 FNA 材质级 GPU 计时接口。可用的 PresentMon 需要独立持续逐帧的 A/B 场景并采集整帧 GPU 时间，尚未建立或测量；不能将 CPU 提交耗时称为 GPU 性能。正式包仍为 0.3.111，磁盘 SHA256 保持 `11cd178e26885298305bad2b0360e8675338c4f40122ff19dc4646b322972e58`。
