# 0.3.130：木质族V2重做与口径统一

## 概述

用户判定 0.3.129 木质族 V2 完成度仅 30%，本轮按其指出缺陷重做：清理未删的旧木剑类、补上木质族属性面板、统一「有效寄宿」口径以解除诅咒过滤造成的判定分裂、去掉祝福接力对特性数值的额外放大，并把三条羁绊从纯客户端判定改为服务端重校验。编译打包并安装成功；图形客户端与真实多人仍未验证。

## 0.3.129 缺陷清单

1. 三把新增木剑只退出名册，`ModItem` 类未删除，仍可获取。
2. 阶段/属性 UI 完全不显示；`BondSnapshot` 分母仍为 12，显示「8/12」永不满。
3. 森林之力的 Full 判定走了诅咒过滤（`TraitEnabled`），未解「切换」诅咒时 8 木永不 Full、层数恒 0；而 UI/羁绊用未过滤 mask，两套口径分裂。
4. 8 项特性数值被 `relayPower`（祝福接力倍率 1~1.5）额外放大；血馥另用了另一套 Strength 源。
5. 三条羁绊入口判 `MultiplayerClient` 后直接 return，多人下完全失效。
6. `WoodCheck` 夹具引用已删除类型，检查项目一度无法编译。

## 0.3.130 改动明细

1. **名册清理**：删除三个木剑 `ModItem` 类与本地化条目。旧档物品变 `UnloadedItem`（可取回、不可放回），去重时跳过无效 type。`WoodColors` 收敛为 8 项。
2. **口径统一**：定义「有效寄宿 = 基础槽 + 已生效支援槽，不受诅咒过滤」，统一用于阶段/生命/支援/Full/森林/归冠；诅咒只压制特性施加。
3. **属性面板**（新文件 `SoulUIWoodPanel`）：显示阶段、S、生命、支援槽、森林层数、四羁绊状态、特性生效 x/8，以及诅咒压制提示。
4. **分母修正**：`BondSnapshot` 改为 `[1,2,4,6,8]`，`max=8`。
5. **特性数值**：去掉 `relayPower` 乘区；霜寂按本剑魂取值；血馥与 `CombatWood.Strength` 同源；森息、血馥 360 帧。
6. **层数保持**：手持非剑魂不再清零森林层数。
7. **羁绊网络化**：三条羁绊改为「客户端 `action=12` 上报 → 服务端重校验执行」；服务端校验存活/距离/D 上限/来源武器匹配，并重新判定组合。
8. **旧断言顺带修正**：`TraitCheck`/`FollowupCheck`/`OreCheck`/`SupportIntegrationCheck`/`UiFixture`/`BlessingCheck` 的 12 木与冠槽前槽位口径。

## 2026-11-05 口径分裂修正（同版本内，不升版本号）

**现象**：玩家寄宿 8 把木剑，剑魂特性页显示「木质族 1/8 · 环境效果 1.1 倍 · 最大生命 +5」，木质族面板的倍率/生命也按 1 把算。

**根因**：0.3.130 只统一了「槽位范围」（`SetItems` → `FamilyItems`），`CombatWood` 上的 `.Where(i=>TraitEnabled(i.type))` 一直在。这个过滤本意只是「哪些剑的特性开火」，却被数值侧一起复用：生命（`WoodPlayer.PostUpdateEquips`）、倍率（图鉴与面板）、森林之力 buff（`PreUpdateBuffs` 的 `Full` 判定）、特性强度 S（`WoodCombat.Apply`）。于是未解除「切换」诅咒时，8 把被压成 1 把，数值与文档定义（阶段/生命/倍率/Full/森林/归冠不受诅咒过滤）不符。

**修法**：把口径显式拆开，不再合成一个属性。

| 口径 | 属性 | 是否受切换诅咒过滤 | 使用方 |
|---|---|---|---|
| 数值 | `SoulItem.HostedWood`（`SoulCurses.cs:89`，新增） | 否 | 阶段、生命、倍率、Full、森林之力 buff、图鉴「自然之力/森林之力」 |
| 特性 | `SoulItem.CombatWood`（`:90`，语义不变） | 是 | 哪些剑的特性开火（`WoodCombat.Apply/ModifyPrimaryHit`）、逐把「木剑·XX」条目、剑格子锁标记 |

特性强度 S 取 `HostedWood.Strength`（族倍率），但**施加与否**仍看 `CombatWood.Has(kind)` —— 未解诅咒时只有第一把的特性开火，这是设计，不变。

**验证**：`dotnet build` 0 错 0 警；`run_wood_checks.ps1` PASS 8511 项（新增 2 条断言：`HostedWood` 与 `BondSnapshot.Wood` 同源且严格大于 `CombatWood`；切换诅咒仍只放行第一把特性）。夹具造魂经兼容路径会把 `LegacyReleased` 置 63（等同旧档已解除），测试里必须一并清零，否则复现不出压制。**图形客户端仍未验证**——面板上的倍率/生命要人眼确认一次。
