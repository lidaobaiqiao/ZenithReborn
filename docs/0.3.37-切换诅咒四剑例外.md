# 0.3.37 · 切换诅咒四剑例外

用户最新要求：飞剑不能完全无视切换诅咒，最多允许四把。

## 实际规则

- 未解除切换时，取有效主攻序列前4把（跳过空格、暂停格）；仅这四把参与百炼战斗矿材计数和首次有效命中积攒。普通槽、奖励槽、传奇槽统一按Active顺序；不是每轮额外4把，不限制成阵后仅4把辅助剑。
- 每把符合条件的已发射主剑仍独立首击积攒。同帧可分别积攒，同一主剑后续帧伤不补触发，衍生攻击不递归；不恢复共用10帧冷却。
- 切换原有普通特性仅首剑与支援过滤不改。第一次完成该组Boss铭刻解除后，立即恢复全部有效主攻参与飞剑，不要求祝福。
- 主剑正常出剑、逐剑直接伤害、动态共用支援结构解锁、累计14材质登记、传奇主攻槽、其他诅咒与独行每轮预算均保持原规则。
- 所有主攻都继续出剑；第5把及以后在诅咒期间仅不参加百炼飞剑例外，并非被删除或停用。

## 实现

`SoulItem.OreFlightMains`统一选择前4或全部。OreFamily的矿材集合、触发判断和图鉴分项均读取它；结构槽位仍使用SoulSupport自身原路径。

主剑发射记录真实有效序列位置PrimaryOrdinal，后继飞剑继承并同步网络；首次触发及飞剑持续来源验证检查该位置，避免第5把与首剑同类型时绕过上限。存档格式不变。普通主攻顺序保持原槽位枚举，不改变编号。

图鉴和诅咒详情明确显示四剑规则，物品悬浮描述仍精简。本轮不更改槽位UI。
