# 0.3.54 · 灵能族基础层

用户要求先做基础，为以后开发准备，机制留空。本版新增 `ZenithReborn/SpiritFamily.cs`，不将此前建议的剑阵／共鸣作为已定机制。

## 开发接口

| 接口 | 用途 |
|---|---|
| `SpiritFamily.Key / Name` | 稳定族标识 `spirit`／灵能族 |
| `SpiritFamily.Members` | 只读名册，22项成员、34个本机物品类型 |
| `SpiritMember.Key / Name / Scope / ItemTypes` | 稳定成员标识、名称、开发范围、原版类型映射 |
| `SpiritFamily.TryGet(type, out member)` | 查询已登记类型 |
| `SpiritFamily.ForType(type) / For(item)` | 查询类型或物品；未知、空物品、null返回null |
| `SpiritFamily.IsMember(type)` | 仅判断登记身份，不代表特性生效或寄宿许可 |
| `soul.InspectSpiritMembers()` | 检查有效主攻与支援，保留实际物品及来源类别 |

`Values`、`Traits`、`SupportThresholds`、`CollectionRewards` 全为只读空集合，没有预填数值、机制、支援档位或奖励，也不注册空支援奖励源。

检查视图使用既有 `Active`／`Supports`：包含已激活普通、奖励、传奇主攻及开放的共用支援；排除未解锁、暂停和旧物取回区。它是结构查询，**不是未来战斗激活清单**。未来机制必须独立接入切换诅咒过滤，不得拿此视图绕过诅咒。

```csharp
if (SpiritFamily.TryGet(weapon.type, out var member))
{
    // member.Key 用于识别成员；此处不触发效果。
}
var inspected = soul.InspectSpiritMembers();
```

## 接入边界

- 旧 `BladeFamily.Arcane` 是兼容战斗分类，不等于新22项登记；原剑气、落星及各剑已有特性保留。
- 木质、矿材、共用支援和奖励槽不改，灵能不发放新槽位，也不增加主动键、计量条或UI。
- 环境仍为并行维度，读取既有武器标签，不按本族或玩家位置补写环境。
- 按类型查询，无新人物／剑魂保存字段、保存版本或网络字段；不改变克隆与词缀。
- 用户已否定0.3.53外观，独立底色＋形状动态蒙版M1仍是后续特效方向。本版保留该纠正，不接入或替其定稿。
