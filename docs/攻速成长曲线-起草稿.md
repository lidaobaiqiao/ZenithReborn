## 二、方案（勾选一个，其余划掉）

### ☐ A · 起步压速 + 单调成长（推荐）

把成长轴从「Flow 连击」换成「三组机械 Boss 进度」，Flow 降级为后期的连击奖励：

```
mech  = SoulProgress.Mechs(Kills)              // 0 / 1 / 2 / 3
start = 0.65 + 0.35 * mech / 3                 // 0.65 → 0.77 → 0.88 → 1.00
flow  = mech == 3 ? 1 + 0.20 * Flow : 1         // 只有三组齐后连击才加速，最高 1.20
倍率  = start * flow * (1 + ForestPower.SpeedBonus) / (迅捷支援 ? 0.85 : 1)
```

| 阶段 | 倍率 | 挥臂帧数（约） | 发射间隔（约） |
|---|---|---|---|
| 开局、三组机械未记录 | 0.65 | 46 | 15 帧 |
| 解 1 组 | 0.77 | 39 | 13 帧 |
| 解 2 组 | 0.88 | 34 | 11 帧 |
| 三组齐、Flow=0 | 1.00 | 30 | 10 帧 |
| 三组齐、Flow=1 | 1.20 | 25 | 8 帧 |

理由：开局慢 35%，随进度单调变快，最终超过原版 20%；去掉「越打越慢」的迟滞段；森林与迅捷支援乘区保持不变。

### ☐ B · 保留现有草稿曲线，先装包看手感

不改公式，只把已验证的草稿打包安装。成长存在（0.65~1.20），但开局第一下仍满速，且连击会先变慢。适合先看实机手感再定。
