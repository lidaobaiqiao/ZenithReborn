# 0.3.39 · 环境属性基础层

本轮只实现数据基础。环境与种族并行，每把剑可挂多个环境属性。环境数值、特性、羁绊、奖励及战斗钩子均未加入。

## 已完成

- `EnvironmentAttributes.cs`定义21项环境，稳定编号1～21对应用户E01～E21；0表示未指定，不作为真实环境。
- 每项定义包含Id、稳定Key、中文Name及只读Values/Traits。21项的Values和Traits全部为空集合，不填假定的伤害、冷却、倍率或效果名。
- 武器类型到环境属性列表独立存储，支持多标签、去重、确定顺序、整体替换与清空。无效环境输入会拒绝整次修改，不留下半条记录。
- 现有木质族和矿石族身份不改，不把环境接到BladeFamily或WoodKind枚举中。
- `Item.GetEnvironmentAttributes()`提供物品查询；`SoulItem.InspectEnvironmentAttributes()`提供结构有效主攻/支援的只读属性视图，普通、奖励、传奇主攻沿用Active，支援沿用Supports。旧扩展取回物品不进入视图。
- 该视图仅供检查元数据，不代表切换诅咒下的战斗特性已激活；未来效果仍需接入各自明确的战斗过滤与结算。

## 后续开发入口

```csharp
// 读取环境定义；Values和Traits当前都为空。
var forest = EnvironmentAttributes.Get(SwordEnvironment.Forest);
var allDefinitions = EnvironmentAttributes.All;

// 读取任何物品的多环境属性，不影响其种族和单剑机制。
var attributes = item.GetEnvironmentAttributes();
var hosted = soul.InspectEnvironmentAttributes();

// 后续在环境归属确认后，于内容加载阶段填关联。
// 下例只是API用法，不是本版已确认的矿石剑归属。
WeaponEnvironmentAttributes.SetForType(ItemID.CopperBroadsword,
    SwordEnvironment.Underground, SwordEnvironment.Caverns);

// 清空一条关联。
WeaponEnvironmentAttributes.SetForType(ItemID.CopperBroadsword);
```

新增环境定义应明确分配稳定Id/Key；不要通过字典顺序产生编号。扩充武器关联可集中写入RegisterBuiltins，其他兼容代码可在PostSetupContent调用SetForType。输入和输出集合均不会直接暴露内部可修改数组。

本轮采用武器类型静态元数据。克隆、词缀、存读档和网络重建后的同类型物品自然查询到相同定义，不追加逐物品存档或网络字段。随机环境词条、逐件环境改变及其持久化不属于当前实现；以后若有需求再独立设计。

## 当前明确留空

- 21项环境的数值与特性。
- 尚未确认的逐剑环境归属。
- 环境羁绊的计数、门槛、全收集方式与奖励。
- 环境战斗状态、自动生物群系判定和效果触发。

不新增物品悬浮描述、界面页签或重复执行旧木质效果。原有伤害、攻速、祝福、槽位及人物/世界数据沿用0.3.38。
