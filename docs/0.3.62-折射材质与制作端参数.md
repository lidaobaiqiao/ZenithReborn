# 0.3.62 折射材质与制作端参数

用户纠正玻璃质感不能靠降低不透明度，并指定折射率1.5、较低粗糙度和适当降低透射。0.3.61主体过淡，本轮提高主体覆盖度与色彩，同时增加真正的背景折射。用户随后明确玩家不需要材质调参界面，本轮已删除试加的客户端配置类及中英文配置入口，参数只在制作端维护。

## 最终材质流程

- `ZRSwordFlow`沿真实剑迹计算颜色、动态形状、局部法线、反光和侵蚀。主体覆盖度恢复，保留逐剑颜色。
- 折射率1.5实际参与`refract`方向计算及菲涅耳反射；粗糙度0.08控制反光宽度和折射模糊；透射0.55与不透明度1分别控制不同作用。
- 提前输出自有法线蒙版，复用原版`FilterManager.BeginCapture`和`ScreenShaderData`进行当前帧屏幕合成。`ZRGlassScreen`只对蒙版覆盖区域偏折背景，不积累旧场景、不反馈上一帧、不处理UI。
- 普通世界绘制目标是丢弃型目标，直接切走复制会有清屏风险，所以正式路径不在`PostDrawTiles`复制场景。这里仅画材质颜色，背景折射由原版滤镜阶段提供安全的当前帧输入。
- 剑体、攻击曲线、伤害、碰撞、存档和槽位不变；矿石21把自有蒙版和慢底色路径保持0.3.61状态。

这是以2D剑迹推导局部法线的屏幕空间玻璃近似，有实际背景偏折，但不是完整的3D体积玻璃或Cycles材质。当前折射厚度是虚拟屏幕厚度，不能解释成毫米。低粗糙度的反光仍是为2D特效设计的近似，不声称已经集成GGX环境光照或完整OpenPBR。

## 参数只属于制作端

唯一制作预设：`VfxLibrary/Materials/SwordTrail/Glass/preset.json`。`checks/emit_glass_preset.py`验证后生成`GlassMaterialPreset.cs`常量；构建已纳入此步骤。游戏只使用编译结果，不加载制作预设、不显示材质滑块，不新增玩家配置。

参数：Ior=1.5、Roughness=0.08、Transmission=0.55、Opacity=1、Thickness=24。Opacity为总覆盖倍率，动态蒙版与生命周期仍参与最终透明度，不能将其误读为所有像素Alpha强制等于1。

## 验证

两工程编译、8346项引擎回归通过。`artifacts/vfx-ownership-0.3.62.json`确认无第三方美术或旧材质资源；当前两份自有Effect为ZRSwordFlow和ZRGlassScreen，服务于同一个主飞剑玻璃流程。

`artifacts/soul-trail-gpu-0.3.62/gpu.json`验证实际GPU的形成、动画、逐剑配色、侵蚀结束、状态恢复和折射对照。在相同网格、颜色、透明度下，分别绘制IOR1与1.5，并比较图案背景与纯色背景，避免仅用表面亮度变化冒充折射；另比较低／高粗糙度的亮区宽度。保持型目标内容和丢弃型目标跳过保护都有检查。主体平均Alpha恢复至约189/255，较0.3.61约65/255提高。

`artifacts/soul-flight-world-0.3.62/world.json`记录隔离世界生产AI、直接命中与正常返回，并要求原版屏幕滤镜实际执行且法线蒙版有非零像素。截图读取最终窗口缓冲；`refraction-mask.png`是辅助数据，不是成品画面。`flight-preview.gif`为1280×720原始倍率受控回放。

美术质量仍待用户判断。没有本轮自然游玩、真实多人或完整模组组合验证，不认定假人黑屏已修复。仅备份替换目标模组，正式人物世界不参与，最终包哈希和已通过项目以最新`artifacts/install-result.json`为准。
