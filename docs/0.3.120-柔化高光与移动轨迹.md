用户认可79高光方向但认为过硬，同时反映人物移动时特效扭曲。高光的屏幕合成此前只取窄核心，虽然定义了光晕与弥散层却没有完整用于合成；本轮保留亮芯，将光晕及弥散层加入合成，降低直绘核心权重并柔化窄反射过渡。保持79主体颜色、带面与118内缘几何，具体美术效果待用户实际判断。
