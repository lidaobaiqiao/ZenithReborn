# 矿石族M1：八种基础金属

日期：2026-10-19。工程基线：ZenithReborn 0.3.5。本页为准备阶段的机制草案，尚未实装；下面明确区分用户已选范围与待讨论的设计数值。

## 1. 范围与定位

用户已选择先做铜、锡、铁、铅、银、钨、金、铂金，不纳入肉后六矿。本轮覆盖16把现有武器，不新增矿石剑。

建议沿用按来源与主题划分的「锻金族」名称，以八种材质作为羁绊计数单位。短剑与阔剑是形态标签：各有独有特性，放入同材质两把可获得两条不同特性，但羁绊只计一种材质。换前缀不增加计数，同物品不能重复寄宿的规则保留。

木系提供槽位、环境状态与战斗成长；矿石组建议提供穿甲、暴击效率、冷却效率和减益利用。低级金属剑的价值来自放大后续主攻剑的机制，而不只是给自己增加一点伤害。仍需保留材料差异，不给每把白板剑都安排大型主动射弹。

## 3. 羁绊建议：百炼

> 族共享羁绊的「百炼飞剑」方案见[矿石族羁绊-百炼飞剑](矿石族羁绊-百炼飞剑.md)。本节固定穿甲与暴击溢出保留为候选被动，是否与飞剑并存待定，不能当作已实装。

以下阶梯、数值与满套奖励均为M1建议，尚非用户确认的最终规则。

| 有效材质数 | 阶梯名 | 建议共享收益 |
|---:|---|---|
| 1 | 开炉 | 本剑魂主剑影固定穿甲＋2 |
| 2 | 合金 | 固定穿甲提高至＋4 |
| 4 | 淬锋 | 固定穿甲提高至＋7 |
| 6 | 精锻 | 固定穿甲提高至＋10 |
| 8 | 百炼成锋 | 固定穿甲提高至＋14，并开启下述暴击溢出转化 |

阶梯为最终值，不把2、4、7、10、14逐项相加。穿甲作用于本剑魂的主剑影，不修改玩家所有武器或敌人的基础防御，也不把穿甲当成持续伤害增幅。

建议满八材质后：每把主剑分别计算超过100%的有效暴击率，每溢出1个百分点转为0.5个百分点暴击伤害，最多增加50个百分点。例如仅按基础2倍暴击计算，150%暴击率对应2.25倍暴击伤害，200%及以上最多2.5倍。这条只改变暴击分支，不增加额外剑影，不把一把剑的高暴击率分给其他剑。

该奖励用于让前期金属在毕业配装里仍有价值。此阶段先不再复制木系的额外槽位奖励，也不增加新的支援槽类型。

## 4. 十六把剑的候选独有特性

下面的数值是第一版起点，主要供讨论作用方向和搭配价值。共享特性仅限这枚剑魂，需把该剑放在有效主槽或有效支援槽中；主槽仍生成它自己的剑影，支援槽不贡献基础伤害或独立主剑。

| 武器 | 候选特性 | 建议作用与数值起点 | 构筑意义 |
|---|---|---|---|
| 铜短剑 | 初心 | 保留已实装的180像素内近身主命中＋20%；主槽作用于自身，支援槽沿用现行支援规则，不再额外重复乘一次。 | 保留既有天顶材料身份，支持近身主攻 |
| 铜阔剑 | 导流 | 本剑魂已登记的冷却型附属特性，冷却缩短5%；各剑冷却分别计算。 | 放大附魔剑、星怒及后续机制的触发频率 |
| 锡短剑 | 延展 | 新施加或刷新的自有持续伤害，持续时间＋10%，仍遵守当前最终8秒上限；不反复延长旧快照。 | 延长高阶武器和木系的有效状态覆盖 |
| 锡宽剑 | 保温 | 自有非伤害印记与连击记忆保留时间＋20%；不延长已经结束的DoT伤害。 | 换剑与Boss转阶段后较容易接上原有连携 |
| 铁短剑 | 穿孔 | 本剑魂主剑影额外固定穿甲＋3，明确与族穿甲合并。 | 让弱剑、高频剑及后续主攻剑都能受益 |
| 铁阔剑 | 锻芯 | 本剑魂特性生成的附属直接攻击固定穿甲＋5；不作用于DoT。 | 专门改善剑气、落星、碎片的小段伤害 |
| 铅短剑 | 压甲 | 本剑魂主剑影获得5%比例穿甲；与固定穿甲交给引擎按相应通道结算。 | 为高防御目标提供另一条支持通道 |
| 铅宽剑 | 咬合 | 对被本剑魂施加盐蚀、蚀枯等已登记弱化印记的目标，主剑影条件增伤＋6%；一种印记即可满足，不按印记数无限叠加。 | 衔接木系减益与矿石强攻 |
| 银短剑 | 锐银 | 本剑魂主剑影暴击伤害增加10个百分点，例如基础2倍变为2.10倍。 | 为后期高暴击主攻剑提供收益 |
| 银阔剑 | 精准 | 本剑魂主剑影暴击率增加3个百分点，各剑在自身暴击率基础上分别计算。 | 前期提高可靠性，满套后可参与溢出转化 |
| 钨短剑 | 承载 | 已登记、允许叠层的自有DoT最大层数＋1；首批仅接入当前裂伤的3→4层。未登记效果不改。 | 提供现有体系欠缺的层数容量乘区 |
| 钨宽剑 | 淬毒 | 本剑魂自有DoT强度＋10%，与同通道既有DoT增幅合并；不放大直接剑伤。 | 为木系或后续持续伤害主攻提供支持 |
| 金短剑 | 催化 | 每第4次合法施加叠层型自有DoT，额外增加1层；遵守层数上限、原施加间隔和来源预算，不触发新一轮计数。 | 缩短达到高层状态所需时间 |
| 金阔剑 | 众彩 | 每种实际生效的自有伤害型减益，使该剑魂自有DoT增伤＋3%，最多按3种计，共＋9%；纯印记不计数。 | 鼓励毒、火、流血等组合，而非堆重复状态 |
| 铂金短剑 | 镀锋 | 本剑魂特性生成的附属直接伤害＋10%；与同通道增伤合并，不放大主剑或DoT。 | 让早期金属成为后期专属射弹的增幅器 |
| 铂金宽剑 | 回火 | 某剑的专属附属射弹命中后，使该来源剑下一次主命中增伤8%；每种来源剑独立120帧触发间隔，只存一次。 | 形成自己的「主剑→特性→主剑」循环，不借用另一把剑的伤害 |

这里的穿甲、暴伤、触发频率、DoT强度、时长、容量与叠层速度属于不同战斗维度，但不把所有百分数强行作为独立最终乘区。不同主剑保持各自伤害、暴击、击退与特性来源；共享增益只能按上表声明的通道生效。

## 5. 与木系及槽位的关系

推荐计数：八材质中每种至少一把同时寄宿，激活百炼；不是背包收藏，也不要求16把同时放入。取下某材质最后一把后，立即按剩余材质重新计算阶梯。

建议有效普通槽、有效支援槽、已经生效的森林奖励槽都允许提供矿石特性与材质计数。矿石剑本身不增加木系计数，也不解锁木系支援槽。失去条件的槽位按现有规则暂停，武器保留可取回。

当前总存储为10普通＋5木系支援＋2森林奖励。木系全套要12把，矿石八材质至少8把，因此两组全套同时要求20把，超过17个槽；而森林奖励本身还要求木系全套。当前方案接受这是配装取舍，不悄悄放宽木系的全套条件或无条件扩槽。可以采用部分木系搭配部分矿石，而非默认两套毕业奖励同时取得。

八种基础金属全部出现并不等于开局就能同时寄宿；仍遵循原有成长槽位。不同世界替代矿的收集成本也应计入满套奖励的价值评估。

## 6. 实现准备与先后顺序

1. **先建矿石登记与羁绊计算**：16物品→8材质，和现有Swift/Solid形态兼容，不把矿石短剑误改成木剑或抹掉铜短剑已有能力。
2. **先接容易观察的通道**：族穿甲、铁/铅穿甲、银系暴击、铜阔剑独立冷却倍率。界面显示材质数、各剑作用及缺失材质。
3. **再接减益增幅**：锡、钨、金。只操作已登记的自有状态，统一保留施加快照、层上限和各来源计数。
4. **最后接来源回流与满套转化**：铂金回火需要给附属弹幕补齐来源武器类型，不能只知道SoulId就把增益送给所有剑。暴击溢出也逐剑计算。
5. **替换旧候选说明**：本轮16项以本页后续定稿为准，D1其余矿石/锻金候选继续保留。新机制未接通前不在游戏提示中宣称已生效。

检查重点是正确来源与实际效果：同材质双剑不重复涨羁绊；独有特性可分别生效；支援剑不出主剑；不同剑不抢冷却；附属攻击不递归触发；多次主命中仍受合法叠层间隔；虫体按主体限制相关计数；取下装备及时失效；存档与已有木系不被破坏。
