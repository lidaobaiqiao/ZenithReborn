## 核对说明

原清单与当前游戏有部分中文译名差异，例如村正／村正大刀、异域弯刀／外星弯刀、地狱之剑／地狱烙印、寒霜剑／霜印剑、臭虫剑／飞虫剑、真断钢剑／原版断钢剑；本次按对应物品内部 ID 核对。清单和完整 Item 数据来自只加载正式 0.3.125 包的独立服务端。检查源码 `SoulItem.cs`、`WoodTypes.cs`、`OreFamily.cs` 和 `HolyHeavenFamily.cs` 与该包中的源码一致。

本文件仅列现状，不改变寄宿条件、种族名册或游戏安装。
