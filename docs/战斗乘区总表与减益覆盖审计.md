# 战斗乘区总表与减益覆盖审计

版本：M1.1，2026-10-18。0.3.0已实现木质族，见[实装说明](0.3.0-木质族实装说明.md)。历史统计基线：ZenithReborn 0.2.4源码、D1历史候选与最新[木质族D2](木质族D2-环境特性与森林之力.md)。木质规则以D2为准，其余维度仍按本表审计。

本表给出本项目可使用的战斗设计目录：**12大类、61个设计维度**。其中减益的伤害、生命周期与联动占16个核心维度，另与降防、易伤、控制、自身抵抗等维度相连。这里不把61项都称为数学上独立的乘法系数，也不要求第一阶段全部实装。

本轮只记录、审计与补齐设计口径，不修改游戏代码或安装包。标为“已实装”的内容是当前源码可确认的基础行为，不能据此宣称所有战斗组合均经过游戏实测。

## 一、先分清伤害乘区与战斗收益

| 类型 | 在模型中的位置 | 代表维度 |
|---|---|---|
| 单次命中结算 | 改变一次有效命中的结果 | 基础伤害、同源增伤、暴击、有效防御、有限易伤 |
| 时间收益 | 改变每秒能有效结算几次 | 出剑速度、触发冷却、命中免疫、连击速度 |
| 数量与覆盖 | 改变有多少攻击真正打中哪些目标 | 剑影数量、附属弹幕、穿透、寻敌、判定体积 |
| 持续伤害支路 | 在主命中之外持续输出 | 毒、燃烧、放血、寄刺等有定义的DoT |
| 状态与联动 | 提供条件、可消费资源或目标弱化 | 叠层、易伤、传播、引爆、控制 |
| 生存、资源与构筑 | 提高可输出时间，或放大其他机制的配置空间 | 回复、减伤、机动、支援槽、羁绊、完整系列奖励 |

设计估算采用：

```text
总输出 ≈ Σ(某类有效命中频率 × 该类命中的期望伤害) ＋ Σ(各类实际DoT输出)

有效命中频率 ≈ 出剑/触发频率 × 有伤来源数 × 每来源有效命中次数
               × 命中率 × 可输出时间占比

主命中期望伤害 = 引擎按来源伤害、修正、防御、穿甲、暴击等计算的结果
单个DoT完整总量 ≈ 实际每秒伤害 × 实际有效时间 × 允许的有效层数
```

这是设计模型，不是替换tModLoader原始命中公式的实现。附属射弹有自己的频率、命中限制与伤害基数，不能把它们的数量直接乘到整套伤害上。

原版防御修改、比例穿甲与固定穿甲共同改变有效防御；暴击和最终修正也有明确的结算位置。它们不能被随意写成若干百分比相乘。[tModLoader NPC.HitModifiers文档](https://docs.tmodloader.net/docs/stable/struct_n_p_c_1_1_hit_modifiers.html)

## 二、61个维度的覆盖总表

状态说明：“仅D1”表示只有设计候选，尚未实现；“空缺”表示尚未分配独立、明确的机制；“用户新方向”表示本次构筑思想已经提出，但计算细则仍需设计。

### A．单次伤害与暴击（7项）

| 编号 | 维度 | 收益性质 | 当前覆盖 | 用途与边界 |
|---|---|---|---|---|
| A01 | 基础伤害与成长 | 伤害基数 | 已实装 | 武器伤害、词缀/装备与残魂效能形成来源伤害；支援槽不得参与基础属性平均。 |
| A02 | 通用与分类增伤 | 同通道加算 | 部分实装 | 已继承装备伤害；新支援增伤要统一通道，不能每个特性各乘一次。 |
| A03 | 条件增伤 | 受条件约束的增益 | 部分实装 | 铜短剑近身增伤已有；D1另有血线、距离、飞行阶段与连击条件。 |

| 霜火 | 冰雪刃显式OnHitNPC施加120帧；寒霜剑在D1 | 有入口 | 缺持续强化、DoT强度、刷新与免疫失效反馈 |
| 中毒 | 草剑显式OnHitNPC施加180帧 | 有入口 | 缺毒强度、叠层、毒爆、传播与高阶转化 |
| 着火/狱炎 | D1熔火族、灰烬木剑、火山、地狱之剑等；原生附属弹幕可能另带效果 | 设计为主，原生需逐项查 | 缺统一状态标签、燃烧强度与消耗反应；不能仅凭名字认定已实装 |
| 灵液/实际降防 | D1舌锋剑 | 仅设计 | 缺降防与穿甲的组合规则、对其他攻击者的作用范围 |
| 暗影焰/诅咒焰 | D1暗影焰刀只写暗焰射弹，未明确施加对应原版减益 | 未明确 | 应补状态定义、来源与触发；效果命名不等于真的施加了Buff |
| 放血、寄刺、日矛印 | D1血腥屠刀、触手钉锤、破晓之光 | 仅设计 | 有层数和伤害建议，缺强弱快照、跨来源覆盖、传播与引爆预算 |
| 寒印、蚀印、月痕、钥印等 | D1剑族和单剑标记 | 仅设计 | 它们首先是自定义战斗标记，不应直接计作原版减益或天然计入DoT增幅 |
| 易伤/脆弱 | D1只有部分按状态增伤的来源特性 | 空缺 | 需要独立定义受击端状态与适用分支，避免和来源增伤重复计算 |
| 攻击削弱/禁疗 | 无统一候选 | 空缺 | 仅对具备对应攻击或回复机制的目标有效；Boss须逐类定义 |
| 玩家自身负面状态抵抗 | D1未覆盖 | 空缺 | 补持续缩短、指定净化、有限免疫，分别限定原版和模组状态 |

代码核对入口：[SoulBlade.cs](../ZenithReborn/SoulBlade.cs)的OnHitNPC、ModifyHitNPC和ReleaseSpecial；[WeaponFamilies.cs](../ZenithReborn/WeaponFamilies.cs)；[D1特性表](剑族与单剑特性设计.md)。原生附属弹幕是否施加额外状态，需要逐项核对它们自身的逻辑。

## 四、减益应细化为21项操作需求

这些操作是前述维度的细化，不再另算21个独立乘法区。

| 序号 | 操作 | 具体含义 | 可承担的支援方向 | 结算边界 |
|---|---|---|---|---|
| DB01 | 施加 | 施加概率、前提与一次命中可施加的状态数 | 附魔、涂层、命中辅助 | 先判定命中和免疫，不能把失败施加当作已有状态 |
| DB02 | 施加频率 | 施加冷却、共享通道与首击/每击差异 | 快速短剑、矿石支援 | 提高攻击次数不应绕过共享施加冷却 |
| DB03 | 伤害强度 | 本模组自定义DoT的单位时间伤害 | 草木、毒性或火焰支援 | 只调整自己的伤害贡献，不粗暴放大全局npc.lifeRegen |
| DB04 | 结算节奏 | 更快跳伤、提前支付或提高每跳伤害 | 蓄能、导流支援 | 先确定总伤害是否守恒；原版跳字频率不能直接当作伤害频率 |
| DB05 | 持续时间 | 延长有效时长、覆盖率和可消费窗口 | 木质、红木等维持型支援 | 对已能全程续上的状态，不再按时长比例额外乘持续DPS |
| DB06 | 刷新与强弱覆盖 | 重挂保留强快照、延长或替换剩余时间 | 白板金属的稳定性支援 | 避免弱来源刷新把强来源快照降级 |
| DB07 | 层数上限 | 允许增加的最大有效层数 | 储存、锻造型支援 | 只作用于明确支持叠层的自定义状态；不自动让原版所有Buff叠层 |
| DB08 | 叠层效率 | 每次施加层数、叠层间隔与满层速度 | 迅捷金属、短剑支援 | 改善起手时间，满层后通常不再持续获得等额倍率 |
| DB09 | 保层与衰减 | 离开目标后逐层衰减、短暂保层 | 木质维持支援 | 与永久保留区分，处理目标消失和战斗结束 |
| DB10 | 并存与种类收益 | 状态家族数量、互斥及按种类触发 | 混合族构筑 | 毒、火、霜与印记分标签；持续刷新同一图标不算新增种类 |
| DB11 | 受击易伤 | 目标承受某类主命中或射弹伤害提高 | 腐化、圣铸或高阶支援 | 写明是否影响DoT；不要默认所有伤害源都获得同一奖励 |
| DB12 | 破甲与抗性作用 | 实际降防、来源穿甲或指定抗性变化 | 矿石、腐化支援 | 破甲和穿甲作用于有效防御，不能当成两个独立百分比增伤相乘 |
| DB13 | 带状态命中收益 | 命中中毒、燃烧或多层目标后加强主攻机制 | 任何有明确主题的联动剑 | 与增强DoT自身分开，防止一次收益在命中端和DoT端各结算一次 |
| DB14 | 消费与引爆 | 消耗层数/剩余时间，提前结算一部分伤害 | 火焰、重刃等终结型主攻 | 从剩余预算扣除已结算部分，不能反复引爆同一份剩余伤害 |
| DB15 | 传播 | 向其他目标复制有限时长、层数或强度 | 植物、虫群支援 | 最大目标数、传播次数、传播冷却分别限额，不允许无限再传播 |
| DB16 | 转移 | 原目标死亡时把一部分状态转移至下一目标 | 群怪构筑 | 明确是搬走还是复制，保留来源，不重复结算已支付伤害 |
| DB17 | 升级与转化 | 毒印转毒爆、燃印转裂焰等自定义转化 | 进阶主攻与低阶支援协同 | 保持前后总预算或明确新增收益，不能无条件转换任意外部Buff |
| DB18 | 元素反应 | 两个指定状态组合产生有限额外效果 | 跨族构筑 | 采用反应表和共享冷却；不假设原版存在通用元素反应系统 |
| DB19 | 敌方控制与弱化 | 减速、束缚、攻击衰减、有限禁疗 | 寒霜、腐化等控制支援 | Boss与普通敌人分开；不通用冻结、取消AI或重写已发射弹幕伤害 |
| DB20 | 免疫与抵抗结果 | 施加失败反馈、允许的替代标记或受限补偿 | 适配性支援 | 不偷偷清除原版/模组免疫；替代标记不自动获得被免疫的DoT或控制 |
| DB21 | 自身减益管理 | 玩家负面状态持续缩短、净化或指定抵抗 | 木质续航与守护支援 | 与施加给敌人的减益分开统计；不无条件删除所有模组负面状态 |

## 五、四种状态必须分开记录

| 状态类型 | 示例 | 记录与适用方式 |
|---|---|---|
| 原版敌方Buff/Debuff | 中毒、霜火、着火、灵液 | 使用引擎实际状态与免疫；先核对当前1.4.4行为，不能直接套新版Wiki数值 |
| 本模组自定义DoT | D1放血、寄刺、日矛印 | 记录归属、快照、层数、剩余时间、剩余预算；只修改自己的持续伤害贡献 |
| 战斗标记与可消费印记 | 寒印、蚀印、月痕、钥印 | 默认是本模组规则状态；是否算作“负面状态家族”、是否允许传播或被引爆必须显式声明 |
| 玩家自身负面状态 | 原版或模组对玩家的负面效果 | 交给净化/抵抗分支，不能直接套用敌方减益伤害或层数规则 |

每个可联动状态至少定义：状态ID、家族标签、受影响对象、归属玩家/SoulId、来源武器、施加条件、免疫规则、单层强度、层数上限、持续与刷新策略、快照策略、传播资格、消费方式、死亡/消失清理方式。多名玩家的普通Buff状态与自定义贡献不能互相覆盖或串归属。

## 六、持续伤害的结算口径

1. 普通命中链与DoT链分开。原版lifeRegen式DoT不是一连串主剑命中，不应自动触发暴击、吸血、命中连击或再次施加自身。
2. “目标受到攻击伤害提高”默认只影响明确列出的命中支路；“目标受到持续伤害提高”另外配置。若同一机制有意影响两条支路，分别核算收益。
3. 本模组新增DoT使用自己的贡献项累加；不要乘算整个npc.lifeRegen，也不要覆盖其他模组的贡献。显示伤害数字的参数也不能当成实际DPS调整。[tModLoader GlobalNPC.UpdateLifeRegen文档](https://docs.tmodloader.net/docs/stable/class_global_n_p_c.html)
4. 同一种原版Debuff不能仅靠多次AddBuff就被设计表认定为多层。需要额外层数时，为本模组定义层数状态和上限；外部原版效果仍保留原本结算。
5. 新DoT可采用施加时强度快照；同族重挂优先保留较强快照并遵循时长上限。具体“覆盖/延长/独立层”须按状态表声明，不能由刷新顺序偶然决定。
6. 引爆只消费有明确归属与剩余预算的状态。不能把敌人全部减益合计伤害直接读出来、乘倍后再保留原减益重复结算。
7. 控制免疫、DoT免疫和自定义印记可用性分开判断。允许一个无控制的寒印，不意味着可以对Boss施加原本免疫的冻结、霜火或减速。

### 示例：延时、增伤与引爆各自改变什么

以下只使用假想的本模组毒印，数值不是原版中毒数据：

| 支援变化 | 单次施加后的结果 | 连续战斗中的含义 |
|---|---|---|
| 基础：10伤害/秒，持续4秒 | 完整结算40伤害 | 作为对照 |
| 时间延长至6秒 | 单次完整结算60伤害 | 原本就能持续刷新至100%覆盖时，稳定DPS仍是10，不额外变成15 |
| 强度提高20% | 12伤害/秒、4秒，总计48 | 对该DoT贡献真正提供20%持续DPS提升 |
| 最大层数1→2 | 达到2层时才有两份伤害 | 需要考虑上层速度与实际保层时间，未满层时不能按双倍估算 |
| 更快结算但保持总量40 | 更早拿到同样总伤害 | 是爆发时机收益；是否提高持续DPS取决于重新施加和冷却规则 |
| 提前兑现剩余预算的一部分 | 这部分立即结算，并从剩余预算扣除 | 获得爆发与转火价值，不重复支付同一份伤害 |
| 传播至另一个敌人 | 增加群体覆盖 | 对单个Boss的伤害可能不增加，不能按目标数乘单体DPS |

## 七、落实到前期支援剑的分工

以下是能力池分工建议。木系已由D2替换9项原有木剑候选并新增3项，其余武器仍需后续重构。

| 支援方向 | 可以优先承担的维度 | 保留给主攻武器的内容 |
|---|---|---|
| 木质大类 | 支援槽、状态维持、保层、持续时间、基础续航 | 强力攻击本体与决定性引爆 |
| 矿石大类 | 固定/比例穿甲、叠层效率、触发稳定性、暴击相关转换 | 大范围攻击与高阶能量表现 |
| 植物、虫群方向 | 中毒强度、传播、死亡转移、状态多样性 | 主要毒性载体与高阶毒爆 |
| 寒霜方向 | 寒印、控制窗口、维持与碎裂条件 | 终结性的碎冰攻击；Boss采用允许的非硬控版本 |
| 熔火方向 | 燃烧维持、有限反应、剩余量消费 | 燃烧引爆与龙焰/太阳类攻击 |
| 腐化、猩红方向 | 侵蚀、血印、易伤、伤害/恢复资源交换 | 高层消费、收割与强力联动 |
| 星辉、圣铸方向 | 附属效果节奏、印记消费、主攻特性联动 | 高阶剑气、落星、圣裁与终局机制 |

同一支援特性优先负责一个主维度，并可附带一个弱辅助维度。种族、单剑和全系列奖励分别占用清楚的收益预算；同一能力不能换三个名字在三个位置重复乘算。

## 八、用户最新构筑方向与D1需要改动的地方

| 内容 | 已提出的方向 | 尚需确定的细则 |
|---|---|---|
| 木质1/2/4/6/8羁绊 | 每档增加1个特殊支援槽，共5个 | W2已定义有效特殊槽参与计数及最小稳定求值，尚未实装 |
| 支援槽提供什么 | 不提供武器基础属性，保留特性与种族数量贡献 | W2已定义木系主攻投射，其他武器主动特性仍需改写 |
| 族基础收益 | 每档增加特殊槽并提高木剑效果强度 | W2给出1.10至1.75倍过渡与生命上限建议，尚未平衡实测 |
| 完整木质大类 | 12种同时寄宿激活森林之力；取下即失效 | 基础3倍、生命＋100、额外2个真实普通剑位；W2.1满层主攻伤害＋36%、速度＋24%、防御＋36、回复＋6生命/秒、自有DoT＋60%、减伤＋12个百分点，60秒封顶 |
| 材质与主题 | W2的乌木、暗影木、灰烬木与珍珠木均保留木质身份和环境主题 | 其他主题族额外羁绊另行定义，不自动获得多个完整族奖励 |
| D1的单一族/自效限制 | 保留D1作为100个独有机制候选库 | 需要支持材质标签、支援入口和羁绊阈值后，再重分配和改写100项，不直接照D1全部实装 |

木系已按W2采用“从普通槽种子开始求最小稳定结果”的计数方案，特殊槽最多5个。其他族若产生额外槽位，仍需单独定义求值规则，不能让装卸顺序偶然产生不同槽数。

## 九、建议下一轮优先补齐的减益能力

1. 状态家族、施加成功/免疫与来源归属。
2. 持续时间、强弱刷新与叠层上限。
3. 可由支援剑提供的DoT强度、保层与叠层效率。
4. 受击易伤与带状态命中收益，并明确影响哪些伤害支路。
5. 有预算的引爆消费、有限传播与死亡转移。
6. 玩家自身减益抵抗与净化，以及Boss适用规则。

先以一个自定义状态和一组支援剑跑通“施加→维持→强化→消费/传播”的完整流程，再扩展状态种类。全维度目录不等于同时实施全部系统。
