# 0.3.13 · 出剑节奏与首击飞剑

## 行为

- 基础挥臂周期按有效主剑平均使用间隔（含原类别修正）的1.5倍向上取整，范围25～90帧。原攻速加成保留；引擎计算后最快25个游戏帧一轮，使五个节点至少相隔5帧。少于5把仍然留空，不重复补剑。
- 每个实际生成的矿石主剑弹幕，仅在首次有效命中时尝试召唤百炼飞剑。通过来源/目标/持有校验后即消耗这次机会；若受原30帧剑魂冷却或60帧目标冷却阻挡，后续命中也不补触发。
- 后续帧伤仍按原规则造成伤害，换目标也不重置召唤机会；下次出剑产生的新主剑拥有新的机会。子飞剑不能递归触发。
- 保留17有效槽、原伤害计算、每8帧主剑重击、各剑轨迹与肉后六矿其他机制。本次只改变出剑频率和百炼飞剑触发次数。

## 调用与验证入口

- `SoulItem.RefreshStats`计算基础周期；`SoulSwingPlayer.PostItemCheck`在原版计算攻速后应用最短周期，五节点继续按完整周期执行。
- `SoulBlade.OnHitNPC → OreFamily.OnMainHit → SoulBlade.TryConsumeOreHit`约束当前弹幕的一次有效命中机会；锁存不依赖目标、时间或物品存档，且在弹幕默认初始化中复位。召唤仅在拥有者执行，不向存档或网络增加字段。
- `SwingCheck`检查原版`ItemCheck`自动连击、极端攻速、节点间隔和轮换；`OreCheck`通过实际`Projectile.Damage`检查后续伤害仍在而飞剑不再重复，另覆盖换目标、新主剑、首次被冷却阻挡后禁止补触发。
- 编译和引擎结果见本次`artifacts/wood-check.txt`、安装结果见`artifacts/install-result.json`；图形客户端与真实多人如未单独记录，不视为已验证。
