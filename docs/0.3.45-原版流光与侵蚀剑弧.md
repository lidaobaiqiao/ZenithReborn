# 0.3.45 · 原版流光与侵蚀剑弧

日期：2026-10-22。用户认为0.3.44的规整渐变剑弧仍然普通。本版改进二／三档巨剑斩击材质和残影，不改变武技逻辑、普通主剑、伤害、碰撞、存档或槽位。

## 视觉修改与现成能力

- 删除七层规整同心色带的主体，改用原版彩虹魔杖的流光和侵蚀材质。内部纹理随时间滚动，边缘被侵蚀，叠加细小扰动形成分离的亮丝和碎边。
- 保留Luminance现成PrimitiveRenderer绘制少量柔光底色及细刃，主体使用原版VertexStrip。没有新增自制HLSL、纹理素材或底层网格框架。
- 渐隐剑影增加青／紫轻微错位，尾部用已有星芒和短光屑补充速度感，刃尖保持较集中的高亮。
- 继续只保存客户端剑姿，最多14姿态、16帧生命周期。传送、角度跳变、非法坐标和取消时切断历史，防止远距离连线或残留。

原版复用路径在本机tModLoader2026.8.3.0中核对：`Terraria.Initializers.DyeInitializer.LoadMiscVertexShaders`为RainbowRod注册MagicMissile pass，并绑定 `ExtrasID.RainbowRodTrailColorGradient`、`RainbowRodTrailShape`、`RainbowRodTrailErosion`；`RainbowRodDrawer.Draw`调用现有 `VertexStrip`。调用API复用这些资源，没有复制反编译方法进项目。

为防止影响其他武器，本模组克隆原版已编译Effect并私有持有参数，卸载时释放；不修改全局RainbowRod的时间、矩阵或透明度。混合、深度、栅格、裁剪、顶点／索引缓冲及0～2号纹理／采样器在绘制后恢复。服务端不创建Effect。私有Effect包装使用tML1.4.4仍支持的Ref构造器，局部标注该API在1.4.5的迁移提示；未把项目升级到1.4.5。
