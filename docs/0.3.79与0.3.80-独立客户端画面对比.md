## 画面观察及源码依据

0.3.79的连续薄亮刃缘、内侧亮线与扫光更醒目，运动轮廓容易从背景中分离。0.3.80的法线、表面流纹、方向反射和树干偏折更能体现弧面，但亮边明显变弱，在相同场景中不够显眼。

源码与这一观察相符：0.3.79在原生合成的coating中直接加入razor、innerRim、reflection和fineReflection；0.3.80改为环境与GGX/菲涅耳反射，并把内部常量/流丝自发光系数压至0.012/0.018量级。它确实改变了光能分配，不能只用「玻璃更通透」解释用户感受到的暗淡。

固定GPU面板的公共有效区域中，0.3.80高于暗背景的平均亮度约为0.3.79的15.9%。这是特定无场景面板的统计，不是实际世界亮度下降84.1%的测量，不用于推导整面统一乘亮系数。

后续美术依据是保留0.3.80弧面/反射/折射的质感，并参考0.3.79的亮刃轮廓和光效可读性。用户尚未在本轮要求制作合并版本，不能把该方向当成已实现或已验收的成果，也不能自行重启0.3.82的整面强发光。

## 采集及验证

Steam会话本轮已能通过校验。两版分别使用独立存档目录，只从同一隔离测试人物/世界复制，加载原始ZenithReborn包和截图夹具。窗口1280×720、照明模式3、相同镜头和白天设置；夹具安排泰拉之刃、附魔剑、星怒的真实AI飞行/命中/返回。

原始包SHA-256：

- 0.3.79：`c7b88428525a192e5764de000e180be73184933a41a86bf61a3832bd1fecdad1`。
- 0.3.80：`6473635ed76bffaeb06bb404375138bdb250b3b0529cb11755419e5d7aef20dd`。

两版世界报告均通过；按tick和物品类型逐项匹配真实AI记录，最大位置差0像素、角度差0。世界材质使用运行中的连续时钟，没有锁到同一绝对时间，因此不能称每个动态流纹都处于同一相位；另加固定时钟0的GPU面板补充比较。

两版材质方法签名不同，初次将0.3.79接口夹具直接用于0.3.80会触发MissingMethod。已保留失败日志，并用同一份截图夹具源码、针对原始0.3.80依赖另行原生编译，零错误、零警告后重新采集；没有修改原包来适配夹具。

旧菜单GPU总套件没有全部通过：0.3.79的body/edge Alpha差断言未通过；0.3.80的旧高光断言未通过，锐利/粗糙材质的亮像素计数均为0，未满足sharp>0及rough>sharp。0.3.80的pattern/solid折射差异阈值本身通过。绘制状态恢复、过期清零及动态截图分别有记录。这里只确认抓帧与实际世界夹具完成，不宣称旧GPU总套件通过。0.3.80隔离窗口日志还有御剑快捷键字典的UI警告；本轮未改该独立问题。

这些是实际图形客户端中的受控世界夹具，不是自然鼠标攻击、完整模组组合或真实多人验证。

正式安装仍为0.3.85的0.3.79回退效果，SHA-256仍为`733da93f4493db9c82d5cd8bd86a42dfebf7edc6ac2b915e2e0a74e9a4ed0b30`，生产源码未修改。
