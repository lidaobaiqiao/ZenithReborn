# 0.3.47 · 厚月牙与白热刃缘

日期：2026-10-22。用户提供鬼切红色宽月牙截图，明确原有流光质感已具备，但特效强度太弱。本轮加强二／三档巨剑的刃面厚度、连续白热外缘、内部笔刷流动与暗侧撕裂，沿用青紫配色、原版流光细节和0.3.46碎光。

## 直接复用现成材质

从本机灾厄大修0.9209随附资源中复用HoCha113的`OniCrimsonSlash`已编译Shader、原始`.fx`、`SlashBrush01`和`NoiseSoft01`。四个资源逐字节保持原样，作者MIT许可证和逐资源SHA256放在`ZenithReborn/Assets/ThirdParty/CalamityOverhaul/`。来源包、路径与哈希见该目录`provenance.json`。打包脚本验证四个资源、许可证、来源记录均实际进入包中且与源码目录一致。

这些资源是公开模组随附的原始资源，不是截图抠图或反编译输出。没有新增HLSL、自制贴图、渲染框架或玩家依赖，也不要求启用灾厄大修或InnoVault。

`MartialCrescentMaterial`仅作接入：从实际记录剑姿计算已经扫过的角度范围，以标准四顶点承载现成极坐标月牙材质；传入原有配色、宽度、流动与消蚀参数。外缘半径310像素，刃面向内变厚；不改变330像素巨剑碰撞、伤害或动作。主体复用材质中的白热外缘、双层流动笔刷及暗侧侵蚀，再叠少量原版MagicMissile流光和Luminance细刃。

材质私有克隆在首次绘制的图形线程创建，固定资源只读取一次；卸载时图形线程释放克隆，不释放由tML管理的共享贴图／源Effect。沿用绘制外层的混合、深度、栅格、裁剪、0～2纹理／采样器及顶点／索引缓冲恢复。
