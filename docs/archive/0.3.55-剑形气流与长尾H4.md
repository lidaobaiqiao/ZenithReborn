# 0.3.55 · 剑形气流与长尾 H4

## 本轮接手与用户要求

接续 DeepSeek 留下的 H2 制作与临时运行时接入。用户最新方向是表现剑刺入空气时，剑尖、刃缘和剑尾共同形成的扰动；放大的剑形只是影响域，不把一张通用锥形套在所有剑上。用户随后要求不同武器保留不同配色，拖尾更长、颜色更亮、效果更明显，并适当增加气流粘性。

H4 为本轮可运行候选，仍待用户观看后作美术判断。21把矿石剑已接入，钛金剑保留既有选择，天铸巨剑的专属气流及圆环／粒子逐剑素材不在本轮完成范围。普通主剑的轨迹与根基材质未更换。

## 形状与运动

- 以每把原版贴图的真实 Alpha 建立轮廓与距离场，气流轨迹只作少量平滑；剑本体仍使用原版贴图、原尺寸及原有攻击方向。
- 剑尖压缩气层、沿刃向后行进的波动、连续尾流共同写入一张动态 Alpha，不额外叠加 V 形、光球或独立尖端白芯。
- H4 单帧画布扩至640×256，枢轴随之平移至497,128，保留原有像素密度；只为尾流增加空间，不横向拉伸剑体。16帧图集循环1.1秒，运行时连续插值。
- 粘性是视觉近似：较长的行进波、沿程相位滞后、连贯尾流与较缓的结束衰减。不是完整流体数值模拟，也不修改飞剑的真实速度。
- 飞行气流浓度由真实速度决定；折返重新加速时重新建立。结束余流在原有20帧独立结束历史中向后漂移并衰减，攻击和寿命规则不变。

## 底色、复用与绘制

`VfxLibrary/Masks/SwordBody/<剑名>/H4/`保存配方、Alpha图集、登记和黑白接触表。各剑引用`ColorFields/SwordBody/<剑名>/entry.json`中的H4色场变体；旧R2配方和R2/H2/H3图集保留。

21种剑形使用13种矿材底色，同矿材短剑／宽剑可以复用颜色；铜橙、金黄、钴蓝、秘银青绿、精金红等独立保留，不统一泛白。H4提高底色可见度，最终用单次柔和加色合成，避免浅色背景中的黑烟。

运行时仍是慢底色×动态蒙版：复用现有MIT噪声资源与原版SpriteBatch／RenderTarget／BlendState。颜色准备与蒙版相乘在`Main.OnPreDraw`中用自有SpriteBatch完成，恢复设备状态；弹幕PreDraw只画一次最终结果，随后画原版剑体，不再中断原版批次，也不再用两帧错相叠色代替相乘。仅准备当前可见类型，每种类型共用一次合成结果，图集按需加载。

无新增插件或资源依赖。本轮保留接手时已经移除的Luminance声明，不重新启用依赖；已有其他模组和启用列表不作无关更改。第三方原资源和许可证保持。
