# 0.3.44 · 武技斩击拖影

日期：2026-10-22。在另一对话完成的[0.3.43三档攻击原型](0.3.43-武技三档攻击试作.md)上，只增强二／三档巨剑斩击的拖影。攻击时序、伤害、碰撞、时停、玩家位移、存档和槽位规则保持；普通天顶主剑及矿石飞剑的既有视觉不改。

## 效果与复用

将巨剑旧的多条放射直线拖影替换为连续渐变剑弧，分层形成透明内弧、青蓝或紫青主体、亮色外刃与细薄余光；沿真实历史剑姿绘制最多三道渐隐剑影。只在斩击阶段采样，收势后自行消散，传送、角度突变、取消和非法坐标会切断轨迹，不连接到远处。

复用Luminance 1.0.14的 `PrimitiveRenderer.RenderTrail`、`PrimitiveSettings` 和预编译 `Luminance.StandardPrimitiveShader`。本项目只提供剑姿历史、宽度／颜色曲线和绘制接入，没有复制或重写网格引擎、GPU缓冲或着色器。资源继续使用原版天顶贴图。[Luminance官方说明](https://github.com/LucilleKarma/Luminance/blob/release/README.md)。

`MartialSlashVisuals.cs`管理客户端视觉；主剑实体始终绘制在剑弧上方。每把巨剑最多14个历史姿态，16帧生命周期，固定48个拖尾细分点。绘制后恢复混合、深度、栅格、裁剪、纹理、采样器和顶点／索引缓冲状态，不让后续原版或其他模组使用遗留状态。服务端不创建GPU资源。

## 构建依赖

游戏需启用Luminance；本机已有工坊版本，交付脚本只启用该依赖，不替换其他正式模组。

`checks/prepare_luminance.py`从已下载的兼容工坊分支提取开发DLL/PDB/XML到被忽略的 `artifacts/dependencies/Luminance/`，不把第三方二进制塞进本模组。其他机器可先安装Luminance，或用 `ZENITH_LUMINANCE_ARCHIVE` 指向其 `.tmod`。本机仍使用.NET8与tModLoader2026.8.3.0；库归档的构建版本为2026.4.3.0，需以本轮真实加载结果验证兼容。

```powershell
pwsh -NoProfile -File checks/run_wood_checks.ps1
pwsh -NoProfile -File checks/run_slash_render.ps1
python checks/package_install.py
```
