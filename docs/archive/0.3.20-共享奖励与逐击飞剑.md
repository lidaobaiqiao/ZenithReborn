# 0.3.20 · 共享全收集奖励与逐击飞剑

## 玩家反馈与修正

左上两格由「森林剑位 F1/F2」统一为「全收集奖励 R1/R2」。条件为已附着且满足任一项：12木剑同时有效寄宿，或同枚剑魂累计有效登记14种矿石材质。两族共用同两格，不相加为四格，总有效槽仍为10普通＋5支援＋2奖励＝17。保留旧`forestHosts`存档字段与索引，已放入武器/词缀不迁移、不丢弃。矿石取下仍保留登记及奖励槽；木质森林之力的属性和增益仍需维持木质全套。

旧飞剑代码在一次命中中遍历所有材质，直接生成整波；现改为每次矿石主剑首次有效命中只积攒一把，按当前有效矿石材质轮流形成。主剑后续帧伤、子弹幕不重复触发。同魂和同目标10帧冷却，完整波次等待最后一把成形/蓄力后共同射出。若中断180游戏帧或原目标死亡，释放已积攒的部分；不因杀死原怪就把成形飞剑全部删除。目标被友善化、NPC槽位被复用或来源失效仍清除。

原飞剑仅取主剑伤害的8%及材质增幅，却再次面对完整的防御减免，容易被压成最低伤害。现在保留原伤害系数和圆满奖励，将防御减免也按同一系数缩放。增加实际移动路径的连续碰撞检查和有限移动预判，保持原20像素碰撞宽度及穿透、6帧局部免疫。成形期间仍不伤害，射出后可命中沿途多个合格敌怪。

按玩家要求，基础挥臂周期与主剑飞行周期除以1.1后向上取整：最快挥臂45→41帧，主剑边界42～96→39～88帧；矿石飞行10.5→11.55像素/帧。不改变单剑自身伤害、三节点轮换、模型尺寸或UI动画速度。
