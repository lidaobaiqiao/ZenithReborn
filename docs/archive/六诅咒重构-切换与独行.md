# 六诅咒重构 · 当前机制

> 2026-10-21设计更新：用户已采纳五种新增祝福机制，御剑改为战斗蓄条、满条保留、手动开启后视野翻倍及远距离最高50%增伤；其余四种采用百刃接力、归鞘留锋、破障、剑痕。详见[六祝福设计](六祝福-机制定稿与御剑爆发.md)。下文“额外效果待设计”是历史状态；当前0.3.37游戏仍未实装这五种强化。

日期：2026-10-20。0.3.27已实装本轮明确范围。以[实现记录](0.3.27-六诅咒与个人封印.md)和[Boss分组](六诅咒-Boss分配与成长节奏.md)为准。

| 诅咒 | 核心限制 | 完全解除后 |
|---|---|---|
| 切换 | 只有当前有效主攻序列第一把武器的特性生效 | 所有有效武器恢复各自合法特性 |
| 独行 | 每轮只一把主剑 | 正常三把，祝福后成长至十把 |
| 缚身 | 只有射程缩短，保留鼠标自由选点、完整回旋 | 正常射程 |
| 断锋 | 同一主剑本趟对同目标只直接命中一次 | 正常8游戏帧重复命中 |
| 阻隔 | 实体地形截断主剑攻击 | 正常穿墙 |
| 归鞘 | 新挥臂提前停止旧轮主剑的伤害并淡出 | 跨轮主剑自然共存 |

切换和独行独立：前者决定特性来源，后者决定出剑数。归鞘不锁攻击键、不增加等待、不恢复吸入动画；只约束主剑，已有减益和衍生弹幕不随之清除。断锋不影响沿途其他敌人，不删除已施加的持续伤害，各主剑分别记录目标。阻隔忽略平台、背景墙、装饰并有出生容错。

两Boss组第一位完全解除、第二位祝福；三Boss组第一位削弱、第二位完全解除、第三位祝福。解除不留下该咒的隐藏限制。除独行外的五种祝福暂只记录状态，额外效果待用户继续设计，不擅自加入伤害、射程或无冷却强化。

有效序列第一把按当前真实主攻物品取值，第一槽空了也不会让全部特性绕过；与当轮轮换到哪把剑无关。切换同时约束木族战斗羁绊、常驻属性、减益、支援与矿石衍生效果。结构槽位和累计登记不抹除；17槽、逐剑独立伤害、不分摊、原版曲线/粒子保留。

旧版只记录机制、尚未授权实装的约束已随本轮“可以开始落实了”更新。本轮用户随后限定先完成明确部分，其他五祝福及外域特殊祝福继续待定。
