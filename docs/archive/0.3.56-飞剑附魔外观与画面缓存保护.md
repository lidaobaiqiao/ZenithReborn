# 0.3.56：飞剑附魔外观与画面缓存保护

> 用户后续指出复现方法不足：原先夹具直接生成普通稻草人、调用超级假人的物品回调，未覆盖真实鼠标点击和界面输入。上述检查只作为绘制／回调夹具证据，不能称实际鼠标放置已测试，更不能据此排除黑屏。后续补测先使用独立副本和相同8模组，从原版菜单进入世界后真实点击放置；记录另行追加，不修改正式档。

用户要求移除飞剑上的火焰减益外观，并报告放置「更好的体验」超级训练假人后世界变黑、物品栏和鼠标仍正常；确认黑屏发生在尚未攻击时。

## 本轮修改

- `SwordEnchantmentVisuals` 对主飞剑、矿石飞剑、天铸巨剑和武技实体剑设置 `noEnchantmentVisuals=true`，停止原版自动附魔粒子。未设置 `noEnchantments`，药剂和装备附带的命中减益保留。原有剑材质、配色、长尾、动态蒙版和攻击参数保持。
- `VfxSwordMask.Prepare` 遇到已绑定的丢弃型或不支持的绘制目标时，延后合成并复用已有帧，不切离其他绘制者的目标。返回窗口缓冲时临时保留像素；同时恢复纹理／采样器 0～2。未修改其他模组的目标或全局配置，未新增依赖。
- GPU 检查增加真实场景内容校验：先在丢弃型目标写入指定颜色，再调用生产合成入口并逐像素比较。0.3.55 的绑定／混合状态虽恢复，但原像素丢失；0.3.56 保持原像素。这是已证实并修复的独立缺陷，不能据此断言用户未攻击时的假人黑屏原因已经解决。
