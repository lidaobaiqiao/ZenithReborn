# 0.3.6 肉后三矿实装

六把现有矿石剑获得剑魂专属机制，不新增武器或配方。普通寄宿槽中各剑继续按自身武器伤害、前缀、暴击、击退和成长效能计算；没有统一天顶伤害下限，没有剑数分摊。保留五段逐把出剑、接续轮换、柔和拖尾与各剑配色。

## 六项效果

| 武器 | 实装机制 |
|---|---|
| 钴剑·快淬 | 同一目标主体累计3次合法主命中，发出一枚40%D钴蓝轻刃，追向原目标、命中一次、至多45帧；同来源触发间隔60帧。 |
| 钯金剑·续锻 | 累计5次合法主命中，尝试回复最大生命0.5%，向上取整后限制1至3点；同来源触发间隔180帧。受下文恢复额度、吸血资源与禁疗限制。 |
| 秘银剑·导刃 | 累计4次合法主命中，为该目标留下180帧导刃印。下一把不同来源主剑消费后，其本次来源伤害修正＋12%；创建当击不能消费。仅一把有效主剑时，允许下一趟该剑消费。 |
| 山铜剑·绽金 | 首次合法主命中发出3枚追向原目标的花瓣，合计30%D，总寿命至多45帧；每瓣命中一次，触发间隔120帧。 |
| 精金剑·硬解 | 对当前防御至少30的目标，该来源主剑条件增伤12%；使用来源伤害修正通道，保留敌方防御和减伤结算。 |
| 钛金剑·环钛 | 累计4次合法主命中，生成一片30%D钛片，沿来源剑影周围18像素环绕，至多30帧、命中一次；该来源通道只保留一片，来源剑影消失时结束。 |

D为对应来源主剑射出时的基础伤害快照，已含玩家加成、寄宿武器前缀与成长效能，不含本次暴击、目标防御与本次条件增伤。森林额外主剑增伤不再次灌入D。附属射弹继承该主剑暴击率，不再次乘成长效能。

## 支援与独立计数

六把剑都可进入已解锁的支援槽。支援模式下不生成该矿石的独立主剑，也不贡献其武器伤害；各实际主攻剑分别获得其机制，使用各自的D、计数和冷却。将伤害不同的两把剑与钴剑支援搭配，产生的轻刃伤害也不同。

主剑依然每8帧可再次命中同一NPC；矿石充能另设30帧合法计数间隔。计数按持有者、剑魂、特性、来源主剑和敌人主体分别记录，180帧未合法命中后清空。虫体部件共用主体计数入口。触发冷却按特性和来源主剑记录，切目标不能绕过。

秘银印记也分来源保存，每次主命中最多消费一枚符合条件的印记。普通多主剑配置需要另一种来源武器消费；单主剑例外仅允许不同飞行实例消费，不允许同一剑影重复自吞。取下提供该特性的矿石或来源主剑后，相关印记及连击不再生效。

所有附属攻击不再为矿石机制充能、不再触发回血；只由拥有者生成派生实体。实体记录剑魂ID与实际来源武器类型，远端和服务器不重复生成。失去有效来源、目标死亡或目标槽被另一敌人复用时结束；飞离持有者600像素也结束。

## 恢复限制

钯金恢复在任意360帧内共用`max(1,min(8,ceil(最大生命×2%)))`点额度，跨剑魂与来源主剑合计。400最大生命时，任何来源组合在6秒窗口中最多回复8点。额度随旧恢复记录过期而恢复，不因多放主剑而扩大。

实际恢复还受缺血量、原版吸血资源和月噬禁疗限制；扣除实际支付的资源，满血不储存治疗。不从训练假人、友方、无敌目标、低生命装饰目标或零伤害事件获取充能。原有木系自然回复与直接治疗入口保留，本批新增直接恢复按上述额度支付。

## 表现、界面与旧档

钴蓝、钯橙、秘银绿、山铜粉、精金红和钛金灰分别用于对应剑的特效。派生实体使用小型碎片贴图、有限追踪与少量粒子，不改变已经稳定的主剑椭圆轨迹。悬浮碎片的实际图形观感本轮尚未实测。

悬停原武器、查看寄宿槽和剑魂提示可看到具体特性与计数间隔。主槽和支援准入已接通；普通槽、支援槽及森林奖励槽的原解锁条件不变。新状态均为临时战斗状态，不修改物品保存格式，不清空已有寄宿武器和成长记录；多人需使用相同模组版本。

另修复既有碰撞漏洞：当主剑的整段短判定落在大体积目标内部时，线段辅助判定可能返回未命中。现在剑影中心位于目标内部也算命中，与当前主剑判定段的几何范围一致。

## 验证与范围

生产编译零警告、零错误。隔离tModLoader检查通过实际`Projectile.Damage()`验证主命中触发、附属实际伤害及不递归；检查三枚花瓣的总预算、低伤害仅分配一次最低伤害、钛片跟随与结束、支援来源独立、印记消费/过期、回血额度到期与资源/禁疗、虫体计数、拥有者限制及来源字段网络序列化。无窗口恢复检查仅屏蔽浮动文字的绘制入口，实际恢复和资源支付路径正常执行。

保留逐剑伤害、重复命中、五段出剑、独立灵能冷却、木系、成长槽位、重铸、保存与月亮领主召唤回归。本轮未运行图形客户端或真实多人联机，不把隔离检查当作全流程平衡结论。
