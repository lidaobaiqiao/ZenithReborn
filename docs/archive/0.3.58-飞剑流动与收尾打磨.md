# 0.3.58 飞剑流动与收尾打磨

本轮接续0.3.57，打磨普通主飞剑`SoulBlade`的材质带面。矿石附属飞剑的H4剑身一体组、武技巨剑斩击和其他对话的改动保留，没有改攻击轨迹、时序、伤害、碰撞或存档。

## 外观变化

- 起步按阶段逐步显现，短轨迹先形成窄带，随实际剑尖走过的距离展开。静止重复姿态不生成整片刃面。
- 材质纵坐标按实际剑尖样本间的累计距离分配，快慢段的纹理密度更连贯。剑尖仍是亮刃的定位依据，未使用玩家中心重新画圆弧。
- 最新剑身附近收紧，向后展开；暗侧轮廓有连续、低频、小幅的宽度起伏，剑尖亮边保持在真实轨迹上。它改变实际蒙版边界，包含形状动画。
- 继续复用巨剑的原始编译材质与笔刷。细白刃保留，减少整段白热展宽，提高主体中的本剑颜色占比。对同一受控画面，近白像素由1848降至129，彩色可见像素由18310变为16520；这只是画面对比指标，不代表用户美术验收。
- 普通返回在阶段60～84逐渐侵蚀并熄灭，提前收回沿既有8次更新结束。结束不追加伤害或延长剑体寿命。
- 保留原版飞行粒子。提前收回时复用`SoulFlowSpark`少量脱落碎光，每四次更新最多一粒，替代此前每次更新四个圆圈；普通返回不额外堆粒子。
- 原版剑体直接绘制，去除额外放大25%的白色剑体副本，原版间隔剑影保留并降低不透明度，让实际剑体更清楚。
- 横截面从8格减为4格，并保留精确落在剑尖的截面顶点；最长带面由4464降为2232个顶点。该数字不等于已完成帧率基准测试。

原始第三方着色器／编译效果／笔刷／噪声未修改，许可证与来源记录继续随包；没有新增插件或运行依赖。
