# 0.3.41 · 环境光环满屏色带修复

日期：2026-10-22。用户提供森林主动领域满屏绿色放射线截图。本版仅修复环境共用画线函数，不更改属性、机制、领域半径、成长、祝福或保存版本。

## 原因与修改

EnvironmentEffect.Line使用MagicPixel整张纹理（sourceRectangle=null），同时把目标长度/宽度直接用作缩放。真实图形客户端测得该纹理为1×1000，并非1×1，导致圆环每段的厚度被放大1000倍，形成辐射色带。魂域UI此前已使用1×1裁剪，新增环境绘制遗漏了同样的处理。

现在显式裁剪Rectangle(0,0,1,1)，再按目标线段长度和宽度缩放。修复同时覆盖领域边界、近身小环、环境范围攻击圆环与机关光束；没有靠隐藏特效或缩小生效范围规避问题。
