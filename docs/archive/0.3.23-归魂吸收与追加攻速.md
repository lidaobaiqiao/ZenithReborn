# 0.3.23 · 归魂吸收与追加攻速

玩家反馈0.3.22收刀是横着停在背后褪色，缺少被人物吸取的动作。本轮将背后14像素停留点改为体内核心（朝背侧2像素、重力反方向3像素），以12帧连续回收动作结束主剑。

- 剑影相对人物移动，距离按进度平方收缩，越靠后收拢越快。
- 每帧让剑尖朝向吸收核心，不再从旧旋转缓慢过渡到固定斜放角。
- 显示尺寸随进度真实缩小，最后一帧缩至约原尺寸12%；前72%保持完整不透明度，末段才淡出。
- 新增SoulAbsorbSpark，复用SwordSpark贴图，小型粒子向移动中的人物核心汇聚，接近核心后销毁。
- 保持原独立背后人物图层、前景去重与收刀阶段CanDamage=false。攻击飞行时长及伤害不变。

相对0.3.22再提高10%挥臂攻速，先取上一版整数周期再除1.1向上取整，最快37→34帧。仍在25%/50%/75%/100%节点逐把释放最多四剑，不足留空；主剑和矿石实际飞行速度未再调整。
