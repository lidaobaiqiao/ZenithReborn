# 0.3.0「森林共鸣」实装说明

本轮实现木质族W2.1，沿用0.2.4的剑影轨迹、弧面拖尾、淡残影与少量粒子。其他剑族的D1候选特性没有全量实现。

## 使用方法

按P或手持右键管理寄宿。上排为原有10个基础普通槽，下排左边为2个森林奖励普通槽，右边为5个特殊支援槽。普通槽正常出剑、提供来源属性；支援槽只提供已登记特性与木质计数，不生成主剑、不参与属性平均与伤害分摊。

木质成员共12种：木剑、针叶木剑、棕榈木剑、红木剑、仙人掌剑、乌木剑、暗影木剑、灰烬木剑、珍珠木剑、王朝木剑、阴森木剑、仙灵木剑。松木不在本套。

1、2、4、6、8种分别解锁累计1、2、3、4、5个支援槽。支援槽中的木剑可以继续贡献数量，但从基础普通槽开始求最小稳定结果，不会空槽自行解锁。全套需要7个基础普通槽和5个有效支援槽；森林奖励槽不能反过来维持自己的解锁。

失去全套或支援阈值时，对应槽暂停生效，里面的武器原位保留，用空鼠标点击可以取回。重复武器在全部17格之间统一去重，暂停格也不会允许复制寄宿。

## 森林之力

12种同时寄宿后立即获得＋100生命、木系基础3倍效果、两个真实普通剑位。它们在当前已解锁普通容量上加2，最终上限为12普通＋5支援；全套需要占7个普通位置，所以最终还能携带5把其他主攻剑。

| 成长属性 | 每层 | 12层上限 |
|---|---:|---:|
| 主攻伤害 | ＋3% | ＋36% |
| 出剑速度 | ＋2% | ＋24% |
| 防御 | ＋3 | ＋36 |
| 自然生命回复 | ＋0.5生命/秒 | ＋6生命/秒 |
| 自有持续伤害 | ＋5% | ＋60% |
| 受伤减免 | ＋1个百分点 | ＋12个百分点 |

有效主命中后5秒内计入战斗时间，每5秒一层、60秒封顶。挥空、训练假人、附属弹幕和旧持续伤害不会刷新战斗计时；脱战后每2秒衰减一层。死亡、更换剑魂或失去全套立即清零。森林伤害奖励只加在主剑影，附属射弹保留未加森林主攻奖励的伤害快照；速度奖励不改剑影飞行轨迹与时长。

森息满套再提供0.75生命/秒，因此满层两者合计额外6.75生命/秒。森林之力有状态图标，鼠标悬停可查看当前层数与实际加成。

## 特性结算边界

12种木剑的环境效果已登记，细节见[木质族D2](木质族D2-环境特性与森林之力.md)。原有木剑的实锋加成由木系规则替代；其他矿石阔剑、骨剑等保留实锋。

- 瘴毒、裂伤、烬燃使用各玩家、各剑魂自己的持续伤害贡献，尊重中毒、着火及自定义减益免疫。浮点预算累计，不逐帧保底伤害。
- 多把主剑共用对应目标的施加间隔，虫体按主体归组；裂伤最多3层，孢光从原始时长加算，最多8秒。
- 悼魂满套使自有持续伤害提高30%。死亡传播最多转移剩余预算75%，360像素内至多两名可见目标平分，保留剩余期限与免疫限制；转移伤害不再传播、不再叠一次增伤。
- 血馥提供剑魂直接治疗的倍率与共享预算接口。当前木剑不自行新增吸血或直接治疗来源，血馥也不提高药水、自然回复或其他模组全局治疗；后续治疗型武器可复用该接口。
- 御令只缩短新施加的原版白名单减益，满套12%；不修改药水病、禁疗和外部模组剧情状态。
- 非木支援限于当前登记的早期五类武器与天顶材料剑，使用已有特性及共享冷却；尚未设计支援机制的其他近战武器可以普通寄宿，不能放入支援槽。
