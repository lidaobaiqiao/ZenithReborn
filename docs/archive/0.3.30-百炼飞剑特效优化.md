# 0.3.30 百炼飞剑特效优化

本版仅调整矿石辅助飞剑与天铸巨剑的画面，沿用0.3.29所有族奖励、独立伤害、飞行速度、穿透、命中间隔、冷却和17槽规则。主剑继续使用原版天顶粒子与轨迹。

## 飞剑

- 各矿材原配色保留；剑身增加低强度边光和局部柔光，剑尖与移动高光使用原版星芒贴图。
- 出现时短暂扩散细环，保留原有膨胀再收稳动画；齐射和折返时闪亮一次，不拖慢攻击。
- 拖尾改为三层渐细短光带，保留少量剑身残影。粒子从剑尖和剑尾分开逸散，随速度向后飘散。
- 命中增加短促星芒和定向火花；同一飞剑的视觉反馈至少间隔12帧，降低持续帧伤产生的粒子堆积。此限制只针对画面，不改变6帧实际命中间隔。

## 天铸巨剑

- 30帧预兆期间，落点椭圆细环逐渐收紧，微粒向落点汇聚，保留细小纵向引导线。
- 下落增加分层金色短拖尾、剑身残影、剑尖星芒与两侧逸散粒子。
- 命中出现短时双层扁平冲击环、局部辉光和向上散开的火花，不增加屏幕震动、全屏闪光或伤害弹幕。

## 绘制与性能边界

`OreSwordEffects`统一处理局部光效。所有线段使用屏幕转换后的有限长度和正向尺寸；轨迹保留原有96像素断点保护，避免连接出生点或突变坐标。使用游戏默认预乘混合下的零透明度发光颜色，不切换SpriteBatch或全局混合状态。

仅客户端产生视觉粒子；命中光效和冲击环保存在对应弹幕的本地字段中，不写人物存档、不新增网络字段、不生成额外攻击实体。巨剑消失时其剩余冲击环也结束，不为了显示特效延长攻击寿命。
