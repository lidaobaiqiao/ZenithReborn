# 用户昼夜录像诊断：白天通透，夜晚灰膜

用户2026-10-25对当前80效果补充：「白天质感很好很通透，但是一到晚上就看起来很脏，没有通透质感」。这修正了此前把问题概括为整体暗淡、继续补发光的方向。80白天的干净通透是本次认可的参照；不能将此反馈当作88增强流纹/发光已获认可。

## 录像观察

从用户提供的两段录屏各提取六个原始帧，第一段是白天、第二段是夜晚。白天的山体和树木可透过弧面辨认，薄边反光较干净；夜晚大片灰白粗纹与重复条带突出，呈现浑浊的灰膜或厚片观感。

## 源码可确认的因素与待验证项

已读取原始80源码归档，不用当前88源码冒充80实现：

- SwordFlowMaterial.Draw按时间计算光向，夜间仍走相同角度公式，没有传入随夜间环境降低的主光强度。
- ZRSwordFlow.fx环境贴图反射使用固定曝光6，方向高光使用固定倍率2.2。环境图本身是灰度天空/山水图。它的反射不会自动跟随当前场景一起变暗。
- ZRGlassScreen.fx仍读取当前帧偏折背景并与反射合成；夜间透射背景的光能变低，固定反射和微表面结构会在视觉上占据更大比重。

因此，固定环境反射及表面结构是夜间灰膜的重要嫌疑。尚未逐项关闭环境反射、方向高光和法线做GPU对照，不能把录像中每一条重复纹理都归因于某一张贴图或宣称已完成根因消融验证。

本次目标应是保住白天80的干净、薄、通透，处理暗背景下反射与透射失衡及灰纹突出；直接把整个带面变亮不能证明该问题得到解决。后续验证须包括白天、黄昏、深夜和局部照明环境，不能继续只用固定白天的世界夹具覆盖美术判断。
