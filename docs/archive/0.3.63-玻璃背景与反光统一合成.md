# 0.3.63 玻璃背景与反光统一合成

用户明确指出0.3.62画面仍没有玻璃折射质感。本轮修正实际合成流程，不把参数已传入、滤镜已执行或法线有像素当成最终效果有效的证明。

## 问题与改动

0.3.62先把彩色材质画进世界，再折射这幅已被涂色的画面，背景细节已经被遮盖；折射还乘了原版全屏滤镜的慢渐入系数。实际第42帧探针读到该系数仅0.3166654，而不是材质预设Opacity=1。Thickness=24的位移又偏弱，最终更像普通彩色薄膜。

0.3.63保持同一套真实剑迹、慢色场、动态形状与侵蚀，安全准备阶段分别输出法线数据和有色吸收／窄反光数据，两者共用形状。准备成功时，PostDrawTiles不再提前涂彩色主体。最终的自有ZRGlassScreen直接读取原版提供的当前帧干净世界，一次完成背景偏折、剑色和反光合成；这两张辅助图是同一材质的数据，不是两层独立形状的叠加。无法安全准备时保留普通材质回退。

法线图现在保存实际表面朝向，IOR在最终合成时直接进入refract。去掉全屏滤镜慢渐入的额外相乘，形成与消失由剑迹本身的覆盖度和侵蚀负责。制作预设仍为IOR=1.5、Roughness=0.08、Transmission=0.55、Opacity=1，虚拟屏幕厚度改为72以提高背景位移的可辨度。厚度是美术尺度，不是现实毫米；这是二维屏幕空间近似，不声称完整体积玻璃或离线渲染器。

参数仍只属于制作端，无玩家配置面板或新依赖。两份Effect均为项目自有。没有接回旧月牙材质、笔刷或噪声，没有引入Filament／MaterialX运行库。剑的运动、伤害、碰撞、槽位和存档保持；矿石H4的4份源码与21张蒙版逐字节对照0.3.62源码包一致，见artifacts/ore-preservation-0.3.63.json。

- artifacts/soul-flight-world-0.3.63/native-probe.json：同一帧、同一场景、同一法线和表面数据，经过完整原版滤镜链两次，只改自有滤镜IOR=1.0／1.5，读取最终窗口缓冲。两次实际Apply；差异总量258340，17136个像素的RGB差异总和大于3，剑迹外变化像素为0。参数1.5、0.55、72与蒙版绑定也记录在结果中。这补上了0.3.62没有验证最终滤镜链的缺口。
