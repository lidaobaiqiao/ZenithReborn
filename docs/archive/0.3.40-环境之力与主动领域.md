# 0.3.40 · 环境之力与主动领域

日期：2026-10-22。用户授权开始实装，并明确森林没有虚弱环境。本版在0.3.39数据基础上接入21种环境的属性、独立机制、收集成长、祝福常驻和主动领域。

## 游戏内入口

按P或手持剑魂右键打开魂域，点击新增“环境之力”页。每种环境显示已收集/未收集、实际属性倍率、机制说明、展开领域与常驻选择。

- 有效主槽和支援寄宿登记武器已有环境标签，累计保存在同一枚剑魂，取下不丢。
- 也可在自然环境中用剑魂攻击击败正常敌人登记当地环境。雕像生成、友善或极低生命目标不登记；主动领域不能冒充自然探索来源。这使没有对应剑来源的神庙、蘑菇等环境也能实际取得。
- 手持已附着剑魂提供已收集属性；放回背包时停止提供，不把属性永久写入玩家基础值。
- 默认仅当前环境的机制运行，其他已收集环境保留属性。收集4/8/12/16/20种各给一个常驻机制名额，共5个；在本页点击选择/取消。
- 点击已收集环境展开随玩家移动的半径960像素（60格）领域，无使用冷却、限时或资源消耗；可直接切换，或恢复自然环境。
- 领域改变本剑魂在范围内的环境机制与适应性判定，绘制对应颜色的边界和近身环。它不是单纯背景特效，也不改写地图方块、原版刷怪、Boss召唤和狂暴规则。

上述获取方式、4种一档名额与60格半径为本轮将未定细节具体化的首版实现参数，不能反向写成用户此前指定的数值。

## 已落地的共同成长

设N为该剑魂累计登记的不同环境数量：

`强度 = (1+0.20×N) × (已登记森林 ? 1.15 : 1) × (当前主动环境为本环境 ? 1.5 : 1) × 适应性`

- 第一种也贡献20%，不同环境加算，不使用1.2的N次方。
- 森林“万境之根”系数为固定1.15，对全部已登记环境结算一次；森林自身的普通属性/免伤也受益，但这个系数不反复强化自己。
- 森林没有任何虚弱环境，在地狱、沙漠、神圣等处均不减半。之前森林受沙漠/地狱削弱的提案已撤回。
- 其他环境采用E6的相克方向首版实现，不适应时对应效果减半；不叠加多次减半。神庙、地牢暂不设相克。
- 对应主动环境50%不扩散给其他环境；森林领域提高森林的防御/护叶生长等，不把固定15%自行改为22.5%。
- 成长分别映射到各机制主参数，不将伤害、触发频率、目标数、持续时间一起乘倍率。

自然环境判定保留本轮工作区已有修改：特殊群系优先于普通地下/洞穴深度，地下丛林、神庙等不同时冒充普通洞穴；地下沙漠也覆盖相应深度的沙漠标记。

## 属性与机制

基础属性采用E7最后一次按属性价值修订的表，未使用被否定的约1%旧表。森林基础6防御、丛林1生命/秒与8%恢复效力、神圣2个百分点暴击与6个百分点爆伤；基础值之后再应用上述成长。

| 环境 | 本版独立机制 |
|---|---|
| 森林 | 林荫护叶，基础约30秒生长，成长强化生长速度；成熟后消耗抵挡一次有效受击，走ConsumableDodge真实免伤 |
| 地下层 | 六次主剑首次命中释放岩震 |
| 洞穴层 | 持续命中叠地脉破甲，六层后岩裂 |
| 地狱 | 有效剑魂攻击按实际伤害基础0.1%汲取生命；受禁疗、原版吸血资源与按最大生命成长的恢复额度约束 |
| 太空 | 三次不同主剑交错引来星辉追击 |
| 雪原 | 凝霜脆化、五次命中碎冰，普通敌人受减速；Boss收益不依赖硬冻结 |
| 地下冰雪 | 凝结可消耗冰甲，受击吸收部分伤害并冰裂；未实际受伤时不消费冰甲 |
| 沙漠 | 三次首击生成延迟蜃影斩，不扣原剑伤害 |
| 地下沙漠 | 流沙区域周期砂刃伤害 |
| 海洋 | 八次首击触发外推与回卷潮波 |
| 丛林 | 有效战斗12秒积攒蜜露，受伤后四秒持续恢复，基础共3%最大生命，再应用强度 |
| 地下丛林 | 自有毒芽持续伤害，不同主剑促成毒花爆发 |
| 丛林神庙 | 十二次首击释放定向机关光束 |
| 发光蘑菇 | 孢子场与自有持续伤害共鸣 |
| 腐化 | 腐蚀破甲，成熟后传播 |
| 地下腐化 | 六次首击追魂攻击 |
| 猩红 | 撕裂伤痕造成自有流血 |
| 地下猩红 | 受伤后逐步修复部分本次损失生命 |
| 神圣 | 超过100%的暴击率，每溢出1个百分点基础转为0.5个百分点爆伤，接入实际CritDamage倍率而非Flat固定伤害 |
| 地下神圣 | 不同主剑积攒晶簇，四次共鸣晶爆 |
| 地牢 | 四把不同主剑编织封印斩 |

各机制首击指每次实际发出的主剑首次有效命中。后续帧伤仍可正常造成伤害及生命汲取，不反复增加机制计数。衍生环境攻击、矿石飞剑等不能递归触发整套主剑环境机制。爆发攻击按敌人主体防止分段重复；区域攻击保留有限命中间隔。

恢复效力首版覆盖本环境提供的持续恢复、环境直接恢复、已有剑魂直接治疗入口与药水，不拦截其他模组任意Player.Heal调用。生命汲取、冰甲、蜜露等使用小数累计，避免低数值每次向下取整而失效。
