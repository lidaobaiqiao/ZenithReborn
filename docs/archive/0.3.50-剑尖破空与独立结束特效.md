# 0.3.50 · 剑尖破空与独立结束特效

日期：2026-10-23。用户指出上一版仍主要表现为拖尾，缺少随剑头移动的破空，以及天铸巨剑、各矿石武器的结束表现。

## 表现与接入

- 十四材质飞剑持续显示前置双层弧形气刃、两侧收束气流和刃尖闪光，位置按实际武器贴图对角长度、显示缩放和方向计算；覆盖原有短促起步环之外的整段飞行。天铸巨剑和钴蓝／山铜／钛金附属弹幕同样接入前置效果。
- `OreFlyingSword.OnKill`保存最终姿态，留下20帧分离剑影、侵蚀裂光、扩散余波，并发出8枚原版Dust池碎光。已经显形但尚未射出的飞剑，中途取消也有收尾；未显形的无效生成不产生空爆点。
- `OreSkyfall.OnKill`保存最终姿态及最近实际命中的位置，巨剑余波持续36帧，发出24枚碎光。剑影留在最终真实位置，冲击收尾留在命中处；没有命中时使用消失位置。不会把已经穿过目标的剑体强行搬回目标，也不修改其穿透／伤害规则。
- `HardOreShot.OnKill`为附属剑片增加20帧侵蚀／残影与碎光；实际碎光按25／36帧独立减速消散。不会生成额外伤害弹幕。
- `OrePierceFeedback`在原版DrawDust之后合成剑尖和收尾，避免被敌人和剑体遮住。结束记录独立于父弹幕，最多64条，按寿命过期，世界卸载及模组卸载清空。
- 沿用原版Dust、SharpTears以及已引入的原始MIT OniCrimsonSlash编译材质和笔刷／噪声资源。没有新增玩家插件、着色器编译链或渲染框架；许可证和来源哈希继续随包保留。

保留0.3.49实际后拉与每趟加速、距离／预判／同步逻辑。此版没有改变攻击时序、伤害、碰撞、槽位与存档，也没有用加快播片代替动作修改。普通主剑和武技已认可的流光主体保持。
