# 0.3.18 · 动态剑环界面

本轮按用户布局要求重做寄宿页，并加入动画。仅改变界面表现，不更改战斗、成长、容量或存档。

## 布局与交互

- 普通 01～10：固定圆环，保留原槽位索引及解锁条件。
- 支援 S1～S5：右下外弧，仍只提供特性和羁绊。
- 森林 F1～F2：左上外弧，保留全木质套装的真实剑位条件；暂停时变暗，物品仍可空手取回。
- 天顶碎片：寄宿、生效特性、成长记忆、特性图鉴；有遗留物品时增加只取回入口。寄宿页入口位于剑环外，其他页面在顶端保留碎片导航。
- 中央显示主攻/支援数量、选中槽或武器、有效/暂停状态和武器面板伤害/暴击。环内悬浮不再弹出遮挡剑环的整张武器长提示；解锁条件、下一步在环下滚动查看，详细效果在特性页和图鉴查看。
- 小视口保留可点击的槽位大小，滚动查看完整剑环及详情，不挤成过小图标。面板继续支持标题栏拖动。

## 动画

- 开启约0.65秒：环线展开，槽位依次渐显。
- 已寄宿有效武器：各剑配色与青色/紫色/绿色分区融合，持续呼吸光晕及绕行光点。
- 放入武器或槽位重新启用：约0.75秒的扩散光环；移除或暂停时光晕平滑熄灭。
- 剑环：慢速流动弧光；选中槽：金色环线缓慢转动。
- 天顶碎片：轻微摆动，选中/悬浮时出现绕行光点和光环；切页约0.24秒旋转过渡、文字渐显。

使用独立实时时钟，暂停游戏时界面动画仍继续。只缓存小型程序生成纹理，不创建世界粒子或弹幕；卸载时释放资源。装饰不改变点击目标，不写入剑魂存档。MagicPixel线段显式指定1×1源区域，避免旧版巨大扇形拉伸问题。

## 源码入口

- `ZenithReborn/SoulUI.cs`：共享布局、页面切换、固定命中框、原输入与拖动入口。
- `ZenithReborn/SoulUIEffects.cs`：剑环、碎片纹理与动画、中央摘要。
- `checks/ZenithPrototypeCheck/UiCheck.cs`：更新圆环布局检查，并检查外弧方向、碎片/槽位互不重叠。
- `checks/ZenithPrototypeCheck/UiFixture.cs`：隔离图形夹具关闭自动暂停及小地图，避免继承旧测试设置影响观察；不修改正式配置。
