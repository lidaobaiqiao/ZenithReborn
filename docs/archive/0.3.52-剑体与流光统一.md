# 0.3.52 · 剑体与流光统一

日期：2026-10-23。用户指出放大的原版像素武器与平滑、高亮特效不和谐。本轮处理剑体、包覆流光和剑尖衔接，而非继续只放大特效。

## 表现

- 原版剑型与贴图明暗保留；客户端以原版纹理的Alpha和亮度生成中性色副本，统一按十四材质／天铸金色着色，减弱原图绿、紫等杂色与特效之间的冲突。不会修改原版共享Texture2D。
- 剑体采用同色轮廓辉光和轻透的明暗层，复用已有OniCrimsonSlash直刃模式包覆剑身，连接尾迹、剑身和前置气刃。飞剑、巨剑、残影及附属剑片使用同一套色彩处理；普通主剑和武技已认可的流光主体保持。
- 原`.32×贴图对角线`低估了实际剑尖距离，尤其在5.6倍巨剑上明显。本版从原图不透明像素轮廓计算沿剑轴的最远点，按实际贴图角度及缩放定位剑尖。包覆、剑尖星光、前置破空和隔离预览均使用相同位置来源。
- 前置气刃的几何中心后移，让弧面围住剑尖并收束到尖端，移除原来悬在剑前方的空隙；保留0.3.51扩大后的体量。
- 转色副本及轮廓只在首次使用时生成并缓存，重复绘制复用；卸载时只释放自己创建的副本。不新建底层渲染框架，不新增玩家插件、绘图资源或自编译Shader，第三方原始资源与许可证保持。

攻击运动、时序、碰撞、伤害、槽位、存档与20／36帧独立收尾生命周期均不变。
