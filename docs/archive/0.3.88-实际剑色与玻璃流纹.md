# 0.3.88 · 实际剑色与玻璃流纹

用户在87后反馈「颜色根本没有随武器变化，而且效果很差」，并提供「所有武器都是一个特效」的实际截图。本版接续旧窗口未交付的88候选，完成最终颜色输出、世界和安装验证。87仅核对79调色表与混色表达式，不能证明最终画面的颜色随实际剑身变化。

## 最终行为

- 默认主飞剑材质从当前物品的实际剑身帧采样主色，缓存键包含物品类型、动画帧和纹理对象；从上半刃身排除透明、暗描边和多数剑柄。银白剑保持无彩色，不分配随机彩色。
- 原调色表继续提供已有形状种子；实际颜色输入改为剑身取色。保留79式最薄的白亮刃芯，内部流纹、内缘及扫光使用剑色；反射也承接剑色。
- 显示色空间会冲淡粉、紫、青色。本版对颜色通道做预补偿，保留原先逐通道光能压缩，增强动态流丝，避免通过整面常亮或扩大覆盖度处理可见度。
- 玻璃法线、受光方向、粗糙度、折射路径和短尾形态保持。矿石H4、武技、攻击、伤害、槽位、个人成长和存档实现不改。

这里已经按用户对实际画面的后续反馈改用实际剑色，不能再宣称「逐剑颜色输入逐字节沿用79」。79的亮刃参考与80的玻璃基底继续保留。

## 验证

最终包SHA-256：`3a3a23f32f73c26d54a1b1621086e17e339c4f8efd6f4bb8c3051c237e3e5f1b`。

- 原生编译两个项目均为零错误、零警告；8393项引擎检查通过。
- 七剑实际生产GPU颜色输出通过：泰拉之刃黄绿、附魔剑蓝、星怒粉、炽焰巨剑橙、冰雪刃青、彩虹猫之刃紫、银阔剑银白。有色六剑的输出平均色饱和度为0.294～0.440，银阔剑为0.032；与剑身主色色相误差均小于0.03圈。
- 最终颜色检查同时约束色相、饱和度和平均颜色最亮通道。修正了旧候选用HSL明度评估亮度的问题：HSL取最亮与最暗通道的均值，提高饱和度会降低这个值，不能据此要求继续泛白。
- 固定相同颜色输入与80比较，法线、光学数据、透射、Alpha逐像素最大差均为0。实际剑色变化时，透射染色会随颜色输入改变；不声称所有武器最终透射RGB仍等于80。
- 默认隔离世界三剑实际命中、返回、父弹幕消失后的材质收尾，以及同帧完整滤镜IOR响应通过；IOR改变的像素均在效果内。
- 另以正式五模组组合和正式画面设置运行隔离世界，三剑命中/返回、三个实体剑影实际伤害及结束清零通过。正式启用项为HEROsMod、ZenithReborn、ImproveGame、SilkyUIFramework、UpgradableZenith；夹具额外加载ZenithPrototypeCheck。加载日志和其他模组文件哈希已核对。
- 与88修改前备份的87生产目录对照，仅新增SwordSpritePalette.cs，修改材质取色、Shader及编译清单和版本号五项，其他120项生产文件保持。原79/80安装包哈希仍匹配。

七剑颜色、默认GPU、80光学对照、默认世界及完整组合世界结果均绑定上述同一最终包；旧候选失败或旧包报告没有当作最终通过。
