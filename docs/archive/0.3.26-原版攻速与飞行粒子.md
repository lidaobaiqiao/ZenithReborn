# 0.3.26 · 原版攻速与飞行粒子

用户要求攻速也换成原版天顶剑，并修正飞行粒子与原版不一致的问题。

## 实现

- 使用本机原版天顶剑物品的基础30帧挥臂、10帧使用间隔和Swing挥臂方式。由游戏实际ItemCheck→Shoot逐次释放，未加成时第0、10、20帧各一把，第30帧下一轮。撤掉四节点、自定义手臂角度、34帧下限、宿主攻速平均及过去各轮百分比周期修正。
- 游戏正常处理玩家攻速和词缀，复制原版BonusAttackSpeedMultiplier；RefreshStats不再重写useTime/useAnimation，避免覆盖词缀速度。机械流转、森林及迅捷支援的现有加速特性保留，按已有规则叠加在原版基础节奏上。少剑时每把每轮只出一次，空余时机留空，下一轮按宿主顺序继续。
- 主剑每帧两次更新，阶段增量与本机Projectile.AI_182_FinalFractal一致，随目标距离从0.7～2变化。不再用39～88帧宿主时长重新缩放原版飞行。仍独立取每把宿主的伤害/暴击/击退/尺寸和专属机制；命中冷却改为16子更新，维持原有8游戏帧。
- 原十种天顶材料剑直接取本机FinalFractalHelper的原版配置，并调用其中dustMethod委托，不再让主剑生成自制SwordSpark。额外剑使用相同原版粒子生成函数并保留自己的颜色。粒子落点随剑魂已有放大模型一起缩放；粒子类型、随机数量、颜色过渡、尺度、fadeIn、发射方向与速度均由原版方法处理。
- 补上原版Extra98剑尖四层星芒与15/30/30/45阶段包络，以及1.25倍半透明剑身光泽；沿用现有弧面拖尾，不扩大重写UI或矿石辅助飞剑。

删除的自定义吸入、缩小和人物收刀层不恢复。17有效槽、旧物取回、全收集、人物/世界存档保护、逐剑伤害与特性保持。

## 验证与界限

本机基线为tModLoader 2026.8.3.0 / Terraria 1.4.4.9；本轮REA核对FinalFractalHelper及其粒子配置类型，继续以本机原版程序集为依据。

1. SwingCheck分别运行原版天顶和剑魂的实际ItemCheck，对照1/1.5/100攻速及无词缀/传奇词缀下的出剑帧、动画计时和自动连用；控制试验只归一化剑魂自有的成长加速，以同样外部条件比较基础原版时钟。另查少剑留空、宿主轮换、取消条件、客户端权威与词缀刷新。
2. VanillaReturnCheck同时运行原版933及剑魂的实际Projectile.Update，覆盖左右、正负曲线、50/240/800距离、重力方向与人物移动。不再改写原版阶段，直接对照每帧阶段、位置、轴向、贴图翻转、淡出和死亡帧。
3. NativeParticleCheck在无绘制的CPU环境执行原版AI及剑魂AI，180组固定种子对子生成实际Dust，对照类型、位置、速度、颜色、scale、fadeIn、重力及alpha；对照时将模型显示倍率归一化。另查额外宿主颜色和剑尖包络。结果写入隔离artifacts/native-particle-comparison.json。
4. 引擎回归覆盖既有成长、槽位、UI输入、存档、逐剑独立伤害及矿石飞剑。编译和CPU粒子生成证明不等同游戏画面实测：本轮图形客户端与真实多人尚未验证。

构建无警告、无错误；隔离引擎通过7557项检查。180组固定种子子更新中实际生成并匹配27粒原版Dust，比较不是只核对常量或委托名称。默认速度、无词缀的双方实际出剑帧均为0、10、20、30、40、50……；详细隔离结果为artifacts/native-cadence.json及native-particle-comparison.json。
