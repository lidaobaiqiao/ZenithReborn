# 0.3.84：指定旧版材质恢复

用户上传本项目此前的玻璃弧面画面，要求实现该效果，并明确“这就是你之前的版本”。因此本轮直接恢复旧配方，保留已经选定的逐剑颜色。

## 实际漏回退的两项

0.3.83虽然撤回整面发光，却仍使用0.3.82的反光染色0.55和刃缘向白混合0.30。0.3.81分别为0.22和0.64。这些参数会改变镜面亮边、暗面以及色彩读感，上轮没有完整恢复旧材质。

本版直接从0.3.81源码归档恢复整份ZRSwordFlow.fx源文件，内容字节一致；刃缘混色也恢复0.64。SwordSpritePalette及其实际剑身取色接入保持，颜色种子与主色RGB继续沿用0.3.82。没有增加贴图、发光层、静态白线或运行依赖，没有改轨迹、短尾、剑影伤害和玩法。

用户参考原图保留在artifacts/glass-user-reference-20261025/target.png，来源与哈希见同目录reference.json；不是新生成的美术。材质基准按用户现有要求采用0.3.81，截图缩放/应用边框不参与逐像素一致断言。
