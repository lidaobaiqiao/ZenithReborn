# 0.3.60 撤下旧材质依赖

用户最新要求是“依赖旧着色器的特效先删除，先替换着色器”。此次按先撤下外观、再以自有材质重建的顺序执行，没有把旧材质改名，也没有用普通纯色色块填补撤下的外观。

## 当前生产状态

| 路径 | 此次处理 |
|---|---|
| 普通主飞剑 | 继续使用0.3.59自有ZRSwordFlow；没有旧材质回退 |
| 武技巨剑 | 删除第三方厚月牙主体；保留原版流光、细刃、剑体、剑影和粒子 |
| 矿石飞剑 | 删除旧直刃拖尾、出鞘光带及依赖第三方噪声的H4剑身气流合成；原版剑体、命中粒子和声音保留 |
| 天铸巨剑、肉后附属剑片 | 删除旧材质光带；原版资源剑体、碎片及结束剑影保留 |
| 矿石结束 | 删除气流蒙版的继续漂移；原有独立剑影和粒子继续完成收尾 |

删除生产适配器MartialCrescentMaterial、OreVisualRenderer与VfxSwordMask，移除所有调用。21套项目自制蒙版及配色表留存待用，但没有当前生产合成入口；VfxLibrary入口已标记停用。撤下部分的外观尚未重建，不能称全部效果已经换成自有材质。

生产资源目录不再包含OniCrimsonSlash源码／编译文件、SlashBrush01或NoiseSoft01。参考区仅保留历史许可证、作者和哈希；原资源只在本机历史备份与旧版本包中留存，新模组包和新源码包均不携带这些文件。

当前唯一打包的非原版着色器是项目自有ZRSwordFlow。其默认慢底色、数学噪声、动态边界与侵蚀均不读取外部素材，美术绑定仍为空；程序版本仍待用户判断。引擎／原版着色器继续使用，不属于此次删除范围。

## 工具与检查

- `check_vfx_ownership.py`核对包内所有fx／fxc均登记为项目自有、哈希匹配，且没有第三方资源和旧生产适配器引用；打包时再次强制执行，并检查新源码包不夹带旧材质。
- 旧矿石材质与旧H4生产合成夹具随对应外观撤下；旧世界叠加预览也撤下，入口明确报错，不能继续生成被误读为当前生产效果的报告。
- 蒙版制作与结构预览仍保留；其色场改用制作工具内部生成的数学噪声，无外部图片。旧导出与旧配方的历史哈希保持原样，不能将其当作新版本验证。
- 未修改攻击、伤害、碰撞、飞行计时、网络、存档或槽位。只删除绘制入口及资源，天铸金色常量和自有纹理缓存清理由删除的绘制器移到现存辅助模块。
