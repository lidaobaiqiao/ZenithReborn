# 第一阶段计划：史莱姆王与「附着」

后续木质构筑方案见[木质族D2](木质族D2-环境特性与森林之力.md)；该文为新设计，尚未替换本文记录的0.2.4实装规则。

状态：核心功能已在0.2.0实现；图形客户端已验证寄宿预览与界面交互，授福、攻击及保存重进尚未完成（用户停止电脑操作）。0.2.4根据参考图改为弧面渐变拖尾，编译与35项功能及网格检查通过；有离线网格预览，游戏内观感待确认。具体实际规则以README为准。

阶段主题：被庇护者的回报。

阶段终点：玩家与友好的史莱姆王相遇，获得首个祝福「附着」，可以通过一把寄宿武器稳定御剑，并能从早期武器类别中选择不同打法。完成后指引止于准备面对克苏鲁之眼。

## 一、已经确定的设定

- 玩家开局得到「诅咒的天顶残魂」，极其脆弱，无法作为正常主武器。
- 史莱姆王是友好的，是第一位帮助残魂复苏的角色。
- 第一个祝福名为「附着」；获得后才真正开启寄宿与御剑。
- 第一阶段只有一个可用寄宿槽，不提前开放多剑轮换。
- 早期可获得的武器按类别提供特性，覆盖矿石剑、冰雪剑、附魔剑、泰拉魔刃、草剑、骨剑等。
- 不要求为所有武器逐个开发特殊攻击。类别规则可以复用，个别代表武器使用少量明确配置。
- 本模组的世界观中，月亮领主代表克苏鲁入侵势力；天顶剑曾对抗它，并庇护大陆上弱小的史莱姆。史莱姆王与残魂的幸存密切相关。

下文中的相遇触发、类别效果和数值是首阶段的建议实现规则，不视为用户已逐项指定。

## 二、从开局到第一祝福

### 1. 开局：包裹在凝胶中的残魂

新角色获得残魂。物品说明明确写出：

> 残魂几乎无法维持形体，尚不能稳定附着武器。
> 包裹它的古老凝胶，正对附近的史莱姆产生回应。

首阶段暂定：未受祝福时不产生有效攻击弹幕。左键仅有微弱闪光或颤动，说明它还活着；正常获得的普通武器照常使用。

寄宿界面可以打开，展示一个待修复的槽位，并允许选择、预览和取回武器。界面注明「等待祝福：附着」，不把预览误写成已经可用。

所有提示放在物品说明和寄宿界面中，不在每次攻击时反复刷聊天文字。

### 2. 寻找帮助：有明确条件的回应

建议采用可主动触发、没有稀有材料门槛的友好相遇：

1. 带着残魂，在白天地表接近一只普通史莱姆。
2. 残魂界面出现「回应呼唤」按钮，逐项显示条件是否满足。
3. 点击后开始友好史莱姆王相遇。原有普通史莱姆被引导离开，避免玩家读剧情时挨打。
4. 条件不满足时直接提示「需要白天／地表／附近的普通史莱姆」，不隐藏条件。

相遇中史莱姆王不会接触伤害玩家、生成攻击性子史莱姆或被误杀。第一次只实现这一条受控的剧情入口，不同时修改全部自然Boss召唤路径。

玩家不必为了获取这次帮助先击杀史莱姆王，也不需要收集史莱姆击杀数量。初次友好相遇不发放原版Boss战利品、不写入原版史莱姆王击杀旗标。

### 3. 认出故人：授予「附着」

演出控制在短对话和少量特效内，玩家可以快进：

- 史莱姆王靠近，残魂上的古老凝胶与王冠共鸣。
- 它认出残魂，但不在第一次相遇就讲完所有历史。
- 一小团凝胶包裹、支撑残魂的裂缝，残魂终于可以依附于一把实体武器。
- 玩家确认接受，获得祝福「附着」，第一个寄宿槽由破损变为可用。
- 史莱姆王友好离开。界面立即提示放入武器并尝试御剑。

祝福不要求战斗、不依赖最后一击、不消耗玩家预览的武器。中途退出或死亡可以再次触发；同一枚残魂已经受福时不重复领取奖励。

### 4. 第一次真正御剑

玩家将铜剑等武器放入第一槽，关闭界面后试挥：

- 武器沿鼠标方向飞出，形成短距离、尚不完整的天顶式回旋轨迹，再返回玩家身边。
- 伤害和攻速由寄宿武器决定；初始剑魂仍有明确效能折损。
- 不增加武器以外的免费基础伤害，矿石材料和武器前缀仍有价值。
- 武器类别带来可见特性，换武器后可以立即比较手感。

这时玩家的收获是「终于可以使用它」，同时仍能感受到距离真正天顶剑很远。

## 三、第一阶段的武器类别

首批以五种类别规则覆盖用户列出的武器。每把武器只激活一个主类别，界面直接显示类别、效果和数值。

| 类别 | 首批覆盖 | 玩法方向 | 首版建议效果 |
|---|---|---|---|
| 迅刃 | 各种矿石短剑、泰拉魔刃 | 短程、快速穿刺 | 使用间隔缩短15%，御剑距离缩短15%，轨迹更紧凑 |
| 实锋 | 各种矿石阔剑、骨剑；木剑等普通实体剑作为基础兼容 | 稳定、容易控制 | 剑影命中宽度提高15%，击退提高20% |
| 寒霜 | 冰雪剑 | 减益牵制 | 剑影命中施加2秒霜火；沿用目标原有免疫，不强制冻结Boss |
| 自然 | 草剑 | 持续伤害 | 剑影命中施加3秒中毒；本阶段不额外生成追踪叶片 |
| 灵能 | 附魔剑；星怒作为可复用规则的补充 | 远处补伤 | 每次飞行最多释放一次削弱后的剑气或落星，共享至少45帧触发间隔 |

说明：

- 矿石剑的档次差异主要由原武器伤害、速度、暴击和击退体现，不再给每种矿石另写一套技能。
- 泰拉魔刃使用迅刃规则，不把原生高频斩击完整叠加到御剑上。
- 附魔剑保留其天顶材料身份，并在本阶段表现为灵能类别；已经存在的专属剑气与类别效果合并，不触发两次。
- 灵能附加弹幕暂按剑影伤害的30%计算；附加射程设上限，避免一把稀有武器直接绕过早期御剑距离限制。
- 其他模组的近战武器可以采用基础寄宿规则，但本阶段只保证上述原版武器和类别的明确适配，不自动复制自定义弹幕逻辑。
- 类别采用数据表与少量共用处理器，后续新武器优先加入既有类别。

## 四、「附着」的首版数值边界

建议作为第一版起点，实战后只围绕明显问题做一次调整，不追求纸面完全平衡：

| 项目 | 祝福前 | 「附着」后 |
|---|---|---|
| 可用寄宿槽 | 0，允许预览 | 1 |
| 稳定御剑 | 无 | 有，单武器飞出并返回 |
| 武器伤害效能 | 不产生有效攻击 | 原武器经玩家加成后伤害的65% |
| 基础御剑距离 | 无 | 约12格／192像素 |
| 攻速 | 无有效攻击 | 继承寄宿武器使用节奏，再应用类别调整和玩家近战攻速 |
| 命中次数 | 无 | 每柄剑影每次飞行对同一目标最多命中一次 |
| 类别特性 | 只展示 | 生效 |
| 机械迟滞 | 未解锁多剑轮换 | 保持沉睡，不影响当前单剑使用 |

初版不引入刷怪经验条、长时充能、维持祝福的消耗或反复修复成本。获得的祝福永久属于这枚残魂。

65%伤害效能是建议值；附着提供短距离御剑和类别能力，武器本体的基础属性仍决定其所处阶段。武器规模过大、特殊攻速过快时使用合理边界，避免残魂让所有剑拥有同一种速度。

## 五、史莱姆王与天顶残魂的剧情

### 因果链

1. 天顶剑曾是大陆对抗克苏鲁入侵的力量，也庇护没有自保能力的史莱姆。
2. 天顶剑遭镇压后，史莱姆无法打败镇压者，却能做它们擅长的事：聚合、包裹、保存。
3. 史莱姆王与众史莱姆将最后一缕剑魂保存在凝胶中，使它没有彻底消散。
4. 这份保护延续至今。玩家开局得到残魂时，它仍包裹着那层古老凝胶。
5. 「附着」是这份保护的延续：史莱姆王帮助残魂重新抓住实体武器，迈出复苏第一步。

这一版本的核心是史莱姆作为弱小生灵的善意与记忆；史莱姆王不必被改写成隐藏的至强者。

### 首次相遇的短对白草案

> “我们还记得你。”
>
> “你曾替我们挡住那些……很可怕的东西。”
>
> “我们留不住你的剑身，只能护住这一点光。”
>
> “这一次，让我们帮你站稳。”

对白可以表现为残魂接收到的记忆与意念，不必让史莱姆王用人类口型说话。完整镇压经过、王冠的来历和残魂如何来到玩家身边，留待后续阶段展开。

## 六、实现顺序与范围

### 第一批：把阶段入口做通

1. 新增持久化祝福标记，状态区分「残魂未稳」与「已经附着」。
2. 修改新残魂的攻击门槛、说明、槽位预览和明确指引。
3. 实现一个受控的友好史莱姆王相遇，以及可恢复、不可重复刷奖励的授福流程。
4. 祝福后单槽御剑正常工作。

### 第二批：让换武器确实有区别

5. 添加五类规则的数据表与统一说明。
6. 覆盖矿石长短剑、冰雪剑、附魔剑、泰拉魔刃、草剑、骨剑；星怒复用灵能发射规则。
7. 合并已有附魔剑、星怒的专属效果，避免与新类别重复触发。

### 第三批：完成可交付阶段

8. 优先提供简单可靠的对话、祝福提示和少量原版特效，不先开发长动画或大量新美术。
9. 保留原有武器、前缀、魂芯和Boss铭刻存档字段，新增字段不覆写旧数据。旧版已可用的剑魂不在更新时被直接清空或降级；旧物品提供补看友好相遇的入口，新的残魂按本阶段流程开始。
10. 既有后期功能暂留兼容；本轮新增开发、平衡与验收仅到史莱姆王授福完成，不继续同时铺设后续Boss内容。

## 七、阶段完成标准

- 新角色拿到残魂时，能看懂它暂时无法稳定使用，以及该去哪里获得帮助。
- 触发条件可直接查看，玩家不需要外部攻略或猜测谜语。
- 玩家能够在不杀死史莱姆王的情况下完成友好相遇；相遇中不会被王或其随从伤害。
- 中途退出、死亡和重新进入不会卡住剧情，已经获得的祝福保存后仍在。
- 授福后只有一个实际可用槽位，铜剑可以正常放入、飞出、命中、返回与取回。
- 矿石长短剑、冰雪剑、附魔剑、泰拉魔刃、草剑和骨剑有与界面说明一致的类别表现。
- 保存重进不丢失寄宿武器及前缀；沿用已经修复的UI坐标处理，覆盖本机约163%界面缩放。
- 第一阶段结束时提示准备迎战克苏鲁之眼；不把魂芯收集、多剑轮换或后期诅咒混入当前教程。

验证只做一次针对本阶段的集中检查，并实际走通「新角色→友好相遇→附着→放入武器→战斗→保存重进」；有明确故障才补充相应检查，不重复扩大测试范围。
