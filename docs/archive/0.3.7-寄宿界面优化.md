# 0.3.7 寄宿界面优化

按 P 或手持残魂右键打开。界面分为三页：

| 页面 | 内容 |
|---|---|
| 武器寄宿 | 10个普通剑位采用两行五列，5个支援槽和2个森林槽分区；显示武器详情、当前状态、特性和解锁条件。 |
| 羁绊特性 | 木质族进度条、12种木剑的已激活/未寄宿清单、当前环境倍率与生命奖励、森林之力状态、当前有效的肉后三矿特性。 |
| 成长与记忆 | 下一步目标、友善史莱姆王对话、10个普通槽条件、6魂芯状态及补办入口、机械诅咒/祝福说明。 |

窗口上限760×650 UI单位，随可用视口缩小；宽窗口使用左右分栏，窄窗口把详情移到槽位下方。长文本按实际字体宽度换行，长页面使用滚轮浏览。页签与底部提示固定，内容裁剪在滚动区域内。鼠标在面板内时拦截背后的物品提示与滚轮切换热栏。

左键与鼠标物品交换。悬停保留原生物品提示；金色边框表示当前查看的槽位，金色星号表示天顶材料剑。支援槽明确标注不出剑，森林槽明确标注完整属性。取下全套后暂停的槽位仍保留物品，可空手左键取回。错误在底部显示，不再刷聊天栏。

本次不改变伤害、成长条件、木质羁绊、矿石触发和17个槽位的存档索引。史莱姆王对话与魂芯补办继续调用已有的联机请求。

验证：编译与隔离引擎检查通过；覆盖720p/1080p/1440p下1、1.25、1.6296296、2倍UI缩放的布局、真实交换处理、词缀保留、拒绝非法物品、全部17个槽位取回和页签/关闭按钮输入。图形客户端另行检查三页显示、清单滚动、固定页签与裁剪。联机真人交互尚未实测。

图形实测记录：1280×720独立测试窗口，配置UI缩放1与1.6296296。最终包确认三页渲染、长清单滚动与裁剪；实际点击取出木剑可使森林槽暂停，放回恢复。记录位于 `artifacts/ui-validation-0.3.7.json`，包含被测安装包哈希。史莱姆王剧情与魂芯补办的处理路径通过已有引擎检查，本轮未进行图形点击流程复测。
