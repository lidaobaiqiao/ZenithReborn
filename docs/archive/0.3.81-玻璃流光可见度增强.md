# 0.3.81：玻璃流光可见度增强

用户认可R3效果，指出太淡。本轮沿用现有全部素材、法线和折射，限定修改自有ZRSwordFlow材质的光能；不增叠层，也不改攻击或透明度。

## 改动

- 环境相对曝光6→10，高光受光系数2.2→3.0，仍随法线/光向变化。
- 逐剑内部底色0.012→0.050，动态流丝0.018→0.070，自发光图调制0.025→0.085；保留各把剑自己的配色。
- Alpha公式、蒙版、结束侵蚀、法线、IOR1.5／粗糙度0.08／透射0.55／厚度72均保持。最终色调压缩保持，避免直接截白。
- 通用表面材质与屏幕合成代码不改；无新贴图/第三方素材/玩家依赖。

## 验证

原生编译0错误，8393项引擎通过。固定几何/光照/时间的GPU对照，三张Alpha>64的材质测试图平均可见亮度从48.06／50.88／48.05提高到64.15／66.72／64.15（31%–33%），Alpha逐像素完全相同。这是受控测试的显示亮度，不是所有游戏场景统一加亮百分比。

实际GPU仍通过光向、环境与粗糙度响应、绘制状态恢复及结束清零。默认与剑影伤害两组隔离世界的真实AI／命中／返回通过，三个剑影分别实际扣血；同帧完整原版滤镜链IOR对照通过，带面外变化为0。初始化/并行日志有共享日志锁及暂态按键字典警告；没有宣称这些问题已修复或完整UI通过，客户端正常退出。

以0.3.80源码归档逐文件比较，仅build.txt、ZRSwordFlow.fx／fxc及构建清单变化，另121项生产文件及全部贴图保持。0.3.80实验室45组结果仍是历史证据，本轮未重跑或冒充0.3.81结果。

这是隔离世界夹具，不是本轮实际鼠标操作、自然游玩、完整模组组合或多人验证；强度待用户判断。正式安装前备份0.3.80，只替换ZenithReborn，配置/其他模组与正式存档保持。安装状态与包哈希见artifacts/install-result.json。
