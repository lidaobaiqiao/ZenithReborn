# 0.3.49 · 飞剑后拉与真实加速穿刺

日期：2026-10-23。用户指出“动效不等于特效”，明确要求解决飞剑本体缓慢、没有速度递进的问题。本轮因此改变实际弹幕运动，不把新增光效或加快播片当作动作改进。

## 实际运动

- 原有齐射准备末6帧，在实际环阵半径上连续后拉22像素；等待材质收集期间不提前后拉，仍等同一释放时刻。
- 每趟从原标称速度的0.28倍起步，以SmoothStep在7帧内升至2.5倍后保持。原基础速度11.55、十层／环境速度因子继续参与计算；基础伤害与命中冷却保持。
- 折返会重置每趟年龄并重新加速，继续穿透和第二趟伤害。距离仍为560／圆满840像素，按加速曲线计算寿命及移动目标预判时间，避免沿用匀速公式导致提前消失。
- 追加同步`passAge`，保证客户端接收后处于同一速度阶段；人物／剑魂存档格式不变。加速缩短了目标内的停留时间，因此不把本版称为只改外观，也不承诺每趟帧伤次数与匀速版相同。

## 动作节点反馈

- 每把剑实际进入一趟飞行时，独立产生沿剑轴的破空椭圆气环、三条短促速度线与刃尖白闪。主剑图像有短促重影，不靠挪动飞行中的贴图伪造真实位移。
- 每剑每趟首次命中各个目标主体，触发定向刺入线、扩散冲击环及前向碎光；后续6帧冷却帧伤不重复刷整套大爆点，第二趟允许再次反馈。
- 前景反馈在原版DrawDust之后绘制，覆盖敌人及剑体，避免刺入爆点埋在NPC下面。使用现有OniCrimsonSlash材质、原版Dust与已接入的碎光，无新Shader或资源。
- 局部反馈最多96条，8／12帧自行过期，即使原飞剑已消失也能完成短尾韵；世界卸载清空。挥空／命中音效按短窗口合并，避免十四剑同帧叠音。声效调用已接入，未单独录音验证。

## 验证

- 两工程编译0警告0错误，8270项引擎检查通过。
- 使用真正的`Projectile.Update`记录首8次飞行速度，约为4.65、8.32、13.33、18.78、23.79、27.45、28.875、28.875像素／帧。样本在首次发射后的下一更新开始；不是仅对曲线函数做断言。
- 相同560像素去程的引擎记录为24帧，旧匀速约49帧；8像素宽目标在去程、返程均受到实际引擎命中。记录见`artifacts/ore-motion-0.3.49.json`，不冒充图形实战／多人证据。
- GPU隔离预览通过十四配色、相机平移、设备状态恢复和结束清理；还调用十四个实际`OreFlyingSword.OnHitNPC`，确认每剑各产生一个刺入反馈，重复命中不刷同一套反馈。
- 预览按同一个`OreFlightMotion`逐帧计算真实后拉／加速位置与历史；示意目标和接触时间为受控场景，不是实际战斗录像。GIF使用约60帧节奏编码；可选MP4用现成FFmpeg按60fps编码原始GPU帧，不做插帧。编码器只是被忽略的开发预览工具，不是玩家依赖。
- 最终测试包哈希在`artifacts/slash-gpu-0.3.49/ore-gpu.json`与`slash-gpu.json`；正式目标包及备份以`artifacts/install-result.json`为准。
