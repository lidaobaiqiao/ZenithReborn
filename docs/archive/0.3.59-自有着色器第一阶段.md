# 0.3.59 自有着色器第一阶段

用户明确要求自己的着色器，并逐步替换美术与材质。此次优先级覆盖历史的“优先复用现成材质”；引擎、标准编译工具继续复用，不重写底层绘制框架。第一阶段迁移普通主飞剑拖尾，未一次替换所有武器。

## 已完成

`Assets/Effects/ZRSwordFlow.fx`由项目独立编写。没有复制、包含或改名OniCrimsonSlash源码／编译结果；采用普通带面坐标与常规数学方法，自行实现慢色场、连续流线、动态暗侧边界、旧尾细缕及返回侵蚀。这里的自有指材质实现由项目编写，不将格点噪声等通用数学方法和FNA引擎算成本项目发明。

默认只使用程序色场和数学噪声，两个可选贴图槽绑定项目自行生成的1×1白纹理占位，不读取外部笔刷、噪声或动态蒙版。主飞剑实际调用链为：`SoulBlade`→`SoulMaterialTrail`→`SwordFlowMaterial`→`ZRSwordFlow`。没有失败后退回第三方材质的隐式路径。

带面改为直接传入路程、宽度和各姿态的寿命Alpha，取消主飞剑对旧极坐标包络的反算。保留0.3.58真实剑迹、逐剑配色、形成与返回阶段，不改变飞行曲线、攻击、伤害、碰撞、存档和槽位。

新增`SwordFlowMaterial`和`Assets/Vfx/Materials/SwordFlow/bindings.json`：以后可按稳定剑名分别绑定慢底色与动态Alpha蒙版图集，不用重写轨迹。当前配置为空，没有真实美术输入；素材配准、尺寸与循环质量要等资源到位后逐剑验收。接口说明与迁移清单见[VfxLibrary](../VfxLibrary/Shaders/SwordFlow/美术接入与替换计划.md)。

自有着色器计1套（源码与编译结果是同一套），不是两个材质。原版剑体、飞行曲线及部分原版粒子仍是游戏资源；武技巨剑与矿石其他路径仍存在原始第三方材质／噪声调用，许可证和来源记录继续保留。不能称全模组已完全原创或所有第三方依赖都已移除。

## 可重复编译与打包

`checks/compile_effects.py`通过开发机已有的微软`D3DCompile`生成FNA可读取的Effect，编译器不随模组分发、不新增玩家依赖。`checks/run_wood_checks.ps1`自动执行编译，`build-manifest.json`记录源码与编译结果SHA256，打包脚本核对包内文件与本地内容一致。原第三方资源仍按旧provenance校验，未修改原文件。
