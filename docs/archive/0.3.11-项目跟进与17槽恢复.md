# 0.3.11 项目跟进与17槽恢复

日期：2026-10-20。用户本轮确认：25槽未确认，先维持17槽。

## 跟进结论

本地0.3.10已增加14材质矿石飞剑、25槽和第4页；GitHub仍为0.3.2，交接文档仍写0.3.8。旧版1784项回归及43项矿石专项可通过，但后者主要验证计数/生成，不覆盖真实飞剑命中和绘制。发现hide=true且没有DrawBehind入队，导致飞剑不进入常规绘制；另外缺少伤害时机、目标/来源验证。

## 本次处理

- **保持17个有效寄宿槽**：10普通＋5木质支援＋2森林；恢复原解锁条件。矿石不再额外开放支援或普通槽。
- 为保护0.3.9/10可能保存的装备，底层保留原扩展字段，全部停用、不计伤害/羁绊。仅有遗留物品时显示「旧物取回」，只允许空手取出，不能放入。取完隐藏该页。不是新增可使用槽位。
- 保留现有矿石飞剑的按材质去重、来源伤害、20帧成形与齐射；不重做独有机制或擅自调整平衡。
- 正常绘制飞剑，外观使用实际寄宿的短剑/阔剑，不固定替换为同材质阔剑；保留有效基础贴图。
- 成形20帧内不造成伤害，第21帧刺出；只攻击绑定目标主体，目标死亡、变友好/无敌、NPC位置被新敌人复用时结束。
- 只有本地拥有者的有效矿石主剑、实际正伤害命中可触发；零伤、假人、附属攻击、已取下来源和远端重复触发被拒绝。飞剑来源失效或材料被取下时结束。
- 按敌人生成身份记录目标冷却，并清理过期记录，避免NPC槽重用承接旧状态。

## 暂不开放的设计

14材质全套、额外8槽和依赖它的毕业奖励没有作为当前可达构筑发布。旧实现的三次命中分支仍被保留以便后续讨论，但在当前17槽与原木质支援规则下，14矿全套不是合法可达配装，游戏提示不承诺该奖励。是否修改计数、共用支援或全套条件，需要用户后续明确决定。

基础八矿16剑的独有新特性仍是M1候选；矿石飞剑羁绊已存在，不等于全部候选均已实装。

## 验证与边界

编译和隔离引擎检查通过1826项断言，包含旧机制回归、真实Projectile.Damage触发和子弹幕伤害、20帧成形、目标过滤、NPC生成身份、来源/材料失效，以及旧扩展物品保存、克隆、重铸、网络与取回。数量包含逐帧断言，不等于同等数量的战斗场景。图形验证记录另见本版本验证记录；真实多人和全流程平衡尚未实测。
