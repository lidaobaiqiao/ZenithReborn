# 0.3.38 · 五祝福与手动御剑

本轮落实用户已确认的五种新增祝福。御剑必须由玩家手动开启；充满资源不会自动消耗。以下未由用户指定的数值为本轮集中设定的首版参数，后续可调。

## 当前玩法

| 祝福 | 首版效果 |
|---|---|
| 御剑 | 主剑有效命中后保持45帧战斗窗口，在有效窗口累计900帧（约15秒）蓄满；按独立按键O手动释放，持续600帧（10秒）。镜头在30帧内平滑拉至原来一半缩放，可见横纵距离各翻倍，操控距离同步翻倍；按命中时玩家到目标距离线性增伤，在扩大后的射程上限达到50%，更远不再增加 |
| 百刃接力 | 不同寄宿主剑首次命中同一目标接力，后续首击特性每层+10%，最多5层（+50%）；180帧断连清空。同剑后续帧伤不获得接力倍率、不叠层。按剑魂ID、真实物理槽位及武器类型识别主剑，普通/奖励/传奇来源共用 |
| 归鞘留锋 | 主剑自然完成原版往返（阶段60）后为自身存一次强化；下次出剑首击生成50%自身主剑伤害斩痕，短线穿透沿途敌人，每根目标只命中一次。提前退休不储能 |
| 破障 | 主剑实际穿越实体地形后，下次命中附加240帧破障，提供15点护甲穿透；每把已发射主剑最多一次，不因反复穿墙叠加。平台和背景墙不提供破障 |
| 剑痕 | 每把已发射主剑分别累计每个敌人根对象的命中，120帧内连续3次触发60%自身伤害爆发；每趟每根目标最多一次。不同主剑不共用计数 |

独行仍按原来个人铭刻增长4/6/7/8/10剑，不增加其他出剑节点。

## 资源与操作

- 注册默认键O，可在游戏「设置→控件→模组控件」重新绑定；已有自定义控件方案可能显示未绑定，此时HUD明确提示，需在控件页指定。不会擅自覆盖用户控件配置。不占普通攻击键，不自动发动。
- 御剑条在屏幕底部显示蓄能百分比、就绪按键或剩余秒数。就绪时有一次提示，满条等待期间不衰减。
- 未消耗的充能保存在这枚剑魂中，脱战、切武器、死亡、保存重进、克隆、重铸及HERO重建不丢失。旧档缺少字段时从0开始，不伪造充能。
- 已开启的爆发按持续时间结束；切武器不会清掉另一枚剑魂的未消耗充能，但已花掉的爆发时间照常走。打开魂域暂停已开启的计时并收回镜头；关闭后继续。死亡和重进不保留已花掉的爆发时间。
- 御剑距离倍率通过SoulSource命中阶段统一结算，作用于这枚剑魂的主剑及有同源标记的衍生伤害，每次命中只结算一次；生成衍生弹幕时不把距离倍率再次烘入基础伤害。
- 归鞘储能及接力是本次游玩的临时战斗状态，死亡/重进清空；不更改寄宿物品或槽位。

## 特性接力范围与边界

百刃接力已接入木质命中效果强度、普通寒霜/自然命中减益持续时间，以及肉后矿石命中效果的伤害、印记和治疗。治疗继续受原本吸血额度和窗口上限约束；原有命中门槛、应用冷却不被绕过。飞行到固定阶段释放的天顶材料弹幕不是首次命中特性，本轮不强行提前或补发它们；结构解锁、羁绊阈值、槽位数量也不吃接力倍率。

全部额外机制仅在相应诅咒达到Blessed时生效；Released仍恢复完整正常能力。旧档LegacyReleased只提供解除兼容，不授予祝福。0.3.37切换未解除的四把主攻飞剑例外保留。

斩痕和剑痕属于独立短时伤害弹幕，不再触发主剑的命中机制、御剑充能、接力、储能或飞剑积攒。各剑基础伤害独立，不平均，不设统一下限。原生主剑轨迹、30/10时序、粒子和支援/奖励/传奇槽均保留。

## 调用与兼容

新SoulBlessings.cs集中参数、玩家战斗状态、逐弹幕状态、短斩弹幕、破障和御剑HUD/镜头。SoulBlade在命中前准备接力、命中后提交及执行效果，实际完成回旋时储能；地形沿途采样使用现有SoulTerrain。

SoulItem存档版本7追加yujianCharge；NetSend/Receive尾部追加16位充能值，新增来源HostSlot用于真实宿主身份。所有参与联机的客户端和服务端需使用相同模组版本。动作10同步御剑爆发状态，服务端以发送者身份处理；木质命中同步携带有界接力倍率。真实多人尚未实测。
