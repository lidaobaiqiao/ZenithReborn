# 开源材质制作方案

用户提供Blender的Principled BSDF面板，希望复用通用开源渲染与材质能力，减少逐个特效手调代码。用户进一步明确：制作参数不能做进玩家界面。

## 可复用方向

1. [OpenPBR](https://github.com/AcademySoftwareFoundation/OpenPBR)：ASWF维护的开放表面材质标准，提供MaterialX参考实现，仓库采用Apache-2.0。适合统一材质语义和制作预设，不是一套可直接替换泰拉瑞亚渲染的插件。
2. [MaterialX](https://github.com/AcademySoftwareFoundation/MaterialX/blob/main/documents/DeveloperGuide/ShaderGeneration.md)：将材质图转换成着色语言源码，输出还需编译和适配目标渲染器。其生成系统没有自己的运行时。可以用于独立制作预览和导出，不能承诺任意Blender节点都能直接生成FNA可用Effect。
3. [Filament材质系统](https://google.github.io/filament/Materials.md.html)：现成的实时PBR渲染器，支持基础色、金属度、粗糙度、IOR、透射、吸收、厚度等。其[源码许可](https://github.com/google/filament/blob/main/LICENSE)为Apache-2.0。适合评估独立制作预览器，或在明确兼容后选取通用实现；整套运行时接入现有FNA设备尚未验证。

上述为调研结论，没有将第三方材质实现复制或集成到当前模组。后续实际采用代码时，应随采用部分记录版本、修改和许可证，不能改名算成项目自有。

## 推荐的制作流程

将材质参数面板放在制作工具中，预设按材质种类与实际剑名登记；色场、动态蒙版、法线及粒子继续按既有库分类。独立预览先用成熟渲染器，导出后在当前游戏着色器路径复核。离线PBR预览与游戏2D效果不能宣称完全一致。

| 用户看到的参数 | 当前或近期映射 | 边界 |
|---|---|---|
| 基础色 | 每把剑自己的色场／Tint | 保留逐剑身份，不统一染色 |
| 粗糙度 | 反光宽度、折射模糊 | 当前为2D近似，未接入完整微表面光照 |
| IOR | 折射方向和菲涅耳 | 1.5已进入实际计算 |
| Alpha | 整体覆盖倍率、蒙版和生命周期 | 与透射分开维护 |
| 透射 | 背景折射的贡献 | 使用原版屏幕合成输入 |
| 法向 | 当前由真实剑迹生成，未来可接法线素材 | 尚无独立美术法线输入 |
| 金属度、涂层、边缘光泽、自发光、薄膜 | 留给成熟材质模型及后续制作工具 | 不添加没有实际渲染作用的空控件 |
| 体积、次表面 | 独立评估 | 当前2D流程没有完整体积和深度信息 |

游戏只接收制作结果。0.3.62没有玩家材质编辑器、滑块或额外设置负担。
