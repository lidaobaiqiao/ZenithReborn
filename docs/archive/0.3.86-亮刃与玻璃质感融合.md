# 0.3.86 · 亮刃与玻璃质感融合

用户在实际两版独立客户端对比后明确要求「做出融合两种优点的第三版」：0.3.79光效不错，0.3.80质感很好但太暗淡。本轮以原始0.3.80为材质基底，在同一带面中补回参考0.3.79的薄亮刃缘、内侧细边与窄扫光。

## 实现

从核验过的0.3.80源码归档恢复三组着色器、主飞剑材质/屏幕折射接入和GlassR3四张同源纹理。随后仅修改ZRSwordFlow的局部光能输出：

- 主刃芯宽度沿用0.004～0.018的窄区间，系数0.85；薄晕光系数0.08，范围收在0.016～0.055。
- 内侧细边系数0.20，窄晕0.035，不扩张动态边界。
- 扫光位置参考79的慢移动曲线，主扫光系数0.16、细扫光0.035，并保留受光方向和前后强弱变化。
- 刃芯颜色由当前剑色向白色混合0.72，窄扫光保留更多剑色；不添加整面统一发光底色。沿用79/80原有逐剑配色输入，不恢复82的取色及整面强发光总成。
- 局部补光在80原始反射压缩之后加入，同一绘制/动态蒙版/消散窗口中完成。法线、粗糙度、环境反射、背景透射、IOR、厚度、覆盖度和结束几何保持80。

以上数值是本轮实现选择，不是用户指定参数，也不代表用户已经验收观感。二维薄面与屏幕空间近似保持，不称完整三维物理渲染。

相比原始0.3.80，125项生产文件中121项字节相同；仅版本号、ZRSwordFlow源码/编译结果及构建清单四项不同。71项非材质接入C#源码与0.3.79逐字节相同，攻击、真实轨迹、剑影伤害、短尾、矿石H4、武技、槽位和存档不改，无新玩家依赖。

## 验证结果

- 原生编译零错误、零警告；8393项引擎检查通过。
- 材质GPU总检查通过：动画/配色、形成/侵蚀/结束清理、绘制状态恢复、折射及光向/环境/粗糙度响应。
- 与原始80的编译Shader在同一客户端、同一组贴图/时钟/几何下逐像素对照：三组颜色的法线遮罩、光学属性缓冲、背景透射缓冲和Alpha差异全部为0。
- 三组固定样本中，各有约2.68万～2.81万像素增亮；约89.6%的内部检测区域颜色仍与80相同。此统计仅描述该固定面板，不能推广为所有战斗画面的增亮比例。
- 光向、环境方向、粗糙度分别产生28097、137142、127381个响应像素，Alpha最大差0；保留方向材质响应。
- 三剑独立世界的实际AI/命中/返回、父弹幕结束后余迹清零通过；额外剑影夹具确认三个可见剑影实际扣血，且本体当时不能伤害。
- 同帧完整原版滤镜链IOR对照：26020个响应像素，带面外差异0；树干固定局部有706个响应像素。保留原像素对照，不把反射颜色差异当作几何位移测量。
- 82项包内源码/着色器/JSON与工作区一致。生产包SHA-256：`186beabb6a913aec03a619c47569e7b12e1a96d67156980d43409195ef45ef6d`。

GPU夹具内临时切换的是生产私有Effect引用，并在退出前恢复；原始80编译Shader仅作为检查模组内的测试资源，不进入生产包。光学对照同时确认新增光效没有改变背景透射和覆盖度。

这是受控图形客户端和隔离世界证据，不是自然鼠标游玩、完整启用组合或真实多人验证；美术观感待用户确认。
