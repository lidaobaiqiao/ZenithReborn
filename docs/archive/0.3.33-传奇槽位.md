# 0.3.33 传奇专属剑位

日期：2026-10-21。基线：ZenithReborn 0.3.32。范围：只增加传奇槽位与对应保存/UI，不改战斗数值、支援/奖励规则或普通10槽。

> 0.3.35 修复：`SupportOrdinal(34)` 曾把传奇槽误判为支援槽，中心说明显示“支援特性·不参与出剑”。现传奇槽返回 `-1`，说明/状态改为普通主攻剑位；位置、存读档、暂停取回不变。

## 规则

- 传奇剑位只在实际传奇难度（`Main.GameMode==2 && Main.getGoodWorld`，即大师＋For the worthy）且残魂已附着时生效。
- 可放一把普通主攻武器，计入 `Active`、逐剑伤害、特性来源；不占普通10槽、不增加支援容量。
- 关闭传奇后不删除物品：槽位变为暂停状态，保留在原位置，空手可取出；暂停期间不参与伤害与特性。
- 重复武器仍按全剑魂唯一规则拒绝；普通/支援/奖励槽规则不变。

## 现有 UI 的位置

- 位置：现有剑环右上外侧 `OrbitPoint(-45, RingRadius+86)`；不新增面板、不移动主环、不改页签。
- 尺寸 58，与现有节点同一绘制语言；只增加金色光晕、两段旋转弧、四颗星屑和 `L` 标记。
- 关闭传奇但槽内有物品时仍显示暂停节点，便于取回；关闭且为空时不显示锁槽。

## 实现

- `SoulItem.LegendaryHost`：独立物品字段；`LegendaryOn` 读取真实难度。
- `LegendarySlotId = 34`：避开 0–16 有效槽、17–24 旧物取回、25–30 动态支援。
- `SoulItem.Active` 包含生效的传奇主攻；`Stored/Clone/SaveData/LoadData/NetSend/NetReceive/PreReforge/PostReforge/HeroPrefixCompat` 均已覆盖。
- `SoulUI.SlotBounds` / `SoulProgress.SlotHint` / `SoulUIEffects.DrawLegendarySlot`：位置、提示与金色特效。
- `SoulDifficulty.Legendary` 是唯一开关，不维护第二套难度标记。

## 验证

- 传奇专项 8 项通过：仅传奇可见、可放入主攻、进入 `Active`、存读档、网络、关闭后暂停可见、暂停拒绝放入、空手取回。
- 既有 7964 项回归在加入前通过；本次改动只新增槽位/字段，仍需在本版重新跑全量后再安装。
- 未验证：图形客户端中的右上角位置/特效观感、真实多人。

## 边界

- 旧档无 `legendaryHost` 时默认空槽。
- 关闭传奇不会把物品自动塞回背包，避免背包满时吞物；通过暂停节点或旧物取回逻辑取回。
- 不改变 `SoulSupport` 的共享支援、奖励槽、矿石/木质羁绊和任何伤害公式。
