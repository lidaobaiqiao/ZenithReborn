# 0.3.76 · 武技三档动作与旋转返航

本轮落实用户指定的动作顺序，继续使用武技原型入口：普通主剑首次有效命中积攒剑势，V选档、G开启／取消；三档巨剑蓄力完后，由下一次攻击发动时停突进。1／2／4种族羁绊与纯支援解锁不在本次范围，不能把攻击原型称为整族完成。

## 实际动作

| 阶段 | 本版行为 |
|---|---|
| 一档 | 飞剑从角色身后弹出，短暂膨胀；高速自旋三圈后单独定向敌人，再加速刺出。保留真实嵌剑和持续减益。 |
| 二档 | 背剑释放完后，一道分叉雷光自上落向角色。落雷当帧天顶巨剑完整浮现，流线沿剑身聚拢，巨剑缓慢后压蓄力，随后快斩打飞刺入剑。 |
| 三档 | 先经历同样雷临与巨剑蓄力。攻击启动局部时停，角色化作流光携巨剑实际突进；剑留在敌人体内造成多段伤害，缓慢压刀顿挫后猛斩，追加剑气与剑痕。 |
| 击飞与返航 | 嵌剑被打飞后旋转三圈，随后转向角色加速返航。击飞和返航沿途均可伤害，抵达角色附近才收回。 |

动作与GPU预览共用 `MartialMotion`；不是单独制作一段与游戏行为不同的动画。`MartialActionVisuals`只绘制动作伴随的雷光、聚拢流线与角色流光，不改玻璃拖尾或矿石H4素材，不新增玩家依赖。

## 首版动作参数与战斗影响

- 背剑基础准备28帧，逐把错开2帧：开头7帧弹出，中段自旋，末8帧定向。突刺在6帧内由8升至46像素／帧。
- 雷临10帧；落雷立即显剑；随后60帧缓慢蓄力。巨剑斩击前先压刀，主体约10帧快斩，末段收势。
- 三档实际突进12帧，顿挫120帧。只在突进期间隐藏人物绘制层，使用真实玩家移动轨迹表现流光；结束或取消时即恢复人物。
- 击飞旋转27帧，再以14至44像素／帧返航。保留原击飞1.5倍伤害与根NPC冷却，返航作为新一趟清空命中记录；衍生攻击不重复蓄势或递归产生普通主剑特性。
- 高速移动增加上一位置至当前位置的扫掠碰撞，避免只检查落点而跨过窄目标。

上述精确帧数和速度为本轮可运行首版参数，不是用户逐个指定的最终平衡值。本轮确实改变武技弹幕速度、巨剑时序、有效斩击窗口，并新增有伤害返航；不能称为纯视觉修改。逐剑独立伤害来源、消耗、存档和槽位仍沿用原逻辑。

整合时保留共享工程已有的普通拖尾60帧历史修改。两处旧检查的固定坐标框改成依据输入轨迹计算边界，未将生产轨迹改回旧长度。
