# 0.3.16 · 精简描述与速度微调

## 悬浮描述

原来把每个激活特性的全文、公式、全部寄宿武器名、下一步和技术说明一起加进悬浮描述。满配时宽高超出屏幕，原版提示框移动后内容仍不可见。

剑魂现在只添加三行短提示：打开窗口操作、主攻/支援数量、详情入口；未附着时仅增加一句与友善史莱姆王对话的提示。中文背景句同步缩短。无逐特性全文、公式、长武器清单或多行技术说明，也不做按住Shift再次展开长文的旁路。每条自有提示最多28字符，全部木剑或超长自定义武器名也不增加描述长度。

已激活效果继续在「生效特性」页查看，所有已实装效果及条件继续留在「特性图鉴」，成长与下一步在成长页。御剑基本规则放在武器寄宿页下方的可滚动段落，既可换行也不会撑大原版悬浮提示。

## 速度

以0.3.15为基准，将出剑周期和主剑绕行时间除以1.3并按整数帧四舍五入，不采用“周期减30%”（会变成速度+42.9%）。基础挥臂周期约31～104帧，额外攻速后的最快一轮31帧，五节点最短间隔6帧；主剑绕行28～69帧。矿石冲刺12×1.3＝15.6像素/帧，成形等待仍是原20帧。放大后的模型、单次伤害、帧伤命中间隔与首击飞剑规则均保留。
