# 0.3.42 · 剑的所属环境标记

日期：2026-10-22。用户反馈剑上没有环境归属说明，本版补齐显示入口，不改变环境归属、收集、成长、战斗和存档规则。

- 所有可寄宿武器的普通物品悬停说明，在名称下面增加“所属环境：…”；一剑多环境完整列出。
- 使用武器实际GetEnvironmentAttributes数据，而非玩家站立环境、剑魂累计记录或临时领域，避免标错来源。
- 未登记标签的武器明确显示“所属环境：未归类”，不擅自虚构归属；工具、非近战武器、天顶剑及剑魂自身不添加此行。
- 新标记只显示名称，不复制数值、独立机制或成长公式；多环境行超过28字符时换行。
- 魂域左侧随身剑库悬停提示、选中剑位详情同步显示同一份实际归属。

实现入口EnvironmentTooltips.cs，复用既有EnvironmentAttributes数据。两项目编译0警告0错误，8206项现有引擎检查通过；本轮未做新增图形客户端或真实多人测试，不沿用0.3.41的GPU结果冒充本轮界面验证。

正式安装、备份和SHA256见artifacts/install-result.json。
