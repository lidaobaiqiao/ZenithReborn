# 武器分类表：常规与非常规

更新日期：2026-10-18。对应工程基线：ZenithReborn 0.2.4，tModLoader 1.4.4。

关联方案：[D1候选表](剑族与单剑特性设计.md)与[木质族D2](木质族D2-环境特性与森林之力.md)。木质族12项以D2的环境特性、羁绊和森林之力为准，最新W2.1强化阴森木剑、提高森林成长，满套额外提供2个真实普通剑位；其余条目保留D1候选。木质族已在0.3.0实现，实际边界见[实装说明](0.3.0-木质族实装说明.md)；其余条目为设计稿。

用途：保留用户原清单100个条目，追加3种新设计木剑，形成103项开发清单。优先考虑常规武器，并从第一阶段能够获得的武器开始推进。本表是规划分类，尚未据此修改游戏中的寄宿准入或武器效果。

名称沿用用户原清单；“陨石光剑”和“晶光刃”的不同颜色暂各合并为一个条目。“肉前”表示困难模式之前，不代表全部都能在第一阶段获得。

## 分类标准

| 分类 | 本项目采用的标准 | 开发顺序 |
|---|---|---|
| 常规武器 | 具有剑、刀的基本形态，以挥砍或突刺为主；附带剑气、落星等效果仍归入常规 | 优先考虑 |
| 非常规武器 | 工具、拳爪、棍锤、镰刀，以及持续剑气、投掷、伸缩、环绕等特殊攻击形态 | 后续单独考虑 |

该分类服务于本模组的开发与表现设计；对边界武器的归组是当前规划判断，不等同于引擎物品类型或Wiki分类。

## 边界项与版本说明

- 星怒、附魔剑、泰拉刃等保留在常规组；附带射弹能力不改变这里的归组。
- 星光暂归非常规组，其攻击依靠快速刺出的短距离光束。参见[官方Wiki：星光](https://terraria.wiki.gg/zh/wiki/星光)。
- 圣骑士锤归投掷及回旋组，其实际类别为回旋镖。参见[官方Wiki：圣骑士锤](https://terraria.wiki.gg/zh/wiki/圣骑士锤)。
- 真铜短剑是1.4.5新增物品，当前1.4.4工程先保留规划条目。参见[官方Wiki：真铜短剑](https://terraria.wiki.gg/zh/wiki/真铜短剑)。
- 原清单001至100编号与71项常规/29项非常规划分保留；新增101至103为3种常规木剑，因此总数更新为74项常规、29项非常规、共103项；松木剑方案已移除。

原始武器清单参考：[官方中文Terraria Wiki：武器](https://terraria.wiki.gg/zh/wiki/武器)。项目第一阶段范围见[第一阶段计划：史莱姆王与附着](第一阶段计划-史莱姆王与附着.md)。
