# 0.3.28 · 天顶魂域与传奇切换

日期：2026-10-21。继0.3.27六诅咒后，仅调整界面、剑库换装和可选世界难度，不改逐剑伤害、飞行、个人成长或17有效槽。

## 全屏魂域

- P或手持右键打开全屏独立空间，Esc或P关闭。星空分层漂移、鼠标轻微视差、透视地平线与原有剑环展开、逐槽点亮、呼吸流光、切页渐显共存。装饰动画不移动点击框。
- 左侧为随身剑库，只列出玩家真实背包前50格中可寄宿的近战武器，排除工具、堆叠消耗武器、天顶剑及剑魂自身。可以筛选尚未寄宿的种类，单独滚轮浏览。
- 中部保留十个普通环形剑位，右下五个支援和左上两个共享全收集奖励位。宽屏右侧显示选中剑位详情；较窄视口把详情放到剑环下面滚动查看。碎片导航统一放在顶部。
- 点击剑位仅选择，不再因鼠标经过另一个槽而改变目标。再点击左侧剑，就直接交换到选中剑位；原剑回到新剑腾出的真实背包格。
- “取下选中剑”将原物品归还背包空格，背包满则保留原状；可直接换另一把剑。旧物取回页也支持归还。鼠标持物时拒绝快捷换装，防止覆盖鼠标物品。
- 剑库没有额外存储，不复制物品，不增加剑魂有效槽。词缀、收藏及其他物品数据沿用原对象；装入调用现有`TrySwapHost`，因此锁槽、重复寄宿、支援限制和停用扩展规则均保留。
- 全屏时在输入阶段捕获整屏点击，底层原版背包和世界拿不到点击；关闭后持键仍捕获至松开。保留的旧窗口路径仍维持面板外原版背包可用。

## 原版传奇按钮

右上按钮开启原版大师难度和`Main.getGoodWorld`，同步世界文件元信息`ForTheWorthy`；使用原版规则，不额外乘Boss伤害或生命。会启用FTW的战斗及种子运行规则，不重新生成地图，不能补出FTW的生成地形。

首次开启保存原难度及FTW状态，再次点击准确恢复；恢复信息随本世界的模组数据保存，当前标记仍由原版世界数据持久化。已是原生传奇的世界不借按钮降级，旅途世界维持其原有难度滑块。Boss战及月总降临倒计时不能中途改基线。

本版按钮仅单人可用，联机显示明确原因，不允许客户端单方面改世界。它改变世界难度，因此也影响其他武器和后续生成的敌人，不是剑魂自身隐藏的伤害惩罚。
