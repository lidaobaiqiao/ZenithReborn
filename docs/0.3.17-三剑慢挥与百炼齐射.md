# 0.3.17 · 三剑慢挥与百炼齐射

2026-10-20用户最新决定替代旧五段规则；全收集登记与奖励已明确确认，不恢复旧25槽设计。

## 主剑

- 每次挥臂最多三把，按三个等分节点逐把实际生成，不足三把留空，下一轮继续遍历所有有效主攻剑；支援不独立出剑。
- 基础挥臂周期为来源平均间隔×2.5，45～150帧；原攻速加成保留，但实际最快45帧一轮，各节点至少相隔15帧。相比0.3.16整体放慢约三分之一。
- 主剑单圈飞行按来源间隔×2÷近战攻速，限制42～96帧；各剑单次伤害、8帧重击、独立来源、放大后的显示与碰撞分离保持。
- `SwordSpark`是独立16×16发光星点，沿剑尖及路径产生，拥有自己的漂移/衰减与局部照明；黑暗中仍有自身亮度，区别于曲面拖尾。粒子渐隐并在约半秒内消失，无全屏闪光或大型爆光圈。素材由`checks/make_sword_spark.py`确定性生成。

## 矿石飞剑

- 按当前有效材质生成实际寄宿剑外观；显示倍率从1.25提高到1.85，碰撞仍为20×20。
- 成形半径至少170像素，大目标按体积外移至最多360像素。每隔3帧显露下一把，每把前10帧膨胀到1.4倍，随后8帧回收到正常尺寸；最后一把准备好后再统一蓄力8帧。
- 成功生成的实体重新编号，统一等待`(数量－1)×3＋18＋8`帧，随后同时向原目标所在方向直线刺出。生成上限导致未出现的实体不进入等待人数。
- 冲刺10.5像素/帧，基础飞行560像素。碰撞敌怪不消失、不停止、不转向；穿透沿途全部合法敌怪，每把剑对每个敌怪以6帧局部免疫重复命中。子飞剑不再触发矿石/木质主剑机制，不递归生成新波。
- 成形期间原目标失效则取消；射出后原目标死亡不影响继续飞行。移除有效来源武器/材质、切换武器或玩家死亡仍会结束，最大行程与生存时间均受限。
- 剑面有移动高光、剑尖光泽、短拖尾/残影及独立发光粒子。所有细线显式采样1×1像素，避免重现整张像素贴图放大的光条问题。
- 原触发规则保留：每次主剑出剑仅首个有效命中尝试召唤；被30帧公共/60帧目标冷却挡住后不补触发。

## 全收集

- `OreCollectionMask`只在这枚已附着剑魂的有效主攻或有效支援里登记材质；同材质短剑/阔剑计一次。暂停槽、停用取回区和未附着预览不登记。
- 累计登记14种即获得百炼圆满，取下不丢。以后新生成的飞剑基础伤害公式额外×1.3，飞行距离560→840；当前寄宿几种仍只生成几种，不把图鉴中的所有历史武器自动变成战斗实体。
- 仍为10普通＋5木质支援＋2森林，绝不额外开槽。原先不可达的14材质同时装备、追加两次命中和扩槽方案由本版确认规则替换。
- 存档新增一个14位掩码，网络在原存储数据后追加一个整数；克隆、重铸与HERO重建均保留。多人两端需要相同版本；本版未进行真实多人测试。
- 旧档没有历史寄宿记录，只登记加载时当前有效寄宿的材质；以前取下的矿石需重新有效寄宿一次。不能以Boss全局击杀或旧扩展存储填满收集。
- 进度/尚缺材质在特性图鉴查看；奖励生效后进入生效特性页，物品悬浮提示仍只保留三行简述。
