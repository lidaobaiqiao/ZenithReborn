# 矿石族M2：肉后三矿

日期：2026-10-19。基线：ZenithReborn 0.3.5。范围为钴/钯金、秘银/山铜、精金/钛金三阶共六把剑。本页先整理可实现的首版机制与接入边界，数值为初案。

落实记录：用户已选择「直接实装六把剑」。本页六项单剑机制已在0.3.6实现，实际数值、边界与验证见[0.3.6实装说明](0.3.6-肉后三矿实装.md)。下文共享矿阶与全套奖励仍为候选，未启用；治疗、计数与来源说明以实装文档为准。

## 与基础八矿的关系

基础八矿的M1仍是设计稿，未实装。本批六把独立推进，不把M1的八材质满套门槛悄悄改成十四材质，也不把两批全部同时寄宿当作正常流程要求。

建议把肉后三矿分为三个矿阶，每阶有两种不同方向。普通寄宿时，各剑继续使用自身伤害、暴击、击退与独立特性；支援寄宿时只提供明确登记的机制，不贡献基础属性、不生成独立主剑。跨剑联动使用接受增益的那把剑自身伤害，不复制供能剑的伤害。

D为该次来源主剑的基础伤害快照，包含寄宿武器自身前缀、玩家加成与成长效能，不含本次暴击、目标防御和本次条件增伤。附属效果不再次乘成长效能，也不读取所有武器的平均伤害。

钴剑的D1旧候选是逐次缩短本剑出剑间隔；但当前统一五段动作无法直接给某一把主剑额外加发而不改变节点规则。M2改用一次受控的轻刃派生表现快淬，主剑发射顺序不变。其余五把沿用D1主题，补齐多次命中后的计数口径与来源归属。

## 多次命中与独立来源

- 主剑仍可每8帧再次命中同一敌人。特性的连击计数另设30帧合法计数间隔，不能把一次贴身飞行的高频命中当作多份无间隔充能。
- 计数和冷却按持有者、剑魂ID、特性种类与来源主剑种类分别记录，避免钴剑、山铜剑、钛金剑互相抢冷却。
- 支援特性借主剑命中触发时，按实际出剑的来源武器建立独立通道，附属伤害取该主剑的D；支援剑自己的高面板不反向灌入主剑。
- 连击记忆按同一敌人主体归组，180帧未合法命中清空。虫体多个部件不各自提供新的计数入口。
- 附属轻刃、花瓣、钛片不再次计数，不触发新的矿石特性或治疗，避免递归。
- 同目标多份导刃印应按来源保留，消费规则明确到来源通道；本次创建不能本次自吞。不得使用一个角色全局冷却代替各剑状态。

## 治疗与实体表现

钯金治疗建议接入统一的治疗预算：单次至多3生命，任意360帧内至多`max(1,min(8,ceil(最大生命×2%)))`；遵守原版吸血资源及禁疗，不从训练假人、友方或无敌目标获取治疗。该上限是新增预算规则，不能仅调用现有直接回血函数就声称完整实现。

轻刃、花瓣与钛片保留SoulId和来源武器类型，附属射弹由拥有者入口生成。需要补齐来源武器元数据，不能只靠SoulId把回流或计数挂给全部剑。

视觉继续使用各剑配色、柔和拖尾和少量粒子。只在实际触发时出现小型派生物，不添加全屏光环、爆闪，也不同时额外生成六把主剑。

## 羁绊与槽位建议

三阶羁绊建议按「第一阶至少一把、第二阶至少一把、第三阶至少一把」识别完整三阶，各阶可从对应两种剑中任选。这样只需三个有效槽位即可形成基本组合，适配肉后进度；同阶放两把时两条单剑机制分别存在，但不当作两个矿阶。

共享羁绊的具体收益及六把全套奖励另行定稿，不能在单剑机制尚未接通时提前给出已生效提示。本批首版优先保证六条单剑机制可见、可验证。

现有肉后五普通槽、机械三王后六普通槽的解锁路线保持。木系支援槽仍需木系条件，不因为加入肉后矿石而免费解锁。

## 接入清单

1. 新增六物品登记、特性说明和支援准入；当前0.3.5尚无这六条新机制，不能把基础寄宿当作实装。
2. 在主剑生成时记录来源武器；主命中后统一分发到矿石机制，条件增伤在对应命中修正入口处理。
3. 按来源处理计数、导刃印、回血额度和附属实体，确保切换装备、死亡和世界切换时清理临时状态。
4. 检查三种附属实体的真实生成和一次命中、重复命中的计数节流、两把不同剑冷却互不干扰、导刃印跨剑消费与单槽下一趟消费、治疗预算和禁疗。
5. 保留逐剑伤害、五段轮换、木系、成长槽位与存档回归。本页不能代替编译、打包和真实引擎检查结果。
