# 0.3.104：刀光周围空间扭曲

用户对103的评价为“仍旧没有做到玻璃质感，但也勉强能用”，要求追加扭曲空间的环境交互。因此103保留为暂可用的材质基准，不能记录为玻璃质感已获认可。本轮只增加邻近背景的空间偏折。

## 实现归属

- `SwordSpaceDistortion`负责空间交互参数和观察坐标映射。显式输入时钟、相机及观察矩阵，通过逆变换使扰动相位保持在世界坐标中；无效输入安全关闭偏移。
- `ZRSwordSpaceWarp.fxh`只计算刀光周围的压力与轻微回旋。以当前真实刀光的覆盖数据作两圈八向采样，空间位移随覆盖和生命周期减弱；不添加颜色，不生成另一张光带，不改动材质法线。
- `ZRGlassScreen`仍在原生当前帧屏幕合成中采背景，在刀光外侧按位移采样。刀光内部保留103已有折射和表面着色，额外偏移在成熟覆盖内部为0。没有新增场景快照、累积缓冲或渲染目标。
- `SoulSceneRefraction`只增加参数提交调用。`VfxIsolation.GlassParts`增加B7-7“刀光周围空间扭曲”，默认开启，仍受纯代码档的屏幕输入限制；现共57项，原56项保持全开。
- 强度、半径、速度继续由制作端`Glass/preset.json`统一生成常量：最大位移10屏幕像素、采样半径36屏幕像素、相位速度1.3。主体密度0.1、金属度0.25、粗糙度0及其余材质参数保持。

为维护Shader职责拆分，构建器只允许登记的自有`ZRSwordSpaceWarp.fxh`包含模块，拒绝未登记或间接包含；清单记录模块哈希，归属检查和安装器同时核对包内依赖。这不引入第三方资源或玩家运行依赖。

## 材质与局部交互检查

两项目原生构建零错误、零警告，自有Shader无编译警告，8444项引擎检查通过。最终68张实际GPU输出位于`artifacts/textured-sword-material/spatial-verified-0.3.104/`，包SHA256为`556171b985b7e386636c8d899a68ac374122901fbe9aed514d88008a8d402eb2`。

- 103的59张原有材质/高光/泛光/折射对照图在104中逐字节相同；原材质并未重制。
- 在生产网格覆盖和固定格线背景中，空间开关改变11094个像素，其中9712个位于刀光覆盖外；超过采样半径的改变为0。
- 不同时间相位改变6810个像素，具有动态响应。
- 纯色背景开关前后差异为0，确认只偏移采样而不染色或增亮；清空覆盖后开关差异也为0，确认没有残留。
- 坐标渐变背景的R/G最大变化为3/5量化级，符合10像素最大位移的检查范围。
- 刀光轮廓、连续UV朝向、剑色调色模块、ZRSwordFlow源码/编译结果以及35项图像/原始数据资产与103保持。证据见`source-audit-0.3.104.json`。

首轮`spatial-first-0.3.104`为观察矩阵映射修订前的检查，不能代替最终结果；最终报告以`spatial-verified-0.3.104`和汇总绑定的包为准。

## 世界、安装与边界

本轮世界检查同时重放同一帧的两种IOR，以及空间扭曲关闭/开启。只比较固定输入中的单一变化，空间偏折不冒充材质颜色变化。最终世界记录、安装与备份以本轮汇总和安装回执为准。

白天、深夜的正式组合完整世界检查通过，三剑命中、返回、独立收尾完成，结束余留为0。刀光外的空间偏折像素分别为27930和16378，范围外变化均为0。黄昏同帧对照通过，但世界夹具超时，未计完整通过；局部光源世界命中/返回/收尾及空间对照通过，IOR严格对照出现1个范围外像素G通道133→134，保留原失败结果，没有改阈值。后续一次串行启动未生成世界报告，也不计通过。用户随后明确要求“不要过度测试”，本轮立即停止复跑，以已完成的核心检查收尾，不称四种光照全部通过，不认定那1像素差异已修复。
