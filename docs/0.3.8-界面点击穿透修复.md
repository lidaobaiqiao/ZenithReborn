# 0.3.8 界面点击穿透修复

原因：寄宿面板绘制在原版背包后面才处理输入。到那时设置 mouseInterface 或取消 mouseLeftRelease，已经无法撤回底层背包/装备栏的操作。

现在在 PostUpdateInput 阶段捕获面板范围内的鼠标输入，原版界面与世界更新期间隐藏左右键及点击边沿，只有剑魂自己的前景层可以读取。绘制结束恢复物理按键状态，但不再把已消费的点击交给其他界面。空白、标题、禁用按钮同样拦截；在界面内按下后拖出或关闭界面，持续捕获到松开。

局部控制钩子同时阻止使用物品及右键世界交互，不限制移动。面板外的背包和装备栏保持正常操作。输入阶段把物理坐标换算为UI坐标；绘制阶段沿用引擎提供的UI坐标，避免二次缩放。

验证包含真实原版 ItemSlot 左/右键处理、剑魂槽位交换、按住不重复交换、关闭及拖出后不穿透、松开恢复、四档缩放与界面层顺序。图形验证与安装状态另记于 artifacts。

图形客户端实测通过：在被面板覆盖的背包区域左/右键点击，50格背包、装备与寄宿内容保持一致；面板外可取放金剑；页签切换和木剑寄宿交换正常；关闭后全部内容与基线一致，鼠标为空。记录：`artifacts/ui-validation-0.3.8.json`。联机未实测。
