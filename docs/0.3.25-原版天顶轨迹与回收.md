# 0.3.25 · 原版天顶轨迹与回收

用户明确要求原版天顶剑效果。删除0.3.22～24另行设计的12帧人物吸收、剑身缩小、向内汇聚粒子和人物背后独立收刀层。

## 本机原版依据

以已安装的tModLoader 2026.8.3.0 / Terraria 1.4.4.9为准。REA确认`tModLoader.dll`的SHA256为`fcc6a9624b12191be4a15d714a3675440911feb8c1d374642ab1fd686f0da0a5`，MVID为`033e87cd-cefe-4dc6-a1fb-e14aa938bbb2`。本机静态实现与引擎执行分别作为证据，不提交反编译文件。

- `Projectile.AI_182_FinalFractal`：阶段0～60绕行，轨道纵向半径受目标距离影响；60后轨迹停在原版终点并随人物移动，120结束。负曲线需要反转spriteDirection。
- `Main.DrawProj`：剑身可见度由0～20渐显、60～68渐隐决定；透明度另受AI的0～5和115～120阶段控制。不是朝人物核心移动或缩小。残影每15个历史阶段采样，各自按其历史阶段淡出。
- `SoulBlade`保留当前39～88帧的宿主绕行时长，将它映射为原版0～60阶段；完整尾迹存活至120，解决慢速宿主被旧timeLeft提前截断的问题。

## 保留与边界

当前挥臂攻速与每轮四把剑保持不变，17有效槽、逐剑独立伤害、首击矿石积攒、共享全收集奖励、特性、各剑配色与原有粒子保留。回收没有额外伤害。剑魂仍使用自身模型显示倍率、彩色网格拖尾和宿主节奏，并非把整个战斗系统替换为原版天顶剑，也不声称逐像素复刻原版着色器。

## 验证

`VanillaReturnCheck`逐帧实际调用安装程序集的原版AI作为对照，验证左右方向、正负曲线、50/240/800距离、正常/倒置重力、持续移动和慢速宿主下的位置、轴向、贴图翻转、透明度及完整寿命。执行原版方法的阶段归一化仅用于保持用户当前飞行速度；预期位置不复制剑魂公式。构建中同时确认旧吸收类已移除，并使用实际敌人命中路径确认尾迹阶段不额外伤害。

编译无警告、无错误；隔离引擎检查通过16579项，包含既有UI输入、槽位、存档、成长、逐剑伤害与矿石飞剑回归。本轮未进入图形客户端或真实多人，图像表现仍需游戏中观察。
