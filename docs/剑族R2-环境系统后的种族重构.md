# 剑族 R2 · 环境系统后的种族重构

> 0.3.54已接入灵能族成员元数据基础，见[基础层](0.3.54-灵能族基础层.md)；仅登记22项身份与查询接口，机制／数值／支援档位／收集奖励留空。本文其他新族与旧机制候选不因此获准实装；旧运行时BladeFamily与环境保持。

> 最新族构筑原则：用户明确武技1／2／4种，分别开放最高二档剑势、三档及增伤、整套不限族；三个档位都增加共用支援。四把武技必须能全放支援，让任意可寄宿主攻武器使用完整玩法。以后新族参照少量支援开放机制/通用化的结构；不自动重做现有木质矿石。具体各档支援格数未定，见[WJ2](武技族WJ2-三档剑势与天顶巨剑.md)。

> 武技机制最新方向由用户提出并确认属于武技族：[WJ2三档剑势](武技族WJ2-三档剑势与天顶巨剑.md)。基本天顶攻击积攒剑势；启动后使用背后旋转刺剑、巨剑打飞刺剑、时停突进与迟滞斩出等新攻击方式。本文旧剑势接力/主修副修设想不再作为武技要求，成员归属与其他新族仍是候选。WJ2尚未实装。

> 后续评审：用户否定了WJ1的玩法方向。七族与本表归属仍是候选，尤其武技族需要重审共同身份；不能将“准备开发”当成对WJ1机制的确认。先参考[玩家武器偏好调研](玩家武器偏好调研-2026-10-22.md)，未产生新机制定案。

日期：2026-10-22。设计依据：用户要求环境系统取代部分旧种族后重新设计。游戏基线仍为 **0.3.42**；本文是完整归属与共享机制的**新方案**，未修改运行时种族、战斗、存档或环境标签。新族名称、成员与机制方向可继续调整，尚未实装，也不代表所有参数已经获用户确认。

武技组已展开为[WJ1开发准备稿](武技族WJ1-剑势与招式开发准备.md)：首批十把常规剑的招式/传授、手动剑势、羁绊与十式收集奖励均有候选，并列出源码接入与验收边界。十三成员归属不变，仍未实装。

本表取代 D1 的十三族划分作为后续设计入口。已实装的木质族、矿石族规则保留。旧 D1 的单剑机制与数值属于历史候选，不能随本次重新分族自动恢复或叠加。

## 三个维度的职责

| 维度 | 决定什么 | 不承担什么 |
|---|---|---|
| 种族 | 武器的材质或玩法身份，以及多把武器怎样配合 | 不按获取地点再复制一套环境羁绊 |
| 环境 | 森林、雪原、地狱、腐化等来源标签及已实现的环境之力 | 不强迫武器退出原种族；不由当前所站地形反推武器标签 |
| 单剑特性 | 这把剑的招式、效果与独特用途 | 不因换了种族就抹去已有独有机制 |

一把剑在本方案中有一个主种族、零至多个环境标签和自己的独有特性。没有环境标签仍然可以有种族。种族只按下方逐剑名册登记，不通过贴图、物品名字、近战伤害类型或某一种原料自动推断。

例如：针叶木剑＝木质族＋雪原；冰雪刃＝灵能族＋雪原；村正＝武技族＋地牢；骨剑＝生体族＋地下层/洞穴层/地牢。属于同一环境不要求属于同一种族。

### 新族羁绊的统一设计原则

1. 先确定独立玩法，再确定档位；不能七族都变成同一套加伤、加速、送槽位。
2. 低阶武器应给后期机制增加可感知的用途，例如提供连携起手、能量通道、培养环节或功能组件。效果仍需适合自身阶段。
3. 木质、矿石现有档位、计数口径及收集奖励保持。新族不能自动借用矿石“累计十四材质”或木质“十二种同时寄宿”的条件。
4. 新族如有支援或奖励剑位，必须通过既有共用奖励源注册。数量、取重与领取条件单独设计；本表不自动为每个新族增加槽位，也不恢复任何固定总槽上限。
5. 重复同类剑不因物品实例不同反复增加收藏、成员或能量通道计数；主剑首击事件仍按真实来源位置识别，不能把剑型去重和逐发事件去重混为一谈。
6. 剑势、共鸣、培养等计数由主剑明确的有效命中事件推动；后续帧伤和衍生攻击不反复积攒、不递归。直接伤害与逐剑独立伤害模型保留。
7. 新族参与诅咒的方式需要接入既有有效特性视图。不能套用矿石特批的“前四把例外”来擅自绕过切换诅咒，也不能削减正常直接伤害或已开放结构槽位。
8. 传承不默认复制原武器所有原生射弹、父代全部特性或父代种族奖励；合成链成员仍各只有一个主族。传承记录不能凭世界 Boss 进度伪造。

## 归属边界与容易混淆的武器

- **矿石族保持现有二十二把**。魔光剑、血腥屠刀、火山、叶绿两剑、陨石光剑等按本表的玩法身份归类，不仅凭配方里有矿锭就扩充矿族。以后若扩充矿材，应单独设计，不能无提示把现有十四材质全收集改成十八材质。
- **血腥屠刀归武技**：本方案突出重刃斩击；猩红身份由环境表达。不是要求它取消流血类独有特性。
- **叶绿两剑归生体**：突出生命金属的培养与生长主题；不自动加入矿石飞剑材质表。
- **村正归武技、骨剑归生体、光束剑归灵能**：三者的地牢来源不再把它们强行放进同一族。
- **阴森木剑继续归木质**，不因魂体主题改族；圣诞树剑与彩虹猫之刃归奇巧，按各自奇异造物的玩法身份设计，不按外观推断木质/生体计数。
- **永夜刃、真永夜刃不再归腐化族**；两条主线最终汇于泰拉刃，统一归传承。它们的环境标签仍读取实际已有登记，本次不推算或补写合成材料环境。
- **同族不要求同一种环境**。灵能族包含冰、火、星光、幽魂等剑，共同机制是共鸣而不是“寒冷/火焰增伤”；不同招式继续留在单剑上。

## 实施顺序

1. 先讨论并定下本次成员与族机制方向，然后建立独立的 `SwordRace` 元数据及逐武器登记。不要把旧 `BladeFamily` 枚举改名后直接当成种族，以免改变现有命中、粒子与速度兼容行为。
2. 元数据阶段让木质、矿石登记与现有 `WoodTypes`、`OreFamily` 一致，其他新族可以先展示身份与“羁绊待实现”，不能展示虚构生效数值。
3. 新族优先从**武技族**开始，先落地剑势与一组前中后期代表剑，确认其价值，再按本表补齐。灵能族随后可利用已有剑气、落星与源身份设施。
4. 每族机制定案后再确定支援贡献、全收集奖励、支援是否能施加/消费对应族机制及与现有祝福的结算顺序。UI 的激活列表只展示实际生效项，完整内容放入特性图鉴。
5. 单剑已有冰火、毒、木剑、肉后矿剑等实现逐项迁移，不先删除再等重写。防止旧 `BladeFamily` 基础效果与新族/新单剑重复执行。
