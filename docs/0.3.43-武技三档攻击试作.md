# 0.3.43 · 武技三档攻击试作

日期：2026-10-22。由“天顶剑魂”对话实现，0.3.44接续特效与交付。用户本轮要求先实现攻击方式，其他细节暂缓；因此这是可关闭的攻击原型，不能宣称WJ2整族设计已经完成。

## 已实现的攻击流程

- 普通主剑首次有效命中积攒剑势，同一发主剑后续帧伤不补充，衍生攻击不递归充能。剑势随SoulItem保存，满条不自动启动。
- G启动或取消，V切换选档。仅在模组按键未绑定时使用G/V回退，采用按键边沿；玩家自定义绑定优先。
- 一档：玩家背后形成旋转飞剑，随后刺出，刺入敌怪后留存并持续伤害。
- 二档：先释放飞剑，再形成巨剑；等待飞剑命中或完成飞行后重斩，打飞已刺入的剑，然后回到普通攻击。
- 三档：巨剑就绪后再次攻击发动局部时停、玩家本体突进、多段伤害、约两秒迟滞、末斩与跟随剑气/剑痕。迟滞锁定实际突进落点，取消及结束后恢复敌怪和敌方弹幕运动。

服务器配置 `MartialConfig.EnableAttackPrototype` 默认开启，暂向已附着剑魂开放全三档。关闭即恢复普通攻击。试作参数集中在 `MartialTuning`，包括每档100、上限300、主剑首次命中30等；这些是本轮试作值，不是用户已经定案的最终数值。1／2／4羁绊、各档支援格数、纯支援容量和增伤比例仍未接入，不得用此开关冒充已兑现四把纯支援要求。
