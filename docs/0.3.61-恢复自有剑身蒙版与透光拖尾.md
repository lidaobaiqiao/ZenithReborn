# 0.3.61 恢复自有剑身蒙版与透光拖尾

## 纠正误删

用户指出原来的飞剑效果并不依赖旧着色器。复查确认：矿石飞剑的H4剑身一体组是项目生成的动态蒙版和普通SpriteBatch合成，没有调用OniCrimsonSlash；它只在慢底色中读取借用的NoiseSoft01。0.3.60将图片依赖误归为着色器依赖，删除整个VfxSwordMask及调用，超出了应删除的范围。

本轮恢复VfxSwordMask、矿石飞剑PreDraw内的速度驱动以及结束漂移，21套蒙版、颜色参数、帧插值、尺寸和慢滚动速度与0.3.59保持一致。只将借用噪声换成SwordBodyColorNoise：项目自行用周期格点值噪声生成512×512灰度纹理，不读取图片或第三方着色器。纯灰度只影响底色明暗，颜色仍取每把剑自己的参数。该运行时纹理由项目拥有并在卸载时释放。

原有丢弃型绘制目标的延后合成和窗口缓冲像素保留逻辑一并恢复，避免准备阶段清掉其他绘制者的场景。此保护仍不代表用户曾报告的超级训练假人黑屏已修复。

真正依赖旧着色器的厚月牙主体、额外直刃／出鞘／天铸／附属剑片光带继续保持移除；没有恢复旧适配器、旧编译文件或两张素材。当前唯一打包的非原版着色器仍为自有ZRSwordFlow。

## 天顶飞剑的透光玻璃候选

用户进一步指出当前攻击像液化，希望增加透明玻璃质感。本轮只调整主飞剑自有材质和视觉网格，不改变实际攻击方式。

- 轮廓伸缩幅度由10%降至2.5%，时间变化放慢，减少材质整体扭动。
- 降低主体覆盖，保留薄而透光的颜色面；收窄亮刃，增加细薄的内缘与缓慢掠过的斜向反光。
- 减弱面内流丝和大幅边缘波动，保留逐剑颜色、动态蒙版与返回侵蚀；仍是同一个材质的一次绘制。
- 这里是透明度与反光模拟的玻璃观感，没有屏幕空间折射，也没有新增场景采样或后处理依赖。当前结果是美术候选，等待用户亲自判断。
