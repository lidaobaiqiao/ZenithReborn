# 0.3.129：木质族V2与复合羁绊

## 概述

按用户设计文档《天顶剑魂·木质族系统规划 V2》重做木质族：名册由 12 收窄为 8 把原版木剑，删除四个旧特性，森林之力重构为分层衰减体系，新增四条复合羁绊与圣林归冠终局形态，并引入 CrownHosts 双真实剑位。已编译打包并安装；**按用户指示跳过回归验证与夹具更新**。

## 改动明细

1. **名册 12→8**：仅保留原版木剑——木/针叶木/棕榈木/红木/乌木/暗影木/灰烬木/珍珠木，`Full=0xFF`。王朝/阴森/仙灵剑退出名册（ModItem 类保留以兼容旧档，不可再获取）；仙人掌剑退族，落入 Swift 族。
2. **五阶段**：门槛 `[1,2,4,6,8]`，S=1.10/1.20/1.35/1.50/2.00，生命 +5/10/15/25/40；支援槽门槛不变。
3. **删除四特性**：裂伤、御令、悼魂、孢光。
4. **森林之力重构**（新文件 `ForestPower.cs`）：8 木 Full 激活；基础 6 层，每层 300 帧——伤 2%/速 1%/防 2/回 0.3/DoT 3%/减伤 0.5pp；脱战 300 帧后每 120 帧 -1 层。圣林之冠时 12 层（3%/2%/3/0.5/5%/1pp）；失冠钳 6；失 8 木/死亡/换魂清零。
5. **复合羁绊**（新文件 `WoodBondCore/Forge/Rot/Ember.cs`、`WoodCrown.cs`）：
   - 锻根共生：≥4 木 + 棕榈 + 铜/铁阔剑；锻芽 3 层补斩 30%D、90 帧冷却。
   - 腐林凋蚀：≥6 木 + 红木/乌木 + 魔光/永夜刃；提前结算 DoT 预算 25%、上限 50%D、180 帧。
   - 灰烬繁生：≥6 木 + 红木/灰烬 + 火山 FieryGreatsword；64px 爆发 30%D、最多 3 敌、180 帧。
   - 圣林归冠：8 木 + 泰拉刃（非圣林槽）；S=3.0/生命 100/12 层/2 真实剑位。
   - 直伤统一走 `NPC.HitInfo`，服务端权威。
6. **槽位**：新增 CrownHosts 35/36——真实普通剑位，防自举（不参与归冠判定），失效时保留物品。ForestHosts(15/16) 改为仅矿石全收集。支援编号跳过 34/35/36。
