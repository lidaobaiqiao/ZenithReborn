# 0.3.1：全部槽位解锁与友善史莱姆王

## 第一步：见到友善史莱姆王

新角色开局附带「诅咒的天顶残魂」和「凝胶信物」。旧角色可以在工作台用凝胶10＋坠落之星1制作信物；信物不消耗。

白天来到地表，背包带着剑魂，使用凝胶信物即可呼唤友善史莱姆王，附近不需要普通史莱姆。右键点击它，逐段「继续聆听」，最后选择「接受祝福：附着」，第一普通剑位就能攻击。也保留原来的入口：白天地表靠近普通史莱姆，按P→回应呼唤。

这位史莱姆王属于独立友善NPC，不攻击、不可误杀、不掉敌对Boss战利品、不修改原版史莱姆王击杀旗标。它会在授福后停留片刻再离开；再次使用信物可以请它回来查看成长路线。正常敌对史莱姆王保持原样。

## 十个普通剑位

普通槽按下面顺序解锁，所有前置槽的铭刻和魂芯也须完成。击败记录属于每枚剑魂：需要用这枚剑魂的主剑、附属剑气或自有持续伤害参与战斗，世界已击败Boss不会自动替你填充记录。

| 普通槽 | 本阶段胜利铭刻 | 本阶段魂芯操作 |
|---:|---|---|
| 1 | 友善史莱姆王对话授福 | 接受「附着」，不需要魂芯 |
| 2 | 克苏鲁之眼 | 融入初光魂芯 |
| 3 | 世界吞噬怪或克苏鲁之脑，二选一 | 沿用初光魂芯，不需要新魂芯 |
| 4 | 骷髅王 | 沿用初光魂芯，不需要新魂芯 |
| 5 | 血肉墙 | 融入血肉魂芯 |
| 6 | 毁灭者、机械骷髅王、双子魔眼两只全部铭刻 | 融入机魂魂芯 |
| 7 | 世纪之花 | 融入生息魂芯 |
| 8 | 石巨人 | 融入神庙魂芯 |
| 9 | 拜月教邪教徒 | 沿用神庙魂芯，不需要新魂芯 |
| 10 | 月亮领主 | 融入天界魂芯 |

击败后拾取并使用对应魂芯。多枚剑魂并存时，魂芯优先融入当前打开寄宿界面的合格剑魂；没有对应胜利铭刻的剑魂不能接受该魂芯。

按P→「成长路线 / 补办魂芯」可查看完整路线与下一步。若已完成对应胜利却遗失魂芯，路线页可以补办并融入；背包有对应魂芯则先消耗一枚，没有则凭本剑魂已有铭刻重新凝聚，不需要重打一遍Boss，也不能跳过尚未赢得的战斗。

十槽全部解锁后，基础普通槽同时寄宿十把天顶材料剑即可完成永久复生；完成后可自由换装。六枚魂芯由上述路线全部集齐，复生不再要求一直保留材料剑配置。

## 支援与森林奖励

| 剑位 | 解锁条件 | 生效方式 |
|---|---|---|
| 支援1 | 1种有效木剑 | 特性和种族计数，不独立出主剑 |
| 支援2 | 2种有效木剑 | 同上 |
| 支援3 | 4种有效木剑 | 同上 |
| 支援4 | 6种有效木剑 | 同上 |
| 支援5 | 8种有效木剑 | 同上 |
| 森林奖励1、2 | 12种木剑同时寄宿于基础普通槽与有效支援槽 | 两个真实普通剑位，正常提供属性并出剑 |

已开启的支援槽可继续放入不同木剑推动羁绊。完整木套需要至少7个基础普通槽＋5个支援槽，因此最早在完成世纪之花与生息魂芯、同时取得全部木剑材料后开启；阴森木剑仍需要南瓜月阴森木。森林奖励槽不能反过来凑齐自己的解锁条件。

鼠标悬停各格会显示对应条件。支援或森林条件失去后，对应槽暂停，武器原位保留，用空鼠标可取回。
