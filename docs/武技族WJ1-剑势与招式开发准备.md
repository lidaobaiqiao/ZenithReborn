## 定位

武技族让玩家从武器中学到招式，凭战斗积攒剑势，然后主动选择时机施展。每把剑兼具自己的完整招式与一条传授效果；传授能修饰其他剑的招式，让罗马短剑等前期武器在后期仍有用途。

现有切换祝福已经有“不同主剑首击接力、强化后续特性”的被动机制。武技组的区别在于：**积攒可保留的剑势 → 玩家手动准备施展 → 实际命中时执行所选招式 → 多把武器的传授改变这次招式。** 不再重复实现一套“连续命中就给全局增伤”的祝福。

## 三层结构

| 层次 | 内容 | 生效来源 |
|---|---|---|
| 族共享 | 剑势、手动施展、招式连携与羁绊档位 | 当前实际生效的武技成员 |
| 单剑招式 | 如三叠刺、居合、回舞、崩山 | 选择当前有效主攻或支援中的对应武技剑作为主修 |
| 单剑传授 | 如追加短刺、补斩、扩大招式判定、利用破绽 | 当前特性有效的武技成员提供；同类型只取一次 |

“已收藏”允许保留收集进度，但不代表取下武器后仍能无限使用其招式、传授或当前羁绊。背包中的剑也不会自动成为可用招式。

### 支援与逐剑伤害

- 支援中的武技剑可以提供可选招式与传授，不发出独立主剑，不贡献自身面板或一次独立蓄势事件。
- 施展时，伤害 D 来自**真正触发施展的那把主剑**的伤害快照。若用支援中的罗马短剑教授三叠刺、用主攻泰拉刃命中施展，招式按该次泰拉主剑的 D 计算。
- 普通主剑仍各自使用自己的伤害。不能将所有剑的伤害求和、取平均、挑最大值，也不恢复统一天顶伤害下限或按剑数分摊。
- D 已包括主剑生成时既有武器、词缀、玩家与成长修正。不得用 `damageDone` 或已经暴击后的数值代替 D，再乘一轮装备与成长。
- 招式登记仍保留实际教授武器与触发主剑两种身份。不要把教授武器覆盖写进 `SoulSource.SourceWeapon`，以免环境、矿石和祝福错误识别父剑。

## 剑势与手动施展候选

| 项目 | 首版建议 |
|---|---|
| 容量 | 100剑势，同一枚剑魂独立保存 |
| 基础获取 | 有至少一种战斗特性有效的武技招式时，任意允许参与特性的主剑首次有效命中＋20 |
| 二层接力 | 两种武技后，相邻有效蓄势事件的真实主剑类型不同时，额外＋10；不限必须同一目标，不要求两把都属于武技 |
| 满势 | 保留，不自行衰减，不自动释放 |
| 手动入口 | 新增独立“施展武技”按键，建议默认G，允许玩家重新绑定；不占用御剑O键、攻击键或打开魂域的操作 |
| 按键行为 | 满势时进入“待施展”；再按一次可以取消准备。准备和取消都不扣剑势，不改变主剑轮转 |
| 真正消耗 | 待施展后下一把符合普通特性规则的主剑，首次对有效敌人造成伤害时扣100并施展所选主修招式 |
| 空挥与停手 | 没命中不消耗；不会向空处自动扔出整套招式。等待期间剑势保持 |
| 充能与施展顺序 | 一个主剑首击事件先判断施展，成功则本事件不再蓄势；未施展才蓄势。本事件由未满充到满时，不顺带自动施展 |
| 切换武器/打开魂域 | 取消待施展，已积攒剑势保留；编辑期间暂停施展 |
| 死亡/退出世界 | 清理待施展和派生队列，未花费剑势仍由剑魂保留 |

选主修的剑被取下、暂停或受诅咒限制时，保留选择用于显示，但本次准备失效并提示原因，不悄悄改成另一招，也不扣剑势。正在执行的招式保留开始时的快照；切换武器、移除必要来源或玩家死亡时按明确的有效性规则停止剩余派生，不退款重刷已经执行的伤害。

普通攻击、御剑充能和武技充能是不同机制；武技不消耗御剑条，御剑也不自动触发武技。默认G是本次建议，不是用户已经指定的键位。

## 羁绊候选：1 / 2 / 4 / 6 / 8 / 10

结构计数和战斗特性分开：结构计数取当前真正开放的主攻/支援中的不同首批武技类型，停用及旧取回槽不算；实际招式、传授与充能还必须通过切换诅咒的普通特性过滤。传奇及已开放奖励主槽作为真实主攻计入，但不能反向用尚未开放的槽解锁自身。

| 当前不同武技数 | 名称 | 新增机制候选 |
|---:|---|---|
| 1 | 习武 | 解锁剑势、主修选择与手动招式；已激活传授先作用于武技主剑施展的招式 |
| 2 | 合招 | 不同主剑首击接力额外＋10剑势；贡献1个共用支援位 |
| 4 | 贯通 | 传授可完整修饰任意职业身份的有效主攻剑所施展的武技招式，不再要求触发主剑属于武技族；不是把它改族 |
| 6 | 变招 | 可选择不同类型的副修招式，主修完成后以50%基础招式伤害接出副修；再贡献1个共用支援位 |
| 8 | 通势 | 每次普通有效蓄势提高到25，二层接力仍额外＋10；传授表中可缩放的数值效果提高50%，数量、条件和次数不跟随放大 |
| 10 | 宗师 | 副修基础伤害由50%提高到100%，替代原50%；再贡献1个共用支援位 |

候选支援奖励源为 `martial`，阈值 `[2,6,10]`，最多贡献3格，加入既有动态共用池。不是建立三个武技专属槽；槽位位置、编号、旧物取回、传奇34号保护继续遵循原有规则。当前代码尚未注册这个奖励源。

主修、副修必须在当前特性有效的成员中，副修不能和主修是同类型。只选主修也能正常施展，不强迫玩家每次填满两个选择。主修和副修组成同一次施展，传授按整次施展应用：固定次数的附加短刺、补斩、追击只触发一组，不能副修再复制一整组。

四层前，非武技主剑已经可以借主修招式施展，但其施展不附加传授。四层解除这个传授范围限制。主修本体与传授分清来源，不能因为没有武技主剑就让支援教授的招式无法使用。

表中 D 为实际触发主剑快照；数值均为调参起点。传授只影响这枚剑魂本次主动施展的武技，不默认影响普通帧伤、百炼飞剑、环境弹幕或全部玩家武器。

| 武士刀 | 居合 | 12帧收束后沿瞄准方向一道3.5D窄长斩 | **凝锋**：主修第一段基础伤害＋25%；仅一段，不把所有后续段都当首段；起手有明显凝光反馈 |
| 村正 | 乱刃 | 在命中区域交错五段蓝色斩击，每段0.65D，段间4帧 | **连式**：完整主修结束追加一次0.6D蓝色补斩；不改变原版主剑攻速 |

| 血腥屠刀 | 开创 | 一道3D重斩，随后留下4秒裂伤，每秒0.15D | **创口**：施展命中的敌人主体留下4秒创口，使本枚剑魂后续主剑直接命中伤害＋10%；不提高自有DoT或其他玩家伤害 |
| 猎鹰刃 | 追隙 | 目标附近三次1.1D追击；可追随目标正常移动，不瞬移玩家 | **追隙**：原目标死亡后，未执行招式可在其最后位置240像素内接续到最近有效敌人；正常存活时不擅自换目标 |
| 毁灭刃 | 崩山 | 一道4D宽重斩，视觉宽度与判定一致 | **重势**：主修与副修的招式判定宽度提高30%；不放大普通主剑贴图、轨迹或所有射弹 |
| 短弯刀 | 登舷 | 三道依次向前推进的0.95D斩线，形成区域推进而非瞬移 | **乘胜**：本次施展击杀实际敌人返还10剑势，整次最多返还20；虫体节段按主体，不从假人或召唤刷怪反复回势 |
| 变态人的刀 | 伏杀 | 18帧残影预兆后，在选定区域连续四刀，每刀0.85D | **终结**：主修最后一段命中当前生命低于50%的敌人时，该段伤害＋50%；不按最大生命扣血、不直接处决 |
| 钥匙剑 | 解势 | 一道3D贯穿斩，命中后显出短暂开锁式裂纹 | **解势**：本次施展命中后挂4秒解势印，后续本枚剑魂主剑对该主体穿甲＋8；同来源重复刷新不叠层 |

### 传授应用细则

- 有效主攻中的武技剑同样提供传授，不需要再复制一把进支援。主攻与支援同类型仅提供一次。
- 基础招式伤害、传授追加段、裂伤、主剑后续收益分别标记。凝锋和终结只修饰主修本体的相应段，不能追着新生成的追加短刺/补斩无限再修饰。
- 八层的1.5倍只提高表中传授的比例/固定数值，例如凝锋25%→37.5%、创口10%→15%、重势30%→45%、补斩0.6D→0.9D、穿甲8→12。两次短刺仍两次，持续4秒仍4秒，血线50%仍50%，乘胜返还与20上限不跟随放大。
- 猎鹰的240像素接续距离不受八层扩大；原目标正常移动时使用招式既有操控范围，不借追隙无限跨屏追踪。
- 主修、副修各自的每段有独立命中记录，多段招式允许明确的重复命中。一个斩段即使在同帧扫到虫体多个节，也只对其主体结算一次。
- 创口与解势属于本武技实例拥有的印记，不改敌人基础防御、全局减伤，不覆盖环境或其他模组的同名减益。裂伤按本枚剑魂和目标主体保留一份预算，刷新而不无限叠层。
- 裂伤需按目标对既定减益类别的免疫处理，免疫不影响基础重斩，也不强迫Boss失去原有免疫。具体采用原版哪一类持续伤害/免疫标志在实现时明确，不能在说明里承诺“无视所有免疫”。
- 创口/解势用于后续普通主剑的各次实际直接命中；是否为帧伤不影响享受已挂印记，但后续帧伤不会再次产势、再次施展或生成新印记事件。

## 本期收集奖励候选：十式通晓

收集范围是十把已计划实现的常规剑，累计记录这枚剑魂实际有效寄宿过的武器类型。取下保留进度，暂停槽、背包预览、未附着状态不登记；不凭当前世界已击败Boss、打开图鉴或物品名称伪造记录。

| 奖励 | 候选行为 |
|---|---|
| 十式通晓 | 永久保留这一收集成就；不把其余已取下剑的传授常驻化 |
| 共用奖励剑位 | 作为新的收集奖励源，解锁既有R1/R2两格；与木质、矿石共用同一组，不新增第三第四格 |
| 宗师终式 | 有当前有效武技并成功施展时，累计三次主动施展，在第三次整套招式结束后追加一记6D终式；D沿用第三次施展真正触发主剑的快照 |

终式不递归、每主体一次、不触发新的武技/矿石/祝福首击计数。不自动解锁十三项全收集，也不为后三件未适配武器展示完成。玩家失去当前有效武技时不能靠收藏成就在空配置中施展招式；两格奖励的长期保留与矿石累计收集采用同一类成就来源。

三次计数属于临时战斗状态，取下剑魂、死亡或退出世界清除；收藏成就、未花费剑势与选择仍保留。终式不得因为虫体多个节、多人各自命中或主副修各算一次而提前触发。

## 反馈与交互准备

- 沿用现有魂域，在特性图鉴的武技分类中选择主修/副修；十把剑显示简短招式卡，未拥有或当前暂停的条目解释不可选原因。
- 战斗HUD显示一条紧凑剑势条与所选招式名，区别于御剑条；满条静态呼吸，按键准备后明显显示“待施展”，不会靠刷聊天提示状态。
- 普通物品悬停仅补“武技族·招式名”和一行传授摘要。详细系数、条件、收集缺项放图鉴，激活信息只列实际生效项。
- 主修开始时一次短促起手动作，按招式使用窄斩线、弧面拖尾、残影和少量剑尖粒子；终式增加明显的收束/落斩识别。不要复用环境的巨大圆环或满屏放射。
- 原版天顶主剑继续按当前速度、模型、配色、轨迹与逐把释放规则飞行。武技斩段是独立派生，不改挥臂时长或夺取玩家移动。
- 所有使用 `MagicPixel` 的绘制显式裁剪 `new Rectangle(0,0,1,1)`，不传整张1×1000纹理去做像素线缩放。

| `MartialArts` / `MartialStrike` | 按招式配置生成斩段、传授补斩与终式；保存触发主剑和教授武器两种身份，不从子弹幕回调主剑积攒 |
| `SoulSupport` / 收集奖励源 | 将 `[2,6,10]` 接入共用支援贡献；将十式通晓接入共用奖励来源，避免第三个种族继续复制wood/ore条件分支 |
| `SoulTraits` / 魂域 | 新增实际武技状态、图鉴条目和主副修选择；仍在底层输入前拦截点击，保留鼠标绘制层 |

当前 `SoulSource` 的环境首击标记是独立私有状态；`BladeBlessings` 的首击按目标主体记录。武技需要自己的**每个真实发射主剑最多一次**的蓄势/施展消费标记，不能借用上述标记相互抢事件，也不能因切换目标而再消费同一发射实例。

建议事件键至少包含 owner、SoulId、真实发射实例、实际HostSlot与SourceWeapon。收到事件时重新验证该位置当前仍是同一有效来源；不能只用武器类型或一个全魂10帧冷却去替代逐剑事件。神吞等虫体目标以Root归组；同帧不同剑分别正常蓄势，只有排在先、真正消费待施展状态的那次事件启动一次整套招式。

### 诅咒与祝福的结算

1. 切换未解除：只按既有普通特性来源执行武技。首把是武技剑可以单剑积攒/施展；其余主剑保留独立直接伤害。矿石前四把例外不扩大到武技。
2. 独行、归鞘、断锋与穿墙限制继续决定主剑实际能否命中。武技不额外召普通主剑，不延长已经被归鞘提前停止的主剑伤害期。
3. 现有 `Blessings.TraitPower` 若要强化武技，只在施展开始时取一次快照，乘到规定的基础招式伤害；传授数值、剑势获取、终式次数不再重复乘。首版候选是基础招式与伤害型传授追加段各用同一快照一次。
4. 环境的现有通用伤害、距离祝福等继续走实际派生来源的共同管线，生成时不要先手工乘入、命中时再乘。派生可享受现有允许的通用效果，但不能作为主剑再次启动环境首击机制、矿石飞剑或武技。
5. 旧的迅刃/实锋等兼容能力保持。新增“武技族”标签不自动移除泰拉魔刃/Arkhalis的旧行为，也不把D1那条整族加速15%/缩距15%重新带回来。

### 持久与多人

实际开始实现时再确定新保存版本；这份准备稿不把当前版本8写成9。新增字段缺失的旧档从零武技收藏/零剑势开始，然后只登记实际有效寄宿成员；不影响已有环境、御剑、矿石、封印和槽内容。

主副修用稳定招式ID，不保存本次加载的临时运行物品数字ID。未知ID保留/归零策略需明确；读取时限制合法剑势、合法收集位和可选招式，不接收任意数值。

多人实现需要单一派生生成权威；施展、消费与逐剑事件由服务器验证真实来源，不能信任客户端上报的伤害、剑势、完成收藏或任意教授武器。客户端与服务器不能各生成一遍同样的斩段。图鉴选择、满势及待施展反馈需要同步；源码和离线序列化检查不等于真实多人实测。

## 建议开发顺序与验收

1. **登记和基础循环**：确认十成员与ItemID，独立种族登记，剑势保存、选择主修、手动准备、空挥不消耗。先用三叠刺打通来源与伤害，不先堆十种粒子。
2. **首批十招与传授**：共用斩段调度实现直线/交错/圆弧/追击，填十条配置，明确主副修和传授一次范围。
3. **结构与收藏奖励**：动态共用支援贡献、十式累计记录、共享R1/R2奖励源和宗师终式；检查不能靠暂停槽自举解锁。
4. **UI与视觉**：复用魂域选招、战斗剑势条、短描述和特性图鉴，验证鼠标、不同分辨率与动画。
5. **构建和适量验证后打包**：只替换目标模组，正式档备份，运行时被锁先准备包等待正常退出。引擎、实际图形和真实多人分别记录验证边界。

| 验收场景 | 必须成立 |
|---|---|
| 同一主剑后续帧伤、同一发射扫过多个目标 | 只产一次剑势；不能重复消费待施展 |
| 同帧不同主剑首击 | 各自产势，至多一组消费成功；不恢复共用冷却 |
| 满条空挥、取消准备、换武器、打开魂域 | 未成功施展前不扣条、不自动释放 |
| 主攻/支援/暂停/传奇/奖励位置 | 只从真正有效位置取成员和来源；传奇34号不能当新支援编号 |
| 低伤支援教授＋高伤主剑触发 | 取实际主剑D，保留教授身份，不用支援面板或全剑平均 |
| 主修＋副修＋全部传授 | 副修倍率正确，整次固定次数追加段不复制；子效果不递归 |
| 切换诅咒未解、解除、祝福 | 普通武技遵守原限制，解除恢复正常；祝福只在施展快照取一次 |
| 虫体/假人/友方/雕像/零伤害 | 按主体结算；不能靠节段重复计数或无效来源刷收藏/剑势/返还 |
| 重铸、HERO、克隆、存读与网络 | 收藏和未花费剑势不丢，旧环境/御剑/矿材/封印与所有槽原样保留 |
| 光效与战斗画面 | 没有满屏色带，斩线与判定一致；保持当前主剑速度和模型 |
